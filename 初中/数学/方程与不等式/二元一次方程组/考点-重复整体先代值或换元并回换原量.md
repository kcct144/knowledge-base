## 讲解

### 判据

两式都含同一和差块，先看某式能否直接定块值；系数结构对称时设块为新元。题只求某个差或目标组合时，选择两式的和差可能直接得到目标，不必先求每个变量。

### 流程

1. 圈出完全一致的重复块，确认符号、分母与范围相同。
2. 单式定整体值后代另一式，或设辅助变量转换成更简单组。
3. 选择加减消掉不求的部分，写出每个系数与常数的变化。
4. 新变量求出后按定义回换，题求原x、y则继续解回换组。
5. 给定所求差的值时把它与所得表达相等求参数，再回验原组。

## 例题

### 重复整体x加y先由一式定值

> 来源ID Q08-15；第8章二元一次方程（组）；101-150/full.md 第28–32行。原答案与解析定位：101-150/full.md 第34–42行。

例4 解二元一次方程组：$\left\{\begin{aligned}(9/5)(x+y)&=18,\\ (2/3)x+(3/2)(x+y)&=18.\end{aligned}\right.$

**原资料答案与解析：**

解析 由①得 $x + y = 10$ ③

将③代入②, 得 $\frac{2}{3}x+\frac{3}{2}\times10=18$ ,

解得 $x=\frac{9}{2}$ ，把 $x=\frac{9}{2}$ 代入③，

得 $\frac{9}{2}+y=10$ , 解得 $y=\frac{11}{2}$ .

所以原方程组的解为 $\left\{\begin{aligned}x&=\frac{9}{2},\\ y&=\frac{11}{2}.\end{aligned}\right.$

**展开解析（依据原详解补足理由与步骤）：**

第一式(9/5)(x+y)=18，两边乘5/9得x+y=10。第二式将整个x+y替换成10，得(2/3)x+15=18；两边减15得(2/3)x=3，乘3/2得x=9/2。回代x+y=10，y=10−9/2=11/2。两数和10，第一式18；第二式3+15=18。原提取把18写成1 8以及方程编号只挂在整组，正文按原解与版面恢复数值，编号不作新增条件。

### 换元解后回到原变量的两层求解

> 来源ID Q08-20；第8章二元一次方程（组）；101-150/full.md 第102–104行。原答案与解析定位：101-150/full.md 第106–108行。

例5 乐乐同学在解方程组 $\left\{ \begin{array}{l}3(m + 5) - 2(n + 3) = -1,\\ 3(m + 5) + 2(n + 3) = 7 \end{array} \right.$ 时，采用了换元法.她把 $m + 5,n + 3$ 分别看成一个整体，设 $m + 5 = x,n + 3 = y$ ，则原方程组可化为 $\left\{ \begin{array}{l}3x - 2y = -1,\\ 3x + 2y = 7, \end{array} \right.$ 解得 $\left\{ \begin{array}{l}x = 1,\\ y = 2, \end{array} \right.$ 即 $\left\{ \begin{array}{l}m + 5 = 1,\\ n + 3 = 2. \end{array} \right.$ 解得 $\left\{ \begin{array}{l}m = -4,\\ n = -1. \end{array} \right.$

请你仿照乐乐同学的方法,解方程组 $\left\{\begin{aligned}\frac{x+y}{3}+\frac{x-y}{5}&=4,\\ \frac{x+y}{3}-\frac{x-y}{5}&=-2.\end{aligned}\right.$

**原资料答案与解析：**

解析 令 $m = \frac{x + y}{3}, n = \frac{x - y}{5}$ , 则原方程组可化为 $\left\{ \begin{array}{l} m + n = 4, \\ m - n = -2, \end{array} \right.$ 解得 $\left\{ \begin{array}{l} m = 1, \\ n = 3. \end{array} \right.$

$\therefore \left\{ \begin{array}{l} \frac{x + y}{3} = 1, \\ \frac{x - y}{5} = 3, \end{array} \right.$ 即 $\left\{ \begin{array}{l} x + y = 3, \\ x - y = 15, \end{array} \right.$ 解得 $\left\{ \begin{array}{l} x = 9, \\ y = -6. \end{array} \right.$

**展开解析（依据原详解补足理由与步骤）：**

题内示范先设X=m+5、Y=n+3；相加3X−2Y=−1与3X+2Y=7得6X=6、X=1；相减得4Y=8、Y=2。回换m=1−5=−4、n=2−3=−1。这是原资料示范，不另编一道题。

所求方程令M=(x+y)/3、N=(x−y)/5。两式成为M+N=4、M−N=−2；相加2M=2得M=1，相减2N=6得N=3。回换得x+y=3、x−y=15；相加2x=18，x=9，再由x+y=3得y=−6。原两块分别1、3，和4、差−2，核验成立。新未知数M、N是中间量，不是题问x、y的答案。

### 已知解的差整体相减求参数

> 来源ID Q08-23；第8章二元一次方程（组）；101-150/full.md 第131–131行。原答案与解析定位：101-150/full.md 第143–148行。

例2 (2023 辽宁朝阳)已知关于 $x, y$ 的方程组 $\left\{ \begin{array}{l} 2x + y = 2a + 1, \\ x + 2y = a - 1 \end{array} \right.$ 的解满足 $x - y = 4$ , 则 $a$ 的值为 \_\_\_\_.

**原资料答案与解析：**

例2 解析 $\left\{\begin{aligned}&2x+y=2a+1,①\\&x+2y=a-1,②\end{aligned}\right.$

①-②得 $x-y=a+2$ ，又∵关于 x,y 的方程组 $\left\{\begin{aligned}&2x+y=2a+1,\\&x+2y=a-1\end{aligned}\right.$ 的解满足
x-y=4,∴ $a+2=4$ , ∴ a=2.

答案2

**展开解析（依据原详解补足理由与步骤）：**

①−②左(2x+y)−(x+2y)=x−y，右(2a+1)−(a−1)=a+2，因此x−y=a+2。题给差4，得a+2=4、a=2。可回验：两式变2x+y=5、x+2y=1，相加3x+3y=6得x+y=2，再与x−y=4相加得x=3、y=−1，确符合差4且两原式值5、1。无需先把x、y都写成复杂参数式。

## 易错

求M、N不等于求原x、y。已知差x−y=4时原两式相减直接a+2=4，避免无依据跨式约掉x、y。
