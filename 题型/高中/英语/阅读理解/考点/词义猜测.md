# 词义猜测

**一句话概念** — 问划线单词、短语或句子在**当前语境**中的意思，不一定是词典第一义。

## 怎么认

题干含 `mean / probably means / can be replaced by`，文中划线标记目标词或短语。

## 思路

**把四个选项分别替换划线词，放回它所在的短语，看哪个合适（代入法）。**

1. 看清划线的是哪个词、它在哪个短语里；
2. 把 A/B/C/D 逐个替换进去，放回这个短语；
3. 看哪个搭配和语义最合适；简单情况到这里即可；
4. 短语不够用时，才读整句、前后句或当前段。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L1 短语代入 | 目标短语本身信息足够，代入即可定 | 上下文线索 |
| L2 所在句 | 同句有定义、解释、举例、转折或因果限制 | 邻句、段落 |
| L3 前后句 | 相邻句提供原因、解释或结果，排除仍合理的词义 | 段落信息 |
| L4 当前段 | 线索分布在段内的对象、事件或多个例子 | 全文 |

**前一层能解决就停**，不为“走完整流程”读遍所有范围。

## 常见线索

| 线索 | 常见信号 |
|---|---|
| 定义或解释 | is / means / refers to / that is / in other words |
| 举例 | for example / such as / like |
| 同义或补充 | and / or / also / too，换词复现 |
| 反义或转折 | but / however / although / unlike |
| 因果和结果 | 前后行为、原因或结果限制词义 |
| 构词信息 | 前缀、后缀、词根和词性 |

## 怎么讲

1. 先给概念；
2. 当成一个小完形填空：在目标词位置逐个比较四个选项；
3. 只讲当前台阶；
4. **常见卡点**：
   - 挑一个自己最熟的词，不逐项代入；
   - 用词典第一义硬套，不看语境。

## 易错

**构词法只是辅助**——前缀后缀能提示方向，但清楚的上下文证据优先；两者冲突时以语境为准。
