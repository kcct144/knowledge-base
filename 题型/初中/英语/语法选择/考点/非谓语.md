# 非谓语

**一句话概念** — 一个分句里已经有谓语时，再出现的动词要用非谓语形式：`to do`、`doing` 或 `done`。

## 怎么认

选项常比较同一动词的不同形式：

```text
to do / doing / done
find / finding / to find
```

出现 `to do`，或同一动词的原形、`doing`、`done` 形式对比时，优先检查「非」。

**信号不是绝对规则**：选项里有 `to do` 不代表一定是非谓语，要先确认这句是否已经有谓语，避免把谓语形式误判成非谓语。

## 思路

**先看有没有谓语，再看搭配和关系。**

1. **找谓语**：句中没有连接词却已经有谓语，空格常考虑非谓语
2. **查搭配**：优先检查空格前后词的固定搭配（如 `enjoy doing`、`try to do`）
3. **判作用与关系**：非谓语在句中的作用，以及与相关名词的主动、被动和动作先后关系

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 识别 | 认出 `to do / doing / done` 差异，并先找已有谓语 | 主被动和意义变化 |
| L1 常见搭配 | 一次积累一个 `to do` 或 `doing` 搭配，以及介词后 `doing` | 分词作定语或状语 |
| L2 常见功能 | 表目的的 `to do`、常见宾补结构 | 复杂主动被动关系 |
| L3 主动被动与特殊意义 | 结构清楚时区分 `doing/done`；`try/remember/stop` 接不同形式意义改变 | — |

**默认停在 L1。** 一次只处理一个搭配或一个功能；学生只学到 L1 时，题目和干扰项不得要求他用 L4、L5 的知识排除答案。

## 怎么讲

1. 先给上面那句概念，够认就行
2. 用最简例子走一遍「信号 → 判断 → 依据」
3. 只讲当前一个搭配或功能，别把 `doing/done` 对比一次倒出来
4. **常见卡点**：
   - 看到 `to do` 选项就直接选，不查搭配
   - 不判断句中是否已经有谓语
   - 只背「某词后接 doing」，不结合例句和意义
   - 使用兜底猜对后误认为已经掌握

## 易错

**看不出同一个动词接不同形式意思会变。**

```text
try to do          ← 努力做某事
try doing          ← 尝试某种方法
remember / forget / stop + to do 与 + doing   ← 意义可能改变
```

感官动词和使役动词后有省略 `to` 的结构，需要专项积累；「看不出时默认 `to do`」只是低置信度兜底，用后仍要标记为未真正掌握。

## 例题

**例一**　Emma and her friends tried ____ what had happened.
A. find out　B. found out　C. to find out
→ **C**。句中已有谓语 `tried`；`try to do` 表示努力做某事，用 `to find out`。

**例二**　The children enjoy ____ stories about the old tower.
A. read　B. reading　C. to read
→ **B**。句中已有谓语 `enjoy`；`enjoy doing` 是固定搭配，用 `reading`。
