# 词性

**一句话概念** — 同一词根的词，按它在句子里当什么成分（名称、动作、修饰）变成不同词性。

## 怎么认

选项通常来自同一词根，但后缀或词性不同：

```text
silent / silence / silently
care / careful / carefully
success / successful / successfully
```

看到同词根的不同形式时，优先想「词」。

**信号不是绝对规则**：`-ly` 多为副词，但 `friendly / lovely / lively` 等通常是形容词；`hard` 可作形容词或副词，`hardly` 意思却是"几乎不"。

## 思路

**先看空格的句子成分，再看后缀。**

1. **判断空格作什么成分**：主语、宾语、谓语、表语还是修饰语，确定需要名词、动词、形容词还是副词
2. **看修饰关系**：形容词修饰名词，也常在 `be / become / remain / feel` 等系动词后作表语；副词修饰动词、形容词、其他副词或整个句子
3. **利用后缀**识别候选词性，再检查固定搭配和词义，代回整句验证，不单靠词尾

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 识别 | 看出选项同词根但后缀不同，知道在考词性 | 不要求一次识别所有后缀 |
| L1 名词与动词 | 在短句中判断需要事物名称还是动作 | 形副辨析和复杂句子成分 |
| L2 基础形容词 | 名词前用形容词修饰；`be` 后用形容词说明状态 | 其他系动词、`-ing/-ed` 形容词 |
| L3 形容词与副词 | 形容词修饰名词，副词修饰常见动作动词 | 感官系动词和例外词 |
| L4 系动词扩展 | 在 `be` 稳定后，逐个学 `become / remain / feel / look` 等常见系动词 | `-ing/-ed` 形容词 |
| L5 词性边界 | `-ing/-ed` 形容词、`friendly` 等例外和一词多性 | — |

**初学默认停在 L2**；本轮目标是形容词和副词时默认停在 L3。L2 未稳定时不引入感官系动词；L3 未稳定时不引入 `-ing/-ed` 形容词或大量词尾例外。
## 怎么讲

1. 先给上面那句概念，够认就行
2. 强调先判断句子成分，再看后缀，顺序不能颠倒
3. 只讲当前台阶，别顺手把 `-ing/-ed` 形容词和大量词尾例外一起倒出来
4. **常见卡点**：
   - 看到熟悉的词义就选，不判断句子成分
   - 认为 `be` 后一定接名词，忽略形容词表语
   - 看到 `-ly` 就一律判断为副词
   - 只靠词尾猜词性，不把答案代回句子

## 易错

**看不出这个词尾其实不是副词。**

```text
friendly / lovely / lively   ← 以 -ly 结尾，却是形容词
hard / fast / early / late   ← 可同时作形容词和副词
hardly                       ← 不是 hard 的副词，意思不同
```

系动词后通常用形容词、不用副词，如 `remain silent`；`to + 动词原形` 属于非谓语结构，不能因此把整句中的空格都判断为谓语。

## 例题

**例一**　One morning, the school bell remained ____.
A. silent　B. silence　C. silently
→ **A**。`remained` 是系动词，后面需要形容词作表语，所以选 `silent`。

**例二**　The teacher explained the rule ____.
A. clear　B. clearly　C. clearness
→ **B**。空格修饰动词 `explained`，需要副词 `clearly`。

（两例均为自编）
