# 词性

**做选词填空的前提**：能看出一个词大概是哪一类。分不清，就先学这一页。

| 词性 | 是什么 | 常见位置 |
|---|---|---|
| 名词 | 人或事物的名称（student / idea / water） | 主语、宾语、表语；限定词、形容词或介词后 |
| 动词 | 动作或状态（run / be / have） | 谓语；`to`、情态动词后 |
| 形容词 | 人 / 事物怎么样（good / happy） | 名词前；`be` 或系动词后 |
| 副词 | 怎么做的（quickly / very） | 修饰动词、形容词、副词或整句 |
| 介词 | 引出关系（in / on / of / with） | 后接名词、代词或动名词 |
| 连词 | 连接（and / but / because） | 连接词、短语、分句 |
| 代词 | 代替人或物（he / it / they） | 主语、宾语 |
| 限定词 | 限定后面的名词（a / the / my / this） | 名词前 |
| 情态动词 | 表语气（can / must / should） | 主语后、动词原形前 |

**一个词可能有好几种词性**（`well` / `fast` / `hard`）——看它在句子里做什么，别只看词形。
