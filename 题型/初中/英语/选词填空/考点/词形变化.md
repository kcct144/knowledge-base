# 词形变化

**一句话概念** — 选对原词只是一半：还要按题目要求，把它写成当前空格需要的形式。原词和形式是两个独立问题，要分开判断。

## 怎么认

题感：题型说明写着"使用正确形式 / change the form"；或者你已经选定了哪个原词，但它在这个空里显然要变。典型：

```text
名词 → 复数 / 所有格         student → students / students'
动词 → 时态 / 三单 / 被动     behave  → behaved / is behaved
形容词副词 → 比较级           well    → better / best
```

## 思路

**先定原词，再单独做一次词形检查。**

| 选中词的类型 | 最低限度检查 |
|---|---|
| 名词 | 单数或复数、可数或不可数、是否要所有格 |
| 动词 | 是否作谓语、主语人称和数、时间与上下文、主动或被动；必要时再看 `to do / doing / done` |
| 形容词 / 副词 | 原级、比较级或最高级；形容词和副词之间是否要转换，由题型规则决定 |
| 代词 | 指代对象、人称、单复数、主格或宾格、后面有没有名词 |
| 所有答案 | 拼写、大小写、是否符合"每空一词" |

**不要在原词还没锁定时就同时猜多个复杂变形。**

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L4 名词形式 | 规则名词单复数 | 被动、完成时、非谓语 |
| L4 基本动词形式 | 一般现在 / 过去 / 将来等已学形式 | 复杂语态和时态 |
| L4 形副与比较 | 形容词副词选择、比较等级 | `-ing/-ed` 形容词 |
| L4 代词与书写 | 代词形式、所有格、拼写、大小写 | 复杂边界 |
| L6 复杂变形 | 一词多性、`to/be` 歧义、复杂派生 | 只在真题需要时 |

**默认停在对应的一个小单元。** 只错名词复数就只补名词复数，不顺带讲完所有时态、语态和非谓语。

## 怎么讲

1. 先给上面那句概念：原词选对 ≠ 形式写对
2. 示范一次"选中原词 → 找信号 → 变形 → 代回"
3. **常见卡点**：
   - 选对原词却直接抄词框形式，漏复数 / 过去式 / 三单 / 比较级
   - 形式碰巧正确，但原词选择没有证据
   - 把"使用正确形式"理解成可以随便派生到另一词性

## 易错（题面看不出来的坑）

- "使用正确形式"不等于允许任意词性派生；跨词性要看说明和可靠实例。
- 原词选对但形式错，是词形断点，不要笼统归为"不会选词"。
- 形式对、原词没证据，也不算掌握。
