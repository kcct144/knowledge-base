# 情态动词

**一句话概念** — 情态动词放在动词原形前，表达能力、许可、可能、义务、建议等语气。

## 怎么认

选项是不同情态动词：

```text
can / may / must
could / should / might
mustn't / needn't / can't
```

看到多个情态动词并列，或选项主要改变语气和可能性时，优先想「情」。

**信号不是绝对规则**：情态动词后动词形式正确，不代表情态意义一定正确；`had better / have to / be able to` 与情态意义相关，但结构不同。

## 思路

**先确认空格后接动词原形，再判句子表达的意义和语气。**

1. **看结构**：情态动词后接动词原形
2. **判意义**：能力、许可、可能、建议、义务、必要，还是推测；比较语气强弱和肯定、否定
3. **对语境**：检查时间背景和委婉程度，代回上下文验证说话人的真实意图

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 结构识别 | 情态动词后接动词原形 | 语气强弱大全 |
| L1 核心意义 | `can` 的能力、`should` 的建议、`must` 的义务 | 推测和委婉差异 |
| L2 可能与委婉 | `may / could / might` 的常见可能或请求语境 | 复杂推测 |
| L3 否定辨析与扩展 | `mustn't / needn't / can't` 的禁止、不必和否定推测；`have to`、`be able to` 等相关结构 | — |

**默认停在 L0、L1。** 别在学生刚掌握「情态动词后原形」时，就用复杂推测或委婉程度考他。

## 怎么讲

1. 先给上面那句概念，够认就行
2. 用最简例子走一遍「信号 → 判断 → 依据」
3. 每次只比较当前语境需要的两三个意义
4. **常见卡点**：
   - 只看情态动词后是不是原形，不判断语气
   - 混淆「不必」和「禁止」
   - 把 `could` 一律理解成过去时
   - 依据中文单字对应，不读完整情境

## 易错

**看不出的推测和委婉差异。**

```text
must 表推测        ← 把握较强
can't              ← 否定推测常用，不是 mustn't
could              ← 既可能是 can 的过去式，也可能是现在的委婉表达
```

`mustn't` 表示「禁止」，`don't have to / needn't` 表示「不必」，两者意思不同。

## 例题

**例一**　You ____ wear a helmet when riding a bicycle. It is safer.
A. should　B. might　C. could not
→ **A**。句子给出安全建议，语气适合用 `should`。

**例二**　Students ____ run in the science lab because it is dangerous.
A. needn't　B. mustn't　C. may
→ **B**。危险场所禁止奔跑，`mustn't` 表示「禁止」；`needn't` 只表示「不必」。

（两例均为自编例题）
