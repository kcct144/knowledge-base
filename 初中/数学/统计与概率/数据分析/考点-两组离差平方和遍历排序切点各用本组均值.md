## 讲解

### 判据

原拓展规定n个不同数排序、只连续切两组，按每组自己的均值比较总平方离差。

### 流程

1.固定候选m1至n−1，避免空组。2.每个m分别算前m均a和后n−m均b。3.前组每项减a平方，后组减b平方，两和相加。4.遍历所有候选比最小，若并列列全部；不是沿用同一个全组均。5.可分别n₁方₁+n₂方₂计算同一总平方和，不能直接加两个方差。6.原无具体数列，保理论过程及缺数值题，不假装已经完成原没给的实算。

## 例题

### 原离差平方和与分组遍历切点原则

> 来源ID Q30-26；第30章数据的分析；351-377/full.md 第1342–1343行。原答案与解析定位：351-377/full.md 第1342–1343行。

知识解读 1. 在一组数据 $x_{1}, x_{2}, \cdots, x_{n}$ 中，各数据与它们的平均数的差的平方和叫作这组数据的离差平方和，若用 $S^{2}$ 表示，则 $S^{2} = (x_{1} - \bar{x})^{2} + (x_{2} - \bar{x})^{2} + \cdots + (x_{n} - \bar{x})^{2}$ .  
2. 假设有 n 个互不相等的数据从小到大排列, 且不失一般性, 表示为 $x_{1}, x_{2}, \cdots, x_{n}$ . 如果把这些数据分为两组, 例如, 前 m 个数据为一组 (称为第一组), 后 $(n-m)$ 个数据为一组 (称为第二组), 那么这 n 个数据的组内离差平方和 (设为 $S_{1}^{2}$ ) 为 $S_{1}^{2} = (x_{1} - a)^{2} + (x_{2} - a)^{2} + \cdots + (x_{m} - a)^{2} + (x_{m+1} - b)^{2} + (x_{m+2} - b)^{2} + \cdots + (x_{n} - b)^{2}$ , 其中, $a = \frac{1}{m}(x_{1} + x_{2} + \cdots + x_{m}), b = \frac{1}{n-m}(x_{m+1} + x_{m+2} + \cdots + x_{n})$ . 一个合理的分组原则是使 $S_{1}^{2}$ 达到最小. 令 $m = 1, 2, 3, \cdots, n-1$ , 分别计算出对应的组内离差平方和并比较大小, 使组内离差平方和达到最小的分组即为合理分组.

**原资料答案与解析：**

知识解读 1. 在一组数据 $x_{1}, x_{2}, \cdots, x_{n}$ 中，各数据与它们的平均数的差的平方和叫作这组数据的离差平方和，若用 $S^{2}$ 表示，则 $S^{2} = (x_{1} - \bar{x})^{2} + (x_{2} - \bar{x})^{2} + \cdots + (x_{n} - \bar{x})^{2}$ .  
2. 假设有 n 个互不相等的数据从小到大排列, 且不失一般性, 表示为 $x_{1}, x_{2}, \cdots, x_{n}$ . 如果把这些数据分为两组, 例如, 前 m 个数据为一组 (称为第一组), 后 $(n-m)$ 个数据为一组 (称为第二组), 那么这 n 个数据的组内离差平方和 (设为 $S_{1}^{2}$ ) 为 $S_{1}^{2} = (x_{1} - a)^{2} + (x_{2} - a)^{2} + \cdots + (x_{m} - a)^{2} + (x_{m+1} - b)^{2} + (x_{m+2} - b)^{2} + \cdots + (x_{n} - b)^{2}$ , 其中, $a = \frac{1}{m}(x_{1} + x_{2} + \cdots + x_{m}), b = \frac{1}{n-m}(x_{m+1} + x_{m+2} + \cdots + x_{n})$ . 一个合理的分组原则是使 $S_{1}^{2}$ 达到最小. 令 $m = 1, 2, 3, \cdots, n-1$ , 分别计算出对应的组内离差平方和并比较大小, 使组内离差平方和达到最小的分组即为合理分组.

**展开解析（依据原详解补足理由与步骤）：**

离差平方和是各数据到本组均值的平方差之和，不除个数。原规定n个不同数已排序，遍历切点m1至n−1，将前m个和后n−m个分别求均值a/b，再分别把组内差平方相加，比较该总和；在给定只分两组、按排序连续切开的候选范围内，最小者满足原准则。不是对任意现实分类唯一“最合理”的证明，原未给一组具体数和逐切点算表，缺数值例题。
