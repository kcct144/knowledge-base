## 讲解

### 判据与流程


题目已经指定α，或指定“有……把握”并给配套临界表时，按这一档进行检验，不擅自换更宽或更严档。

1. 写H₀：所研究总体的两个分类变量独立，说明样本及变量类别。
2. 补列联表，检查四边际正，计算χ²观测值k。若题表近似前提有疑点，计算仍按题做，但风险结论加“按题给近似检验”。
3. 查表找α对应cα，读的是H₀成立下的高尾概率。α=.05对应3.841；α=.01对应6.635，较严档阈值更高。
4. k≥cα：在该α水平拒绝H₀，样本支持有关。k<cα：在该水平未拒绝H₀，样本证据不足以认为有关。无论哪支，都不能说逻辑上证明了总体性质。
5. 结论带研究总体、变量名称及α，并区别因果、个人发生概率。原答案口径错误时照原块保留，另列规范结论，不能改原题选项凑答案。


## 易错

- 未拒绝不是“无关已成立”，也没有给出接受H₀错误概率≤α。
- α不是该次结论错的后验概率，亦不是个体疾病概率。
- 边界按常用≥；原例中的>若不影响整数答案，也不能推广。

## 例题

### 原例：例5：篮球迷与性别的检验

来源：HSMA-B5-C8-D9e1bd0cb65d9-P0412-P0462。原件：专题8.3 列联表与独立性检验【八大题型】（举一反三）（人教A版2019选择性必修第三册）（解析版）.docx。

#### 原题与原解（完整保留）

【例5】（24-25高二下·山东德州·阶段练习）某学校在一次调查“篮球迷”的活动中，获得了如下数据，以下结论最准确的是（   ）

|  |  | 男生 | 女生 |  |
| --- | --- | --- | --- | --- |
| 篮球迷 |  | 90 | 20 |  |
| 非篮球迷 |  | 60 | 30 |  |

附：${χ}^{2}=\frac{n{(ad-bc)}^{2}}{(a+b)(c+d)(a+c)(b+d)}$

| $P\left( {X}^{2}\ge k\right)$ | 0.10 | 0.05 | 0.01 | 0.005 |
| --- | --- | --- | --- | --- |
| k | 2.706 | 3.841 | 6.635 | 7.789 |

A．有99．5%的把握认为是否是篮球迷与性别有关

B．有$99\%$的把握认为是否是篮球迷与性别有关

C．在犯错误的概率不超过0.1的前提下，可以认为是否是篮球迷与性别有关

D．在犯错误的概率不超过0.05的前提下，可以认为是否是篮球迷与性别有关

【解题思路】列出$2\times 2$列联表，计算${χ}^{2}$即可得解.

【解答过程】列出$2\times 2$列联表：

|  |  | 男生 | 女生 |  |
| --- | --- | --- | --- | --- |
| 篮球迷 |  | 90 | 20 | 110 |
| 非篮球迷 |  | 60 | 30 | 90 |
|  |  | 150 | 50 | 200 |

${χ}^{2}=\frac{n{(ad-bc)}^{2}}{(a+b)(c+d)(a+c)(b+d)}=\frac{200\times {\left( 90\times 30-20\times 60\right)}^{2}}{150\times 50\times 110\times 90}\approx 6.061>3.841$，

故在犯错误的概率不超过0.05的前提下，可以认为是否是篮球迷与性别有关.

故选：D.

#### 补讲与资料勘误

总样本200，男150、女50，篮球迷110、非篮球迷90。按原表取a=90、b=20、c=60、d=30，则ad−bc=2700−1200=1500，四边际为110、90、150、50。χ²=200×1500²/(110×90×150×50)=200/33≈6.060606。

在H₀下，四格期望频数为110×150/200=82.5、110×50/200=27.5、90×150/200=67.5、90×50/200=22.5。四格“观察−期望”的平方除以期望再相加也得到200/33，解释了闭式的来源。

3.841<χ²<6.635，所以α=0.05拒绝H₀，但α=0.01不拒绝。A的99.5%、B的99%档均未达到；C较宽的0.1档也可拒绝，但题问“最准确”，D使用样本所能支持的更严格0.05档，故原答案D。表内0.005档实际XML写7.789；同源其他表写7.879，原表照留并单列此误植，终答未使用该列。“犯错误概率”仍应按H₀成立时程序的误拒风险理解，不能变成本次结论正确率。

### 原例：例6：阈值以下的规范结论

来源：HSMA-B5-C8-D9e1bd0cb65d9-P0546-P0554。原件：专题8.3 列联表与独立性检验【八大题型】（举一反三）（人教A版2019选择性必修第三册）（解析版）.docx。

#### 原题与原解（完整保留）

【例6】（24-25高三下·湖南永州·阶段练习）根据分类变量x与y的成对样本数据，计算得到${χ}^{2}=2.974$．依据$\alpha =0.05$的独立性检验，则下列结论正确的是（   ）

A．变量x与y不独立  B．变量x与y不独立，这个结论犯错误的概率不超过0.05

C．变量x与y独立  D．变量x与y独立，这个结论犯错误的概率不超过0.05

【解题思路】直接利用独立性检验的知识求解.

【解答过程】按照独立性检验的知识及比对的参数值，当${χ}^{2}=2.974$，我们可以下结论变量$x$与$y$独立.故排除选项A,B；

依据$\alpha =0.05$的独立性检验$\left( {x}_{0.05}=3.841\right)$，${χ}^{2}=2.974<3.841$，

所以不能得到：变量x与y独立，这个结论犯错误的概率不超过0.05；

故C正确，D错误.

故选：C.

#### 补讲与资料勘误

题给α=0.05，阈值3.841，而χ²=2.974<3.841。规范结论为“在α=0.05水平下未拒绝H₀，样本尚不足以认为两个分类变量不独立”。它没有证明H₀成立，也没有给出把H₀判真时的错误风险。

原题与原答案C照留，另列勘误：A、B直接断言不独立，没有达到拒绝阈值；C断言独立，比“未拒绝”更强；D还把误拒H₀的α用成接受H₀的错误概率。故四项均没有严格可推出的检验结论，原C不是规范统计结论。可与原变式6-1“不能肯定或否定假设”的表述对照，不能为了让四选一成立而改写原选项。
