# 复合不定代词

**一句话概念** — some / any / every / no 与 one / body / thing 组合，指人还是指物、肯定还是否定语境，都要一起判。

## 怎么认

选项常由 some / any / every / no 与 one / body / thing 组成，例如：

```text
someone / anyone / no one
something / anything / nothing
```

看到这些形式时，要同时判断指人还是指物，以及句子的肯定、否定或疑问语境。

**信号不是绝对规则**：不能只按否定选 no；指人的 no one 和指物的 nothing 要分清。

## 思路

**先判指人还是指物，再看 some / any / every / no 系列。**

1. **指人还是指物**：-one / -body 通常指人，-thing 指物
2. **语境**：someone / something 常用于肯定句；anyone / anything 常用于疑问或否定；everyone / everything 表示全部；no one / nothing 本身带否定意义

依据行：复合不定代词作主语时，谓语通常用单数；形容词修饰复合不定代词时通常后置，如 something useful。some 系列也可用于希望得到肯定回答的请求或邀请；any 系列在肯定句中可表示“任何一个”。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 识别 | 认出指人或指物的形式 | 不要求判答案 |
| L1 基础流程 | 先判指人指物，再判肯否语境 | 请求/邀请特例 |
| L2 修饰与一致 | 后置形容词、单数谓语 | 反意疑问句回指 |
| L3 特例 | 请求邀请用 something、肯定句 anyone | — |

**默认停在 L1。**

## 怎么讲

1. 先给上面那句概念，够认就行
2. 用最简例子走一遍「指人还是指物 → 语境 → 选词 → 依据」
3. 只讲当前台阶，别顺手把反意疑问句回指等细节一起倒出来
4. **常见卡点**：
   - 指人和指物混淆
   - 看到疑问句就机械选择 any 系列，忽略请求或邀请
   - 形容词放在复合不定代词前面
   - 主语是 everyone 却使用复数谓语

## 易错

**看不出形容词要后置、谓语要用单数。**

```text
There is ____ wrong with the bell.        ← 指事 + 形容词 wrong 后置，用 something
____ in the class is ready for the trip.  ← 指每个人，谓语 is 单数一致，用 Everyone
```

Would you like something to drink? 是提供或邀请，常使用 something；Anyone can join the club. 中 anyone 表示“任何人”，用于肯定句；no one 通常分写，nobody 合写，两者都指人。

## 例题

**例一**　There is ____ wrong with the bell.
A. something　B. someone　C. everyone
→ **A**。空格指某件事情，不是人；形容词 wrong 后置修饰，所以用 something。

**例二**　____ in the class is ready for the trip.
A. Everyone　B. Everything　C. Anything
→ **A**。指班里的每个人，使用 Everyone；谓语 is 也符合单数一致。

（两例均为自编）
