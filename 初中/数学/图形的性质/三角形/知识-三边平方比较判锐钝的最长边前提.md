## 讲解

### 是什么

先确认三条正线段能组成三角形，再把最长边记为$c$，另两边记为$a,b$。有以下分类：

$$a^2+b^2>c^2\Rightarrow\text{锐角三角形},\qquad a^2+b^2=c^2\Rightarrow\text{直角三角形},\qquad a^2+b^2<c^2\Rightarrow\text{钝角三角形}.$$

等号时最长边对着直角，小于时最长边对着钝角。大于时不能只说某一个角锐就结束，还需保证另外两角也锐；最长边条件正是保证完整分类的关键。这是原书勾股逆定理的延伸，考试可用。

### 怎么来的

**先证明一个角的判据，再把它用于最长边。** 在△ABC中，令$AB=a$、$AC=b$、$BC=c$，所比较的角是∠BAC，它的对边为$c$。

从C向直线AB作垂线，垂足为H。以A为数轴原点、从A到B为正方向，把H的有向位置记为$t$。H在A右侧时$t>0$，在A处时$t=0$，在A左侧时$t<0$；实际线段AH的长度为$|t|$，BH的长度为$|a-t|$。这样不必假设垂足一定落在AB内部。

对两组垂直方向用勾股关系，得到$AC^2=t^2+CH^2$、$BC^2=(a-t)^2+CH^2$；若H与A或B重合，关系中相应的水平距离为0，仍可直接成立。第二式先按完全平方展开：

$$c^2=a^2-2at+t^2+CH^2.$$

第一式给$t^2+CH^2=b^2$，代入上式得$c^2=a^2-2at+b^2$。两边移项，得到：

$$a^2+b^2-c^2=2at.$$

因为$a>0$，平方差与$t$同号。若$t>0$，C位于A处垂线朝B的一侧，射线AC与AB之间的角小于90°；若$t=0$，AC本身垂直AB，角为90°；若$t<0$，C位于该垂线背离B的一侧，角大于90°。这把“平方差正、零、负”与“角锐、直、钝”逐一接上，没有使用余弦定理或未说明的圆内外结论。

**再说明为什么要选最长边。** 若$c$最长，则$c\ge a$、$c\ge b$。当$a^2+b^2>c^2$时，刚才的判据说明∠A锐；另两角的平方差分别为$b^2+c^2-a^2=b^2+(c^2-a^2)>0$、$a^2+c^2-b^2=a^2+(c^2-b^2)>0$，因为边长为正、括号非负。对同一角判据换顶点使用，∠B、∠C也都锐，所以整个三角形为锐角三角形。等号或小于时，∠A分别是直角或钝角，已能确定三角形类型。

注意上面投影到的是AB，允许有向位置为负。若另向最长边BC作高，垂足必在BC内部：假如垂足在B外侧，则C到垂足的水平距离大于BC，勾股关系使AC更长于BC，矛盾；在C外侧同理会使AB更长于BC。垂足恰在B或C时，另一条斜边也会严格长于BC。因此最长边排除了这条高线的外垂足及端点情形。

### 什么时候能用

先三边成立且长度正同单位；最长相同有并列也能按一条最长比较。未成立的3段不分类三角。原四组第4原答案仅说非直角，补锐角是按原书延伸规范判断，不冒充原详解原句。

## 例题

### 四组三边整数根式分式与40 50 60判形状

> 来源ID Q22-17；第22章勾股定理；251-300/full.md 第224–226行。原答案与解析定位：251-300/full.md 第228–232行。

例1 判断由线段 a, b, c 组成的三角形是不是直角三角形.

(1) $a = 7, b = 24, c = 25$ . (2) $a = \sqrt{41}, b = 4, c = 5$ . (3) $a = \frac{5}{4}, b = 1, c = \frac{3}{4}$ . (4) $a = 40, b = 50, c = 60$ .

**原资料答案与解析：**

解析（1）因为 $a^2 + b^2 = 7^2 + 24^2 = 625 = c^2$ ，所以由线段 $a, b, c$ 组成的三角形是直角三角形.

(2) 因为 $b^{2}+c^{2}=4^{2}+5^{2}=41=a^{2}$ ，所以由线段 a, b, c 组成的三角形是直角三角形.  
(3) 因为 $b^{2} + c^{2} = 1^{2} + \left(\frac{3}{4}\right)^{2} = \frac{25}{16} = a^{2}$ ，所以由线段 $a, b, c$ 组成的三角形是直角三角形.  
(4) 因为 $a^{2}+b^{2}=40^{2}+50^{2}=4100, c^{2}=60^{2}=3600$ ，所以 $a^{2}+b^{2}\neq c^{2}$ ，所以由线段 a, b, c 组成的三角形不是直角三角形.

**展开解析（依据原详解补足理由与步骤）：**

先确认四组正长度能成三角形，再在每小题找实际最长边，不能因题干用字母$c$就默认它最长。

（1）最长边为25。$7+24>25$，三边成立；$7^2+24^2=49+576=625=25^2$，由勾股逆定理是直角三角形，25所对角为直角。
（2）$41>25>16$，所以$\sqrt{41}>5>4$，实际最长边为$a=\sqrt{41}$；$4+5>\sqrt{41}$，三边成立。$4^2+5^2=16+25=41=(\sqrt{41})^2$，所以是直角三角形，直角对着$a$。
（3）最长边为$a=5/4$，$1+3/4=7/4>5/4$，三边成立。$1^2+(3/4)^2=16/16+9/16=25/16=(5/4)^2$，仍是直角三角形，直角对着$a$。
（4）最长边为60，$40+50>60$，三边成立。$40^2+50^2=1600+2500=4100$，而$60^2=3600$，不相等，所以原答案“不是直角三角形”成立。进一步按本条已证明的平方比较判据，$4100>3600$，三个角均锐，可补判为锐角三角形；这个细分是规范补充，不冒充原详解原句。

根式和分数也能作为直角三角形边长；但勾股数组要求全为正整数，所以（2）（3）虽直角，并非整数勾股数组。

## 易错

比较顺序反了会把锐钝对调；只检a²+b²≠c²还不能直接说钝角。
