# 指对幂函数

## 幂函数学习入口

1. [幂函数的概念](知识-幂函数的概念.md)：先识别标准形式，分清固定指数与待定参数。
2. [定义域与分数指数](知识-幂函数的定义域与分数指数.md)：把指数和根式约定、零值与负输入的条件联系起来。
3. [正半轴单调性与值域](知识-幂函数的正半轴单调性与值域.md)：结合指数与实际输入范围判断输出。
4. [奇偶性与负半轴性质](知识-幂函数的奇偶性与负半轴性质.md)：先确认定义域，再讨论对称与分支。
5. [图象与指数范围](知识-幂函数图象与指数范围.md)：由图象的合法信息判断参数，不把示意图外观当成完整证据。

## 指数与对数学习入口

1. 从[整数指数幂与零负指数](知识-整数指数幂与零负指数.md)、[n次方根与根式的取值](知识-n次方根与根式的取值.md)出发，再读[正数分数指数幂的意义与运算](知识-正数分数指数幂的意义与运算.md)和[实数指数幂的推广](知识-实数指数幂的推广与同底数等式.md)。每次变形先核查底数与根式条件。
2. 读[指数函数的概念](知识-指数函数的概念与标准结构.md)及[图象与单调性](知识-指数函数的图象与单调性.md)：区分底数大于1与小于1，再用于解不等式或比较大小。
3. 读[对数的定义与指对互化](知识-对数的定义与指对互化.md)，理解对数回答的是“指数是多少”；随后学习[积商幂运算](知识-对数的积商幂运算性质.md)和[换底公式](知识-对数换底公式与倒数链式推论.md)。先保证底数、真数合法，再使用恒等式。
4. 读[对数函数的概念](知识-对数函数的概念与合法等价标准结构.md)及[图象与单调性](知识-对数函数的图象与单调性.md)，把定义域、底数分类和函数性质连起来。

各知识条目配有来自原资料的例题，相关考点和坑点解释识别、取值、分支及退化条件。比较大小时先找共同的底数、真数或中间值，模型应用再回到实际变量与取值范围。
