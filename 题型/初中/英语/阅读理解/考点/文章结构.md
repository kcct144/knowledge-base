# 文章结构

**一句话概念** — 段落怎样组织、信息怎样推进。

## 怎么认

`How is the passage organized?` / `How does the author develop the passage?`

## 常见结构

| 结构 | 常见推进 |
|---|---|
| 总—分 / 总—分—总 | 提出中心 → 分项说明 → 可选总结 |
| 时间或事件顺序 | 起因 → 经过 → 变化 → 结果 |
| 对比 | 对象 A 与对象 B 的异同 |
| 问题—解决 | 问题 → 原因或影响 → 办法 → 结果 |
| 观点—理由—例子 | 观点 → 支持理由 → 证据或例子 |
| 说明分类 | 对象 → 多个方面、类型或步骤 |

## 思路

```text
先确认全文主旨
→ 给每段贴功能标签
→ 找时间词、转折、因果、顺序和总结表达
→ 画出段落之间的关系
→ 用选项核对，而不是只数段落
```

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 认问法 | 认出结构题 | 不要求分功能 |
| L1 总—分—总 | 先看有没有开头总、结尾总，中间是分 | 其他推进方式 |
| L2 中间怎么展开 | 分项并列、举例、时间先后、对比 | 多层结构 |

**默认停在 L1。**

## 怎么讲

1. 先给上面那句概念；
2. 演示“贴段落功能标签 → 画关系 → 用选项核对”；
3. **常见卡点**：只数段落、只背结构名称，不看段落之间是什么关系。

## 易错

- `first / then / finally` 只是线索，没有明显连接词时仍要看内容关系；
- 同一文章可能同时有多层结构，例如全文“总—分”，某一段内部按时间推进。
