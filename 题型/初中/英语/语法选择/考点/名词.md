# 名词

**一句话概念** — 表示人或事物的名称。它有两种变化：**数**（单复数）和**所属**（所有格）。

## 怎么认

选项是同一个名词的不同形式：

```text
student / students / student's
child / children / children's
```

看到单数、复数、`'s`、`s'` 摆在一起，优先想「名」。

**信号不是绝对规则**：`-s` 也可能是动词三单；`'s` 也可能是 `is / has` 的缩写。

## 思路

**先看所有格，再看单复数。**

1. **所有格**：空格后面**有没有名词**？有 → 多半用所有格（还要确认语义上确实所属）
2. **单复数**：`a / an / one / each / every` → 可数单数；`many / several / a few / few` → 可数复数；
   `some / a lot of` → 复数或不可数，**先判名词性质**

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 识别 | 从选项认出单数、复数和所有格 | 不要求判答案 |
| L1 基础流程 | 先判所属，再用常见数量词判规则可数名词的单复数 | 不规则复数、不可数、复数所有格 |
| L2 名词性质 | 不规则复数和常见不可数名词 | 复杂所有格 |
| L3 所有格边界 | 复数所有格、`at Tom's` 这类省略 | — |

**默认停在 L1。** 只有 L1 稳了、真题需要、或学生明确追问，才往下走。

## 怎么讲

1. 先给上面那句概念，够认就行
2. 用最简例子走一遍「信号 → 判断 → 依据」
3. 只讲当前台阶，别顺手把不规则复数和不可数一起倒出来
4. **常见卡点**：
   - 看到 `-s` 就选复数，不先查所有格
   - 看到空格后有名词就机械选所有格，不判所属关系
   - 把 `some` 当成只能接复数（它后面也可能是不可数）

## 易错

**看不出这里要填名词。**

```text
two minutes' walk        ← 量词所有格；中心名词是 walk，不是 minutes
two hours' ride
Amy's favorite animal    ← 所有格后面跟的是「短语」，不是一个词
```

`Amy's favorite animal` 这种最容易漏：空格后跟着**一整个短语**，学生只盯紧挨着的那一个词，就看不出有所属关系。
`two minutes' walk` 则是先要认出 `minutes` 是量词、`walk` 才是中心名词，再处理"复数已以 s 结尾只加 `'`"。

## 例题

**例一**　Many other ____ joined the school club.
A. student　B. students　C. student's
→ **B**。空格后没有"被所属的东西"，不用所有格；`many other` 后接可数名词复数。

**例二**　This is my ____ new bicycle.
A. sister　B. sisters　C. sister's
→ **C**。自行车属于妹妹，空格后有 `new bicycle`，用所有格。

（两例均为自编）
