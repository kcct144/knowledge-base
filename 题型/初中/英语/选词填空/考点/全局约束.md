# 全局约束

**一句话概念** — 使用次数、多余词、每空词数这类规则，用来在最后验证和排错。它不参与锁定答案，不能代替局部证据。

## 怎么认

题感：说明里给了"每词一次 / 有剩余词 / 每空一词"，或者你快填完了，问：

```text
✓ 这个词是不是已经用过？
✓ 最后该剩几个词？
✓ 每空只写了一个词吗？
```

## 思路

**先局部证据，后全局验证。**

1. **剩余词只帮助缩小范围**，不能因为"只剩这个词"就跳过语法和语义检查
2. **若剩余候选都不合适**：回查最早的 `?` 答案，而不是强塞
3. **完成后再通读全文**，逐项检查：

```text
使用次数 → 多余词数量 → 每空词数 → 词形 → 拼写 → 大小写
```

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L1 把握标记 | 用 `✓` 锁高把握、`?` 保留低把握，不提前永久划掉候选 | 时间训练 |
| L5 回溯 | 剩余词不合适时回查最早的 `?` | 复杂全局策略 |
| L5 全文检查 | 通读并查次数、多余词、词数、词形、拼写、大小写 | 限时迁移 |

**默认停在 L1 的把握标记。** 一个 `?` 被当确定答案，会造成后面连续错。

## 怎么讲

1. 先给上面那句概念
2. 示范一次 `✓ / ?` 标记，再说"剩下一个词也未必对"
3. **常见卡点**：
   - 没注意有剩余词，做不满就慌
   - 过早划掉低把握候选，前面一错导致后面连续错
   - 最后只看有没有用完词，不通读、不查形式和大小写

## 易错（题面看不出来的坑）

- "只剩这个词"不是证据；剩余词全部不合适时优先回查 `?`。
- 全局排除只辅助，不能证明一个局部证据不足的答案。
- 通顺只是检查之一，答案仍要有词框、结构、搭配和上下文证据。
