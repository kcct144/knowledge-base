# Unit 05 常见选项词群

**一次课。** 按选项词群归类：先辨清同类词的区别，再回原文用语境选词。

## 讲什么

完形选项常成"群"出现（一组情绪词、一组时间词……）。认出词群，先比同类词的区别，再对语境。下面按实际选项归类，每行给出代表词，不逐词背表：

- **情绪感受**：害怕与担心（scared / terrified / nervous / anxious / worried / panic）；失望、惊讶与开心（disappointed / astonished / surprise / delighted / cheerful）
- **态度与意愿**：愿意与犹豫（eager / willing / reluctant / hesitate / ready）；信心、怀疑与信念（confident / doubt / belief / hope）
- **人物品质**：友善与关照（friendly / kind / generous / considerate / care）；耐心、决心与坚持（patience / determined / firm / committed / persistent）
- **性质与评价**：重要、必要与紧迫（important / essential / necessary / significant / pressing / urgent）；普通与特别（ordinary / normal / typical / unique / unusual / special）
- **频度与程度**：频度（always / constantly / frequently / occasionally / rarely / never）；程度与限定（barely / almost / completely / extremely / slightly / merely）
- **时间与进程**：立刻、突然与逐渐（immediately / instantly / suddenly / gradually / eventually / temporarily）；起初、此前与后来（initially / previously / recently / later / finally / then / soon）
- **方式与句子副词**：动作方式（quietly / silently / skillfully / firmly / cheerfully / lovingly）；幸运、意外与评价（fortunately / unfortunately / surprisingly / obviously / Needless to say）
- **逻辑连接**：因果、转折与让步（however / although / despite / instead / therefore / because）
- **行为动作**：寻找、发现与认出（search / find / discover / recognize / identify）；尝试、完成与达成（attempt / try / achieve / succeed / complete / quit）；表达、解释与回应（express / explain / demonstrate / persuade / reply）
- **抽象名词**：问题、困难与挑战（problem / difficulty / challenge / crisis / struggle / disaster）；机会、选择与责任（chance / opportunity / option / choice / responsibility / duty）；结果、进步与成就（achievement / relief / gratitude / pride）
- **常见短语**：turn / give（turn into / turn down / give up / give away / give way to）；look / get（look back / look upon / get out / get through / get over）；行动、联系与回报（work out / carry on with / pay off / step up / reach out to / rely on）

## 怎么讲

1. 先定词群：看选项是否同一类（情绪 / 态度 / 品质 / 性质 / 程度 / 时间 / 逻辑 / 动作 / 名词 / 短语），同类才需要比区别
2. 用自己的话说区别：每个词的主要义 + 一处不同（对象、程度、词性），**不背**"优先顺序"
3. 回原文定位：这个空修饰谁、什么时候、与前后句什么关系，时间词和逻辑词尤其要看
4. 先排除再精辨：先按语境排除方向不符的，再在同向项里比精确含义
5. 短语整体记：动词短语按整体理解，别拆成单个动词，并核对宾语和搭配

## 例题

**一**（情绪感受）
> I was beginning to get ____, too.
> A. nervous　B. embarrassed　C. angry　D. disappointed
→ **C**。前文女士 with fire in her eyes，空后 too，说明"我"和她情绪相同——是生气。

**二**（人物品质）
> Cathy kept swimming and didn't miss a single practice. She had a ____ intention within herself to be the best she could be.
> A. rich　B. weak　C. firm　D. kind
→ **C**。Cathy 从不缺席训练，内心有"坚定"的意志；rich / weak / kind 都不能修饰这种决心。

**三**（频度与程度）
> “Mid” is an obvious example in my son’s usage, things that are mid are things that are average or ____ below.
> A. unbelievably　B. terribly　C. slightly　D. unreasonably
→ **C**。average 之后承接 below，是"稍微低于"平均；terribly 过重，方向也不符。

**四**（逻辑连接）
> ____ her doubts, Ward decided to sign up.
> A. Besides　B. Despite　C. Beyond　D. Except
→ **B**。前后是让步关系，且空后接名词 doubts，用 Despite 最合适。

**五**（常见短语）
> What was meant to be a six-month adventure soon ____ a new way of life.
> A. turned into　B. took up　C. looked for　D. held back
→ **A**。短期冒险后来"变成"长期生活方式，turned into 表示转变。

## 过关

拿到一组同类选项，能先说清它们的主要区别，再用原文语境选出并说出依据。
