## 讲解

### 判据与流程


一道题先补表/检验，再从样本或总体抽取若干对象求概率、分布、期望时，要为后续试验重新定对象和机制，不能把检验中的独立当作抽样独立。

1. 完成前半检验，说明H₀涉及同一对象的两特征。后半若改为只在一类人中抽取，样本空间已缩小，先重算人数与组比例。
2. 后半从整个固定总体独立等可能有放回抽取时，每次组成不变，抽中目标的概率相同；按独立事件乘法算联合。若用的是调查频率，则标成概率估计，并非总体比例已精确已知。
3. 比例分层抽样先按层总数分配名额，名额须整数。再从抽出的固定名单不放回取人时，用组合计数或超几何分布，组成变化不能套同p独立重复。
4. 写随机变量取值，按每值数有利组合/总组合，核互斥穷尽概率和1；期望按值乘概率相加。原题多个小问完整保留，不只摘前半检验。
5. 回验变量独立H₀与每次抽取独立分别来自什么：前者是待检验总体性质，后者是后续随机机制条件，两者无相互蕴含。

后续基础方法见既有[独立事件乘法](../概率/知识-独立事件与补事件的乘法公式.md)、[超几何模型](../随机变量及其分布/知识-超几何分布与有效取值范围.md)，本条重点是模型衔接与范围变化。


## 易错

- 第1问拒绝H₀，不会阻止后续独立放回抽取；第1问未拒绝也不会让不放回抽取变独立。
- 原表新能源100/150，是在新能源意向者中的青年比例，不是全200人中的青年比例。
- 样本频率估计不能在不说明误差/代表性的情况下变成总体精确概率。

## 例题

### 原例：变式7-3：测试成绩检验与放回抽样

来源：HSMA-B5-C8-D9e1bd0cb65d9-P0737-P0792。原件：专题8.3 列联表与独立性检验【八大题型】（举一反三）（人教A版2019选择性必修第三册）（解析版）.docx。

#### 原题与原解（完整保留）

【变式7-3】（24-25高二下·河南驻马店·阶段练习）为了解学生性别与掌握消防安全知识情况的关系，某校组织了消防安全知识测试，在高二年级中随机抽取600名学生统计其测试成绩，如下表（单位：人）：

| 测试成绩性别 | 良好 | 不够良好 | 总计 |
| --- | --- | --- | --- |
| 男生 | 150 |  | 300 |
| 女生 |  | 100 |  |
| 总计 | 350 |  | 600 |

(1)将上表中数据补充完整；

(2)从该校高二年级的学生中有放回地随机抽取2次，每次抽取1名学生，以频率作为概率，估计这2次抽取的学生的测试成绩全都良好的概率；

(3)试问是否有99.9%的把握判断消防安全知识测试成绩与性别有关？

附：${χ}^{2}=\frac{n{(ad-bc)}^{2}}{(a+b)(c+d)(a+c)(b+d)}$，$n=a+b+c+d$．

| $\alpha $ | 0.100 | 0.010 | 0.001 |
| --- | --- | --- | --- |
| ${x}_{\alpha }$ | 2.706 | 6.635 | 10.828 |



【解题思路】（1）根据已知填写表格即可；

（2）应用独立事件概率乘积公式计算即可；

（3）先计算${χ}^{2}=\frac{120}{7}\approx 17.143$，再与临界值比较即可判断相关性即可.

【解答过程】（1）

| 测试成绩<br>性别 | 良好 | 不够良好 | 总计 |
| --- | --- | --- | --- |
| 男生 | 150 | 150 | 300 |
| 女生 | 200 | 100 | 300 |
| 总计 | 350 | 250 | 600 |



（2）该校高二年级600名学生中测试成绩良好的频率为$\frac{350}{600}=\frac{7}{12}$，$\frac{7}{12}\times \frac{7}{12}=\frac{49}{144}$，

故估计这2次抽取的学生的测试成绩全都良好的概率为$\frac{49}{144}$．

（3）根据表中数据，计算${χ}^{2}=\frac{600\times {(150\times 100-150\times 200)}^{2}}{300\times 300\times 350\times 250}=\frac{120}{7}\approx 17.143$．

因为$17.143>10.828$，所以有99.9%的把握判断消防安全知识测试成绩与性别有关．

#### 补讲与资料勘误

（1）男生不够良好300−150=150，女生良好350−150=200，女生合计200+100=300；不够良好总250，两列350+250=600，两行300+300=600，核对无冲突。

（2）350/600=7/12是本次抽到600人的良好频率，不是原题已知整个高二只有600人；原解这一措辞照留，规范为用样本频率估计总体良好概率。后续每次在同一固定总体中等可能独立抽取并放回，故抽中良好的概率保持不变，用估计概率得到两次全良好(7/12)²=49/144。放回保持组成，独立随机抽取机制给乘积，二者理由分别写清。

（3）χ²=600×(150×100−150×200)²/(300×300×350×250)=120/7≈17.143>10.828，按题给α=.001拒绝H₀，样本支持性别与成绩类别有关。这个H₀研究一个学生上的性别和成绩；它不等于后续两次抽取事件是否独立。有关不证明性别造成掌握程度差异。

### 原例：例8：购车意向检验与分层抽样

来源：HSMA-B5-C8-D9e1bd0cb65d9-P0794-P0864。原件：专题8.3 列联表与独立性检验【八大题型】（举一反三）（人教A版2019选择性必修第三册）（解析版）.docx。

#### 原题与原解（完整保留）

【例8】（24-25高二下·江西抚州·阶段练习）为了解消费者购买新能源汽车意向与年龄是否具有相关性，某汽车公司通过问卷调查对200名消费者进行调查．数据显示200名消费者中，青年人共有125人，且中老年中愿意购买新能源车的人数是愿意购买燃油车的2倍：青年中愿意购买新能源车的人数是愿意购买燃油车的4倍．

(1)完善$2\times 2$列联表，请根据小概率值$\alpha =0.05$的独立性检验，分析消费者对新能源车和燃油车的意向购买与年龄是否有关；

| 年龄段 | 购车意向 |  | 合计 |
| --- | --- | --- | --- |
|  | 愿意购买新能源车 | 愿意购买燃油车 |  |
| 青年 |  |  |  |
| 中老年 |  |  |  |
| 合计 |  |  |  |

(2)采用分层随机抽样从愿意购买新能源车的消费者中抽取6人，再从这6人中随机抽取2人，求这2人中青年人数$X$的分布列和期望．

附：${χ}^{2}=\frac{n{\left( ad-bc\right)}^{2}}{\left( a+b\right)\left( c+d\right)\left( a+c\right)\left( b+d\right)}$，$n=a+b+c+d$．

| $\alpha $ | 0.05 | 0.01 | 0.001 |
| --- | --- | --- | --- |
| ${x}_{\alpha }$ | 3.841 | 6.635 | 10.828 |



【解题思路】（1）填写$2\times 2$列联表，求出卡方值，比较临界值即可判断；

（2）由超几何分布求出分布列及其期望.

【解答过程】（1）

| 年龄段 | 购车意向 |  | 合计 |
| --- | --- | --- | --- |
|  | 愿意购买新能源车 | 愿意购买燃油车 |  |
| 青年 | 100 | 25 | 125 |
| 中老年 | 50 | 25 | 75 |
| 合计 | 150 | 50 | 200 |

零假设${H}_{0}$：费者对新能源车和燃油车的意向购买与年龄无关，

因${χ}^{2}=\frac{200\times {\left( 100\times 25-50\times 25\right)}^{2}}{150\times 50\times 75\times 125}=\frac{40}{9}\approx 4.444>3.841$，

则根据小概率值$\alpha =0.05$的独立性检验，消费者对新能源车和燃油车的意向购买与年龄有关.

（2）愿意购买新能源车的消费者中，青年与中老年的人数之比为$2:1$，

所以采用分层随机抽样抽取的6人中，4人是青年，2人是中老年，

记抽取的2人中，青年的人数为$X$，则$X$的可能取值为0，1，2，

$P\left( X=0\right)=\frac{{C}_{2}^{2}}{{C}_{6}^{2}}=\frac{1}{15}$，$P\left( X=1\right)=\frac{{C}_{4}^{1}{C}_{2}^{1}}{{C}_{6}^{2}}=\frac{8}{15}$， $P\left( X=2\right)=\frac{{C}_{4}^{2}}{{C}_{6}^{2}}=\frac{6}{15}=\frac{2}{5}$，

所以$X$的分布列如下：

| $X$ | 0 | 1 | 2 |
| --- | --- | --- | --- |
| $P$ | $\frac{1}{15}$ | $\frac{8}{15}$ | $\frac{2}{5}$ |

$E\left( X\right)=1\times \frac{8}{15}+2\times \frac{2}{5}=\frac{4}{3}$.

#### 补讲与资料勘误

（1）青年共125人，新能源:燃油=4:1，所以新能源100、燃油25；中老年75人，2:1给50、25。合计新能源150、燃油50；χ²=200×(100×25−25×50)²/(125×75×150×50)=40/9>3.841，按给定α=.05拒绝H₀。题仅说问卷调查200人，未明示随机样本；按题算所得统计证据可保留，外推总体需要调查代表性，不能由这一步论证年龄导致偏好。

（2）抽样对象换成愿买新能源的150人；两层100:50=2:1，比例分层抽6人给青年4、中老年2。再从这固定6人等可能不放回抽2人，X=0、1、2，对应组合数1、8、6，总C₆²=15，分布1/15、8/15、2/5，和1。均值0×1/15+1×8/15+2×2/5=4/3。两次不能直接用(2/3)²当两青年概率：不放回条件下第二次组分会变化；X=2实际是C₄²/C₆²=2/5。这里复用既有超几何方法，不将独立性检验的“独立”当抽球独立条件。
