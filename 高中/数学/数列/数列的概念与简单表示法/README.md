# 数列的概念与简单表示法

数列是按确定次序排列的数，也可看成定义在正整数或其有限前段上的函数。序号n与项aₙ不同；有穷数列须保留末项编号。有限观察能提出通项猜想，完整规律还需要题给定义、递推关系或证明。

先读概念与表示，再读通项和前n项和的关系，随后处理递推、单调、最值与周期。由Sₙ求项时，a₁=S₁；n≥2才直接用aₙ=Sₙ−Sₙ₋₁。可另定义S₀=0统一书写，但不能将只在正整数有效的原公式未经验证代入0。

递推关系须有足够初值，并保证每一步根号、分母等都合法；连续算几项不能证明周期。差aₙ₊₁−aₙ须对全体合法n判断；借连续函数找最值后，还须在合法整数下标和有限端点间比较，零差可能给相邻并列项。
