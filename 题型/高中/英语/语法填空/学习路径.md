# 学习路径

**两条入口：**

- **新手 / 没有报告** → 上 [`专项课程/`](专项课程/README.md)：**一次课一个专题，13 次课**
- **已经有报告**（段位模式导出的） → 按报告走，别从头教

**课程学完之后** → 回 **YouthPractice 段位模式**随机做题、导报告，用它查缺补漏。

下面是没有报告时的系统起步顺序。

## 默认顺序

**补前置 → 会认考点 → 逐个考点突破 → 混合强化 → 整篇**

`专项课程/` 里的 14 个单元、60 个关卡就是这个顺序；单元序号是编排顺序，**不代表必须从头学**，按实际缺口选。

## 一、补前置（Unit 01 基础知识，5 关）

- 01 词性和句子作用
- 02 主语谓语和宾语
- 03 修饰语修饰谁
- 04 分句内找谓语
- 05 独立回忆必要形式

不熟就先补，一次一小块。不从一个时态的困难扩展成整套语法课。

## 二、会认考点（Unit 02 判断空格需要什么，3 关）

- 01 提示词与空格需求
- 02 无提示词看结构
- 03 判断之后写全形式

**练法**：用 `question` 出题——题干给提示词和句子，选项给"空格需要什么 / 考什么"，让他点选；**先判断方向，再填写**，两个结果分开核对。不给提示、不预选。

**过关**：连续两轮混合识别约 80%，并能说出至少两个"提示词不能直接决定答案"的例子。

## 三、逐个考点突破（Unit 03—13）

按「快速规则型 → 系统理解型 → 按题补充型」推进。每个考点的小闭环：认入口 → 学判断步骤 → 最小示范 → 独立做 → 换新材料验证。

各考点的**逐级台阶**见 `考点/` 下对应卡片（每一关一级，绝不合并）；材料里的关卡顺序如下。

- **谓语动词（Unit 03，7 关）**：01 过去的事情 → 02 完成的时间参照 → 03 写全被动 → 04 找主语中心 → 05 一般现在与正在进行 → 06 完成时的现在和过去参照 → 07 综合
- **非谓语动词（Unit 04，8 关）**：01 动词后不定式 → 02 搭配中动名词 → 03 分词修饰名词 → 04 结合结构选择 → 05 不定式表目的 → 06 动作作主语与被动 → 07 补足语 → 08 对照
- **名词（Unit 05，3 关）**：01 数量 → 02 所属 → 03 综合
- **形容词、副词与词性转换（Unit 06，5 关）**：01 形容词 → 02 副词 → 03 派生为名词 → 04 综合 → 05 派生后核对数量
- **比较等级（Unit 07，3 关）**：01 比较两个状态 → 02 最高级范围 → 03 两个变化关联
- **代词（Unit 08，4 关）**：01 物主 → 02 反身 → 03 it 形式主语 / 宾语 → 04 混合
- **冠词（Unit 09，3 关）**：01 a / an 看发音 → 02 the 限定已明确的对象 → 03 混合
- **介词（Unit 10，4 关）**：01 搭配 → 02 时间与起点 → 03 同一介词不同关系 → 04 混合
- **定语从句（Unit 11，4 关）**：01 关系代词作主语 → 02 时间名词后的缺口 → 03 所属与介词后关系词 → 04 地点名词后的缺口
- **名词性从句（Unit 12，4 关）**：01 从句作主语 → 02 宾语 / 表语从句的 what → 03 that 引出内容 → 04 是否与从句混合
- **并列句与状语从句（Unit 13，5 关）**：01 并列成分 → 02 转折 → 03 结果与条件 → 04 时间与条件 → 05 三类从句混合

**过关**：不看提示能说出主要判断顺序；新题里先认考点、再给依据；同类关键错连续两轮不重复。

## 四、混合强化与整篇（Unit 14，2 关）

两三个易混考点混合 → 随机混合 → 完整语篇（先不限时）→ 整篇 + 限时。

**答案对但考点判断错、或凭语感猜中，不算能力提升。**

## 五、整篇复盘

| 错误层级 | 表现 | 下一步 |
|---|---|---|
| 考点识别 | 没认出或认错考点 | 回识别练习 |
| 流程记忆 | 考点对，但说不出先做什么 | 学并复述标准流程 |
| 步骤执行 | 知道流程，某一步错或被跳过 | 补对应知识 + 单步变式 |
| 语境理解 | 结构可行，但句意 / 上下文判断错 | 精读相关句段 + 比较选项 |
| 执行检查 | 会做但漏看提示、主语或语境 | 固定检查清单后再限时 |

已掌握的仍要间隔复习：1 天、3～4 天、1～2 周。
