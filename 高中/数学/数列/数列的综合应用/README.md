# 数列的综合应用

建立数列模型先确定第1项代表哪个时点或对象，再把每一步的变化与前一步联系。固定差对应等差，固定倍率对应等比，“先增减固定量、再按比例变化”等过程通常先写递推，不直接判成等比。

单次量aₙ与累计量Sₙ不同；题目问总数、总距离等时先确认是否求和。递推式中先发生哪一步决定常数项与倍率的位置，初始量可能对应a₀，也可能对应a₁，必须声明并保持一致。

最终答案须还原单位、整期或整数对象数量、实际起止范围；数学根不一定合法。来源情景中的时间、倍率与规则按原题使用，结论仅在该题假设内成立。
