# 平面向量的数量积

数量积把两个向量与它们的夹角联系到一个数。它能处理长度、角度和垂直关系，结果类型和运算规律都需要单独辨清。

1. 读[数量积的定义](知识-平面向量数量积的定义.md)，理解夹角要把两个非零向量移到公共起点，数量积的符号取决于夹角。
2. 读[数量积的运算律](知识-数量积的运算律.md)，理解分配律如何展开向量平方，并区分它与普通数的乘法。
3. 读[投影与投影向量](知识-向量的投影与投影向量.md)，区分有符号的投影数值、投影长度和投影向量；投影所沿的方向必须明确。
4. 按问题选择[夹角与垂直](考点-由数量积求夹角与垂直关系.md)、[向量平方求模与参数](考点-用向量平方求模与参数.md)或[数量积和投影的范围](考点-求数量积和投影的范围.md)。

检查[误用结合律](坑点-把数量积当成向量或使用结合律.md)与[数量积为零时的零向量边界](坑点-由数量积为零直接断言两个向量有直角夹角.md)。坐标计算可接着读[坐标表示](../平面向量的基本定理及坐标表示/README.md)，实际应用见[向量应用举例](../平面向量的应用举例/README.md)。
