# 代词

**一句话概念** — 代词代替名词或名词短语；**形式由指代对象和它在句中的作用决定**。

## 怎么认

给代词，或空格需要一个**指代**（指人或指物），就走代词形式。常见三类：名词前的物主形式、动作回到自己、`it` 作形式主语 / 宾语。

**信号不是绝对规则**：`its` 不带撇号，`it's` 是 `it is / it has` 的缩写。

## 思路

**先找指代对象，再看句中作用，最后选形式。**

1. **找指代**：它代替前面哪个词？指人还是指物？单数还是复数？
2. **看作用**：在句中作主语、宾语、名词前，还是动作回到自己？
3. **选形式**：主格 / 宾格 / 形容词性物主 / 名词性物主 / 反身。
4. **代入核对**。

## 怎么讲

1. 先给概念：代词考的是"指谁 + 做什么"，不是背表格。
2. 用一句走"找指代 → 看作用 → 定形式"。
3. **基础形式不熟时先补回忆**，别直接进语境判断。
4. **常见卡点**：
   - 不找指代对象，凭语感选
   - `its` 与 `it's` 混
   - 反身代词的人称 / 数错

## 易错

**区分"指代对象"和"形式占位"。**

```text
its beauty      ← 指代事物，后面仍保留名词，不带撇号
their relatives ← 名词前的物主限定形式
ourselves       ← 动作回到自己
It is ... that  ← it 作形式主语，真正的主语在后面
```

同一类形式要按范围分别记，不默认整表都会。
