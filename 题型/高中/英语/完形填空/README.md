# 完形填空

高中英语。一篇短文挖若干空，每空四个选项，选一个。选项多是**同一词性的不同实词**，考**词义**和**上下文**，不是语法形式。

长什么样、完整示例见 [`题型介绍.md`](题型介绍.md)。

**以考点为中心。** 完形分两层：

- **词汇门槛** — 四个选项认不认识，决定这题能不能用来练方法；
- **篇章意识 + 找证据** — 先建立“谁 / 什么事 / 什么方向”，每空再靠一类证据决定。

高中题里局部几个选项都成立很常见：**局部短语能定就停手，定不了就按“句 → 前后句 → 段 → 全文”扩大找证据。**

## 边界

- 选项是同一实词的不同形式、或选虚词（连词 / 引导词 / 介词 / 冠词），考语法 → `题型/初中/英语/语法选择/`；按提示词自己写形式 → `题型/高中/英语/语法填空/`；
- 给词框选词 → `题型/初中/英语/选词填空/`；
- 多空共用一个句子选项池 → `题型/高中/英语/七选五/`。

## 怎么教

**新手一次课一个 Unit**（见 [`专项课程/`](专项课程/01-基本方法与做题流程.md)），共 14 次课：

1. 读该 Unit 的讲什么、怎么讲
2. 讲这个单元
3. 拿单元里的**例题**示范一遍
4. 让他自己做同类题；**出练习题时参考例题的形式与难度**

**有报告（段位模式导出的）就按报告走**，别按课程从头教：

1. **找卡点**——材料答案可靠吗？四个选项认识几个？作答前有没有说出“谁 / 什么事 / 方向”？
2. **只补第一个断点**——按 [`学习路径.md`](学习路径.md) 的顺序找，一次只补一个
3. **让他继续做新题**

**证据边界**：没有可靠答案时只讨论证据并标“待核验”，不判分、不统计正确率、不更新能力；答对但说不出依据（或只说“读起来顺”）不算提升；做错也不能只凭答案反推他不会哪种方法。
