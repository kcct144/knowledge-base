# 人机对话

本目录讲计算机呈现任务并录制口答的准备、理解和表达。本册6组原任务，含8个信息或情景问答小题，以及朗读、转述、话题表达各1任务；没有实际音频、示范朗读或学生录音。文字内容核对不能替代真实听说评估。

## 路由与证据边界

- 只从录音选择或填空、无需口答，归听力理解；有录制回答或朗读才走本目录。
- 朗读先查给定原文是否读全，不要求自行创作；转述依原输入和提示，话题表达依题内要点。
- 当前可核原题内容、参考语法和准备流程；发音、韵律、流利度须本人录音，机器分须真实平台结果。看稿正确不当听清证明。
- 时限、耳麦和提交方式按当地当次说明；本书例题要求原样保留，不能由外地考试类推。

## 断点诊断与最小补漏

先问做的是哪一种任务以及卡在理解、组织、说出还是设备。读得懂却说不出，先示范原词块组成一个所问句；说得出但关系错，回到人、事件和要点定位；词音问题须听具体录音再指出一个妨碍理解的点。设备异常依考试指引报告，不让学生边录边调试。

反馈先指出有证据的正确事实，再只修当前目标：例如farm采纳状态、20米单位、there回指书房或跨页末轮漏读。没有学生录音时明确目前核的是文字内容，禁止给发音分。不给万能长句或固定语速数字当全国评分线。

## 练习与结束

学生要求练时先找题型练习及实际音频；当前未建可播放练习，不拿二维码当音频。新音频或录音需用户提供或依授权获取。内容与表达目标达到即停止，不强迫反复重读整篇；能在不同原任务独立完成并说明依据才作进阶证据。
