# 排除

**一句话概念** — 先排除有明确冲突的选项，再比较剩余选项；排除的依据要能说清，不能只说“感觉不对”。

## 怎么认

选项之间有**明显冲突**时用。冲突可以是：词义不合、搭配不成立、人物不一致、褒贬方向冲突、上下文矛盾。

## 思路

1. 先排除有明确冲突的选项，并说出依据；
2. 再比较剩下的选项，而不是排掉一个就以为答案确定；
3. 两个都说得通时，交回找线索或看话题。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 区分两种情况 | 说出“我知道它不合适”还是“我只是不认识它” | 找冲突依据 |
| L1 找明确冲突 | 用词义、搭配、人物或褒贬方向排除 | 比较剩余项 |
| L2 比较剩余项 | 两个都说得通时，交回找线索或看话题 | — |

**默认停在 L1。**

## 怎么讲

1. 先给上面那句话；
2. 用一道题走一遍“找冲突 → 排除 → 比较剩余”；
3. 只讲当前台阶；
4. **常见卡点**：
   - 不认识某选项就排除，碰巧做对当掌握；
   - 排掉一个选项就收工，没和剩余项比较。

## 易错

**排除法不能弥补大量生词。** 不认识某选项时只能说“暂时无法判断”，不能把“不认识”当作“这个词一定不对”。
排除理由必须是题目里的证据，不是“读着不顺”。
