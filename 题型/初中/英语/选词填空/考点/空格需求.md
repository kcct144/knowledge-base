# 空格需求

**一句话概念** — 截取空格前后最小的有意义结构，判断这里需要什么词性，再回词框缩候选。先看空格要什么，再看词框有什么。

## 怎么认

题感：拿到一个空，先不看词框，先问"这个位置缺什么"。

| 空格附近的情况 | 常见需求 | 不能机械套用的边界 |
|---|---|---|
| `a / an / the / 限定词 + ____` | 名词，或形容词 + 后面的名词 | 必须继续看空格后是否已有名词 |
| `形容词 + ____` | 常见为名词 | 也要确认是不是固定结构或并列成分 |
| `介词 + ____` | 名词、代词或动名词 | 先确认前面的词确实是介词 |
| `主语 + ____` | 常见为谓语动词 | 还要检查句中是否已有谓语核心 |
| `情态动词 + ____` | 空格直接承担后续动词时通常是动词原形 | 若后面已有主要动词，空格可能是修饰它的副词 |
| `to + ____` | 常见为动词原形 | `to` 也可能是介词，此时接名词或动名词 |
| `be + ____` | 形容词、名词、现在分词或过去分词等 | 结合主语、结构和意思判断，不能只看 `be` |
| `常见系动词 + ____` | 常见为形容词 | 也可能接名词短语表示身份 |
| `very / so / too + ____` | 形容词或副词 | 看它说明状态还是修饰动作、形容词或副词 |
| `____ + 名词` | 常见为形容词、限定词，也可能名词修饰名词 | 继续检查词义和固定表达 |
| `完整分句 + ____ + 完整分句` | 连词或起连接作用的表达 | 检查标点、前后结构和并列 / 转折 / 因果 |

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L2 名词 / 动词 | `a/the + ____`、主语 + ____：判名词还是动作 | 形容词副词细分 |
| L2 形副 | `very/so/too + ____`、修饰关系：判形容词还是副词 | 感官系动词 |
| L2 功能词 | 介词、连词、代词、限定词等明显功能词位置 | 复杂从句引导词 |
| L3 歧义边界 | `to`、`be` 等一个结构多种可能时，标为后续边界 | 一次讲完所有例外 |
| L6 一词多性 | 结构无法唯一确定时，保留多候选，回语境判断 | 只在真题需要时 |

**默认停在 L2。** 结构判断后还必须代入意思和全文，结构只用于缩小候选。

## 怎么讲

1. 先给上面那句概念，拿一个空截结构示范
2. 只讲当前结构，别把整张表一次讲完
3. **常见卡点**：
   - 不看结构，逐句翻译整篇后才敢填
   - 只看空格前一个词，不看后面有没有名词
   - 看到 `to` 就填动词原形，看到 `be` 就填形容词

## 易错（题面看不出来的坑）

- `a/the + ____` 后可能直接是名词，也可能是"形容词 + 名词"，必须继续看后面。
- `to + ____` 常接动词原形，但介词 `to` 后接名词或动名词。
- `情态动词 + ____`：后面若已有主要动词，空格可能是副词。
- `to / be` 等歧义处标为后续边界，不因基础信号就机械下结论。
