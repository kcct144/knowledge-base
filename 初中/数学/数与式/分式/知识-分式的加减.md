## 讲解

### 是什么

同分母分式具有相同的“每份大小”，直接加减分子，分母保持不变；异分母先通分成为同分母，再合分子。减一个多项式分子，要把它整体放在括号中。加减后的结果还需因式分解并约分，保留原条件。

### 怎么来的

同分母$A/D+B/D=(A+B)/D$，来自把和乘相同的倒数1/D并使用分配律。减法同理是$(A-B)/D$，B若含两项，两项都被外负号乘到。异分母没有共同的单位，先用基本性质统一分母，再利用同分母规则；不能各自加减分子分母得到所谓新分数。

### 什么时候能用

通分前可先分解分母、约分，运算中用相反因式把分母统一方向。多项式分子先保持括号，完成去括号、合并同类项后再判断能否约。分母之和或差不参与同分母加减；若公分母零则整个讨论不成立。

## 例题

### 同分母相减把第二分子整体去括号

> 来源ID Q06-18；第6章分式；51-100/full.md 第2481–2481行。原答案与解析定位：51-100/full.md 第2483–2485行。

例3 计算: $\frac{4}{x-2}-\frac{x+2}{x-2}.$

**原资料答案与解析：**

解析 $\frac{4}{x - 2} -\frac{x + 2}{x - 2} = \frac{4 - (x + 2)}{x - 2} = \frac{2 - x}{x - 2}$ $= -1.$

注意 同分母分式相减且减式的分子为多项式时，应将减式的分子用括号括起来.本题中应将 $x + 2$ 用括号括起来.

**展开解析（依据原详解补足理由与步骤）：**

分母相同且x≠2，分子为$4-(x+2)$。外减号乘到括号内两项，得到$4-x-2=2-x=-(x-2)$。约去非零x−2得−1。若写成4−x+2，错在第二分子的常数项没有同时变号；分母不能相减为0。

### 相反分母与三项异分母的加减

> 来源ID Q06-23；第6章分式；51-100/full.md 第2631–2633行。原答案与解析定位：51-100/full.md 第2635–2637行。

例2 计算：

(1) $\frac{a - 3b}{a - b} -\frac{a + b}{b - a}$ . (2) $\frac{5c}{6a^2b} +\frac{7a}{8b^2c} -\frac{b}{12a^2c}$ . (3) $\frac{x^2 + 4x}{x^2 + 2x} +\frac{x^2 - 4}{x^2 + 4x + 4}$ .

**原资料答案与解析：**

解析（1）原式 $= \frac{a - 3b}{a - b} +\frac{a + b}{a - b} = \frac{2(a - b)}{a - b} = 2.$ （2）原式 $= \frac{20bc^2}{24a^2b^2c} +\frac{21a^3}{24a^2b^2c} -\frac{2b^3}{24a^2b^2c} = \frac{20bc^2 + 21a^3 - 2b^3}{24a^2b^2c}.$

(3) 原式 $= \frac{x(x + 4)}{x(x + 2)} + \frac{(x + 2)(x - 2)}{(x + 2)^2} = \frac{x + 4}{x + 2} + \frac{x - 2}{x + 2} = \frac{x + 4 + x - 2}{x + 2} = \frac{2x + 2}{x + 2}$ .

**展开解析（依据原详解补足理由与步骤）：**

（1）b−a=−(a−b)，所以减$(a+b)/(b-a)$等于加$(a+b)/(a-b)$。合分子a−3b+a+b=2a−2b=2(a−b)，约得2，a≠b。

（2）公分母$24a^2b^2c$，各原分母要求abc非零。三分母分别缺4bc、3a²、2b²，对应分子成为20bc²、21a³、2b³，保持第三项减号，得$(20bc^2+21a^3-2b^3)/(24a^2b^2c)$。

（3）原式要求x≠0、−2。第一项$x(x+4)/[x(x+2)]=(x+4)/(x+2)$；第二项$(x-2)(x+2)/(x+2)^2=(x-2)/(x+2)$。同分母合分子x+4+x−2=2x+2，得$(2x+2)/(x+2)$。原x=0禁值必须仍保留。

## 易错

4−(x+2)是4−x−2，不是4−x+2。分母b−a换成a−b会带一个负号，外减号与这个负号相遇变加。通分后减的整个分子仍要括号。
