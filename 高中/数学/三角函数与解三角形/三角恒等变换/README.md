# 三角恒等变换

恒等变换要同时检查角、函数名称和合法条件。先看目标需要什么结构，再选择公式，避免只凭式子长得相似就替换。

1. [同角三角函数的基本关系](知识-同角三角函数的基本关系.md)：从单位圆联系正弦、余弦和正切，理解平方关系为什么不能直接决定符号。
2. [两角和与差的三角函数公式](知识-两角和与差的三角函数公式.md)：理解和差角公式的几何来源，再练拆角、配角和公式逆用。
3. [二倍角公式与降幂关系](知识-二倍角公式与降幂关系.md)：把同一个角代入和差公式，区分升角、降幂与保留合法条件。
4. [辅助角公式](知识-辅助角公式.md)：把正弦与余弦的线性组合统一成一个三角函数，确定系数、角和范围。

随后读[恒等式的证明](考点-三角恒等式的证明.md)，学习从较复杂的一边出发、保持等价并说明每次变形的依据。求值和实际应用还需结合角的范围；正切与分式中的分母限制不能在化简后丢掉。
