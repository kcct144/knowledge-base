# 褒贬方向

**一句话概念** — 选项是形容词时，先按**正面 / 负面 / 中性**分类，再看人物态度和故事走向，把方向不对的先排除。

## 怎么认

- 选项是形容词，空在描述心情、评价、态度；
- 局部词义都说不清，但能感觉出句子的情感基调。

例：老师认可学生的成果，描述心情的形容词通常应与正面语境一致。

## 思路

1. 把候选形容词分正面 / 负面 / 中性；
2. 用人物态度和故事走向排除方向不符的；
3. **褒贬只能缩小范围**：两个正面词之间，仍要比较准确词义、搭配或上下文。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 分方向 | 把形容词按正面 / 负面 / 中性分类 | 具体词义 |
| L1 对齐态度 | 用人物态度和故事走向排除方向不符的 | 两个同方向词的精辨 |
| L2 精辨 | 两个同向词比较对象、程度、动作方向等 | 高中 [`词义精辨`](词义精辨.md) |

**默认停在 L1**；两个同向词分不清时转 [`词义精辨`](词义精辨.md)，别把褒贬当终点。

## 怎么讲

1. 先给概念：**用态度方向快速缩范围**；
2. 用一个“正面 / 负面”对比句走一遍；
3. **常见卡点**：
   - 形容词只看褒贬，不比较具体含义；
   - 把“褒义 / 贬义”当精辨终点。

## 易错

**方向对了，词未必对。** 两个正面词、两个负面词仍需比较；态度还要分**谁对什么、什么时候**，不要用全文“作者态度”一个标签盖住。
