# 要点（审题与切题）

**一句话概念** — 切题：写的是题目要的。正常审题看六项——**形式、主题、要点、人称、时态、给定内容**；这六项帮成文，不是动笔前必须通过的考试。

## 怎么认

- 能成篇，但主题偏了或明显漏点；
- 题目要求的要点没有一一落实；
- 人称、主要时态或给定格式没对上。

## 思路

1. **圈出六项**：写作形式；全文主要写什么；题目要求写的要点；主要人称（I / you / we）；主要时态（现在 / 过去 / 将来）；题目给的称呼、开头、结尾、署名；
2. **一一对应**：一个题目要点对应提纲中的一项；
3. **点题**：开头或结尾提到主题；
4. **保留给定内容**：称呼、开头、结尾不删不改；
5. **先补最明显的漏点**，不同时重写全文。

学生一看这些项目就更不敢写时，先只问两句：**这篇主要写什么？你现在能想到哪两三件事？** 先动起来，其余等成篇后再补。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 只抓主题 | 说清主要写什么 | 不要求列全六项 |
| L1 要点对应 | 一个题目要点对应提纲一项 | 人称/时态/给定内容 |
| L2 六项 | 形式、人称、时态、给定内容都照顾 | — |
| L3 无原题自查 | 没有原题也能说出待核对项 | — |

**默认停在 L1。**

## 怎么讲

1. 先给六项概念，够用就行；
2. 用当次题目走一遍「圈六项 → 要点对应」；
3. 只补当前缺失的那一项；
4. **常见卡点**：
   - 一审题就卡住 → 降级为「主题 + 两三个内容点」，先成篇；
   - 写得出但偏题 → 先对照题目要点，找最明显的漏点。

## 易错

**没有原题时声称已切题。** 学生没给原题，只能做基础正确性和已确认内容的局部修改，并标明「**切题性和必写点仍待核对**」。
**把助手代选的内容当成题干事实。** 题目未规定而由助手补出的主题、时间、方式或情节，要明确称为「**代选内容**」或「建议」，不虚构学生真实经历。
