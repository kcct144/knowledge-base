# 平面向量的实际背景及基本概念

向量用大小和方向共同描述一个量。学习时先分清“向量本身”“表示它的有向线段”和“向量的模”，后面的运算才能有明确对象。

1. 读[平面向量的概念与模](知识-平面向量的概念与模.md)，认识自由向量、始点终点和长度；向量可以平移，模才是可以比较大小的数。
2. 读[零向量与单位向量](知识-零向量与单位向量.md)，区分教材对零向量方向的约定与非零向量的实际方向，注意单位向量的定义不限定方向。
3. 读[相等向量与共线向量](知识-相等向量与共线向量.md)，分别检查长度和方向；几条有向线段的位置关系不能代替向量关系。
4. 用[由方向与长度判断向量关系](考点-由方向与长度判断向量关系.md)练习从定义作判断，再查[把模相等当成向量相等](坑点-把模相等当成向量相等.md)和[给零向量指定方向或夹角](坑点-给零向量指定方向或夹角.md)中的边界。
