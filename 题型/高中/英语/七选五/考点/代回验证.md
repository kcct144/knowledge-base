# 代回验证

**一句话概念** — 任何正面线索都只能先**建立候选**；候选最终都要**代回必要上下文和全文主线**验证。

## 怎么认（先看多大范围）

默认先读空格相邻的必要上下文；证据不足时再扩大：

    相邻句 → 当前段 → 前后段 → 全文主线

- 中间空通常需要检查前后两侧；
- 文章首尾天然少一侧；
- 段首或段尾有时需要跨段判断；
- 个别空可能由一侧的唯一强约束和全文结构共同决定。

**“前后都看”是默认动作**，不是要求每个空必须凑出两条同等强度的证据。

## 思路（代回检查清单）

放回必要上下文，逐条检查：

- 指代是否有明确对象；
- `it` 是否真的回指前文，而不是天气、时间、距离、形式主语 / 形式宾语、强调结构等非回指用法；
- 叙述者、发言者、参与者和视角的延续或切换是否清楚；
- 句子是否接住前文并自然推进后文；
- 逻辑方向、条件或例外范围是否正确，后文所需的过程环节和语义前提是否成立；
- 内容是否符合本段功能和全文主线；
- 是否有其他候选在这里证据更强。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 相邻句 | 用紧邻空格的前后句验证候选 | 段与段 |
| L1 当前段 | 证据不足时扩大到整段 | 前后段 |
| L2 前后段 | 跨段检查功能与连贯 | 全文主线 |
| L3 全文主线 | 用全文主线和非回指 `it` 等边界排除“看似合理”的候选 | — |

**默认停在 L1。**

## 怎么讲

1. 先给那句概念；
2. 用最简例子走一遍“放回去 → 接住前文了吗 → 推进后文了吗”；
3. 只讲当前台阶；
4. **常见卡点**：
   - 只看同词，或只看一侧；
   - 选项看似合理，却放回不连贯；
   - 证据不足时不主动扩大阅读范围。

## 易错

**强行让非回指 `it` 寻找前文名词**：天气、时间、距离、形式主语 / 形式宾语、强调结构里的 `it` 都不回指，先看它在句中的语法和语义作用。
