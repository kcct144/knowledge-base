# 回答问题

读材料后按问题书面输出信息，可为细节、推断、指代、归纳或开放回答。本册此章4组独立回答材料与2组综合任务；综合任务按具体小题另分填句和翻译，不套同一回答模板。

无选项问答走本目录；选择字母走阅读理解；将若干信息配同池走配对阅读。原答是参考，事实必须有原文支持，开放题可在任务内有其他合理表达；不虚构分值或唯一逐字评分规则。

先定位断点：问词读错、范围圈错、原文位置找错、推断/归纳缺一步，或语言输出形式错。只补第一个断点；如Happy题能定位曲名，先让其用原短答完成，不扩成治疗或歌曲知识课。反馈把事实证据与拼写句法分开，不把语法流畅当理解正确。

看清具体词数、方面、句式要求。缺可靠原答时只讨论证据，不能判分更新状态。本次只建老师材料，没有学生实答；练习依学生意愿并用真实题，目标判断独立成立后结束。

完整知识与例证见[条目索引](条目索引.md)，方法入口见[考点列表](考点列表.md)。
