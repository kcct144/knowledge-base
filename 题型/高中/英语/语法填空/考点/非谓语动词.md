# 非谓语动词

**一句话概念** — 一个分句只能有一个谓语；动词不做谓语时，用**不定式、动名词或分词**，形式由结构和逻辑关系决定。

## 怎么认

给动词，但**本分句已有谓语**，或空位落在搭配、主语、宾语、定语、状语、补语的位置，这个空多半填非谓语。

**信号不是绝对规则**：句子可以有多个分句和并列结构，**"句里已有动词就一定填非谓语"是错的**，要分清是哪一分句的谓语。

## 思路

**先确认本分句有没有谓语，再看结构要什么，最后判逻辑关系。**

1. **定分句**：本分句的谓语已经有了吗？
2. **看结构**：这里需要搭配、主语、宾语、定语、状语还是补语？
3. **判逻辑**：动作的逻辑主语是谁？主动还是被动？
4. **选形式**：to do / doing / done，必要时用完成式或被动式。
5. **代回核对**。

## 怎么讲

1. 先给概念：一个分句一个谓语，多出来的动词要变成非谓语。
2. 用"找本分句谓语 → 看结构 → 判主动被动"的顺序示范。
3. **常见卡点**：
   - 见动词就套时态，没查本分句是否已有谓语
   - 把 `to` 一律当不定式标志（也可能是介词）
   - 忽略逻辑主语，主动被动判错
   - 固定搭配不熟，只背形式名称

## 易错

**搭配要连意义一起记，不能推成"所有动词后都接 to do"。**

```text
to do      ← 常接在 hesitate / attempt / agree 后
doing      ← 常在 invest...in / succeed in / postpone 后
done       ← 与逻辑主语是被动关系时常表被动或完成
```

定语、状语、补语都要落回**被修饰 / 补充的对象**，不能只看形式。
