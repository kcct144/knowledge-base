## 讲解

### 是什么

so that、in order that可引出为了实现的目标小句，常含can/could等能力或可能表达。目的说明动作想达到什么，不证明目标已经成功；so that有时也可表达结果，须读具体关系。

### 怎么来的

原I put it here so that he can see it when he comes.先放在这里，后说明目的是他来时能看见；when he comes又是内层时间条件，不因小句嵌套便删连接。I get up early in order that I can catch the early bus.=I get up early so that I can catch the early bus.用早起服务于赶早班车目标。

can表示能做到，不能据句法硬说实际已赶上。目的从句有完整I can catch，而in order to若使用则是另一个不定式框架，不能只删that仍留I can。原书so that只能句中是常见后置用法的过窄概括，规范语法资料也允许较正式的前置目的小句；这里保留原后置例，不凭位置绝对排除。

主将从现也不能套全部目的从句，规范so that目的可见现在式或will等情态，当前can原例正说明目标可达性。这些补充用来说明边界，不把外部例句当原练习。

### 什么时候能用

先找实现目标的行动和期望结果，再辨目的还是实际后果。若要选so that或so...that...，还要看有没有程度形容词和被隔开的that，不能只比较两个词是否出现。原赶车未给时刻，不编迟到分钟。

### 复合句节补充：同主语转换与情态目标

She dresses like an angel so that/in order that everyone will notice her.中穿着者she与注意者everyone不同，目的小句需要明确不同主体，不能随意删everyone改成she自己注意。will在目的内容中可用，不是未来条件从句的主将从现限制。

He worked day and night in order that he could succeed.→He worked day and night in order to succeed.两个动作执行者同为he，上层work的目标可由to succeed表示；删去he could不意味着将目标当成已经成功。We’ll sit in the front of the hall so that we can hear more clearly.→...so as to/in order to hear more clearly.同样保留we的听清目标及大厅内部前面位置。

Take this medicine so that you can become well soon.和She spoke very slowly in order that we could follow her.均按原语言例说明情态能力与目标，不把语法目的当医学疗效或确已听懂的证据。so that常后置是倾向，原本节已允许目的前置，不沿前章过窄“只能句中”。

## 例题

从属连词；意义及用法；例句

so that；意为“为了;以便”,只能用于句中,引导的从句中常含有 can、could、may、might、would 等情态动词；I put it here so that he can see it when he comes.我把它放在这儿,以便他来时能看见。

in order that；意为“为了;以便”,可用于句首或句中;有时可与 so that 互换使用;引导的从句中常含有 can、could、may、might、would 等情态动词；I get up early in order that I can catch the early bus.=I get up early so that I can catch the early bus.我早起是为了能赶上早班车。

原同主语转换：He worked day and night in order that he could succeed.→He worked day and night in order to succeed.；We’ll sit in the front of the hall so that we can hear more clearly.→We’ll sit in the front of the hall so as to/in order to hear more clearly.。原另三例见讲解，全部人物及比较程度保留。

## 易错

- **目的可以达成就等于已达成**：can说明能力/可能，不是事实完成。
- **so that只能中间**：原表过窄，规范允许较正式前置。
- **so that与so tired that只差空格**：目的与程度结果结构不同。
