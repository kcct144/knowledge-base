## 讲解

### 是什么

$NaOH$白色腐蚀性固体，吸水潮解、溶解放热；敞口吸收$CO_{2}$生成$Na_{2}CO_{3}$发生化学变质。

### 怎么来的

吸水只改变物态或浓度，不产生$Na_{2}CO_{3}$；$CO_{2}$+2$NaOH$反应才变质。部分变质有$NaOH$和$Na_{2}CO_{3}$，完全变质模型只有$Na_{2}CO_{3}$，溶液仍可能碱性。

### 什么时候能用

密封防潮防$CO_{2}$。$NaOH$样品质量变大不全因变质，也可能吸水；定量需干燥二组分等条件。原涂硼酸急救说法纠正为流水冲洗和医疗指导。

### 原氢氧化钠变质检验除杂表

> 来源ID Q10-31；第十单元常见的酸碱盐；151-200/full.md 第194–218行。原答案与解析定位：151-200/full.md 第194–218行。

1. 变质的实质: $2 \mathrm{NaOH} + \mathrm{CO}_{2} = \mathrm{Na}_{2} \mathrm{CO}_{3} + \mathrm{H}_{2} \mathrm{O}$ 。

2. 成分分析: ①没有变质, 为 $\mathrm{NaOH}$ ; ②部分变质, 为 $\mathrm{NaOH} 、 \mathrm{Na}_{2} \mathrm{CO}_{3}$ ; ③完全变质, 为 $\mathrm{Na}_{2} \mathrm{CO}_{3}$ 。

3. 验证方法

(1) 验证 $NaOH$ 固体是否变质, 只需验证样品中是否存在 $Na_{2}CO_{3}$ 即可, 方法如下。

| 试剂 | 操作及现象 | 原理 |
| --- | --- | --- |
| 酸(如稀盐酸或稀硫酸) | 取样品加水溶解,加入稀盐酸或稀硫酸,有气泡产生,则证明样品中存在 $Na_{2}CO_{3}$ ,$NaOH$变质 | $Na_{2}CO_{3} + 2HCl = 2NaCl + H_{2}O + CO_{2} \uparrow$  或  $Na_{2}CO_{3} + H_{2}SO_{4} = Na_{2}SO_{4} + H_{2}O + CO_{2} \uparrow$ |
| 碱(如氢氧化钙或氢氧化钡) | 取样品加水溶解,加入氢氧化钙溶液或氢氧化钡溶液,有白色沉淀产生,则证明样品中存在 $Na_{2}CO_{3}$ ,$NaOH$变质 | $Na_{2}CO_{3} + Ca(OH)_{2} = CaCO_{3} \downarrow + 2NaOH$  或  $Na_{2}CO_{3} + Ba(OH)_{2} = BaCO_{3} \downarrow + 2NaOH$ |
| 盐(如氯化钙或氯化钡) | 取样品加水溶解,加入氯化钙溶液或氯化钡溶液,有白色沉淀产生,则证明样品中存在 $Na_{2}CO_{3}$ ,$NaOH$变质 | $Na_{2}CO_{3} + CaCl_{2} = CaCO_{3} \downarrow + 2NaCl$  或  $Na_{2}CO_{3} + BaCl_{2} = BaCO_{3} \downarrow + 2NaCl$ |

(2) 验证 $NaOH$ 溶液的变质程度, 需分别检验 $NaOH$、 $Na_{2}CO_{3}$ 。

操作及现象:①向溶液中加入过量的 $CaCl_{2}$ 溶液(或 $BaCl_{2}$ 溶液),有白色沉淀产生,则证明溶液中存在 $Na_{2}CO_{3}$ 。

②过滤,向滤液中滴加无色酚酞溶液,若溶液变红,则有 $NaOH$,说明 $NaOH$ 溶液部分变质;若溶液仍为无色,则无 $NaOH$,说明 $NaOH$ 溶液全部变质。

温馨提示 a.问题的关键是要确认溶液中是否有 $\mathrm{NaOH}$ , 在检验 $\mathrm{NaOH}$ 时必须排除 $\mathrm{Na}_{2} \mathrm{CO}_{3}$ 的干扰, 因为 $\mathrm{Na}_{2} \mathrm{CO}_{3}$ 溶液显碱性, 也能使酚酞溶液变红。

b. 在除去 $Na_{2}CO_{3}$ 时不能用盐酸, 因为盐酸也会与 $NaOH$ 反应; 也不能用 $\mathrm{Ca(OH)}_{2}$ 溶液, 因为 $Na_{2}CO_{3} + Ca(OH)_{2} = CaCO_{3} \downarrow + 2NaOH$ , 会生成 $NaOH$, 干扰 $NaOH$ 的检验; 应选用 $\mathrm{CaCl}_{2}$ (或 $BaCl_{2}$ ) 溶液除去 $Na_{2}CO_{3}$ , 因为 $Na_{2}CO_{3} + CaCl_{2} = CaCO_{3} \downarrow + 2NaCl$ (或 $Na_{2}CO_{3} + BaCl_{2} = BaCO_{3} \downarrow + 2NaCl$ ), 没有碱性物质生成, 不会干扰 $NaOH$ 的检验。

4.除杂:$NaOH$ 溶液中混有 $Na_{2}CO_{3}$ 。

(1)试剂:适量的 $\mathrm{Ca(OH)}_{2}$ 溶液或 $\mathrm{Ba(OH)}_{2}$ 溶液。  
(2) 原理: $\mathrm{Na_{2}CO_{3}+Ca(OH)_{2}=CaCO_{3}\downarrow+2NaOH}$ 或 $\mathrm{Na_{2}CO_{3}+Ba(OH)_{2}=BaCO_{3}\downarrow+2NaOH}$   
(3) 操作方法: 取变质的 $NaOH$ 溶液, 加入适量的 $\mathrm{Ca(OH)}_{2}$ 溶液 [或 $\mathrm{Ba(OH)}_{2}$ 溶液], 过滤, 所得滤液即为 $NaOH$ 溶液。

**原资料答案与解析：**

1. 变质的实质: $2 \mathrm{NaOH} + \mathrm{CO}_{2} = \mathrm{Na}_{2} \mathrm{CO}_{3} + \mathrm{H}_{2} \mathrm{O}$ 。

2. 成分分析: ①没有变质, 为 $\mathrm{NaOH}$ ; ②部分变质, 为 $\mathrm{NaOH} 、 \mathrm{Na}_{2} \mathrm{CO}_{3}$ ; ③完全变质, 为 $\mathrm{Na}_{2} \mathrm{CO}_{3}$ 。

3. 验证方法

(1) 验证 $NaOH$ 固体是否变质, 只需验证样品中是否存在 $Na_{2}CO_{3}$ 即可, 方法如下。

| 试剂 | 操作及现象 | 原理 |
| --- | --- | --- |
| 酸(如稀盐酸或稀硫酸) | 取样品加水溶解,加入稀盐酸或稀硫酸,有气泡产生,则证明样品中存在 $Na_{2}CO_{3}$ ,$NaOH$变质 | $Na_{2}CO_{3} + 2HCl = 2NaCl + H_{2}O + CO_{2} \uparrow$  或  $Na_{2}CO_{3} + H_{2}SO_{4} = Na_{2}SO_{4} + H_{2}O + CO_{2} \uparrow$ |
| 碱(如氢氧化钙或氢氧化钡) | 取样品加水溶解,加入氢氧化钙溶液或氢氧化钡溶液,有白色沉淀产生,则证明样品中存在 $Na_{2}CO_{3}$ ,$NaOH$变质 | $Na_{2}CO_{3} + Ca(OH)_{2} = CaCO_{3} \downarrow + 2NaOH$  或  $Na_{2}CO_{3} + Ba(OH)_{2} = BaCO_{3} \downarrow + 2NaOH$ |
| 盐(如氯化钙或氯化钡) | 取样品加水溶解,加入氯化钙溶液或氯化钡溶液,有白色沉淀产生,则证明样品中存在 $Na_{2}CO_{3}$ ,$NaOH$变质 | $Na_{2}CO_{3} + CaCl_{2} = CaCO_{3} \downarrow + 2NaCl$  或  $Na_{2}CO_{3} + BaCl_{2} = BaCO_{3} \downarrow + 2NaCl$ |

(2) 验证 $NaOH$ 溶液的变质程度, 需分别检验 $NaOH$、 $Na_{2}CO_{3}$ 。

操作及现象:①向溶液中加入过量的 $CaCl_{2}$ 溶液(或 $BaCl_{2}$ 溶液),有白色沉淀产生,则证明溶液中存在 $Na_{2}CO_{3}$ 。

②过滤,向滤液中滴加无色酚酞溶液,若溶液变红,则有 $NaOH$,说明 $NaOH$ 溶液部分变质;若溶液仍为无色,则无 $NaOH$,说明 $NaOH$ 溶液全部变质。

温馨提示 a.问题的关键是要确认溶液中是否有 $\mathrm{NaOH}$ , 在检验 $\mathrm{NaOH}$ 时必须排除 $\mathrm{Na}_{2} \mathrm{CO}_{3}$ 的干扰, 因为 $\mathrm{Na}_{2} \mathrm{CO}_{3}$ 溶液显碱性, 也能使酚酞溶液变红。

b. 在除去 $Na_{2}CO_{3}$ 时不能用盐酸, 因为盐酸也会与 $NaOH$ 反应; 也不能用 $\mathrm{Ca(OH)}_{2}$ 溶液, 因为 $Na_{2}CO_{3} + Ca(OH)_{2} = CaCO_{3} \downarrow + 2NaOH$ , 会生成 $NaOH$, 干扰 $NaOH$ 的检验; 应选用 $\mathrm{CaCl}_{2}$ (或 $BaCl_{2}$ ) 溶液除去 $Na_{2}CO_{3}$ , 因为 $Na_{2}CO_{3} + CaCl_{2} = CaCO_{3} \downarrow + 2NaCl$ (或 $Na_{2}CO_{3} + BaCl_{2} = BaCO_{3} \downarrow + 2NaCl$ ), 没有碱性物质生成, 不会干扰 $NaOH$ 的检验。

4.除杂:$NaOH$ 溶液中混有 $Na_{2}CO_{3}$ 。

(1)试剂:适量的 $\mathrm{Ca(OH)}_{2}$ 溶液或 $\mathrm{Ba(OH)}_{2}$ 溶液。  
(2) 原理: $\mathrm{Na_{2}CO_{3}+Ca(OH)_{2}=CaCO_{3}\downarrow+2NaOH}$ 或 $\mathrm{Na_{2}CO_{3}+Ba(OH)_{2}=BaCO_{3}\downarrow+2NaOH}$   
(3) 操作方法: 取变质的 $NaOH$ 溶液, 加入适量的 $\mathrm{Ca(OH)}_{2}$ 溶液 [或 $\mathrm{Ba(OH)}_{2}$ 溶液], 过滤, 所得滤液即为 $NaOH$ 溶液。

**展开解析（依据原详解补足理由与步骤）：**

原三目标区别。是否变质检$Na_{2}CO_{3}$即可；程度必须先用过量中性$CaCl_{2}$/$BaCl_{2}$除碳酸根、过滤，再用酚酞看原余$NaOH$。加酸会耗$NaOH$，$Ca(OH)_{2}$会新生$NaOH$，都不能用于该余碱验证。恢复$NaOH$作为主物的除杂反而可用适量$Ca(OH)_{2}$，生成$NaOH$不算引新杂；但过量$Ca(OH)_{2}$也会留新杂，要适量。

## 易错

分类、酸碱性、强弱、浓稀、溶解性分别判断。原例与纠正内容分开。
