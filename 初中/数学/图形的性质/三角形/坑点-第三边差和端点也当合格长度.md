## 错法

原2/7选项5或9、原3/5选项2，长度正就被当可能边；没有核严格不等式。

## 正解

下界绝对差、上界和都不能取等号，两圆相切使三点共线无三角区域。2/7只选6，3/5只选7；每项明确退化还是过短过长。

## 例题

### 2与7的第三边四选一严格范围

> 来源ID Q19-13；第19章三角形；201-250/full.md 第2235–2243行。原答案与解析定位：201-250/full.md 第2245–2247行。

例1 若长度分别为 2,7,x 的三条线段能组成一个三角形,则 x 的值可以是 ( )

A.4

B.5

C.6

D.9

**原资料答案与解析：**

解析 $\because$ 三角形的三边长分别为 $2,7,x,\therefore 7 - 2 <   x <   7 + 2$ ，即 $5 <   x <   9.$ 故选C.

答案 C

**展开解析（依据原详解补足理由与步骤）：**

两边2、7给|7−2|<x<7+2，即5<x<9。A4小于下限，不能闭合；B5等于差，三点共线退化，排除；C6严格落内部，正确；D9等于和，也退化，排除。选C。长度为正且两个端点都是严格边界，不可把>改成≥。

### 3与5木棒第三边范围逐项验

> 来源ID Q19-16；第19章三角形；201-250/full.md 第2333–2341行。原答案与解析定位：201-250/full.md 第2303–2305行。

例1（2024 江苏淮安）用一根小木棒与两根长度分别为 3 cm、5 cm 的小木棒组成三角形,则这根小木棒的长度可以是 ( )

A.9 cm

B.7 cm

C.2 cm

D.1 cm

**原资料答案与解析：**

例1 解析 设小木棒的长度为 x cm, 则 5-3<x<5+3, 即 2<x<8. 故选 B.

答案 B

**展开解析（依据原详解补足理由与步骤）：**

设第三棒x，|5−3|<x<5+3，所以2<x<8。A9超过和8，不能闭合；B7在严格区间内，正确；C2等于差，退化；D1小于差，不可闭合。选B。三棒首尾顺接且不共线是三角形，不能只看两根棒够不够长。
