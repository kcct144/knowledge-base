# 排除

**一句话概念** — 先排除有**明确冲突**的选项，再比较剩下的。冲突可以来自词义、搭配、人物、褒贬方向或上下文矛盾。

## 怎么认

有一眼就不对的选项，就用排除法先清场：

- 词义和句子 / 语境明显不符；
- 搭配不成立；
- 与人物身份、动作发出者不一致；
- 褒贬方向和人物态度 / 故事走向冲突；
- 与前后文事实矛盾。

## 思路

1. 逐项检查，能明确排除就**说出理由**；
2. 再在剩余选项间比较；
3. 不能因为“不认识”就排除——不认识只能说“暂时无法判断”。

**排除法不能弥补大量生词**：生词一多，先回 [`词汇门槛`](词汇门槛.md)。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 明确冲突 | 排除词义 / 搭配 / 人物 / 褒贬 / 上下文明显冲突的选项 | 剩余比较 |
| L1 剩余比较 | 在剩余选项间用短语、句、段、全文证据比较 | 高中句篇逻辑 |

**默认停在 L1。**

## 怎么讲

1. 先给概念：**排除要有理由，不是“感觉不对”**；
2. 用一组选项走一遍“逐个检查冲突 → 说理由”；
3. **常见卡点**：
   - 把不认识的选项当“一定不对”；
   - 只说“不合适”，说不出哪条冲突；
   - 靠排除做对后，以为已经掌握了那个生词。

## 易错

**“排除对了”不等于“懂了”。** 三个选项已知、靠排除选对，仍要记录那个生词没掌握，不把它算成方法或词汇能力提升。
