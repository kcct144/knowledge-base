## 讲解

### 判据与流程


2×2交叉表已补齐，题要算χ²或检验时使用。设四格按两行排列a、b/c、d，总n；四边际都正，闭式

$$k=\frac{n(ad-bc)^2}{(a+b)(c+d)(a+c)(b+d)}.$$

1. 按当前表抄a、b、c、d及其类别，不必强制原表一定以性别为行。核n与四格和、行列和一致。
2. 先算ad与bc再作差，差可能负；负号保留到平方，平方使统计量非负。先平方每一乘积再相减是另一式，会错。
3. 写出四个正边际再相乘，用精确分数或保留足够小数，最后比较临界值时才按要求显示近似。若任何边际0，停止套式。
4. 可用H₀拟合期望eᵢ=对应行总×列总/n作核验，(观察−期望)²/eᵢ四项和应等于闭式。期望格可非整数，因为是模型拟合数，不是实际人数。
5. 算完再查近似模型条件，能计算并不保证χ²临界值适用。

交换两行或两列只使ad−bc变号，平方不变；转置保持四边际乘积不变。因此完整交换表方向应给相同统计量，可作为必要自检，不能只换其中一格。


## 易错

- 把原a、b符号与四格位置混淆，先读表再赋值。
- 省一个边际或把n也当边际再多乘一次，会变成不同统计量。
- 提前舍入会使靠近阈值的决策不稳定，保精度至比较。

## 例题

### 原例：例5：篮球迷与性别的检验

来源：HSMA-B5-C8-D9e1bd0cb65d9-P0412-P0462。原件：专题8.3 列联表与独立性检验【八大题型】（举一反三）（人教A版2019选择性必修第三册）（解析版）.docx。

#### 原题与原解（完整保留）

【例5】（24-25高二下·山东德州·阶段练习）某学校在一次调查“篮球迷”的活动中，获得了如下数据，以下结论最准确的是（   ）

|  |  | 男生 | 女生 |  |
| --- | --- | --- | --- | --- |
| 篮球迷 |  | 90 | 20 |  |
| 非篮球迷 |  | 60 | 30 |  |

附：${χ}^{2}=\frac{n{(ad-bc)}^{2}}{(a+b)(c+d)(a+c)(b+d)}$

| $P\left( {X}^{2}\ge k\right)$ | 0.10 | 0.05 | 0.01 | 0.005 |
| --- | --- | --- | --- | --- |
| k | 2.706 | 3.841 | 6.635 | 7.789 |

A．有99．5%的把握认为是否是篮球迷与性别有关

B．有$99\%$的把握认为是否是篮球迷与性别有关

C．在犯错误的概率不超过0.1的前提下，可以认为是否是篮球迷与性别有关

D．在犯错误的概率不超过0.05的前提下，可以认为是否是篮球迷与性别有关

【解题思路】列出$2\times 2$列联表，计算${χ}^{2}$即可得解.

【解答过程】列出$2\times 2$列联表：

|  |  | 男生 | 女生 |  |
| --- | --- | --- | --- | --- |
| 篮球迷 |  | 90 | 20 | 110 |
| 非篮球迷 |  | 60 | 30 | 90 |
|  |  | 150 | 50 | 200 |

${χ}^{2}=\frac{n{(ad-bc)}^{2}}{(a+b)(c+d)(a+c)(b+d)}=\frac{200\times {\left( 90\times 30-20\times 60\right)}^{2}}{150\times 50\times 110\times 90}\approx 6.061>3.841$，

故在犯错误的概率不超过0.05的前提下，可以认为是否是篮球迷与性别有关.

故选：D.

#### 补讲与资料勘误

总样本200，男150、女50，篮球迷110、非篮球迷90。按原表取a=90、b=20、c=60、d=30，则ad−bc=2700−1200=1500，四边际为110、90、150、50。χ²=200×1500²/(110×90×150×50)=200/33≈6.060606。

在H₀下，四格期望频数为110×150/200=82.5、110×50/200=27.5、90×150/200=67.5、90×50/200=22.5。四格“观察−期望”的平方除以期望再相加也得到200/33，解释了闭式的来源。

3.841<χ²<6.635，所以α=0.05拒绝H₀，但α=0.01不拒绝。A的99.5%、B的99%档均未达到；C较宽的0.1档也可拒绝，但题问“最准确”，D使用样本所能支持的更严格0.05档，故原答案D。表内0.005档实际XML写7.789；同源其他表写7.879，原表照留并单列此误植，终答未使用该列。“犯错误概率”仍应按H₀成立时程序的误拒风险理解，不能变成本次结论正确率。

### 原例：变式7-3：测试成绩检验与放回抽样

来源：HSMA-B5-C8-D9e1bd0cb65d9-P0737-P0792。原件：专题8.3 列联表与独立性检验【八大题型】（举一反三）（人教A版2019选择性必修第三册）（解析版）.docx。

#### 原题与原解（完整保留）

【变式7-3】（24-25高二下·河南驻马店·阶段练习）为了解学生性别与掌握消防安全知识情况的关系，某校组织了消防安全知识测试，在高二年级中随机抽取600名学生统计其测试成绩，如下表（单位：人）：

| 测试成绩性别 | 良好 | 不够良好 | 总计 |
| --- | --- | --- | --- |
| 男生 | 150 |  | 300 |
| 女生 |  | 100 |  |
| 总计 | 350 |  | 600 |

(1)将上表中数据补充完整；

(2)从该校高二年级的学生中有放回地随机抽取2次，每次抽取1名学生，以频率作为概率，估计这2次抽取的学生的测试成绩全都良好的概率；

(3)试问是否有99.9%的把握判断消防安全知识测试成绩与性别有关？

附：${χ}^{2}=\frac{n{(ad-bc)}^{2}}{(a+b)(c+d)(a+c)(b+d)}$，$n=a+b+c+d$．

| $\alpha $ | 0.100 | 0.010 | 0.001 |
| --- | --- | --- | --- |
| ${x}_{\alpha }$ | 2.706 | 6.635 | 10.828 |



【解题思路】（1）根据已知填写表格即可；

（2）应用独立事件概率乘积公式计算即可；

（3）先计算${χ}^{2}=\frac{120}{7}\approx 17.143$，再与临界值比较即可判断相关性即可.

【解答过程】（1）

| 测试成绩<br>性别 | 良好 | 不够良好 | 总计 |
| --- | --- | --- | --- |
| 男生 | 150 | 150 | 300 |
| 女生 | 200 | 100 | 300 |
| 总计 | 350 | 250 | 600 |



（2）该校高二年级600名学生中测试成绩良好的频率为$\frac{350}{600}=\frac{7}{12}$，$\frac{7}{12}\times \frac{7}{12}=\frac{49}{144}$，

故估计这2次抽取的学生的测试成绩全都良好的概率为$\frac{49}{144}$．

（3）根据表中数据，计算${χ}^{2}=\frac{600\times {(150\times 100-150\times 200)}^{2}}{300\times 300\times 350\times 250}=\frac{120}{7}\approx 17.143$．

因为$17.143>10.828$，所以有99.9%的把握判断消防安全知识测试成绩与性别有关．

#### 补讲与资料勘误

（1）男生不够良好300−150=150，女生良好350−150=200，女生合计200+100=300；不够良好总250，两列350+250=600，两行300+300=600，核对无冲突。

（2）350/600=7/12是本次抽到600人的良好频率，不是原题已知整个高二只有600人；原解这一措辞照留，规范为用样本频率估计总体良好概率。后续每次在同一固定总体中等可能独立抽取并放回，故抽中良好的概率保持不变，用估计概率得到两次全良好(7/12)²=49/144。放回保持组成，独立随机抽取机制给乘积，二者理由分别写清。

（3）χ²=600×(150×100−150×200)²/(300×300×350×250)=120/7≈17.143>10.828，按题给α=.001拒绝H₀，样本支持性别与成绩类别有关。这个H₀研究一个学生上的性别和成绩；它不等于后续两次抽取事件是否独立。有关不证明性别造成掌握程度差异。
