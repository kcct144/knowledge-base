# 从句引导词

**一句话概念** — 先判断从句是否完整，再决定用「只连接」还是「要补成分」的引导词。

## 怎么认

选项可能出现：

```text
that / whether / what
who / which / where
if / when / why
```

这类题不能只看引导词中文意思，需要判断从句结构是否完整，以及引导词是否在从句中充当成分。

**信号不是绝对规则**：同一个词在不同从句中作用不同，不能只背一个译法；that 可引导不同类型从句，判断方式依赖结构。

## 思路

**先找主句和从句边界，再看从句缺不缺成分。**

1. **从句是否完整**：从句已有完整的主语、谓语和必要宾语 → 考虑只连接、不充当成分的引导词（that；表示“是否”的 whether / if）；从句缺成分 → 选能补足人、物、地点等成分的引导词（what / who 等）
2. **检查语序、先行词和上下文意义**：宾语从句通常使用陈述语序；定语从句先找被修饰的先行词，再判断缺少的成分

依据行：whether / if 常表示“是否”，从句本身结构通常完整；what / who 等可在从句中充当主语或宾语。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 识别 | 认出选项是引导词 | 不要求判答案 |
| L1 基础流程 | 从句完整用 that，缺成分用 what / who | 定语从句先行词 |
| L2 定语从句 | 找先行词，判断从句缺的成分 | 关系词省略 |
| L3 边界 | if 的“如果/是否”、whether 与介词 | 限制性用法 |

**默认停在 L1。**

## 怎么讲

1. 先给上面那句概念，够认就行
2. 用最简例子走一遍「划分从句 → 看缺不缺成分 → 选词 → 依据」
3. 只讲当前台阶，别顺手把定语从句省略和 if 双重用法一起倒出来
4. **常见卡点**：
   - 只按中文翻译，不检查从句是否缺成分
   - 宾语从句中使用疑问语序
   - 看到人就选 who，却没检查它是否需要在从句中充当成分
   - 混淆表示“如果”和“是否”的 if

## 易错

**看不出从句其实缺一个成分。**

```text
Emma knew ____ the cat needed a warm home.    ← 从句主谓宾完整，只连接，用 that
The student ____ found the cat ...            ← 从句缺主语，先行词是人，用 who
if                                             ← “如果”引导条件状语从句 / “是否”引导宾语从句
```

从句看着完整时，仍要检查是否缺少宾语或指代对象；介词后更常使用 whether，不能在所有位置把 if / whether 视为完全相同。

## 例题

**例一**　Emma knew ____ the cat needed a warm home.
A. that　B. what　C. who
→ **A**。从句 the cat needed a warm home 主谓宾完整，只需连接词，使用 that。

**例二**　The student ____ found the cat told the headmaster.
A. who　B. where　C. when
→ **A**。先行词是人 the student，从句缺主语，使用 who。

（两例均为自编）
