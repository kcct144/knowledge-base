# 连词

**一句话概念** — 连词连接词、短语或分句；选哪个连词，看前后两部分是什么逻辑关系。

## 怎么认

选项是不同连词：

```text
and / but / or
if / because / when
so that / although / since
```

看到选项主要表示不同逻辑关系时，优先想「连」。

**信号不是绝对规则**：有些词既可作介词、连词，也可作副词，要看它后面接什么结构。

## 思路

**先看前后连接什么，再判逻辑关系。**

1. **看结构**：空格前后连接的是词、短语还是分句，两边结构是否完整
2. **判关系**：并列、转折、选择、原因、结果、条件、时间、目的，还是让步
3. **代回验证**：一次只比较两三种清晰关系，放回上下文看逻辑是否通

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 识别 | 认出选项是连接词，并看前后连接什么 | 从句成分分析 |
| L1 基本并列 | `and / but / or / so` 的并列、转折、选择和结果 | 成对连词和多义用法 |
| L2 常见从属关系 | `because / if / when` 的原因、条件和时间 | 复杂从句引导词 |
| L3 让步、目的与边界 | `although / so that`；成对连词、`if` 多义和与从句引导词的边界 | — |

**默认停在 L1。** 学生还不能区分并列和转折时，不引入成对连词或复杂从句术语。

## 怎么讲

1. 先给上面那句概念，够认就行
2. 用最简例子走一遍「信号 → 判断 → 依据」
3. 一次只比较两三种清晰关系，别把所有连词一次列出
4. **常见卡点**：
   - 只翻译一个连词，不分析前后逻辑
   - 混淆 `because` 和 `because of` 后面的结构
   - 同时使用 `although` 和 `but`
   - 看到空格后是句子就随便选连词，不检查关系

## 易错

**看不出同一句中文可能对应不同关系。**

```text
because + 分句  /  because of + 名词、代词或名词性结构
so that                       ← 可表目的或结果，要看上下文
not only ... but also ...     ← 成对结构要检查对应成分
```

同一句中文可能对应不同逻辑关系，必须看上下文；从句引导词若在从句中还充当成分，不能只按普通连词处理。

## 例题

**例一**　The children wanted to find the cat a new home ____ the bell could ring again.
A. so that　B. ever since　C. because of
→ **A**。空格后是完整分句，前面行为的目的是让铃重新响，用 `so that`。

**例二**　Emma was tired, ____ she continued climbing the tower.
A. and　B. but　C. because
→ **B**。「疲惫」与「继续攀登」形成转折，用 `but`。
