# 关键长句

**一句话概念** — 只拆开**决定当前空**的那一句，找出主干、逻辑接口和指代，然后立刻回到选项；不把完形课变成整句语法分析或全文翻译。

> 高中扩展。它常是**临时补丁**：结构如果挡住词义或逻辑判断，拆清后马上回到 [`词义精辨`](词义精辨.md) 或 [`句篇逻辑`](句篇逻辑.md)。

## 怎么认

- 选项认识、篇章主线也清楚，但学生说不出长句的主语和核心动作；
- 分号、并列、插入成分、非谓语或多层从句，使学生把修饰语当主干；
- 不清楚 `it / this / what / wherever` 所在部分与主句的关系；
- 逐词都能译，却把因果、时间、让步或动作发出者接错；
- 解释主干后，学生就能回到词义或逻辑继续作答。

## 思路

    保留空格所在句和必要前一句
    → 圈连接词、标点和关系信号
    → 框主句主语 + 谓语 + 必要宾语 / 补语
    → 用斜线隔开从句、非谓语和插入成分
    → 还原代词或概括词指向
    → 只翻译主干和决定当前空的逻辑关系
    → 立即回到语境义或篇章逻辑流程

学生输出只需三行：

    主干：谁/什么 + 做什么/怎么样
    附加信息：何时、为何、让步还是条件
    当前空控制的部分：

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| P0 保句 | 保留空格所在句和必要前一句 | 不处理整段 |
| P1 找主干 | 框主谓宾，斜线隔开从句 / 非谓语 / 插入 | 不背术语 |
| P2 还原指向 | 还原代词 / 概括词指向，只翻主干和逻辑 | 不扩展语法章节 |

结构障碍解除即停，**不单独扩展名词性从句、状语从句或非谓语章节**。能用“主干 + 附加信息”说清就停。

## 怎么讲

- “先删掉修饰信息，主句还剩什么？”
- “这个连接词左边和右边各是什么完整意思？”
- “这个代词或概括词具体指前文哪件事？”
- “拆清以后，本空回到词义问题还是逻辑问题？”

## 易错

- 把拆句变成全文翻译；
- 要求学生背语法术语；
- 一路讲完整章从句 / 非谓语，偏离当前空；
- 逐词能译却仍说不清结构关系，就当成“懂了”。
