# 配对阅读

初中英语。左栏若干条信息，右栏一组选项（卡片、广告、说明等），为每条信息配一个选项；选项多于信息，有多余项。

长什么样、完整示例见 [`题型介绍.md`](题型介绍.md)。

**以配对为中心。** 每条信息到右栏找唯一“对得上”的那一项：先抓这条信息的关键特征，再和选项逐条比对。

## 边界

- 把词或句子放回短文的空里 → `题型/初中/英语/选词填空/`、`题型/初中/英语/阅读理解/` 的句子还原流程，不是配对阅读；
- 短文挖空、所有空共用一个句子选项池 → `题型/高中/英语/七选五/`；
- 选项能否重复用、有几个多余项，**一律按题面确认**，不从“配对阅读”这个标签反推。
