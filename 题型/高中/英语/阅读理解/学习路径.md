# 学习路径

**有报告就按报告走，别按本文件从头教。** 下面是**没有报告时**的系统起步顺序。

## 默认顺序

材料适配 → 主旨意识 → 定位与细节证据 → 按报告补题型 → 高中扩展 → 混合整篇

## 一、台阶表（逐级，不跳）

台阶是**前置关系**，不是难度标签；前一级不稳，后一级没有理解基础。

| 台阶 | 单一目标 |
|---|---|
| L1 一句抓骨架 | 用难度合适的短句 / 段，只抓“谁做什么、结果或态度怎样”，不逐句翻译 |
| L2 一段贴标签 | 读完一段只写一个短标签（提出问题 / 解释 / 举例 / 建议…） |
| L3 先定位后精读 | 先读题干，用定位词和段落地图找到证据区，只精读定位句及必要上下文 |
| L4 整篇速度迁移 | 在篇幅相近的新材料里分层阅读，速度改善而主旨和证据不降 |
| 关1 主旨意识 | 略读后用“对象 + 重点”说主旨，给主要段落贴功能标签 |
| 关2 定位与细节证据 | 题干定位词 → 预计同义替换 → 原文位置 → 必要上下文 → 选项核对 |
| 关3 按报告补题型 | 报告暴露哪个考点就补哪个，一次一个断点 |
| 关4 混合与整篇迁移 | 在新文章里先建主旨、自己认题型、用对证据范围、识别干扰项 |

L1—L4 的分层诊断见 `存档/资料/分层阅读与翻译边界.md`；`关1`、`关2` 是阅读方法主线。

## 二、按报告补题型流程（一次一个考点）

- **细节**：定位词 → 同义替换 → 定位句及必要上下文 → 核对选项
- **推理**：先扫选项排掉明显错的，再对剩余选项回原文找决定性证据，只补最短一步
- **词义**：把选项代入划线短语，不够再读整句、前后句、当前段
- **主旨与标题**：对象 + 重点 + 段落覆盖；全文目的加写作动作
- **指代**：语法匹配 → 语义代回 → 篇章延续
- **结构**：段落功能 + 逻辑推进
- **句子还原**：前后双向衔接；共享句子池转七选五
- **写作手法**：区分“怎么写”和“局部起什么作用”

报告没有出现的考点保持未评估，不把九类一次讲完。

## 三、高中扩展（基础流程走完仍卡时，按报告只补一个）

| 台阶 | 单一目标 |
|---|---|
| 1 精确改写 | 保留主体、关系、条件、范围和语气，处理复杂同义改写 |
| 2 证据扩围 | 单句不足时组成最小证据链，够了就停 |
| 3A 多声部立场 | 区分作者与不同被引人物：谁、针对什么、态度和强度 |
| 3B 相关与因果 | 保留方向、条件、中间环节和语气，区分相关、条件性影响和明确的因果 |
| 4A 研究结构 | 看懂分组、测量、结果和替代解释，正确限定人群和比较 |
| 4B 议论结构 | 看懂观点、让步、回应和权衡，段落怎样共同服务核心议题 |
| 5 目的与作用 | 区分内容、局部功能和全文目的，用“材料—局部动作—全文作用”作答 |

详细内容见 `存档/资料/高中扩展.md`。3A 与 3B、4A 与 4B 是并列入口，不必按编号全做。

## 四、整篇复盘（找错因）

| 错误层级 | 表现 | 下一步 |
|---|---|---|
| 材料 / 词汇 | 关键内容大量不认识 | 先补词汇或换材料 |
| 阅读方式 | 逐句翻译拖慢，主旨和证据质量下降 | 走 L1—L4 分层阅读台阶 |
| 主旨意识 | 没有主旨和段落地图，连续错 | 回主旨训练 |
| 考点识别 | 认错考点 | 回题干信号训练 |
| 定位 | 定位词选错或位置错 | 重练定位词与同义替换 |
| 证据范围 | 读少了或读多了 | 用最小充分范围 |
| 证据理解 | 读到了但没读懂关系 | 精读相关句段 |
| 选项核对 | 没识别干扰项变化 | 逐项对照干扰项类型 |

## 五、过关标准

- **可独立**：无需提示，能说出“考点 + 位置 + 证据”并做对；
- **稳定**：换新材料或间隔复测后仍能保持；
- **答对但说不出依据、或靠常识与原词猜中，不算能力提升**。
