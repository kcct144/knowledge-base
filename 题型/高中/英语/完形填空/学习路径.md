# 学习路径

**两条入口：**

- **新手 / 没有报告** → 上 [`专项课程/`](专项课程/01-基本方法与做题流程.md)：**一次课一个 Unit，共 14 次课**
- **已经有报告**（YouthPractice 段位模式导出的） → 按报告走，只处理它暴露的问题

**课程学完之后** → 回 **段位模式**随机做题、导报告，用它查缺补漏。

## 一、材料与词汇匹配（第一道闸）

先确认**材料配不配**他现在的水平：

- 让他标出每道错题四个选项里的生词
- 让他用一两句中文说文章的人物、事件、结果

| 结果 | 怎么办 |
|---|---|
| 多数题只有 0–1 个生词，能说出大意 | ✅ 可以练方法 |
| 少数题有 2 个以上生词 | 只处理那几个必要词汇，再回原题 |
| 大量题有 2 个以上生词，或说不出主线 | **暂停技巧训练，换更容易的材料** |

材料偏难时，不要求背完整篇生词，也不用正确率评价完形能力。

## 二、篇章意识

词汇够用后，先查他作答前有没有建立上下文：

- 主要人物/事物是谁？
- 当前目标、问题或变化是什么？
- 整体态度和发展方向是什么？
- 有没有把低把握答案当成后面的事实？

**同一段连续错**：先找**最早**改变人物、事件或态度理解的那一题，不要拆成多个词义问题。

**过关**：新文章开始时会用短语建草图；局部定不了时会主动找前后文，并把待定和已确认分开。

## 三、代入与排除

最基本的流程：**截短语 → 逐项代入 → 说出能排除的理由**。

**过关**：能自己截出合适的小结构（不把整句塞进脑子）；能分清"我知道它不合适"和"我只是不认识它"。

## 四、找线索

按报告逐个补，**不一次教完**：

1. 报告出现原词照应 → 学**原词复现**
2. 出现换一种说法 → 学**同义复现**
3. 出现转折或对比 → 学**反义复现**
4. 形容词选择出方向问题 → 学**褒贬法**

**过关**：不只圈出线索，还能说明线索怎样**支持或排除**某个答案。

## 五、全文检查

两个习惯：

- 用作答后的新信息**更新**人物、事件和方向
- 一篇完形**至少从头到尾完整读一遍**，回查低把握题

**过关**：局部两个选项都说得通时能主动扩大上下文；填完能用后文线索修正或确认。

## 高中扩展关

只有基础关都走过、或真实高中题明确需要时才进，**一次只走一个分支**：

- **词都认识但分不清** → 比较语境义、搭配对象、褒贬或语气
- **局部都成立** → 判断逻辑关系、指代链、段落功能、态度变化
- **证据句看不懂** → 只拆当前关键句的主干、修饰范围和连接，再回选项
- **单空能做、整篇不稳** → 换难度相近的新整篇，标低把握题并全文回查

完成一个分支**不自动**证明其他高中能力。

## 什么时候该换材料

- 多数题四个选项里有两三个不认识
- 解释选项后，正文仍看不懂
- 主要靠随机猜或按字形选
- 换成更容易的材料后表现明显改善

结论说"**当前材料和词汇水平不匹配**"，不要给学生贴"不会完形"的标签。
