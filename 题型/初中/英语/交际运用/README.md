# 交际运用

本册三组选择型补全对话、两组填空型，共25空。选择型包含五选五、六选五、七选五；开放题所有原提供参考句均保留。详见[条目索引](条目索引.md)。

## 路由与证据

补全多轮对话走此处；独立情景问答概念取学科情景交际；音频辨听走听力理解，实际朗读问答输出走人机对话；整句翻译转换走句子运用。相同情景不代表同一输出任务。

判定先用当前说话者、相邻回应、代词对象和话题推进，再看选项一次使用及空数。原题原答原详解为证据，补写只解释依据与边界。开放题参考不自动唯一，没有评分细则不自定分数。图中文字恢复需先认左右气泡，当前已准确转写，不保留装饰图。

## 教学与结束

先分清读不懂语境、没入口、角色反了、请求感谢混淆或语法形式错。没入口示范一个“答地点→前句问哪里”的判断，再回原题；只卡一处就讲一处，不把全部31类情景一次灌给学生。选对后能指出衔接证据才说明该判断有依据，不能凭文字任务更新现场口语能力。

学生要求练才从可靠原题取，不主动加题。缺原答时讨论可行回应但不冒称标准答案；本册原题可用答案完整。能独立解释并作出一个同类判断即停，学习进度与记录只填实际学生表现。
