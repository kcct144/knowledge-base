## 错法

找到x=3使3x≥9成立就写解集x=3，漏所有更大值；反过来把x≥3这整个范围叫一个具体的解。原四句辨析正区分这两层。

## 正解

代一个值验证只证它是一个解；解不等式要说明全部值范围。本式除正3得x≥3是解集，3是其中一个解。限定整数后仍需从范围取所有允许整数，不能随便挑一个代过值就结束。

## 例题

### 一个解与全部解集四句辨析

> 来源ID Q11-02；第11章不等式（组）；101-150/full.md 第1630–1644行。原答案与解析定位：101-150/full.md 第1630–1644行。

1. $x = 3$ 是不等式 $3x \geqslant 9$ 的解集.

( × )

2. 不等式 $3x \geqslant 9$ 的解是 $x = 3$ .

( × )

3. $x = 3$ 是不等式 $3x \geqslant 9$ 的一个解.

(√)

4. $x \geqslant 3$ 是不等式 $3x \geqslant 9$ 的解.

( × )

**原资料答案与解析：**

1. $x = 3$ 是不等式 $3x \geqslant 9$ 的解集.

( × )

2. 不等式 $3x \geqslant 9$ 的解是 $x = 3$ .

( × )

3. $x = 3$ 是不等式 $3x \geqslant 9$ 的一个解.

(√)

4. $x \geqslant 3$ 是不等式 $3x \geqslant 9$ 的解.

( × )

**展开解析（依据原详解补足理由与步骤）：**

原3x≥9除正3得到全部解x≥3。第1句把x=3这个单值说成解集，漏其他所有大于3值，错；第2句用“解是x=3”表达全部解也漏值，错；第3句明确说一个解，代入3×3=9满足≥，对；第4句x≥3是范围应称解集，不是一个具体的解，按原定义错。区别“3是一个解”和“解集是x≥3”，而不争日常语言中泛称解的习惯。
