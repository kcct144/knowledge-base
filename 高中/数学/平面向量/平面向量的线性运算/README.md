# 平面向量的线性运算

先把向量运算理解成位移的合成，再学习如何用一组向量表示其他向量。每次写式子都核对始点、终点和方向。

1. 从[向量的加法与减法](知识-向量的加法与减法.md)开始，理解首尾相接的三角形法则、公共起点的平行四边形法则和减法方向。
2. 读[向量数乘与共线定理](知识-向量数乘与共线定理.md)，把数乘的绝对值与长度、正负号与方向对应起来；使用共线表示时核对参照向量非零。
3. 读[位置向量与分点关系](知识-位置向量与分点关系.md)，选公共原点，把几何位置转成同一套向量表达式。
4. 按需要练[化简向量](考点-用首尾相接与公共起点化简向量.md)、[线性表示求参数](考点-用线性表示求参数.md)和[共线关系求分点与比例](考点-用向量共线关系求分点与比例.md)。比例的方向和参照线段要在图上核对。

常见错法对应[减法弄反起点终点](坑点-向量减法弄反起点终点.md)、[共线表示忽略非零条件](坑点-共线表示忽略参照向量非零.md)和[线性组合系数误作长度比](坑点-把线性组合系数直接当成长度比.md)。随后可学习[基本定理与坐标表示](../平面向量的基本定理及坐标表示/README.md)和[数量积](../平面向量的数量积/README.md)。
