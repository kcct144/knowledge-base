# 共享池

**一句话概念** — 所有空共用一个句子选项池；**一个空的选择会改变剩余选项池**，最终要把全部句子代回全文复查。

## 怎么认

- 题面可能写明每项只能使用一次，也可能允许重复；
- 题目可能有多余项，也可能没有；
- 题面规定每项只用一次时，两个空可能**争用同一候选**；
- 有多余项时，剩余选项也可能与全文话题相关、局部通顺。

规则一律**按题面确认**，不能从“七选五”这个标签反推。

## 思路

1. 按题面确认选项能否重复、有无多余项；
2. 若每项只用一次，两个空争用同一候选时，比较**哪个位置有更独特的证据**；
3. 有多余项时，检查剩余选项是否只是话题相关，却无法真正衔接；
4. 没有多余项时，每个位置仍要有**正面证据**，不按剩余项硬塞；
5. 全部代回后，检查选项使用次数与段落、全文连贯。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 规则 | 按题面说清空数、选项数、能否重复、有无多余项 | 单空判断 |
| L1 单空正面证据 | 每个位置都用正面证据，不靠“最后剩一个” | 跨空冲突 |
| L2 跨空冲突 | 两个空争用同一候选时，比较哪个空证据更独特 | 整组复查 |
| L3 整组复查 | 全部代回，检查使用次数与全文连贯 | — |

**只有出现真实冲突时才需要跨空比较**，不要求每次画分配表。默认停在 L1。

## 怎么讲

1. 先给那句概念；
2. 用最简例子走一遍“确认规则 → 比独特证据 → 整组复查”；
3. 只讲当前台阶；
4. **常见卡点**：
   - 题面规则不明时“用过即删”；
   - 靠最后剩余项倒推答案；
   - 两个空争用同一选项时，不比独特证据。

## 易错

**规则不明时**标为待核实、向教师或原出处确认；确认前可以逐空建立暂定候选，但**不“用过即删”**，也**不靠最后剩一个定答案**。
**多余项不是错误句子**，它也可能全文通顺或话题相关，不能因为“相关”就选。
