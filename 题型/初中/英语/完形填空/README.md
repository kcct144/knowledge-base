# 完形填空

初中英语。一篇短文挖若干空，每个空给若干选项，选一个。**本目录主要讲语境型：词义、搭配和上下文；其中也可能有连接词或语法空。**

长什么样、完整示例见 [`题型介绍.md`](题型介绍.md)。

**以证据为中心。** 完形首先是词汇和语篇理解题，方法不能替代选项词汇量。练的是两个意识：

- **证据意识** — 每个空先问：这一空主要靠哪类证据决定（代入 / 排除 / 找线索 / 看话题）
- **流程意识** — 做这种题，**先看什么、再看什么**

## 边界

- 选项是同一个实词的不同形式（`silent / silence / silently`）或虚词 → `题型/初中/英语/语法选择/`
- 给一个词框，从框里选词 → `题型/初中/英语/选词填空/`
- 初中不给选项、按提示词或语境写形式 → `题型/初中/英语/语篇填空/`；高中按高中语法填空路由。

## 怎么教

分两种场景。

### 讲解（他不懂这个考点）

1. **介绍考点**——这些空卡的是同一类判断，我们叫它 ××
2. **讲解判断依据**——这一类空分别看什么
3. **总结一般思路**——先看什么、再看什么
4. **让他带着思路，照着流程做**
5. **让他自己尝试**

第 1、3 步看 [`考点列表.md`](考点列表.md) 里那一行，细节点进它链的卡片。

### 讲题（他拿来一道题）

1. **先过两关**——四个选项和正文读得懂吗？能说出"谁、什么事、什么方向"吗？
2. **找卡点**——认得出这一空靠哪类证据吗？按思路做了吗？做到哪一步出问题了？
3. **针对卡点讲解和训练**——只补第一个断点，不把所有可能原因讲一遍
4. **让他继续做新题**
