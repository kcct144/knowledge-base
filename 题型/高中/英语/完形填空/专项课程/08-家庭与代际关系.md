# Unit 08 家庭与代际关系

**第 8 次课。** 按“家庭关系”话题练：理清人物关系，读懂细节里的情感。

## 讲什么

- 先理清**谁和谁**、什么关系（祖孙 / 亲子 / 兄妹），再看事件
- 家庭类文章常靠**具体细节**承载情感：一件物品、一个日常动作、一句话，而不是直接说“爱”
- 常见走向：**隔阂 / 差异 → 细心体会 → 理解、感恩**；结尾认识常回扣前文的具体行为
- 常见词群：**照料**（care / lovingly）、**记忆**（memory / presence）、**信任**（trust / faith）、**代际**（generation / tradition / gap / bridge）
- 讲代际差异的说明文里，要把**文中人物的评价**和**作者认可的事实**分开

## 怎么讲

1. 先画人物关系：谁照料谁、谁在看谁
2. 找承载情感的那件物品或那个动作，作为理解结尾的锚点
3. 注意时态和人称：**现在回想**与**过去经历**要分清
4. 结尾的理解 / 感恩，回到前文找它对应哪件具体的事

## 例题

**一**（日常照料，隔阂与消解）

> There was a grand gap between us on the sofa that could have been ____ by words, if we had only known then how to speak each other’s mother tongues.
> A. covered　B. measured　C. widened　D. bridged

→ **D**。前文的 `gap`（隔阂）与 `if` 从句说明：若当年会讲对方的话，这道隔阂本可以用语言**消除**，`bridge the gap` 正合。

**二**（重新理解家人，从不解到理解）

> Helen came to realize that they had been given such ____ during the time for the rent.
> A. luxury　B. reputation　C. responsibility　D. observation

→ **C**。女儿原想劝父亲卖房，后来明白低租是父亲主动担起的**责任**；这是“重新理解家人”的落点，不能理解成一种“奢侈”。

## 过关

他能先理清人物关系，指出一处承载情感的具体细节，并说出结尾的理解或感恩如何回扣前文的具体行为。
