# 解三角形

解三角形就是由已知边角确定其他边角。先把每条边与它的对角配好，再根据已知条件选定理，并检查解能否构成实际三角形。

1. 读[余弦定理](知识-余弦定理.md)与[正弦定理](知识-正弦定理.md)，理解它们的来源、符号对应及可用条件。
2. 用[按已知边角选择定理](考点-按已知边角选择定理解三角形.md)建立入口；两边与一边对角已知时，单独看[三角形解数](考点-判定两边与一边对角的三角形解数.md)。
3. 读[三角形面积公式](知识-三角形面积公式.md)，再练[边角互化判断形状](考点-边角互化判断三角形形状.md)和[面积关系求边角与范围](考点-用面积关系求边角与范围.md)。
4. 测量应用先读[方位角与仰俯角](知识-测量问题中的方位角与仰俯角.md)，再看[测距测高条件转成三角形](考点-将测距测高条件转成三角形.md)。画出的内角必须由题设方向关系得到。

容易漏解时看[只取一个反正弦值](坑点-正弦定理求角只取反正弦的一个值.md)；符号混乱时看[边与所对角](坑点-正弦定理混淆边与所对角.md)；测量图角度不确定时看[把方位角直接当内角](坑点-测量题把方位角直接当成三角形内角.md)。条目保留所选原题与原解，规范补讲、原资料疑点和勘误分开呈现。
