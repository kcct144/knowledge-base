# 介词

**一句话概念** — 介词引出关系（时间、位置、方式、对象等），而且**常是固定搭配的一部分**。

## 怎么认

无提示词，结构里缺一个**关系或搭配成分**，可能填介词。

**信号不是绝对规则**：不靠相邻词猜；只补当前必要内容，不扩成搭配大全。

## 思路

**看空格前后构成的搭配和关系，只补这一个。**

1. **看搭配**：前面是哪个动词 / 形容词 / 名词？它常和哪个介词连用？
2. **看关系**：这里表达时间、位置、方式，还是动作的实施者？
3. **核对**：代入原句通不通。

## 台阶（讲到哪停）

材料里的 Unit 10，逐关如下，**每一关一级，不合并**。

| 关 | 本级只解决 |
|---|---|
| 01 | 在具体动词短语中填写介词 |
| 02 | 根据时间表达和行程起点填写介词 |
| 03 | 区分 by 表达的差值、动作实施者、方式与衡量依据 |
| 04 | 混合判断搭配、起点、差值与动作实施者 |

不要求逐级学完；按当前断点挑关。

## 怎么讲

1. 先给概念：介词常和短语是一个整体，**连同意义一起记**。
2. 用一个短语走"看搭配 → 定介词 → 代入"。
3. **常见卡点**：
   - 只背孤立介词，不连同短语记
   - 时间 / 起点等关系判错
   - 一题对了就推及所有介词

## 易错

**同一介词可以表达不同关系，别死记一个意思。**

```text
focus on / upon   ← 把注意力放在……
keep an eye on    ← 照看
ban ... from doing ← 禁止做……
recover from      ← 从……恢复
by + 差值 / 实施者 / 方式 / 依据 ← 同一个 by，关系不同
```

只记**实际遇到的**搭配或语义关系，不据一题推及所有介词。
