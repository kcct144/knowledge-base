# 作文

初中英语。按题目要求自己写一篇短文（邮件、记叙、介绍等），没有选项，答案不唯一。

长什么样、完整示例见 [`题型介绍.md`](题型介绍.md)。

**以能力为中心，顺序不能跳：**

```text
成篇 → 切题 → 正确 → 优化
```

不成篇时，不用字数、评分点、高级句型压学生。

## 边界

- 材料同时含「回答问题」和「书面表达」→ 只处理**书面表达**，不给回答问题建能力状态
- 读后续写 / 高中应用文 → `题型/高中/英语/作文/`
- 单个语法、词汇错误 → 归对应知识卡片，不在本工作区开语法专题

## 怎么教

分两种场景。

### 讲解（他不懂这篇怎么写 / 卡在某一层）

1. **定位当前层**——用「成篇 / 切题 / 正确 / 优化」判断他卡在哪一层（见 [`考点列表.md`](考点列表.md)）
2. **只讲这一层**——一次只推进一个能完成的小目标
3. **给最小示范或保底稿**——作文允许示范、给句子，不要求先独立写完才帮
4. **让他在同一篇或新一篇里应用一次**
5. **能独立了就停**——回到新的真实作文，不自动加模板和难句

### 讲题（他拿来一道作文题 / 一篇草稿）

1. **找断点**——按 [`学习路径.md`](学习路径.md) 的「查缺入口」，找**第一个**真实断点
2. **针对断点带写或订正**——细节点进 [`考点列表.md`](考点列表.md) 对应卡片
3. **让他继续写新题**

**怎么判**：材料只给**教学优先级**（能成篇 > 大致切题 > 覆盖更多要求 > 基础正确 > 表达自然），
不是官方评分权重；批改一次只看当前那一个断点，不做整篇打分。
**给不给提示**：作文允许直接给示范和保底稿；给过提示要注明，独立写出才算过关。**范文怎么用**：模板和范文是「可誊写的骨架」，不是标准答案；要有至少一次实际替换或迁移才算能力。

## 原资料教学条目

2026知识清单的7篇原作文、原写作指导和完整范文见[条目索引](条目索引.md)。它们服务成篇、切题、正确、优化的现有教学顺序；不会写时仍先做最小可完成稿，不先堆词库和难句。

各原题身份标签未认证；书面表达中的原范文不唯一。苏轼范文漏抗洪且明显偏长，团队稿也明显偏长，详细缺点与计数已写入相应教学条目，不能照范文默认符合题定限制。新整理的[换词候选核查CSV](表达候选核查.csv)逐组标词义、词性、程度和结构边界；原候选不是逐词同义等式。

本册图示要求与四格式方法有区分：邮件有独立题，日记、通知和演讲只有格式清单，未添无来源的例题。
