# 统计案例

先辨明每一对数据的观察对象和两个变量的类型，再选择方法。数字成对数据可观察散点和线性相关；回归用样本拟合预测关系；分类成对数据用列联表与独立性检验。每条独立讲清定义、理由、使用条件、原题流程和边界，完整原答案与补讲或勘误分列。

## 学习顺序

1. 保持数据配对 → 散点图 → 正负方向 → 样本相关系数 → 中心化、范围和变换边界。
2. 线性回归模型 → 最小二乘与系数 → 样本中心和残差 → 拟合效果 → 预测与非线性线性化。
3. 二分类与列联表 → 边际和组内频率 → 独立假设下的期望格 → 卡方统计量 → 显著性水平、阈值与结论范围。

相关系数衡量线性关联，零相关不证明独立；经验预测不是必然观测，拟合优度不证明因果。卡方检验的显著性水平约束零假设成立时的拒绝风险，未拒绝并不等于证明独立。数据来源、样本与总体、独立抽样和模型近似条件须分别说明。
