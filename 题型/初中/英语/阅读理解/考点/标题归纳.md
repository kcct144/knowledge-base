# 标题归纳

**一句话概念** — 为整篇文章选最合适的标题：主旨准确优先，再检查覆盖和简洁。

## 怎么认

`What / Which is the best title for the passage?`

## 思路

```text
先独立说出全文主旨
→ 提取核心对象和作者重点
→ 检查标题是否覆盖主要段落
→ 检查是否符合文章文体和态度
→ 排除细节标题、过宽标题和无中生有
```

## 好标题的顺序

1. 准确；2. 能覆盖全文；3. 简洁清楚；4. 在准确的前提下可以有吸引力。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 认问法 | 认出标题题 | 不要求概括 |
| L1 先出主旨 | 先独立说出全文主旨，再从选项里选 | 逐类排除 |
| L2 三类排除 | 判掉以偏概全、过于宽泛、无中生有 | — |

**默认停在 L1。**

## 怎么讲

1. 先给上面那句概念；
2. 演示“先说主旨 → 用主要段落逐一验证覆盖”；
3. **常见卡点**：看到最生动的选项就选，不检查它是否覆盖全文。

## 易错

- 一个醒目的例子不一定代表全文；
- 不硬性规定标题必须 3～5 个词，以准确概括原文为准；
- 标题题与主旨题相关，但还要看标题表达是否自然、凝练。
