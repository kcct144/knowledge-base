# 比较等级

**一句话概念** — 比较级、最高级表示相对程度；**形式由比较意义、比较范围和结构决定**。

## 怎么认

出现 `than`、整体范围（`of / in ...`）、或两个相互关联的变化，可能考比较。

**信号不是绝对规则**：不凭单个标志词机械作答——比较对象有时藏在上下文里。

## 思路

**先说清比较什么，再定范围和结构。**

1. **明确比较对象**：谁和谁比？还是在一个整体范围里的最高？
2. **判范围**：两者 → 比较级；三者及以上、有整体范围 → 最高级。
3. **查结构**：`the + 比较级`、`the more ... the more ...` 等固定结构。
4. **写形式并核对拼写**。

不要求逐级学完；按当前断点挑关。

## 怎么讲

1. 先给概念：比较等级看**意义和范围**，不是见 `than` 就填。
2. 用一组对比走"判对象 → 判范围 → 定形式"。
3. **常见卡点**：
   - 只看 `than`，不判比较范围
   - 拼写错（`bigger` 双写、`easier` 变 y）
   - 最高级漏掉 `the`

## 易错

**比较范围、语义和结构要一起看。**

```text
longer   ← now 与"再睡一会儿"的对比
easier   ← now 与 during the Spring Festival 的对比
bigger   ← 双写 g
the tallest ← 最高级前一般有 the
```

`than` 后面比较的可能是上下文里的对象，不一定紧挨着出现。
