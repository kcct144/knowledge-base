## 讲解

### 是什么

代数式按约定写清乘法、除法和括号：数字因数放字母前，字母相乘通常省乘号；字母作除数通常写成分式；带分数作乘法系数先化假分数。系数1通常省略，−1保留负号，写−a而不是−1a。

### 怎么来的

规范书写的目的在于让运算位置一眼可读。9y中9是系数，y是被乘量；a7容易与编号或指数混淆，所以写7a。分式用分数线明确分子、分母的整体范围；当分子有和差时，分数线本身相当于给分子整体加括号。

带分数在乘号省略时容易混成“一个整数加一个分数乘字母”，先写成7/2再乘ab能明确整个系数。单位也要对应完整数量，原总费用5m+2n后加元，应写(5m+2n)元，避免只让单位看似跟在末项后。规范不代替运算合法性，d/c书写正确仍须c≠0。

### 什么时候能用

此处讲通常教材约定。原y×9虽不够规范，在明确乘法意义下仍与9y同值；格式判断与数值判断分别说明，不能声称不规范的写法必然代表不同值。

数字与数字相乘不能简单并列省乘号，否则12会被读成十二而非1×2。相同字母连续相乘可以写幂，但指数应注明在相应底数上；括号外指数作用于整个括号，字母上的指数只作用于该字母。

## 例题

### 代数式规范书写逐项辨别

> 来源ID Q04-01；第4章整式的加减；51-100/full.md 第384–386行。原答案与解析定位：51-100/full.md 第388–390行。

例 下列代数式中,符合书写规范的是\_\_\_\_.(填序号)

① $y \times 9$ ; ② $x \div y$ ; ③ -1a; ④ a7; ⑤ a + b; ⑥ $\frac{d}{c}$ ; ⑦ 3 $\frac{1}{2}ab$ ; ⑧ $-\frac{1}{4}a$ .

**原资料答案与解析：**

解析 ①应写成 $9y$ ; ②应写成 $\frac{x}{y}$ ; ③应写成 $-a$ ; ④应写成 $7a$ ; ⑦应写成 $\frac{7}{2}ab$ .

答案 ⑤⑥⑧

**展开解析（依据原详解补足理由与步骤）：**

①数字因数置前且省乘号，应写9y；②字母作除数用分式x/y，保留y≠0的有效条件；③系数−1按规范省略1，写−a；④数字7移到字母前，写7a；⑤a+b为和，书写正确；⑥d/c为分式，书写正确，值存在须c≠0；⑦3又1/2先化7/2，写(7/2)ab；⑧−(1/4)a的分数系数置前，正确。选⑤⑥⑧。这里问通常书写规范，有些未规范式在明确读法下仍能表示同一数量，不把格式问题说成所有情况下值都错。

### 速度和购买总价的代数式

> 来源ID Q04-02；第4章整式的加减；51-100/full.md 第410–413行。原答案与解析定位：51-100/full.md 第415–419行。

例1 列代数式表示:

(1) 如果王红 5 h 走的路程为 s km, 那么她的平均速度为 \_\_\_\_ km/h.  
(2) 每本笔记本 m 元, 每支笔 n 元, 王刚买了 5 本笔记本, 2 支笔, 他一共花了 \_\_\_\_ 元.

**原资料答案与解析：**

解析（1）根据“速度= $\frac{路程}{时间}$ ”，可知王红的平均速度为 $\frac{s}{5}$ km/h.

(2)5本笔记本共5m元,2支笔共2n元,所以王刚一共花了 $(5m+2n)$ 元.

答案 (1) $\frac{s}{5}$ (2) $(5m + 2n)$

**展开解析（依据原详解补足理由与步骤）：**

（1）平均速度=总路程/总时间。总路程s km、时间5 h，时间非零，得到s/5 km/h；单位随相除成为km/h，不误乘为5s。

（2）5本笔记本，每本m元，费用5m；2支笔，每支n元，费用2n；两项同为费用可相加，总计(5m+2n)元。括号使单位作用于整个和；m、n在实际价格情境中不取负。

### 读出省略乘号的实际意义

> 来源ID Q04-09；第4章整式的加减；51-100/full.md 第495–503行。原答案与解析定位：51-100/full.md 第525–527行。

例1 (2024 四川广安)下列对代数式-3x的意义表述正确的是()

A.-3 与 x 的和

B.-3 与 x 的差

C.-3 与 x 的积

D.-3 与 x 的商

**原资料答案与解析：**

例1 解析 $-3x = -3 \cdot x$ ，乘号可省略.

答案 C

**展开解析（依据原详解补足理由与步骤）：**

−3x按规范省略的是乘号，所以表示−3与x的积，选C。A的和应写−3+x；B的差应写−3−x；D的商应写−3/x且要求x≠0。这些不同运算不能只凭两边都出现−3和x就当成同义。

## 易错

- 数字系数置前，不将a7当标准代数乘积。
- 带分数系数先转假分数，避免乘法范围含混。
- 单位作用于整个和差，多个费用相加后用括号承接单位。
