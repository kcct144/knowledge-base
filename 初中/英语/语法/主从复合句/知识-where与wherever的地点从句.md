## 讲解

### 是什么

where小句可说明某行为所在的地方，wherever扩展为任何符合所说条件的地方。小句整体作地点说明时，与问具体地点的疑问句或修饰地点名词的关系从句要区别。

### 怎么来的

原Stay where you are.用where you are这个小句定位待在哪里，you是小句主语，are说明所处位置；不是要求另外回答一个Where are you?问句。Sit wherever you like.允许在任何合意地点坐下，wherever把可选地点范围展开，但不是保证现实所有地点都可以合法进入。

Where there is a will, there is a way.用抽象情境表达有意志就有办法，原书指出“地点”也可取抽象意义，所以不能认定where后必须给街道、房间或国家名。小句主谓there is...完整，不能把where作为缺失地点名词的实体替换。

读小句功能看它是否直接说明主句行为位置，若在名词后限定某地要进入另一关系结构，不因开头where一样就全称地点状语。原谚语是语言思想表达，不当现实任何任务必能完成的逻辑证明。

### 什么时候能用

主句问在何处或任意哪里时，核对小句是否承担地点说明；范围宽窄依where/wherever和后面的条件。原两个指令没有地图，不能补具体坐标、座位号或活动范围。

### 复合句节补充：放置位置与任意合意地点

Put it where we can see it.中where we can see it直接说明把物放在哪里；小句we执行see，it为所看对象，where为位置，两it分别在主句put和从句see的对象位置并非关系词重复对象错误。where不代替物品it。

We’ll go wherever you like.把目的地范围扩成任何你喜欢的地点；will go为未来行动，like的内容按前后地点语境省略，不据此补哪座城市。名词后where修饰某地点的定语任务在关系副词专条辨认，不能把同形词每次都称地点状语。

从属连词；意义；例句

where；(在)......的地方；Stay where you are. 待在原地。

wherever；在任何地方；Sit wherever you like. 请随便坐。

原抽象句：Where there is a will, there is a way. 有志者，事竟成。

原例：Put it where we can see it. 把它放在我们能看得见的地方。We’ll go wherever you like. 你想去哪儿我们就去哪儿。

## 易错

- **where后必须地名**：原you are为完整小句。
- **wherever等于每一处实际都可进入**：仍有后述条件和语境。
- **同一个where全作同一成分**：先看整个小句任务。
