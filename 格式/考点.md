# 考点文档格式

路径 `初中|高中/<学科>/<板块>/<专题>/考点-<考点>.md`

**判据**　什么时候用它（特征、条件）。
**流程**　步骤，每步带判断依据。
**例题**　一句话级的小例子；真题只写 `题 id`，题干在题库。
**来源**　`教材` / `老师讲义《…》` / `讲解整理 YYYY-MM-DD`（未核实）。

```markdown
# 整体法与隔离法

- 判据：各部分加速度相同 → 整体法；要算内力 → 隔离法。
- 流程：先整体求加速度，再隔离求内力。
- 例题：斜面上两木块一起加速下滑，求绳的张力。
- 来源：讲解整理 2026-09-30（未核实）
```
