## 讲解

### 是什么

the number of强调一组对象的数量，整体所谈是一个总数；a number of用于表示不少对象，整体谈多个对象。两种都可能接复数名词，配数却由完整主语任务决定，不能看到of后一律复数。

### 怎么来的

The number of the workers in this factory is over 5,000.回答该厂工人的总数，一个数量中心number所以is，workers只是计数对象。over 5,000是原阈值“超过5,000”，不能换成恰5,000或为数目大就用are。

A number of girls like the colour blue.在谈不少女孩的喜好，girls构成所谈多人，like用复数主语形式，number在这组数量限定表达中不当一个被评价的总数。中文“数量多”不足以区分两句：前者谓语是在说明多少，后者是在报告那些人的活动或性质。

步骤先读整句所断言的是一个数量还是多个对象，再认the/a与后面of构式，最后检查数及时态。原厂句用is并不因factory单数；原女孩句用like并不因blue为形容词。只取离谓语最近的词会丢掉主语中心。

### 什么时候能用

本书两例的一般介绍语境可据以上区分。a large number of等扩充数量限定仍要按实际结构理解；不是所有a number的单独用法都表示许多人。原未给专测两结构的独立题，不编题凑配套。

### EN-LEX-N原词汇补充

原A number of students are waiting for you.谈多个正在等待的学生，are配这一群体；原The number of students is fifty.报告学生的总数为50，is配数量中心number。两句没有说明指同一组学生，不能据并排例句补出恰50人全在等你；原fifty数值保留而a number只说一些。waiting是正在等待，不证明后来全部见到you。

“the number of+可数名词复数”作主语时；The number of the workers in this factory is over 5,000.这家工厂的工人数量超过5,000人。

“a number of+可数名词复数”作主语时；A number of girls like the colour blue.许多女孩子喜欢蓝色。

### 原词汇例句补充

**原词目 number**

A number of students are waiting for you.一些学生正在等你。The number of students is fifty.学生的数量是50个。

## 易错

- the number of workers后用are：把计数对象当数量中心。
- a number of girls后用likes：把数量限定误当一个总数。
- 超过5,000改为5,000：丢掉over的原边界。

补充：并排范句认同一组50人都等待；a number自行定50；quantity句is因students复数改are。
