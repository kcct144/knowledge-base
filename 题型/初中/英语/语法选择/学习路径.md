# 学习路径

**有报告就按报告走，别按本文件从头教。** 下面是**没有报告时**的系统起步顺序。

## 默认顺序

**会认考点 → 逐个考点突破 → 混合强化**

## 一、会认考点

**练法**：用 `question` 工具出题——**题干给这题的选项，选项给考点**，让他点选：

> **题干**：`silent / silence / silently`
> **选项**：名 · 人 · 冠 · 时 · 词 · 比 · 介 · 连 · 情 · 非

只看选项判断考点，**暂时不要求选答案**；认识信号边界（`-s` 不一定是复数，`to` 不一定是不定式）。

点选时**不给提示、不预选、也别把答案标在选项上**。

**选不出来或选错** → 别让他反复猜，**讲**两样，都到"能认"为止：

1. **认脸的技巧**——这组选项长什么样，一看就知道是哪一类（[`考点列表.md`](考点列表.md) 的「选项信号」列）
2. **最小概念**——给个名字 + 一句话，够认就行。
   例：`to do` 这种形式叫**非谓语**；他现在不用懂什么叫非谓语，**见到认得出来**就够了。

讲完**换一组新的**再试。

题目从哪来：优先让他拿真实材料（试卷 / 作业）；拿不到就**自编**，给之前**自己先核一遍**唯一答案和干扰项。
**不要拿 `题型介绍.md` 里的示例出题**——那是给人看"长什么样"的，不是练习素材。

**过关**：连续两轮混合识别约 80%，并能说出至少两个"信号不能直接决定答案"的例子。**基本能认出来，就进下一阶段。**

## 二、逐个考点突破

按「快速规则型 → 系统理解型 → 按题补充型」推进。

**第一层 · 快速规则型：名、人、冠**（先建考点意识和流程意识）

- **名**：先判是否用所有格 → 再判可数性和单复数
- **人**：先做 L1 主格、宾格、形容词性物主代词；稳了再进名词性物主代词、反身代词
- **冠**：先看可数单数和限定关系 → 再判泛指特指、`a / an` 发音

**第二层 · 系统理解型：时、词、比**（多步判断，放慢）

- **时**：先会找谓语 → 一般现在 / 过去 / 将来 → 再进行、被动、完成
- **词**：名词与动词、`be` 后形容词 → 基础形副辨析 → 再扩展其他系动词、`-ing/-ed` 形容词
- **比**：判形容词 / 副词 → 找比较标志和范围 → 查固定结构 → 看句意

**第三层 · 按题补充型：介、非、连、情**（不设独立背诵线）

- 先教会识别考点 + 基本流程；只有真实题目暴露某个具体搭配时，才做最小说明
- 不一次展示长表，也不因为属于这一类就自动安排背诵

**低频考点**（感叹句、特殊疑问词、从句引导词、other 系列、few/little 系列、复合不定代词）不排固定课时——诊断出现、真题反复出现、或正是当前断点时才处理。

**每个考点的小闭环**：前置检查 → 看选项认考点 → 学判断步骤 → 跟一个最小示范 → 独立做基础题 / 变式题 → 换新材料验证迁移。

**过关**：不看提示能复述主要判断顺序；新题里先认考点、再给证据；同类关键错连续两轮不重复。

## 三、混合强化

按这个顺序加难度：

两三个易混考点混合 → 十类随机混合的单句 → 加入已学的低频考点 → 完整语篇（先不限时）→ 完整语篇 + 限时。

**答案对但考点判断错、或凭语感猜中，不算能力提升。**

## 四、整篇复盘

做完一篇，按四层找错因：

| 错误层级 | 表现 | 下一步 |
|---|---|---|
| 考点识别 | 没认出或认错考点 | 回选项对比训练 |
| 流程记忆 | 考点对，但说不出先做什么 | 学并复述标准流程 |
| 步骤执行 | 知道流程，某一步错或被跳过 | 补对应知识 + 单步变式 |
| 语境理解 | 结构可行，但句意 / 上下文判断错 | 精读相关句段 + 比较选项含义 |
| 执行检查 | 会做但漏看标志、主语或上下文 | 固定检查清单后再限时 |

已掌握的仍要间隔复习：1 天、3～4 天、1～2 周。
