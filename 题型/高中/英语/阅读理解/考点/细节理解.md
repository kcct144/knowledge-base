# 细节理解

**一句话概念** — 原文明确提供了某项信息（人物、时间、地点、原因、方式、结果、数字），题目直接问它是什么。

## 怎么认

题干用 `who / when / where / why / how / which / according to` 等直接询问信息，选项多是原文内容的同义改写。

## 思路

**定位并读足证据，再核对选项。**

1. 明确题干到底问什么（问时间、原因还是做法）；
2. 划出少见且稳定的定位词，优先人名、数字、地点、专有名词；
3. 预测原文可能用的同义表达；
4. 扫读找到证据区，读定位句及必要前后句；
5. 用自己的话说出证据意思，再逐项核对选项。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 认题干 | 从题干看出问的是哪类信息 | 不要求选答案 |
| L1 基础定位 | 一句或相邻句能决定的直接细节 | 多句压缩、范围与语气 |
| L2 复杂改写 | 选项高度概括、证据分散时保留条件与范围 | 需要时按高中扩展 |

**默认停在 L1。**

## 怎么讲

1. 先给上面那句概念，够认就行；
2. 用最简例子走一遍「定位词 → 同义替换 → 定位句 → 选项」；
3. 只讲当前台阶，别顺手把多句压缩和范围偷换一起倒出来；
4. **常见卡点**：
   - 找到关键词就选，不读周围文本；
   - 只认原词，把同义改写当成无中生有；
   - 把题序与文序当成硬规则，跨段题不回头核对。

## 易错

**选项复现原词却改变了原文关系**——如人物、时间、范围、程度或肯否。判断要落到证据句，不落到词面。
