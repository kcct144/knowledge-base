## 讲解

### 是什么

常见-ing词块应按直接支配层分组：介词后的活动、某个形容词或动词搭配后的活动、宾补活动及句式中的活动内容。记完整结构能解释为何选-ing，也能避免只看远处的be、to或have就套另一条规则。

### 怎么来的

be interested in /be good at /thank sb for /spend time (in)后接活动时，in/at/for等是介词。look forward to与be/get used to中的to也是介词，所以原表接doing；与过去惯常used to do中的不定式层不同，不能把所有used to都算同一个结构。

busy doing、worth doing、feel like doing、give up doing、put off doing、can’t help doing各有自己的意义和搭配；can’t help表示禁不住时接-ing，不同于help (to) do的帮忙。have trouble/difficulty (in) doing说活动有困难，不是have+对象+过去分词的使役，也不是完成have done。

see/notice/find/catch/keep sb doing中的sb为活动执行者，doing补充其状态，不能因看见一个名词就在其后加任意动词-ing。原there is (no) difficulty (in) doing、it is a waste of time doing、it is no use doing各自先建立困难、价值或无益的评价，再说明活动；主语位置、介词和评价词不可随意混装。

### 什么时候能用

先圈最近的结构核心，明确to是否介词、have是否实义及doing是谁的活动，再决定词形。原表提供结构没有为每一项配题，逐项保留词块和用途，不能声称本节已用原题验证所有18项。be worth及感官宾补同一概念合并已有条目，本条用分类建立检索入口。

## 例题

**原资料词形、词组或例句，非独立试题。** 本小节未配一题单独检验本概念，保留原材料并解释这一缺口。

sth be worth doing 某事值得做；be busy doing sth 忙于做某事

be interested in doing sth 对做某事感兴趣；be/get used to doing sth 习惯于做某事

give up doing sth 放弃做某事；put off doing sth 推迟做某事

feel like doing sth 想要做某事；can't/couldn't help doing sth 情不自禁做某事

be good at doing sth 擅长做某事；look forward to doing sth 期待做某事

have trouble doing sth 做某事有困难；have difficulty (in) doing sth 做某事有困难

see/notice sb doing sth 看见某人正在做某事；find sb doing sth 发现某人正在做某事

catch sb doing sth 当场发现某人正在做某事；keep sb doing sth 使某人一直做某事

thank sb for doing sth 感谢某人做某事；spend time (in) doing sth (某人)花费时间做某事

原句式：There is (no) difficulty (in) doing sth.；It is a waste of time doing sth.；It is no use doing sth.。

## 易错

- to后一律原形：look forward to的to是介词。
- can’t help与help (to) do互换：当前义项禁不住与帮忙不同。
- have trouble doing判完成时：trouble是困难名词，have为实义。
