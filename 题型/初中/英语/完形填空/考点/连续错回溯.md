# 连续错回溯

**一句话概念** — 同一段或相邻题连续错时，优先检查篇章意识，不把每题拆成独立知识点。

## 怎么认

相邻或同一段连续错；或学生把前面低把握的答案当成了后续题的事实。

## 思路

1. 找这一串里**最早**的低把握或错误题；
2. 回到它前面的确认信息，检查人物、问题和态度方向是否已经理解错；
3. 去掉该题及后续低把握答案，用没有挖空的正文重新读；
4. 更新篇章草图；
5. 再按“局部 → 上下文 → 全文”重做这一串题。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 认出连续错 | 定位这一串里最早的 `?` 或错题 | 回溯主线 |
| L1 回溯主线 | 去掉待定答案，用正文重建人物、问题、方向 | 重做整串 |
| L2 重做一串 | 更新草图后按 局部 → 上下文 → 全文 重做 | — |

**默认停在 L1。**

## 怎么讲

1. 先给上面那句话；
2. 用一段连续错走一遍“找最早断点 → 重建主线 → 重做”；
3. 只讲当前台阶；
4. **常见卡点**：
   - 连续错就逐题补十个知识点；
   - 把自己前面的低把握答案当成事实。

## 易错

**若重建主线后多题一起改正，主要断点是篇章意识**，不是多个独立词汇或技巧问题；只记一个篇章意识问题，不要拆成十个。
