# 知识库

AI 讲解时用的**内容库**：教材目录、题型教学决策、学科知识（知识 / 考点 / 坑点）。

**这是可选增强**：不装它，只装 harness 也能正常讲题（`tutor` §4 会降级）。装上是让 AI 讲得前后一致、贴老师的口径。

与 `学习数据/`（学生数据）、`.kilo/`（harness）分开维护，**一份知识库服务多个学生**。

## 架构

```
knowledge-base/
│
├─ 教材/<学段>/<学科>/目录/<册别>.md   章节名对照表（查章节名 / 给 topic 取名）
│
├─ 题型/<学段>/<学科>/<题型>/           ① 练法（题本体也在这）
│  ├─ README.md                        导览 + AI 怎么教这个题型（路由/查缺/反馈/结束）
│  ├─ 题型介绍.md                       是什么题型 · 考哪些考点 · 由哪几项能力构成
│  ├─ 学习路径.md                       先练什么后练什么
│  ├─ 练习模式/                         关卡本体（一关一个文件）
│  ├─ 练习/                             题本体（文件名即 id）
│  └─ <年份>-真题.md                    命题趋势分析（题目靠 id 指向）
│
├─ 通用/*.md                           ② 跨学科方法：时间分配、草稿、检查
│
├─ 格式/                               ③ 文档格式
│  └─ 知识模板.md · 考点模板.md · 坑点模板.md
│
└─ 初中/ 高中/                         ④ 学科知识库
   └─ <学科>/
      ├─ index.md                     板块 → 专题 清单
      └─ <板块>/<专题>/
         ├─ 知识-<概念>.md            是什么
         ├─ 考点-<考点>.md            怎么判
         └─ 坑点-<坑>.md              哪儿翻车
```

## 两套正交系统

题型和学科内容**不是一回事**，是两个维度：

| | 学科内容 | 题型训练 |
|---|---|---|
| 回答 | 是什么 / 怎么判 / 哪儿翻车 | 练什么 / 练到哪 / 下一步练什么 |
| 单位 | **考点**（一条判断） | **能力**（一项技能） |
| 结构 | 板块 → 专题 → 知识/考点/坑点 | 题型 → 能力 / 关卡 / 台阶 |
| 学生数据 | 缺口表（缺哪一层） | 学习进度（过到哪一关） |

**对接点是考点名**：关卡里"这一步要判断什么"指向 `考点-` 条目，那条考点再说清怎么判、哪儿容易错。
题型**消费**考点，不重复生产它。

## 三级定位

```
高中/物理/力学/牛顿运动定律/
├─ 知识-惯性.md
├─ 知识-牛顿第一定律.md
├─ 考点-整体法与隔离法.md
├─ 考点-瞬时加速度问题.md
└─ 坑点-误把「速度为零」当平衡.md
```

| 级 | 粒度 | 稳定性 | 例 |
|---|---|---|---|
| 板块 | 课标大领域 | 改课标才动 | 力学 · 电磁学 |
| 专题 | 一级主题（约一章的体量） | 几年一变 | 牛顿运动定律 |
| 条目 | 一个概念 / 考点 / 坑 | 随时增补 | 惯性 · 整体法与隔离法 |

## 各学科的板块

各科的板块 → 专题清单见 `初中|高中/<学科>/index.md`。

## 格式

**只有项目根目录有 `AGENTS.md`**（harness 一份，Kilo 自动加载）；其余所有目录一律用 `README.md`。

默认 markdown，一个条目一个文件（样子见 `格式/`）。
**表格式数据用 csv**——章节清单、考点对照、词汇表这类"一行一条、字段固定"的，直接存 `<用途>.csv`（UTF-8、首行表头、一个文件一张表），比 markdown 表格好处理。例：`单词,词性,释义,单元`。

## 关联规则

1. **题本体在各题型工作区的 `练习/`**（文件名即 id）；自编题要注明来源、**不当证据**
2. **题型工作区**的"做题思路"每一步**指向**学科知识库的 `考点-…` 文件
3. **关联单向**：每条只声明自己的向上依赖——考点写 `知识`/`前置`，知识写 `前置`，坑点写 `考点`。反向关系靠 grep，不写第二遍，免得两边漂
4. 四层用**同一套考点名**互相关联

学习进度、学习记录、错题、背诵卡在各自的 workspace 里，本目录不放。
