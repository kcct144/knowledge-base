# 冠词

**一句话概念** — 冠词放在名词短语前：`a / an` 泛指单数可数名词，`the` 限定**已经明确**的对象。

## 怎么认

无提示词，空后是名词短语且缺限定成分，可能填冠词。

**信号不是绝对规则**：无提示词不限定只填冠词，也可能是介词、连词、关系词。

## 思路

**先看名词短语，再判泛指特指，最后看发音和搭配。**

1. **看名词短语**：是不是单数可数？需不需要限定？
2. **判泛指 / 特指**：泛指一个 → `a / an`；已明确、独一无二、固定表达 → `the`。
3. **`a / an` 看发音**：紧跟其后的第一个音素是元音还是辅音。
4. **结合固定表达核对**。

## 怎么讲

1. 先给概念：两件事——泛指还是特指；`a` 还是 `an` 看发音。
2. 用 `a unique ...`、`an extremely ...` 走一遍发音判断。
3. **常见卡点**：
   - 按字母不按发音（`a unique`、`an honest`）
   - 不判特指就填 `the`
   - 漏掉固定表达 / 独一无二的对象

## 易错

**`a / an` 看的是紧跟其后的第一个音素，不是首字母。**

```text
a unique combination   ← unique 开头是辅音音素 /j/
an extremely rewarding experience ← extremely 开头是元音音素
a professor            ← 辅音音素开头
```

`the` 用于已明确、独一无二、或固定搭配中的对象。
