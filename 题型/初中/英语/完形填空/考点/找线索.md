# 找线索

**一句话概念** — 局部不能决定答案时，从上下文里找与答案对应的信息，并说明它怎样支持或排除选项。

## 怎么认

空格所在句及前后句里出现**对应信息**：原词复现、同义复现、反义复现；也可以是人物态度、因果、转折或事件结果。

## 思路

1. 由近到远扩大范围：当前短语 → 完整句 → 前后句 → 当前段 → 全文；
2. 找到线索后要说清它与答案的关系，不能只圈一个看起来相似的词；
3. **形容词褒贬法**：先按正面 / 负面 / 中性分类，再看人物态度和故事走向；它只能缩小范围，两个正面词仍靠准确词义、搭配或上下文区分。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 认三类复现 | 从上下文认出原词、同义、反义复现 | 说清关系 |
| L1 说清关系 | 说明线索怎样支持或排除某答案 | 情感与逻辑线索 |
| L2 情感与逻辑线索 | 用人物态度、褒贬、因果、转折、事件结果 | — |

**默认停在 L1。** 按报告逐个补：出现哪类线索，才学哪类。

## 怎么讲

1. 先给上面那句话；
2. 用一道题走一遍“扩大范围 → 找线索 → 说关系”；
3. 只讲报告暴露的那一类，不一次教完；
4. **常见卡点**：
   - 看到相同词就机械选择，不说明复现关系；
   - 形容词只看褒贬，不比较具体含义；
   - 只圈出相似词，不说明它和答案的关系。

## 易错

**复现按原词、同义、反义逐个按需出现**：本次只暴露原词复现，就不顺带讲完另外两种。
**有复现词不等于关系成立**，要验证它和答案的语义关系。
