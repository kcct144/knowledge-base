# 阅读理解

高中英语。一篇短文配若干道四选一小题，每题问的是原文的某处信息或某种关系。

长什么样、完整示例见 [`题型介绍.md`](题型介绍.md)。

**以考点为中心。** 练的是两个意识：

- **考点意识** — 这些题长得差不多，放到一起当一类题来研究；给它起个名字，就叫考点
- **流程意识** — 做这种题，**先看什么、再看什么**

## 边界

- 所有空共用一个句子选项池（五选四、六选五、七选五…）→ `题型/高中/英语/七选五/`
- 只给一个独立句子判断插入位置，或每题各自独立选项 → 本工作区的句子还原
- 多条待匹配信息共用一个选项池 → 配对阅读

## 怎么教

分两种场景。

### 讲解（他不懂这个考点）

1. **介绍考点**——这些题长得差不多，是一类，我们叫它 ××
2. **讲解考点相关知识**
3. **总结一般思路**——做这类题，先看什么、再看什么
4. **让他带着思路，照着流程做**
5. **让他自己尝试**

第 1、3 步看 [`考点列表.md`](考点列表.md) 里那一行，细节点进它链的卡片。

### 讲题（他拿来一道题）

1. **找卡点**——材料读得懂吗？主旨建了吗？认得出考点吗？定位和证据到哪一步出问题？
2. **针对卡点讲解和训练**
3. **让他继续做新题**

**证据边界**：靠常识、原词或感觉选中的，不算提升；答对但说不出依据，不算掌握。

- `学习路径.md` — 先练哪个考点、按什么顺序

- `存档/` — 旧版 README、资料、练习，不再用于教学
