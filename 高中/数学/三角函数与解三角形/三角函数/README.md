# 三角函数

先理解角怎样表示，再理解三角函数把角对应到什么数。图象、公式和实际模型都建立在这两个问题上。

## 基础概念

1. 从[任意角与终边相同的角](知识-任意角与终边相同的角.md)、[象限角与轴线角](知识-象限角与轴线角.md)入手，分清旋转量、终边位置和坐标轴上的边界。
2. 学习[弧度制](知识-弧度制.md)及[弧长与扇形面积](知识-弧长与扇形面积.md)，每次计算先统一角的表示单位。
3. 学习[任意角三角函数的定义](知识-任意角三角函数的定义.md)，把函数值与终边点的坐标联系起来，再读[符号](知识-三角函数值的符号.md)、[特殊角](知识-特殊角的三角函数值.md)和[诱导公式](知识-诱导公式.md)。
4. [同角基本关系](../三角恒等变换/知识-同角三角函数的基本关系.md)用于从已知函数值求另外的值；开方后的符号仍要由角的范围确定。

## 图象与应用

- 先分别读[正弦](知识-正弦函数的图象与性质.md)、[余弦](知识-余弦函数的图象与性质.md)、[正切](知识-正切函数的图象与性质.md)的图象与性质。不要把一种函数的定义域或单调区间套给另一种。
- 再读[正弦型函数的参数与图象](知识-正弦型函数的参数与图象.md)及[平移与伸缩](知识-正弦型函数图象的平移与伸缩.md)。分析限定区间时，先求相位实际走过的范围。
- 最后读[周期模型](知识-三角函数的周期模型.md)，根据实际数据确定振幅、周期和起点，并检验预测范围。

考点条目用原题展示如何选择入口、判断范围、作图、求参数与建立模型；坑点条目解释常见错法的成因和修正依据。
