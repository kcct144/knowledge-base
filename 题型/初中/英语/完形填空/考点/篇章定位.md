# 篇章定位

**一句话概念** — 逐空作答前，先用已有正文建立一个轻量篇章草图：**谁或什么 → 发生了什么 → 往哪发展**。它不是逐句翻译，也不用提前猜出答案。

## 怎么认

需要建立草图的时候：拿到一篇新完形、准备逐空作答之前。只给一个孤立错句时，先请学生补前后句或原文。

**最重要的区分**：正文里**没有挖空的部分**和已有明确证据的答案是确认信息；学生自己低把握填入的词只是假设。把假设当事实，会造成“前一空猜错 → 把错误答案当线索 → 后面连续错”。

## 思路

1. 用已有正文回答三问：谁或什么？发生了什么目标、问题或变化？整体态度、结果或发展方向是什么？
2. 只用短语或一两句中文回答，允许写“暂不确定”，读到新内容再更新；
3. 作答时用 `✓`（有明确证据）/ `?`（暂选待验证）区分确认信息和待定答案。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 说出三问 | 用短语或一两句中文说出人物、事件、方向 | 段落推进、标记 |
| L1 确认与待定分开 | 用 `✓` / `?` 标记，不拿 `?` 去证明另一个答案 | 段落推进 |
| L2 段落推进 | 每读完一段用几个字更新草图（背景→问题→行动→结果→主题） | 全文结构分析 |
| L3 上下文意识 | 按 局部 → 完整句 → 前后句 → 当前段 → 全文 带着问题找证据 | — |

**默认停在 L1。** 只有 L1 稳了、真题需要、或学生明确追问，才往下走。

## 怎么讲

1. 先给上面那句话，够用就行；
2. 用最简一段走一遍“三问 → 草图 → 更新”；
3. 只讲当前台阶，不一次讲完段落推进和上下文意识；
4. **常见卡点**：
   - 从第一空直接开始，逐空作答前没有主线；
   - 看完第一句就把话题固定，后面出现转折也不更新；
   - 把自己低把握的答案当成后续题的事实。

## 易错

**“看上下文”不是重新读一遍所有文字**，而是带着一个明确问题找证据，例如“这个动作是谁做的”“后一句是原因还是结果”。
**每空都强制看全文也不对**：局部能直接决定答案时，不需要拉扯全文。
