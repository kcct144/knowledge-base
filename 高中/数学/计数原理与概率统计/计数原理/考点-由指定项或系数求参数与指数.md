## 讲解

### 判据与流程

题目给定某项的项序或数值，要反求 n、常数参数时，把“幂指数条件”与“数值系数条件”分成两步。

1. 若给第 j 项，先固定 r=j−1，再写通项。若给常数项或指定 x 幂，先用指数方程找 r；不能先拿组合数直接凑数值。
2. 由幂指数条件反求 n 或 r，立即核 n 为非负整数、0≤r≤n，以及指定项存在。若解出 n<j−1，原指定项不存在，应排除。
3. 把已确定的指数与下标代入系数式，再用“常数项=给定数值”等条件解常数参数。偶次幂方程通常有正负分支，原参数正性可用于筛选，不能跳过。
4. 把所有保留参数回代原通项和原定义域，确认是指定项、系数确为给定值。多个合法参数时要全列，不能只挑一个。

原例3中第 4 项意味着 r=3，常数要求 (n−18)/5=0，所以 n=18；随后核 n≥3。变式3-1先由 12−3r=0 确定 r=4，再得 15a⁴=240；必须用 a>0 才从 ±2 中保留 2。

## 易错

- 用系数相等代替指数相等：即使系数数值碰巧正确，也未必是所求项。
- 未知 n 的组合数下标越界，阶乘无定义；解参数先查范围。
- 对 a⁴=16 直接说 a=2，忘记题目正性是排负根所依据的条件。

## 例题

### 【例3】：指定项求指数

来源：HSMA-B5-C6-D8ee685bf3cd9-P0080-P0085。原件：专题6.3 二项式定理【十一大题型】（举一反三）（人教A版2019选择性必修第三册）（解析版）.docx。

#### 原题与原解（完整保留）

【例3】（23-24高二下·江苏连云港·期末）若${\left( \sqrt[5]{x}-\frac{1}{x}\right)}^{n}$的展开式中第4项是常数项，则n的值为（    ）

A．14  B．16  C．18  D．20

【解题思路】写出二项式展开式的通项，令$k=3$时$x$的指数位置等于$0$即可求解.

【解答过程】${\left( \sqrt[5]{x}-\frac{1}{x}\right)}^{n}$展开式的通项为${T}_{k+1}={C}_{n}^{k}{\left( {x}^{\frac{1}{5}}\right)}^{n-k}{\left( -1\right)}^{k}{x}^{-k}={C}_{n}^{k}{\left( -1\right)}^{k}{x}^{\frac{n}{5}-\frac{6k}{5}}$，

令$k=3$可得${T}_{4}={C}_{n}^{3}{\left( -1\right)}^{3}{x}^{\frac{n}{5}-\frac{18}{5}}$为常数项，可得$\frac{n}{5}-\frac{18}{5}=0$，可得$n=18$，

故选：C.

#### 补讲与必要修正

第 4 项先固定 k=3，第一部分贡献 x⁽ⁿ⁻³⁾⁄⁵，第二部分贡献 x⁻³，指数相加为 (n−18)/5。常数项要求 n=18；它确实是非负整数且 n≥3，故第 4 项存在。实数五次根允许负 x，但 1/x 要求 x≠0；在负 x 上最好保留真实奇次根乘法，不能把它未经约定解释为任意实指数幂。四个选项中仅 C 使指数等于 0。

### 【变式3-1】：常数求参数

来源：HSMA-B5-C6-D8ee685bf3cd9-P0086-P0092。原件：专题6.3 二项式定理【十一大题型】（举一反三）（人教A版2019选择性必修第三册）（解析版）.docx。

#### 原题与原解（完整保留）

【变式3-1】（23-24高三下·湖南娄底·阶段练习）已知$a>0$，若${\left( {x}^{2}+\frac{a}{x}\right)}^{6}$的展开式中，常数项等于240，则$a=$（    ）

A．3  B．2  C．6  D．4

【解题思路】根据二项展开式的通项公式求出常数项，建立方程得解.

【解答过程】由二项展开式的通项公式可得${T}_{r+1}={C}_{6}^{r}{\left( {x}^{2}\right)}^{6-r}{\left( \frac{a}{x}\right)}^{r}={a}^{r}{C}_{6}^{r}{x}^{12-3r}$，

令$12-3r=0$，解得$r=4$，

即常数项为${T}_{5}={a}^{4}{C}_{6}^{4}=240$，解得$a=2$.

故选：B.

#### 补讲与必要修正

x≠0，通项为 C₆ʳaʳx¹²⁻³ʳ。常数项方程 12−3r=0 给 r=4，它在 0,…,6 中，因此系数是 15a⁴。15a⁴=240 给 a⁴=16；实数解本有 ±2，题目 a>0 才保留 2，选 B。不能在求参数时丢掉正性条件，其他正数选项回代都不等于 240。
