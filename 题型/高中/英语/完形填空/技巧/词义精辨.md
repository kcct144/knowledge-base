# 词义精辨

**一句话概念** — 四个词大致认识、局部搭配也都行，最后两个意思接近时，用**一个决定性语义维度**把它们分开，而不是说“这个更顺”。

> 高中扩展。基础流程（词汇门槛 → 篇章定位 → 代入排除 → 找线索 → 全文验证）走完仍有断点才用。

## 怎么认

- 四个选项基本认识，局部搭配也不明显错，但最后两个词义接近；
- 按最常见中文义代入不合适——词在文中是抽象义、引申义或比喻义；
- 选项是短语动词，逐词翻译后都“差不多”；
- `only / still / even / indeed` 等词改变焦点、预期或语气；
- 学生只能说“这个更顺”，说不出另一个错在哪一维。

## 思路

先缩到最后两个候选，然后：

1. **说共同点**——它们为什么都像答案；
2. **只找一个决定性差异**——从对象、方向、程度、态度、时间状态、范围、搭配框架里选最相关的一维；
3. **把空格改写成中文约束**（不先写选项），例如“这里需要的是离开以后才产生的认识”；
4. **逐个核对约束**，能满足共同义但不满足约束的排除；
5. **回句、回段验证**。

常用维度：对象 / 动作方向 / 主动性与意图 / 程度与语气 / 时间状态 / 评价色彩 / 搭配框架 / 语篇角色。

- 抽象 / 引申 / 比喻义：先问“这个词在文章里具体指什么人、事或关系”，再比较；
- 短语动词按整块处理：`主语是谁 → 作用于什么对象 → 朝什么方向发展 → 放回人物目标和时间线`；
- 焦点词先去掉，写基本事实，再问是“范围受限 / 状态延续 / 超出预期 / 确认加强”中的哪一种。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| H0 基础排除 | 明显不合词性 / 搭配 / 人物 / 情节的仍按基础流程排除 | 精辨 |
| H1 两候选精辨 | 共同点 → 一个决定性差异 → 文本约束 → 排除理由 | 抽象义、短语动词、焦点词 |
| H2 复杂维度 | 抽象 / 引申 / 比喻义，短语动词整体，焦点词 | — |

**默认停在 H1。** 学生能独立说出“共同点—决定性差异—文本证据—排除理由”，本轮即完成。

## 怎么讲

一次只追问最后两个候选：

- “它们为什么都像答案？”
- “只准说一个差别，你选哪一维？”
- “文中哪个词或事实需要这个差别？”
- “另一个候选违反了哪条约束？”

## 易错

- 只报中文释义、只说搭配顺，说不出决定性差异；
- 两个模糊中文义互相替换；
- 一处近义词错误被扩展成同义词大全；
- 把褒贬当精辨终点（两个正向 / 两个负向词仍需比较对象、程度、动作方向）。
