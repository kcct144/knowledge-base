# 随机变量及其分布

从明确一次随机试验的结果开始，区分已知条件下的概率、随机变量的取值事件及整张分布列。数字特征概括平均与离散，分布模型还需核抽样、独立性、参数和停止规则。每条独立解释定义、理由、条件、步骤与边界，并保留完整原例。

## 学习顺序

1. 条件概率 → 条件乘法 → 全概率划分 → 贝叶斯；随机变量 → 分布列 → 两点分布 → 变量变换。
2. 期望 → 方差与标准差 → 线性变换与求和条件 → 二项分布与超几何 → 按题设目标比较方案。
3. 正态曲线 → 位置尺度与标准化 → 对称、σ区间与估计 → 有限停止与状态递推。

条件概率方向、零分母、同值合并、分布列非负归一、二项的同概率独立及不放回的供给限制均应先核。正态密度高度不是点概率，3σ不是绝对界；期望与方差不自动决定晋级或达标概率。
