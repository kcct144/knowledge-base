# 学习路径

**有报告就按报告走，别按本文件从头教。** 下面是**没有报告时**的系统起步顺序。

默认路线：**读规则 → 看词框 → 判空格 → 双向匹配锁原词 → 定词形 → 整篇迁移**，模式沉淀与熟练化贯穿各级。报告或错题先按证据定位第一个断点，只补那一个。

## L0 题型规则与词汇门槛

本级只解决：

- 从说明找出：能否变形、一词几用、多余词数量、每空词数；
- 说出词框里大部分关键候选的核心意思；
- 材料词汇明显不匹配时，主动提出降难度。

**过级**：不再因误读说明丢分，且具备比较词框候选的基本词汇条件。

## L1 快速观察词框

本级只训练：

- 给熟悉词标最常用的名词 / 动词 / 形容词 / 副词等基本词性；
- 识别少量一眼可见的搭配；
- 从熟悉词出发，说出它通常可找的结构或位置；
- 不确定、一词多性的词标 `?`，不假装只有一种用法。

暂不要求后缀、词形转换、冷僻词义。**过级**：能把词框快速分成几个候选组，而不是每空重新搜全表。

## L2 观察空格需要什么

从最常见结构起步，逐步判断空格需要：名词还是动作；形容词还是副词；谓语动词还是其他形式；介词、连词、代词或限定词等明显功能词。

先用学生已学的 `a/the`、形容词、介词、主语、情态动词、`to`、`be` 等清楚信号；一词多性和 `to/be` 歧义标为后续边界，不一次讲完。**过级**：能截取空格附近的小结构，给出合理词性需求，并从词框缩到少量候选。

## L3 搭配、词性和意思双向匹配

训练顺序：**空格需求 → 词框候选 → 搭配和结构 → 当前句意思 → 必要上下文**。

要能说出最后锁定答案靠的是搭配、词性结构还是上下文意思。**过级**：基础材料中能独立选对原词并说出证据。

## 贯穿各级：模式沉淀与熟练化

把真实题目中验证过的有效判断练成更快的第一反应，只处理本轮真正出现的关系：写清触发、第一反应、验证、边界，后续新题主动调用。

熟练度分四级：**见过 → 需提示 → 可快速调用 → 稳定迁移**。只有后两级才能在开局当减负工具；老师刚提示就答对、只靠最后一个剩余词猜中，都不算。同一模式做按证据需要安排的无提示新空后，就回到新的完整短文。

## L4 按报告补词形变化

拆成小单元，按真实题目逐个补：规则名词单复数 → 一般现在 / 过去 / 将来等已学基本动词形式 → 常见 `-ing / -ed`（只在题目和前置需要时）→ 形容词、副词和比较等级 → 代词形式、所有格、拼写与大小写。

在哪个小单元错就只补那个。基本时态未稳时，不因词框有动词就自动讲被动、完成时和全部非谓语。**过级**：选中原词后，能对当前已学范围独立做一次词形检查。

## L5 整篇、排除与时间迁移

在词汇匹配的新短文中检查能否：

1. 略读话题、人物、时间和发展方向；
2. 先做高把握空，区分 `✓` 与 `?`；
3. 主动调用熟练模式，只用高把握答案缩小词框；
4. 剩余词不合适时回查最早的 `?`；
5. 通读全文并查词形、使用次数、多余词、拼写、大小写；
6. 不牺牲证据和正确率，逐步接近个人时间目标。

**过级**：能在完整新材料中独立跑全流程并说明关键证据。到"稳定"还要不同话题、混合变形或间隔复测的持续表现。

## L6 一词多性与结构边界

只有真实题目反复需要时才处理：一词多性；`to` 是不定式还是介词；`be + 空格` 是状态、身份、进行还是被动；情态动词后已有动词时空格是否副词；题型是否允许词性派生。

不属必学主线。**过级**：能说明为什么基础信号不够、还要看哪一项；不要求背完所有例外。

## 常见分流

- 词框关键词不认识 → 词汇补漏或降难度
- 知道词义但不会标词性 → 回 L1
- 会分类但看不出空格需要什么 → 回 L2
- 词性匹配但意思不通 → 补 L3 语境验证
- 原词选对但形式错 → 只补 L4 对应小单元
- 一个 `?` 导致后面连续错 → 补 L5 的把握标记和回溯
- 会做但来不及 → L0～L5 独立后，再做个人基线上的时间训练
- 学过思路但开局想不起来 → 不新增知识，回模式库做提取练习

已掌握的仍要间隔复习：1 天、3～4 天、1～2 周。
