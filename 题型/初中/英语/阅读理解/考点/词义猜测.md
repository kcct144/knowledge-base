# 词义猜测

**一句话概念** — 划线单词、短语或句子在当前语境里的意思；把四个选项分别替换回去，看哪个合适。

## 怎么认

题干问 `What does the underlined word ... mean?` / `probably means` / `can be replaced by`。

## 思路

```text
看清划线的是哪个词、它在哪个短语里
→ 把 A/B/C/D 分别替换掉划线词，放回这个短语
→ 看哪个搭配和语义最合适（简单情况到这里即可）
→ 短语不够用时，才读整句、前后句或当前段
```

入门时可以把它当作一个小完形填空：在目标词的位置逐个比较四个选项。

常见线索：定义或解释 `is / means / refers to`；举例 `for example / such as`；同义或补充 `and / or / also`；反义或转折 `but / however`；因果或结果；构词信息。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 短语代入 | 把四个选项放回所在短语，比较搭配和意思 | 所在句线索 |
| L1 所在句线索 | 短语不够时，看同句的定义、举例、同反义、因果 | 前后句 |
| L2 前后句 | 所在句仍不能确定时，用前后句的解释、原因、结果区分 | 段落 |
| L3 段落 | 结合段内对象、事件或多个例子判断 | — |

**默认停在 L0。** 前一层能解决就停，不为“走完整流程”读遍所有范围。

## 怎么讲

1. 先给上面那句概念；
2. 演示“逐项代回短语 → 比较 → 说明依据”；
3. 只讲当前台阶；
4. **常见卡点**：挑一个自己最熟的词，而不是把四个选项都放回同一短语比较。

## 易错

- 构词法只是辅助，清楚的上下文证据优先；
- 题目问的是当前语境义，不一定是学生最熟悉的词典义；
- 短语代入能确定答案时无需扩大；多个选项仍合理时，再读整句、前后句或当前段。
