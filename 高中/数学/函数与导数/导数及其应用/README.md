# 导数及其应用

导数从平均变化率的极限出发，表示一点附近的瞬时变化率，也是可导曲线在该点处切线的斜率。先辨别求导、切线、函数性质还是参数问题，再确定函数的定义域与题目要求的范围。

求单调、极值和最值时，用导数符号证明一段走势；驻点只是候选，闭区间须比较端点，开区间还要判断边界是否取得。零点问题把每段的实际值域与水平线比较，存在和唯一都须说明。参数题先写清“对所有”或“存在”，严格号再核是否能达到边界。

双变量与偏移问题说明构造或换元为什么能降维，并回验原范围。二阶导数与拐点内容标为拓展；题目给出的定义按该题条件使用，不能当成一般结论。实际优化保留单位、时点、整数限制和可行端点。
