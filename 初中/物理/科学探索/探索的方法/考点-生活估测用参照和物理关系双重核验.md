## 讲解

### 判据

给生活物理量与数字，要判断其大致合理性或解释原估值。

### 流程

1. 确定物理量：质量、重力、压强、功率等不能混称。
2. 把数值换成熟悉单位，保留平方立方意义。
3. 找原资料同类对象参照并说明对象差异。
4. 能用物理关系时再核验，如质量到重力、压力和面积到压强。
5. 只给近似数据时保持相应精度，不把粗略估值写成精确测量。

## 例题

### 原生活数据估测清单

> 来源ID Q27-01；附录5生活数据与估测；201-233/full.md 第2071–2071行。原答案与解析定位：201-233/full.md 第2071–2071行。

| 1张纸厚度约 $10^{-4}$ m |
| --- |
| 人步行正常速度为1~$1.5\,\mathrm{m/s}$;骑自行车的正常速度为3~$5\,\mathrm{m/s}$ |
| 一个鸡蛋的质量约为50g,举起两个鸡蛋用力约为1N |
| 初中物理课本的长约25.5cm,宽约18.5cm |
| 普通鸡蛋、人体的平均密度约为 $1$ g/$\mathrm{cm^3}$,合 $1.0\times10^{3}$ $\mathrm{kg/m^3}$ |
| 报纸平放时对桌面的压强约0.5Pa,砖块平放时对地面的压强约为 $10^{3}$ Pa |
| 一名中学生的质量约为50kg,每只脚与地面的接触面积约为 $130$ $\mathrm{cm^2}$,站立时中学生对地面的压强约为2× $10^{4}$ Pa |
| 家庭节能灯正常工作时的电流约为0.1A |
| 在正常工作时,电热水壶的功率约为1000W,电吹风机的功率约为500W |
| 液晶电视机的功率约为100W,台式计算机的功率约为200W |

**原资料答案与解析：**

原表给出近似生活数据，没有独立习题答案；上表是原数据，经恢复平方与立方单位书写。

**展开解析（依据原详解补足理由与步骤）：**

原表的每个“约”都表示相应常见对象的尺度，不能当精确统一值：

1. 一张纸$10^{-4}\,\mathrm m$即0.1 mm，是普通纸厚度估值；不同纸张不同，多张叠测须计张数并扣除其他厚度。
2. 步行1至1.5 $\mathrm{m/s}$、自行车3至5 $\mathrm{m/s}$是原表日常范围，不能推出每个人、每时刻均在这个范围。
3. 鸡蛋约50 g，两个约100 g即0.1 kg；取$g=10\,\mathrm{N/kg}$得到重力约1 N。质量单位g不能直接当力单位N。
4. 原课本长25.5 cm、宽18.5 cm是该类课本参考，尺寸约四分之一米、五分之一米；不是所有版本的精确尺寸标准。
5. 鸡蛋、人体平均密度约$1\,\mathrm{g/cm^3}=1.0\times10^3\,\mathrm{kg/m^3}$。平均是整体质量除整体体积，不表示每个组织或鸡蛋壳都同密度。
6. 报纸平放约0.5 Pa、砖块平放约$10^3\,\mathrm{Pa}$与质量、接触面积和摆法有关，侧放等改变受力面积后不能保持原估值。
7. 50 kg学生每脚130 cm²，两脚面积260 cm²即0.026 m²，取$g=10$时压力约500 N，压强约$1.9\times10^4\,\mathrm{Pa}$，与原约$2\times10^4\,\mathrm{Pa}$一致；原站立按双脚支承的普通模型，单脚不是同一面积。
8. 原节能灯电流0.1 A是某类常见灯的工作估值，换灯、额定功率和工作电压会不同。
9. 原电热水壶约1000 W、电吹风机约500 W，是装置类型数量级参考；档位与产品改变可影响实际值。
10. 原液晶电视约100 W、台式电脑约200 W，同属工作功率参考，实际取铭牌和工作状态；功率W与累计电能kW·h不是同一量。

原附录没有选项题。量级判断需识别物理量、单位和模型，再看是否在相应常见范围，不靠孤立背数。

### 原站立压强估值核对

> 来源ID Q27-02；附录5生活数据与估测；201-233/full.md 第2071–2071行。原答案与解析定位：201-233/full.md 第2071–2071行。

| 一名中学生的质量约为50kg,每只脚与地面的接触面积约为 $130$ cm2,站立时中学生对地面的压强约为2× $10^{4}$ Pa |
| --- |

**原资料答案与解析：**

原表给出的近似结果见上表；没有另设题干条件。

**展开解析（依据原详解补足理由与步骤）：**

按原“站立”的通常双脚支承模型，学生静止且竖直只受重力和地面支持，故地面对脚的支持力等于重力；脚对地面的压力与支持力是相互作用力，压力$F=mg=50\times10=500\,\mathrm N$，g取原常量表粗略值10 $\mathrm{N/kg}$。每脚130 cm²，合计$S=2\times130=260\,\mathrm{cm^2}$；因$1\,\mathrm{cm}=10^{-2}\,\mathrm m$，故$1\,\mathrm{cm^2}=10^{-4}\,\mathrm{m^2}$，面积$S=260\times10^{-4}=0.026\,\mathrm{m^2}$。定义$p=F/S$，代入$p=500/0.026\approx19231\,\mathrm{Pa}\approx2\times10^4\,\mathrm{Pa}$。原结果是约数，不是要求精确等于20000 Pa；两脚面积必须合计。

### 原两鸡蛋重量估值

> 来源ID Q27-03；附录5生活数据与估测；201-233/full.md 第2071–2071行。原答案与解析定位：201-233/full.md 第2071–2071行。

| 一个鸡蛋的质量约为50g,举起两个鸡蛋用力约为1N |
| --- |

**原资料答案与解析：**

原表给出的近似结果见上表；没有另设题干条件。

**展开解析（依据原详解补足理由与步骤）：**

原一个鸡蛋质量约50 g，两个合计$2\times50=100\,\mathrm g=0.1\,\mathrm{kg}$。用原常量表粗略$g=10\,\mathrm{N/kg}$，两蛋重力$G=mg=0.1\times10=1\,\mathrm N$。静止托住且只计重力与支持力时，手给的总支持力约1 N；若加速举起，手力不必等于重力。原“举起两个用力约1 N”是日常估测口径，需明示近似静止或缓慢条件，不泛化为任意动作。

### 原纸厚与课本尺寸参照

> 来源ID Q27-04；附录5生活数据与估测；201-233/full.md 第2071–2071行。原答案与解析定位：201-233/full.md 第2071–2071行。

| 1张纸厚度约 $10^{-4}$ m |
| --- |
| 初中物理课本的长约25.5cm,宽约18.5cm |

**原资料答案与解析：**

原表给出的近似结果见上表；没有另设题干条件。

**展开解析（依据原详解补足理由与步骤）：**

原纸厚约$10^{-4}\,\mathrm m$；$1\,\mathrm m=10^3\,\mathrm{mm}$，因此$10^{-4}\,\mathrm m=10^{-1}\,\mathrm{mm}=0.1\,\mathrm{mm}$。这是小厚度，不是0.1 m。课本25.5 cm和18.5 cm分别除以100换m，得到0.255 m、0.185 m；长度估值与面积单位不同，不能把厘米到米系数直接用于平方厘米。只将原尺寸作为这类书的参考，不声称所有课本都如此。

## 易错

台式电脑等功率随状态变化；不会因原表写某个数而恒定。
