# 圆与方程

圆由圆心和正半径确定。求方程、判位置和算弦长时，把几何距离与代数方程对应起来；求轨迹或最值时还要核查原来的取点范围。

## 学习顺序

1. 读[标准方程与一般方程](知识-圆的标准方程与一般方程.md)、[判定与点圆位置](知识-圆方程的判定与点圆位置.md)。从距离定义得到标准式，再配方识别圆心及半径平方；半径平方为0或负数时不是正半径圆。
2. 读[轨迹与对称变换](知识-圆的轨迹与对称变换.md)。轨迹方程需核必要性和充分性，排除不合原条件的点；对称变换保持半径。
3. 读[直线圆位置关系和弦长](知识-直线与圆的位置关系和弦长.md)、[切线方程与切线长](知识-圆的切线方程与切线长.md)。先比较圆心到线距离和半径；半弦、弦心距、半径构成直角三角形。切点处半径垂直切线，竖直切线也要检查。
4. 读[圆上点的距离与表达式范围](知识-圆上点的距离与线性表达式范围.md)。识别目标是距离、距离平方、线性式还是斜率，再选对应的几何方法；比值的分母为零另讨论。
5. 读[两圆位置关系与公切线](知识-两圆位置关系与公切线.md)。比较圆心距、半径和及半径差；同心等半径是重合，不能当内切。
6. 读[公共弦与相减直线](知识-两圆公共弦与相减直线.md)、[圆系方程与参数限制](知识-圆系方程与参数限制.md)。先统一二次项系数再相减，真实有两公共点才称公共弦；参数表达须核遗漏的原圆和退化情形。

## 条件复核

- [未检半径平方为正](坑点-圆方程未检半径平方为正.md)：圆心可配出，不代表方程一定是圆。
- [轨迹无效点与充分性](坑点-轨迹消元后未去无效点或检充分性.md)：反向代回原几何条件和参数范围。
- [切线漏竖直线或切点不在圆上](坑点-圆切线漏竖直线或切点不在圆上.md)：切点公式有适用前提。
- [部分圆只看判别式](坑点-对部分圆只看判别式或忽略弦存在.md)：交点须在指定弧段，弦长式也须有真实交弦。
- [相减直线与同心重合](坑点-两圆相减就断言公共弦或误判同心重合.md)：先判公共点及非退化关系。
- [圆系特殊参数与原圆](坑点-圆系归一化漏特殊参数与原圆.md)：除以参数式前查零值，最后再查正半径和遗漏。
