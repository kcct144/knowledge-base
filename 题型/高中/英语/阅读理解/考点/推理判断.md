# 推理判断

**一句话概念** — 答案不是原文照抄的，而是原文事实能支持、又不超出的一步结论。

## 怎么认

题干用 `infer / imply / suggest / conclude / probably / learn from` 等。

## 思路

**先扫选项排掉明显错的，再对剩下的选项回原文找决定性证据。**

1. 看清题干问什么；
2. 带着它扫四个选项，排掉一眼就错的（靠常识、绝对化、多跳、与全文方向冲突）；
3. 对剩下的选项回原文找证据；
4. 用自己的话重述证据，只补最少的一步关系，不新增原文没有的信息。

主旨是前提：先理解全文主旨，再走上面流程会顺利很多。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 认题干 | 认出这是需要推断的题 | 不要求选答案 |
| L1 局部推断 | 附近事实足够、一步能推到的结论 | 多声部立场、条件因果、跨段证据 |
| L2 篇章推理 | 态度、立场、目的等需要篇章证据 | 按高中扩展处理 |

**默认停在 L1。**

## 怎么讲

1. 先给概念；
2. 分清“原文写了什么”和“我多推出什么”，后者不能新增未经支持的信息；
3. 只讲当前台阶；
4. **常见卡点**：
   - 用常识代替原文；
   - 从“可能”推成“一定”；
   - 推得太多，新增了原文没有的原因、动机或结果。

## 易错

**仅因选项接近原文就排除它**——判断关键是题干所问及选项是否正确表达原文能支持的结论，不是词面像不像。
