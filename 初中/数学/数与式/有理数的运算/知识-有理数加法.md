## 讲解

### 是什么

有理数相加要同时处理符号和绝对值。同号两数相加，沿共同方向累积，结果取相同符号，绝对值相加。异号两数相加，两个方向抵消，绝对值不等时取较大绝对值那一方的符号，大小等于两绝对值之差；互为相反数相加得0。与0相加仍为原数。

这里a+b中的“+”表示加法操作，a、b本身可以为负。加一个负数仍叫加法，不能因为看见负加数就说题目已换成减法。

### 怎么来的

可以从数轴上的移动理解。把第一个加数作为起点：加正数向右走相应距离，加负数向左走。两段方向相同，距离叠加；方向相反，较短的一段先抵消较长的一部分，剩余方向由较长的一段决定，剩余距离就是差。两段一样长又相反，恰好回到0。

所以相加不保证结果比每个加数大。加上负数会往左移动；只有明确加的是正数时，结果才一定比原数大。两个负数相加继续往左，结果仍是负数，“负负得正”不能从乘法移用到加法。

多个加数可逐次相加，也可依据交换律与结合律分组；但必须把负号作为加数的一部分一起移动。

### 什么时候能用

适用于所有有理数的有限次相加，整数、小数、分数遵循同一符号规则。分数的绝对值作和或差时，仍要遵守通分等普通分数运算规则。

实际题中先确认记录的是带方向变化还是无方向长度；只有沿用统一正负规定的有向变化才能直接作代数和。横纵共用一格的幻方，公共中心数同时出现在两条和中，比较时可以同时去掉中心数，不能在其中一条单独删除。

## 例题

### 用相反数和同分母分组求和

> 来源ID Q01-21；第1章有理数；1-50/full.md 第3391–3391行。原答案与解析定位：1-50/full.md 第3393–3393行。

例1 计算： $(+3) + \left(+\frac{1}{4}\right) +$ $(-3.3) + (-3) + (+0.3) +$ $\left(-6\frac{1}{4}\right).$

**原资料答案与解析：**

解析 原式 $= [(+3) + (-3)] + [(-3.3) + (+0.3)] + \left[(+\frac{1}{4}) + (-6\frac{1}{4})\right] = 0 + (-3) + (-6) = -9.$

**展开解析（依据原详解补足理由与步骤）：**

六项全是加数，可用加法交换律和结合律重新分组，但要连同各数的符号移动。把 +3 和 −3 配对，$3+(-3)=0$；把 −3.3 和 +0.3 配对，$-3.3+0.3=-3$；把 $+\frac14$ 和 $-6\frac14$ 配对，后者是 $-(6+\frac14)$，故 $\frac14+(-6\frac14)=\frac14-6-\frac14=-6$。于是总和 $0+(-3)+(-6)=-9$。每个原加数都恰好使用一次，负号没有跟丢。

### 十字幻方的中心数

> 来源ID Q01-26；第1章有理数；1-50/full.md 第3517–3519行。原答案与解析定位：1-50/full.md 第3537–3539行。

例1 新考法（2024 陕西）小华探究“幻方”时,提出了一个问题:如图,将 0,-2,-1,1,2 这五个数分别填在五个小正方形内,使横向三个数之和与纵向三个数之和相等,则填入中间位置的小正方形内的数可以是\_\_\_\_。(写出一个符号即可)

![](图片/01-原图-50b03f1a01fe.webp)

**原资料答案与解析：**

例1 解析 $-2+0+2=-1+0+1$ , $-1+2+0=-2+2+1,-1+(-2)+2=0+(-2)+1$ , 共3种情况.

答案 0(也可填“2”或“-2”)

**展开解析（依据原详解补足理由与步骤）：**

横向和纵向都包含中心数 c，把相等两式同时减去 c 后，要求横向剩下两数的和等于纵向剩下两数的和。若中心填 0，可以让横向两端为 −2、2，纵向两端为 −1、1，两组端点和均为 0，两行总和也均为 0，故填 0 即可。

原答案还允许 2 或 −2：中心填 2 时，两组端点可配成（−1，0）和（−2，1），端点和都是 −1，加上中心后都是 1；中心填 −2 时，可配成（−1，2）和（0，1），端点和都是 1，加上中心后都是 −1。

若要核对没有其他中心值，五数总和为 0，两组端点和相等且是整数 s，就有 $2s+c=0$。c 必须是偶数，给定五数中的偶数只有 −2、0、2，上述三种都已构造成功。题目只要求写一个，写 0 已够；此处列出另两种是展开原解析已有的三种情况。

## 易错

- 异号相加把两个绝对值相加：两个方向会抵消，应较大减较小。
- 结果符号跟第一个加数：异号且大小不等时，跟绝对值较大的一方。
- 与0相加得0：0表示没有新增变化，原数不变；得0是乘0的规则。
- 负数加负数写正：加法的同方向累积仍是负，不能套乘法符号口诀。
