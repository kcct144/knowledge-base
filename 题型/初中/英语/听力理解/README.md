# 听力理解

初中英语。通过听句子、对话或独白获取信息，按任务选图、选答语、选答案、排序、判断或填写信息。先读题规再用本题型流程，不假定所有地区都同一遍数、词数或时限。

本册提供18组、44小题的题面、答案和文字稿；**没有本地实际音频**。条目可独立学习判断方法，不能据看稿答对评估真实听辨。必要选项图已保留，二维码不冒充可播放录音。

材料见[题型介绍](题型介绍.md)、[考点列表](考点列表.md)、[条目索引](条目索引.md)、[学习路径](学习路径.md)。[学习进度模板](学习进度模板.md)只是空白模板，本次资料建设没有导入学生能力状态。

## 路由边界

- 有音频输入，任务为获取或处理听到的信息，归本题型；多题不改变归属。
- 要录制本人朗读或口头回答，归人机对话；能听懂与能说出分开判断。
- 仅给阅读文章及书面问题，归相应阅读题型；听力原稿复盘仍在这里，但标为文字稿讲解。
- 听句子选答语调用情景交际知识，当前主任务仍是听力；不能只看选项短句便路由语法选择。

## 教学决策

先明确材料载体和题规，再找学生断点。只解决报告或原错题已暴露的第一个问题：辨不出声音、认错问法、配错人物动作、漏方案更新、数值单位不合、或书写空数错误。没有实际音频或学生真实听答记录，不能把某次看稿出错断定为声音识别弱。

讲声音断点需实际可听材料；讲内容关系可用本册原稿，但先说清媒介。给提示以后答对与无提示答对分开，刚看过稿再听原题不是新题独立证据。无可靠原答案只讨论证据，不判分、不更新能力。

反馈顺序为：原题目标→学生实际依据→第一个断点→对应的一步修复→原文核对。学生只卡一处就讲那处，不按12考点目录整套灌输。听前预测不能泄露答案；播放次数、暂停和重听以任务或学生训练要求为准。

本轮达到目标就停止；真实听辨进阶需未见稿的新音频独立获取信息，并说明依据，必要时隔期复查。资料建设本身不证明任何学生已会。需要练习时先找真实可用题源；本目录尚无音频练习文件，不靠自编声音或旧文字题冒充原录音。

## 来源与准入

本题型由用户确认目录，依据所给2026版书中的多种完整实例建设。官方[Cambridge听力任务说明](https://www.cambridgeenglish.org/exams-and-tests/qualifications/key/format/)用于核对声音输入、图像选择、信息填写和主旨等独立任务形态，不移植该考试分值与时限。原题考试标签仅按书保留，未独立验证真题身份。作者核验通过，未作独立教学验收。
