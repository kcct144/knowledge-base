# 特殊疑问词

**一句话概念** — 用 who / what / which / whose / when / where / why / how 等问句词，问出句子里缺的那一类信息。

## 怎么认

选项是不同特殊疑问词：

```text
who / when / why
what / which / whose
where / how / when
```

它们既可用于直接疑问句，也可引导宾语从句等结构。

**信号不是绝对规则**：同一个词既能直接提问也能引导从句，认出选项只是第一步，还要看它在句中作什么成分。

## 思路

**先看缺哪类信息，再看词在句中作什么成分。**

1. **缺哪类信息**：人 / 物 / 选择范围 / 所属 / 时间 / 地点 / 原因 / 方式；有前后问答应先对齐（回答由 Because 引出 → 问 Why）
2. **词的作用**：疑问词在句中作主语、宾语、定语还是状语；作主语时后面直接接谓语
3. **语序**：进入宾语从句后通常使用陈述语序

依据行：who 问人，what 问事物或内容；which 常在明确范围中选择，whose 询问所属；when 问时间，where 问地点，why 问原因，how 问方式或状态；how many / how much / how long / how often 等组合要结合被询问的信息。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 识别 | 从选项认出是特殊疑问词 | 不要求判答案 |
| L1 基础流程 | 按缺失信息和回答内容选主要疑问词 | 从句语序和成分 |
| L2 成分 | 疑问词在句中作主语、宾语还是状语 | 与从句引导词交叉的情况 |
| L3 从句语序 | 宾语从句用陈述语序、词序检查 | — |

**默认停在 L1。**

## 怎么讲

1. 先给上面那句概念，够认就行
2. 用最简例子走一遍「缺什么信息 → 选哪个词 → 依据」
3. 只讲当前台阶，别顺手把从句语序和交叉情况一起倒出来
4. **常见卡点**：
   - 不看回答内容，只凭句子翻译选择
   - 混淆 what 和 which 的范围
   - 宾语从句中仍使用疑问语序
   - 认出问人或问物，却没有检查疑问词在从句中的成分

## 易错

**看不出这里要按回答或范围反推。**

```text
—Why did the bell stop ringing?
—Because a cat was sleeping on the button.   ← 回答由 Because 引出，问题用 Why
what / which                                  ← 差别常在于有没有明确选择范围
```

回答里的 Because 是问句该用 Why 的直接线索；what 与 which 的取舍，要回到上文有没有给出范围。

## 例题

**例一**　The children wanted to know ____ was inside the tower.
A. who　B. when　C. why
→ **A**。空格指塔里的人，并在从句中作主语，所以用 who。

**例二**　—____ did the bell stop ringing?
—Because a cat was sleeping on the button.
A. Where　B. Why　C. How many
→ **B**。回答由 Because 引出原因，问题应使用 Why。

（两例均为自编）
