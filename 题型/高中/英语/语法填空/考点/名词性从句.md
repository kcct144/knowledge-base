# 名词性从句

**一句话概念** — 一个从句**整体**作主句的主语 / 宾语 / 表语 / 同位语；分析分两层：整个从句在外面做什么，引导词在从句里做什么。

## 怎么认

无提示词，从句整体当名词用（作主语、宾语、表语或同位语），就是名词性从句。

**信号不是绝对规则**：不把"认出从句名称"当成"会填"。

## 思路

**先看整个从句在外的身份，再看从句内部缺什么，最后选引导词。**

1. **看外部**：整个从句在主句里作主语、宾语、表语还是同位语？
2. **看内部**：从句内部缺不缺主语 / 宾语？还是成分完整？
3. **选引导词**：缺成分用 `what` 等；成分完整用 `that`；表"是否"用 `whether`。
4. **复核从句类型**。

## 台阶（讲到哪停）

材料里的 Unit 12，逐关如下，**每一关一级，不合并**。

| 关 | 本级只解决 |
|---|---|
| 01 | 主语从句内部确定 what 所承担的主语作用 |
| 02 | 宾语 / 表语从句内确定缺少的宾语 |
| 03 | 用 that 连接内容完整的同位语从句 |
| 04 | 混合判断是否、事物与内容连接，并复核从句类型 |

不要求逐级学完；按当前断点挑关。

## 怎么讲

1. 先给概念：**两层**——外面的身份 + 里面的缺口。
2. 用一句 `What makes it special is ...` 走两层分析。
3. **常见卡点**：
   - 把整个从句的作用和引导词的作用混为一谈
   - `that` 与 `what` 混（`that` 后不缺成分，`what` 后缺）
   - 只认名称，不判内部缺口

## 易错

**先看从句内部缺不缺成分，再看整体作用。**

```text
What makes Yunjin special is ...  ← 从句缺主语 → what
What is so breathtaking ... is ... ← 从句缺主语 → what
that 引出内容完整的从句           ← 从句不缺成分 → that
whether / if                      ← 表"是否"
```

`what` 在从句里一定充当成分；`that` 后面的从句成分完整。
