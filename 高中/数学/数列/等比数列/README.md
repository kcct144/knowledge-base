# 等比数列

等比数列各项非零，从第2项起后项除以前项都等于同一个非零常数q。由递推相乘得到aₙ=a₁qⁿ⁻¹。零数列不能按商的定义算作等比数列；平方中项关系也须和各项非零、完整下标范围一起使用。

先读定义和性质，再读前n项和及单调最值。q=1时Sₙ=na₁；q≠1时由Sₙ与qSₙ错位相减得到Sₙ=a₁(1−qⁿ)/(1−q)。q<0时奇偶项异号，不直接沿正底数连续指数图象判断全列单调。

等长块和满足后一块等于q的块长次幂乘前块，但块和可能全为0；须核块和非零后才称这些块构成等比数列。等比中项G²=ab给正负可能，依题给正项等条件筛选；对数变换需项为正、底数大于0且不等于1。最大最小值须核下标、奇偶和取点是否实际达到。
