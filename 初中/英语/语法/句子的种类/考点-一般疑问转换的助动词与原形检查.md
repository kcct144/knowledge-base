## 讲解

### 判据

要求陈述改一般疑问，先找外层现成的be、情态或第一个助动词；若当前结构需do支持，则按原时态人称选do/does/did，再恢复实义动词原形。to be中的be是非限定部分，不能把它误认作可直接前移的原限定谓语。

### 流程

1. 原Linda used to be a dancer.陈述过去身份，不是现在Linda is a dancer.；把used to整体标为过去习惯表达。
2. 本题按原解析采用did疑问式，把Did放在Linda之前，首字母大写。
3. did承担过去时，原used恢复use；原to be a dancer作为后续部分保留。
4. 按实际原页两个空的先后回填Did和use，句尾原问号保留，得到完整的Did Linda use to be a dancer?。
5. 再核对有无重复助动词、人称和时态变化。若原句是完成结构，前移have后分词保留，不把这一use恢复原形的动作推广到每种疑问句。



### 本章补充：EN-SENTUSE

新增两例分别验证现成完成助动词与do支持。Zibo原has become整体完成，Has前移，become仍分词；末空yet是本原中性询问，不由此禁用带意外语气的already疑问。Bob原set out是已出发过去叙事，Did承担过去，后set原形；set前后拼写相同不代表没变语法功能。实际页两空恢复，不能因为OCR少空省略其中一个所需结构。

## 例题

### 原例题 EN-SENT-E05

例（2024 四川达州中考）Linda used to be a dancer.（改为一般疑问句）

\_\_\_\_ Linda \_\_\_\_ to be a dancer?

**OCR恢复说明**：实际PDF第44页有两个空，位于Linda前和Linda后；恢复空格位置，答案Did；use。

**原答案**：Did；use。

**原解析（原文）**

分析句子结构可知,谓语动词是实义动词 used,时态为一般过去时。改为一般疑问句时需要在句首增加助动词 did,谓语动词变回原形。故填 Did;use。

**完整解析（依据原解析展开）**

原句used to be表达过去习惯或身份，按资料要求采用did构成一般疑问句。第一空在主语Linda前，填句首大写Did；did承担过去时，第二空由used还原use，后面原有to be a dancer保留。完整句为Did Linda use to be a dancer?不是Did Linda used to，也不是把不定式中的be移到句首。原解析称used为实义动词是为句型转换作简化说明，used to应整体识别为过去习惯结构。


### 原例题 EN-SENTUSE-E05

例1（2023 黑龙江牡丹江中考）Zibo barbecue （烧烤）has already become a hit.（改为一般疑问句）

\_\_\_\_ Zibo barbecue become a hit \_\_\_\_?

**OCR恢复说明**：实际351第1页Has在主语前，yet在hit后，两空漏识

**原答案**：Has；yet。

**原解析（原文）**

分析句子结构可知,谓语含助动词 has,时态为现在完成时,改为一般疑问句时直接将助动词 has 放到句首,首字母大写;陈述句中的 already 在疑问句中要改为 yet,放在句末。故填 Has;yet。

**完整解析（依据原解析展开）**

原has already become为现在完成，has是可前移的限定助动词，主语Zibo barbecue单数，用句首Has；become是完成分词而非恢复原形动作，拼写恰同原形。原题另句末空按中性完成询问取yet，完整Has Zibo barbecue become a hit yet?。不借Does破坏完成结构，不把has与become都提前。

原解析说already疑问要改yet过度绝对。already也可在疑问里带意外或提早发生语气；本题句末空和原任务采用常见yet询问完成。保原答Has/yet，纠正普遍禁用already的结论，不给新增另题。

### 原例题 EN-SENTUSE-E06

例2 (2024 黑龙江牡丹江中考) Bob set out on his new journey this morning. (改为一般疑问句) \_\_\_\_ Bob \_\_\_\_ out on his new journey this morning?

**原答案**：Did；set。

**原解析（原文）**

分析句子结构可知,谓语为实义动词 set,时态为一般过去时,改为一般疑问句时要借助助动词 did,将 did 放到句首,首字母大写,再将 set 还原为动词原形。故填 Did;set。

**完整解析（依据原解析展开）**

原Bob set out...this morning在题内已发生叙述，set为过去拼写，与原形相同但语法位置不同。纯实义过去谓语需Did句首，后set回到原形，其他out/on/his...不改，原Did/set。不因set没ed就用Does，不将人称Bob单数覆盖过去事件时间；this morning本身依说话时点可未结束，但当前原陈述过去set与题解给过去读取。

## 易错

- 把be移到句首：它在used to be中不承担原外层过去时。
- Did后保留used：时态词形重复。
- 句子改问句就删除to：use to这一题要求的结构需完整保留。
