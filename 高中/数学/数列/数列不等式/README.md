# 数列不等式

数列不等式先读清“对所有n成立”还是“存在n成立”，并保留正整数、有限范围及参数条件。恒等裂项不改变值，放缩替换改变值：先证明逐项比较和方向，再在同一合法范围相加，说明最终严格性从哪里来。

参数问题把原不等式等价转成参数与某个数列值的比较。乘分母前核符号；求全体成立要找所有项的共同界，求存在要找合法项。最大最小值未必存在，确界只表示最紧的界，还须据原严格或非严格比较判断边界参数能否取到。

使用分组、裂项或归纳证明，须说明新增项如何被控制。有限项的数值核算可核算术或提出猜想，不能证明全体下标。需要无穷背景的原题可通过有限几何和上界解释，不据此自动覆盖数列极限或无穷级数专题。
