# 正确

**一句话概念** — 文章**完整**的同时，让基础表达可靠：人称、主要时态、动词形式、单复数、拼写、标点。

## 怎么认

学生已经有可誊写底稿，但读起来错误较多时进入这一层。看的是**反复出现、影响理解**的那一类，
不是挑个别小毛病。

## 怎么做

**只选当前作文暴露最明显的一类错误**，改完，再写一篇**新**作文验证。

常见的一类：

- 人称不统一（一会儿 `I` 一会儿 `we`）；
- 时态混乱（记叙里现在、过去混用）；
- 主语和动词不一致（单复数、三单）；
- 动词形式错（该用 `to do / doing / done` 的地方用错）；
- 单复数、拼写、标点。

**不要把一篇作文变成完整语法课程。** 一处错误只处理当前的，不讲整章语法。

## 怎么判

- 判的是**是否影响理解**，不是错误数量；先改最影响理解的那类。
- 修改前后的对照要能说清「原来错在哪、为什么改、改后对在哪」。
- 学生在**新作文**里独立避免了同类错误，才算过关；只会改旧作文不算。

## 怎么讲

- 先肯定他做对、能用的句子，再指出第一个断点。
- 用「原句 → 问题 → 改句」三步，一次一类。
- 给过提示的部分要注明；下次换新题不再提示还能对，才记为可独立。

## 卡点

- **基础错误影响理解**：人称、时态或基础语法不稳 → 只挑出现最多的那一类。
- **改一处错一片**：说明他还没掌握这个形式 → 退回正确简单句版本，别硬升难度。

## 易错

- 借一处错误顺带讲完整语法专题，把作文课变成语法课。
- 为了「正确」把正确但简单的句子换成没把握的难句，反而增加错误。
- 优化过程中错误变多 → **退回上一版正确底稿**，不要继续。
