## 讲解

### 判据

要求方根落在哪个整数区间、近似到哪位或区间内有多少整数时，先用相邻完整平方/立方夹住被开方数。若要求四舍五入，还要比较目标位的半单位中点，不能只取夹逼的左端。

### 流程

1. 如表达式由同类根组成，先准确化简以缩小估值范围。√27−√3=2√3=√12，直接由9<12<16判断3<m<4；分别粗估两根再相减可能无法得到这个范围。
2. 从相邻整数幂开始夹，再按要求向十分位、百分位逐层细分。非负平方保持大小，立方在实数范围保持大小。
3. 舍入前检查区间中点。√7夹2.64与2.65时，比较2.645²与7，发现根在中点右，结果2.65；立方根100夹4.6与4.7时，比较4.65³与100，根在中点左，结果4.6。
4. 若根不等式限定整数被开方数，平方后得整数端点开区间。两端整数且不包含，数目是右端减左端再减1；两区间比较个数时都执行同一规则。
5. 检查包含关系和整数前提。原a、b、n均正整数，n=1时a区间无整数，也符合少2个结论。

### 根式在数轴上的区间定位

> 来源ID Q02-17；第2章实数；1-50/full.md 第4668–4678行。原答案与解析定位：1-50/full.md 第4680–4684行。

例2 如图, 数轴上的点 A, O, B, C, D 分别表示数 -1, 0, 1, 2, 3, 则表示数 $\sqrt{5}-1$ 的点 P 应落在（）

![](图片/02-原图-86a9e8d2e280.webp)

A. 线段 AO 上

B.线段 BO 上

C. 线段 $BC$ 上

D. 线段 $CD$ 上

**原资料答案与解析：**

解析 $\because 4 <   5 <   9,\therefore 2 <   \sqrt{5} <  3,$

∴ $1 < \sqrt{5} - 1 < 2$ , ∴ 表示数 $\sqrt{5} - 1$ 的点 P 应落在线段 BC 上.

答案 C

**展开解析（依据原详解补足理由与步骤）：**

4<5<9，两端非负且为2²和3²，故2<√5<3；整个不等式减1得1<√5−1<2，因此P在线段BC，选C。AO表示[−1,0]，BO表示[0,1]，CD表示[2,3]，均不含这个严格在1与2之间的数；端点1、2也不等于√5−1。不要先把√5估为整数2而把P放在B点。

### 用中点幂判断舍入

> 来源ID Q02-19；第2章实数；1-50/full.md 第4740–4742行。原答案与解析定位：1-50/full.md 第4744–4750行。

例1 估算下列数的大小.

(1) $\sqrt{7}$ (精确到0.01).(2) $\sqrt[3]{100}$ (精确到0.1).

**原资料答案与解析：**

解析（1）因为 $2^{2} = 4,3^{2} = 9$ ，所以 $2 < \sqrt{7} < 3.$ 因为 $2.6^{2} = 6.76,2.7^{2} = 7.29$ ，所以 $2.6 < \sqrt{7} < 2.7.$ 因为 $2.64^{2} =$ $6.9696,2.65^{2} = 7.0225,$ 所以 $2.64 < \sqrt{7} < 2.65.$ 因为 $2.645^{2} = 6.996025,$ 所以 $\sqrt{7} >2.645.$

因为要求精确到0.01,所以 $\sqrt{7}\approx2.65$ .

(2) 因为 $4^{3}=64<100<125=5^{3}$ ，所以 $4<\sqrt[3]{100}<5$ 。因为 $4.6^{3}=97.336<100<103.823=4.7^{3}$ ，所以 $4.6<\sqrt[3]{100}<4.7$ 。因为 $4.65^{3}=100.544625>100$ ，所以 $\sqrt[3]{100}<4.65$ 。

因为要求精确到 0.1, 所以 $\sqrt[3]{100} \approx 4.6$ .

**展开解析（依据原详解补足理由与步骤）：**

（1）先由2²<7<3²夹整数，再用2.6²=6.76<7<7.29=2.7²夹十分位，再用2.64²=6.9696<7<7.0225=2.65²夹百分位。仅知2.64<√7<2.65还不能决定四舍五入；检验中点2.645，其平方6.996025<7，故√7>2.645，应向上舍为2.65。

（2）4³=64<100<125=5³，进一步4.6³=97.336<100<103.823=4.7³。舍到十分位的中点为4.65，4.65³=100.544625>100，故立方根100<4.65，应舍为4.6。精确到指定数位是四舍五入，不是只取所夹区间的左端。

### 先化根式再夹整数区间

> 来源ID Q02-23；第2章实数；1-50/full.md 第4806–4814行。原答案与解析定位：1-50/full.md 第4832–4834行。

例2 (2024 重庆 A) 已知 $m = \sqrt{27} - \sqrt{3}$ , 则实数 $m$ 的范围是 ( )

A.2<m<3

B. $3 < m < 4$

C.4<m<5

D.5<m<6

**原资料答案与解析：**

例2 解析 $m=3\sqrt{3}-\sqrt{3}=2\sqrt{3}=$ $\sqrt{12}$ ，易得 $3 < \sqrt{12} < 4$ .

答案 B

**展开解析（依据原详解补足理由与步骤）：**

27=9×3，非负平方根 $\sqrt{27}=3\sqrt3$，因为3√3≥0且其平方为27。故m=3√3−√3=2√3；它非负且平方为12，所以m=√12。9<12<16，得3<m<4，选B；A的(2,3)、C的(4,5)、D的(5,6)均不含√12。分别用两根很粗的整数估值相减，会丢掉精确区间，先按原结构合并更可靠。

### 平方根开区间内整数的个数

> 来源ID Q02-24；第2章实数；1-50/full.md 第4816–4820行。原答案与解析定位：1-50/full.md 第4836–4840行。

例3 新考法（2024 河北）已知 a, b, n 均为正整数.

(1) 若 $n < \sqrt{10} < n + 1$ ，则 n = \_\_\_\_.

(2) 若 $n-1<\sqrt{a}<n, n<\sqrt{b}<n+1$ ，则满足条件的 a 的个数总比 b 的个数少 \_\_\_\_ 个.

**原资料答案与解析：**

例3 解析（1）∵ $\sqrt{9} < \sqrt{10} < \sqrt{16}$ , ∴ $3 < \sqrt{10} < 4$ , ∴ n = 3.

(2)由题意得 $(n-1)^{2}<a<n^{2},n^{2}<b<(n+1)^{2},\because n^{2}-(n-1)^{2}=2n-1,$ $(n+1)^{2}-n^{2}=2n+1,2n+1-(2n-1)=2,\therefore$ 满足条件的a的个数总比b的个数少2个.

答案 (1)3 (2)2

**展开解析（依据原详解补足理由与步骤）：**

（1）3²=9<10<16=4²，所以3<√10<4，n=3。

（2）均非负，平方保持大小，得（n−1）²<a<n²，n²<b<（n+1）²。两个整数端点之间严格不含端点，整数个数=右端−左端−1。因此a有 $n^2-(n-1)^2-1=2n-2$ 个，b有 $(n+1)^2-n^2-1=2n$ 个，两者差为2。n为正整数，n=1时a数目0、b数目2，也符合。原解析比较区间长度直接给出差，本展开补上两区间各减1的计数依据。

## 易错

- 夹出最后两候选不等于已决定舍入，还需中点判定。
- 原数区间两端严格不含，计整数时各减1，不能把平方端点算进去。
- 根式化简应准确进行，不能先取近似造成误差相减。
- 开方的大小单调性有对应范围，平方前检查非负。
