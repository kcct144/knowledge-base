# 选词填空

初中英语。一篇短文挖若干空，给一个词框，从框里选词填进去；题目常要求用正确形式，并规定每词用几次、有几个多余词。

长什么样、完整示例见 [`题型介绍.md`](题型介绍.md)。

**以考点为中心。** 练的是两个意识：

- **考点意识** — 每个空主要靠哪类证据锁定（规则、词框、空格结构、搭配、语境、词形、全局约束），把它当一类题研究
- **流程意识** — 做这种题，**先看什么、再看什么**：读说明 → 快看词框 → 略读文章 → 双向匹配 → 定词形 → 全文检查

## 边界

- 每题自带选项、考语法和上下文 → `题型/初中/英语/语法选择/`
- 选项是不同实词、考词义 → `题型/初中/英语/完形填空/`
- 不给词框、按提示词自己写形式 → `题型/高中/英语/语法填空/`

## 怎么教

分两种场景。

### 讲解（他不懂这个考点）

1. **介绍考点**——这类空长什么样，靠什么锁定，我们叫它 ××
2. **讲解考点相关知识**
3. **总结一般思路**——做这类空，先看什么、再看什么
4. **让他带着思路，照着流程做**
5. **让他自己尝试**

第 1、3 步看 [`考点列表.md`](考点列表.md) 里那一行，细节点进它链的卡片。

### 讲题（他拿来一道题）

1. **找卡点**——规则读清了吗？词框认不认？空格需要什么说得出吗？断在哪一步？
2. **针对卡点讲解和训练**
3. **让他继续做新题**
