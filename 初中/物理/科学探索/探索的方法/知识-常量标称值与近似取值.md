## 讲解

### 是什么

资料中的“常量”可能包含物理常量、条件固定的物性近似值、设备标称值或教学估值。数字能否直接使用由量的含义、单位和题目条件共同决定。

### 怎么来的

真空光速与电池标称端电压的性质不同；同一水的沸点可随气压改变。把数字与条件一起记，才能解释为什么题目另给数据时应取题给，而非从记忆表强行覆盖。近似数值是为相应精度减少计算负担，不能无条件用于精密测量。

### 什么时候能用

先取题给数据，再核近似条件，统一单位和整题取值。材料密度须看状态、温度、成分；家庭交流标称和瞬时电压不同，安全值需环境条件。没有匹配的条件就不擅自使用。

## 例题

### 原常用数值表及取值条件

> 来源ID Q26-01；附录4常量与条件取值；201-233/full.md 第2067–2067行。原答案与解析定位：201-233/full.md 第2067–2067行。

| 物理量 | 数值 |
| --- | --- |
| 光(电磁波)在真空中的传播速度 | 约  $3.0 \times 10^{8}$  $\mathrm{m/s}$ |
| 声音在空气中的传播速度(15°C) | 340 $\mathrm{m/s}$ |
| 冰的熔点(标准大气压下) | 0 °C |
| 水的沸点(标准大气压下) | 100 °C |
| 水的比热容 | $4.2 \times 10^{3}$  J/(kg·°C) |
| 水的密度 | $1.0 \times 10^{3}$  $\mathrm{kg/m^3}$ |
| 冰的密度(0°C) | $0.9 \times 10^{3}$  $\mathrm{kg/m^3}$ |
| 酒精的密度 | $0.8 \times 10^{3}$  $\mathrm{kg/m^3}$ |
| 铁的密度 | $7.9 \times 10^{3}$  $\mathrm{kg/m^3}$ |
| 铜的密度 | $8.9 \times 10^{3}$  $\mathrm{kg/m^3}$ |
| g的数值 | 9.8 $\mathrm{N/kg}$,粗略计算时可取 10 $\mathrm{N/kg}$ |

| 我国交流电的周期 | 0.02 s |

**原资料答案与解析：**

原表直接给出常用数值，没有另列习题答案；完整原句及其条件见上表。

**展开解析（依据原详解补足理由与步骤）：**

逐项看条件而非把全部数字叫不变常量：

- 真空光速约$3.0\times10^8\,\mathrm{m/s}$只用于真空或题设相应近似；声音在15°C空气中取340 $\mathrm{m/s}$，介质、温度改变不能机械套用。
- 纯冰熔点0°C、纯水沸点100°C对应标准大气压等相应条件；气压、杂质会改变物态温度。
- 水比热容取$4.2\times10^3\,\mathrm{J/(kg\cdot{}^\circ C)}$是学校范围的近似；不因物质名相同就忽略状态与温度。
- 水、0°C冰、酒精、铁、铜密度分别取$1.0,0.9,0.8,7.9,8.9$乘$10^3\,\mathrm{kg/m^3}$。这是相应材料和常见状态的近似；酒精浓度、温度等未由原表详列，实际数据不能只凭名称唯一确定。
- $g=9.8\,\mathrm{N/kg}$，粗略取10时应统一整题取值，题干另给则以题干为准；g会随地点等略变，不是物体质量的单位。
- 标准大气压$1.013\times10^5\,\mathrm{Pa}$对应标准约定；760 mm汞柱是相应标准重力、温度等条件下的等效压强表示，不是任何液体760 mm。
- 干电池1.5 V、单节铅蓄电池2 V是原表常见标称；使用状态和具体电池类型会影响端电压，不能把所有可充电电池都叫2 V。
- 原“不高于36 V对人体安全”过于绝对：一般教学安全口径需结合干燥、皮肤和接触条件，潮湿等场景有更严格要求。低于36 V不能保证任何环境任何接触都无害；原句保留并纠正，不作为尝试触电依据。[官方条件说明](https://yjt.hunan.gov.cn/tszt/aqzs/202007/t20200728_13103073.html)。
- 我国家庭供电220 V按常见交流标称值理解，不是每时每刻同方向的恒定值；50 Hz表示每秒50个周期。因此周期$T=1/f=1/50\,\mathrm{s}=0.02\,\mathrm{s}$。频率和周期由同一周期现象定义互为倒数，不是50次“正负合计”另除以2。

原附录只有数值表，无独立计算题；这些是对表中数值的规范解释。

## 易错

把密度、沸点、干电池电压当任何情形不变；把一般安全口径当绝对保证。
