## 讲解

### 是什么

先确定纯净物：同一种元素组成是单质，多种元素组成是化合物；含两种元素且之一为氧的化合物是氧化物。

### 怎么来的

分类先数物质种类，再数元素种类。氧化物是化合物子类；含氧化合物还可有三种以上元素，不能一律归氧化物。状态变化不改组成，冰仍为水，干冰仍为二氧化碳。

### 什么时候能用

单一元素也可组成多种单质的混合物，不能跳过纯净物前提；硬水与合金按多物质处理。氧气为单质，含氧字不满足氧化物定义。

## 例题

### 氧化物化学式分类

> 来源ID Q04-06；第四单元自然界的水；51-100/full.md 第386–394行。原答案与解析定位：51-100/full.md 第418–420行。

例2 (2024 江苏苏州中考)下列物质中属于氧化物的是 ( )

A. $\mathrm{KMnO}_{4}$

B. ${\mathrm{K}}_{2}{\mathrm{{MnO}}}_{4}$

C. $MnO_{2}$

D. ${\mathrm{O}}_{2}$

**原资料答案与解析：**

例2 解析 氧化物只含两种元素,且其中一种元素为氧元素。

答案 C

**展开解析（依据原详解补足理由与步骤）：**

选C。A$KMnO_4$含K、Mn、O三种元素；B$K_2MnO_4$也含三种，均非氧化物。C$MnO_2$只含Mn和O两种元素，是氧化物。D$O_2$虽含氧却是单质，不是化合物。含氧是必要条件，但还须纯净化合物与两种元素。

### 两种物质均为氧化物

> 来源ID Q04-07；第四单元自然界的水；51-100/full.md 第396–404行。原答案与解析定位：51-100/full.md 第422–424行。

例3 (2024 陕西中考)下列各组物质均属于氧化物的是 ( )

A.冰、干冰

B.铜、黄铜

C.硫、硫酸

D. 水、硬水

**原资料答案与解析：**

例3 解析 冰( $H_{2}O$ )、干冰( $CO_{2}$ )均属于氧化物;铜、硫是单质,黄铜、硬水属于混合物,硫酸由三种元素组成,不属于氧化物。

答案 A

**展开解析（依据原详解补足理由与步骤）：**

选A。冰是固态水、干冰是固态二氧化碳，均纯净且含两种元素其中之一为氧。B铜为单质、黄铜为合金混合物；C硫为单质、硫酸含三种元素；D水符合，但硬水含可溶钙镁物质，是混合物，因此不是“两种都符合”。冰与干冰名称相似，组成和变化规律不同。

### 没食子酸质量计算

> 来源ID Q04-12；第四单元自然界的水；51-100/full.md 第677–682行。原答案与解析定位：51-100/full.md 第722–724行。

例1 (2024 江苏宿迁中考)中医常用没食子酸(化学式为 $\mathrm{C}_{7} \mathrm{H}_{6} \mathrm{O}_{5}$ ) 治疗流感。下列有关没食子酸的描述正确的是 ( )

A. 没食子酸的相对分子质量是 170, 是氧化物  
B.没食子酸中氧元素的质量分数最大  
C. 没食子酸中碳、氢、氧元素的质量比为 $42: 3: 40$   
D. 没食子酸由 7 个碳原子、6 个氢原子和 5 个氧原子构成

**原资料答案与解析：**

例1 解析 A(×) 没食子酸不属于氧化物; B(×) C(√) 没食子酸中碳、氢、氧元素的质量比为 $(12 \times 7) : (1 \times 6) : (16 \times 5) = 42 : 3 : 40$ , 其中碳元素的质量分数最大; D(×) 没食子酸由没食子酸分子构成。

答案 C

**展开解析（依据原详解补足理由与步骤）：**

选C。每个分子C、H、O原子数7、6、5；相对质量贡献分别$12\times7=84$、$1\times6=6$、$16\times5=80$。A相对分子质量$84+6+80=170$对，但含三种元素不是氧化物，整项错。B共同分母170下，84大于80，碳质量分数最大，不是氧。C质量比$84:6:80$各除以2，得$42:3:40$正确。D这些个数属于一个分子，不能写整份物质只有这些原子。题干医学背景保留但不作为治疗证据。
