# 圆锥曲线

圆锥曲线先由距离关系定义，再选择坐标系得到方程。做题时把每个代数条件对应回几何对象：焦点、轴、真实交点、弦端点或切点。每条正文都给出必要定义、理由、使用条件和完整原例，可按当前问题单独阅读。

## 三种曲线先辨清

| 曲线 | 距离定义与非退化条件 | 原点中心、坐标轴方向的方程 | 先辨认什么 |
| --- | --- | --- | --- |
| 椭圆 | 到两个不同焦点距离和为2a，2a>2c>0 | x²/a²+y²/b²=1，a>b>0，或交换x、y | 较大分母对应长轴，c²=a²−b² |
| 双曲线 | 到两不同焦点距离差的绝对值为2a，0<2a<2c | x²/a²−y²/b²=1，a,b>0，或交换x、y | 正项对应实轴，c²=a²+b²，a不必大于b |
| 抛物线 | 到焦点与准线距离相等，焦点不在准线上 | y²=±2px或x²=±2py，p>0 | 未平方变量与符号定开口，焦顶距p/2、焦准距p |

本章标准式以题给的中心/顶点位置和轴方向为前提。平移坐标后须把中心或顶点带回；不能把任意位置的曲线强设为原点标准式。椭圆的0<e<1、双曲线的e>1、抛物线的e=1，与各自合法参数同时检查。

## 联立与证明时的共同检查

- 先确认方程表示所需的真实曲线、直线确实存在。消元后先查最高次系数；一元二次式才可使用判别式和韦达。双曲线的渐近线、抛物线的平行轴线需单独处理，一个公共点不无条件表示相切。
- 弦要求两个不同的真实端点。点差法先作差，除以坐标差前处理零值；由中点推出的候选直线还须检验弦存在，双曲线还要核同支或异支。竖直方向可交换消元变量或用向量表示。
- 距离最值既证明上/下界，也找出合法取点证明达到；只有趋近而不能取得时，用上确界/下确界的拓展解释，不误报最大值/最小值。根号、分母、轴线、指定弧或支、线段参数范围从原条件一直保留。
- 特例能帮助猜定点和定值，结论仍须对所有合法参数证明。约分、平方和消元后的必要条件要反向核验；所求轨迹还需充分性，明确删除点。切点公式先确认点在原曲线上，外点引切线另做存在性和数量判断。

直线方程、点线距离、反射和圆的基础见[直线与方程](../直线与方程/README.md)与[圆与方程](../圆与方程/README.md)。原题原解与补充解释、资料疑点分别标明；以正文给出的条件为适用边界。
