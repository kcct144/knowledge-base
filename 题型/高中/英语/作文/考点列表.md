# 考点列表

作文没有选择题那样固定的选项考点。这里的「考点」就是**写作能力项**：这次卡住时，该补哪一层。

## 怎么用这张表

**先按断点认能力项，再按该能力项的思路往下做。**

四层顺序是**前置关系**，不是难度标签：**成篇 → 切题 → 正确 → 优化**。不能成篇时，不先拿字数、评分点、高级句型压住学生。

有报告就按报告走，别从本表从头教。台阶按材料逻辑拟定。

| 能力项 | 常见表现（怎么认） | 思路（作答时重点做什么） | 卡片 |
|---|---|---|---|
| 成篇 | 面对题目写不出、只有零散词，或说「不会写 / 快没时间」 | 抓主题＋两三个内容点 → 选骨架 → 先得到可誊写底稿 | [成篇](考点/成篇.md) |
| 结构 | 不知用列点式还是记叙式；不会保留题目给的外壳 | 判任务是介绍/建议还是经历/故事 → 选骨架 → 保留称呼/开头/结尾 | [结构](考点/结构.md) |
| 要点 | 写得出但偏题、漏点 | 六项审题 → 一个要点对应一项 → 先补最明显漏点 | [要点](考点/要点.md) |
| 语言 | 内容完整但人称/时态/单复数/拼写错多，影响理解 | 先稳定人称和主要时态 → 动词形式、单复数、拼写、标点 | [语言](考点/语言.md) |
| 优化 | 已经能可靠成篇，学生要求更好 | 补漏点 → 补一两个细节 → 改善连接 → 只升级真会的表达 | [优化](考点/优化.md) |

**能力项不是分数**：成篇优先于高级表达；重复使用正确的简单句，好于为变化写错难句。
