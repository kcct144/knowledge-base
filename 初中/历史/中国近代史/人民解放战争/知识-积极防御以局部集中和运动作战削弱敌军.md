## 讲解

### 是什么

积极防御是本课自卫反击的作战方针：总体上应对敌军进攻，又主动选择有利战机。原作战原则是集中优势兵力、各个歼灭敌人，主要方式为运动战，主要目标为歼灭敌人有生力量。原则、方针、方式和目标各回答一个不同问题。

### 怎么来的

总体较弱若在各处同敌军硬拼，容易处处不足；敌军占地、展开作战时力量会分布在不同位置，我军机动集中力量，便可能在选定局部形成优势。各个歼敌使敌军可继续投入的一线力量逐步减少，这才从一次次战斗接到粉碎全面进攻。运动战的机动是为了争取战机，不是无目的逃跑；总体战略防御也不禁止具体战斗主动进攻。续表据有生力量的消耗判断持续攻势受挫，不能只以占了多少城作唯一胜负标准。

### 什么时候能用

材料同时出现“敌强我弱”“集中优势”“占了地盘却进攻受挫”，应分总体与局部、地盘与持续作战力量解释。原表未给每次交战的兵力数和地图，不能编数算优势比例；暂让地盘也不是任何时候都可以放弃城市的通用命令。

## 例题

本项原资料没有另列匹配的独立题。下面完整保留原表或原陈述作辨析，不将它另计为一道试题。

**原自卫反击表及续表（Y20-S04、S08）：**

| 项目 | 原内容 |
| --- | --- |
| 实际情况 | 国民党军队疯狂进攻，敌强我弱 |
| 中共中央号召 | 解放区军民以自卫战争粉碎国民党军队进攻 |
| 作战原则 | 集中优势兵力，各个歼灭敌人 |
| 作战方针 | 积极防御 |
| 主要方式 | 运动战 |
| 主要目标 | 歼灭敌人有生力量 |
| 结果 | 经过半年多作战，国民党军队虽占领一些地盘，但损失大量有生力量，能够用于一线的兵力日渐不足，对解放区的全面进攻被粉碎 |

**完整分析补写：**“敌强我弱”描述总体对比，不能推出我军在每一个具体地点都只能比敌人少。通过机动集中力量，在选定战场对敌军的一部分形成优势，才有条件各个歼敌；不是拿分散的少量兵力在所有地点同时硬守。运动战强调在机动作战中寻找有利战机，机动服务于作战目标，并非只撤退、不作战。积极防御既应对来犯，又主动选择时机与方法，因此总体防御可以包含具体的进攻行动。续表的判断依据是敌人一线作战力量减少、持续进攻能力受损；敌暂占地盘与其全面进攻被粉碎并不矛盾，也不表示土地、人口、生产的损失无关紧要。


## 易错

“主要方式”不等全程只许一种战法。地盘损失是真实困难，原表强调有生力量，并没有宣称土地、人民和生产都不重要。
