# 语篇填空

初中无共享词池的语篇填词：可有括号基本词、首字母或无提示，常混合。给词池走选词填空，每空选字母走语法选择或完形；高中材料按高中语法填空处理。单句词形题先查学科对应语法或词汇条目，不凭题名强加篇章。

## 教学与证据边界

本册龙、社区、苦甜、月饼四篇35空有原文、原答及完整原解析。先看题面词数、提示与允许形式，提示词不是答案，未提示也不只填虚词。别把一篇所有谓语统一过去或现在。原民俗、传说和叙述数据只作材料内容，不认证现实统计或个人操作建议。

断点先分原意不懂、词义入口缺、句架角色错、时间关系错或拼写漏。没有入口时示范一个由原句可判的空，说明“看到什么→需要何角色→哪条条件限制形式”，让学生继续；不把整篇所有空一轮灌完。反馈事实和形式分别说，错在to类别就只修这类判断，不扩讲所有非谓语。

若多个参考原允许，分别说明适用人数或含义；原来源不足不假称唯一评分答案。没有可靠参考只讨论证据，不判分或更新状态。练习按学生意愿用真实材料，教学例不冒作学生已完成；一个可迁移判断形成便结束本轮。
