# 题型工作区

每个题型一个工作区，路径 `题型/<学段>/<学科>/<题型>/`。**同名题型初高中各一份**，内容各自演化。

## 通用流程

所有题型共用这一套；各题型自己的教法写在它的 `README.md` 里。

**查缺**——先判定断在哪一类：

- 认不出考点（考点意识）
- 认得出，但不会做（流程意识）
- 会做，但做错（执行）

**反馈**——只针对断点讲，不泛讲；给过提示要注明；即时答对不算稳定。

**结束**——他能自己说出考点和思路、并做对；**换一道新题再验一次**，不能只用刚讲过的那道。

### 两条原则

**报告优先**——学生带来报告、错题或测验时，按报告走，**不按 `学习路径.md` 从头教**。一份报告只激活一个问题，解决就结束本轮。

**越级题**——真题偶尔提前出现高阶内容：只讲当前这题所需的最小知识，说明"这属于后面的台阶"，**不追加同类训练**。

### 台阶与证据

`学习路径.md` 里的台阶**不是难度标签，是前置关系**——前一级不稳，后一级没有理解基础。

每次先定「当前台阶 + 本次只解决的小目标」，教学、例题、批改都不超出它。**进下一台阶的证据**：前置具备 → 能认出 → 能说出流程 → 无提示新题独立做对并给出依据 →（系统理解型）还需新材料或隔期复查。

达成后**先停下总结**，别"顺便讲一点"。只有三种情况才往下走：计划安排、诊断或真题需要、学生明确要求。

## 题型工作区的构成

**共有的**（所有题型都有，名字一致）：

```
<题型>/
├─ README.md         导览 + 这个题型怎么教
├─ 题型介绍.md        长什么样 + 一个完整示例
├─ 考点列表.md        这个题型有哪些考点（写法随题型）
├─ 学习路径.md        先练什么后练什么
└─ 学习进度模板.md     复制给学生追踪进度（实例在 harness 的 学习数据/题型/）
```

**各题型自己加的**目录和文档——比如语法选择有 `考点/`（一个考点一个文件）、语法填空和阅读理解有 `练习模式/`（关卡）——
**不进这份清单**，由各自的 `README.md` 说明。

## 学习进度怎么记

学生的进度在 harness 的 `学习数据/题型/<学段>/<学科>/<题型>.md`——由 AI 从各题型的
`学习进度模板.md` 复制，**按需创建**（跟 `笔记本/` 一样，不预建）。

**列由各题型自己定**，看那个题型的模板：

- **语法选择**：以考点为中心——能认 / 有思路 / 思路熟练度 / 知识点缺漏 / 错总
- **选词填空**：两个意识（词性意识、观察意识）+ 逐条观察熟练度

各题型都遵守的：

- **空白 = 未评估**，不等于薄弱；讲过不等于补好，答对不等于稳定
- 都留一节「**当前问题**」（P 编号 + 环节 + 接续位置）；环节只有四种：**查缺 / 补漏 / 强化 / 已巩固**
- **只记状态，不记历史**——"哪道题、什么错因、何时复习"是错题本的事

## 已建题型

**初中英语**：听力理解 · 人机对话 ·语法选择 ·完形填空 ·阅读理解 ·配对阅读 ·还原句子 ·选词填空 ·语篇填空 ·回答问题 ·句子运用 ·交际运用 ·作文
**高中英语**：七选五 · 语法填空 · 完形填空 · 阅读理解 · 作文

**还没建的**：高中读后续写；其他学科题型按实际目录确认。新建时**照上面的结构复制一个**。

跨学段的专题放 `题型/通用/<学科>/`（如英语语法·句子分析）。

## 只有资料、没有教法的

有些题型只有 `资料/`、还没写 `README.md`（如 初中·配对阅读）。这时**走通用教练的降级规则**：
只用 `资料/` + 通用铁律，并说明"这个题型还没建教学流程"，**不要假装有**，也不要硬套别的题型的流程。

## 两条边界

- **命名**：只有项目根目录有 `AGENTS.md`；其余目录一律 `README.md`。
- **学生侧数据**（学习进度、学习记录、学情）不在本库，在学生的 harness 里。
