## 错法

把周期表20.18或6.941当克数，或减序数后把非整数强行当中子数。

## 正解

它是与碳-12标准的质量比值，单位相消；周期表标准相对质量不一定对应某一个同位素的整数质量数。求中子须有具体核素信息。

### 原相对原子质量公式案例

> 来源ID Q03-17；第三单元物质构成的奥秘；1-50/full.md 第2408–2418行。原答案与解析定位：1-50/full.md 第2408–2418行。

1. 定义：以一种碳原子(碳-12)质量的 1/12 为标准, 其他原子的质量与它相比, 得到这种原子的相对原子质量(符号为 $A_{r}$ )。

# 2. 计算公式

某原子的相对原子质量 $(A_{\mathrm{r}})=\frac{\text{一个该原子的质量(kg)}}{\text{一个碳-12原子质量(kg)}\times\frac{1}{12}}$ （原旁注：不是g或kg）

3.单位：相对原子质量有单位,国际单位为“1”,一般不写也不读。

4. 近似计算：整个原子的质量主要集中在原子核上, 相对原子质量 $\approx$ 质子数 + 中子数。

特别说明 碳原子有很多种,它们的质子数都是6,但中子数有6、7、8等,碳-12是指含有6个质子和6个中子的碳原子。

**原资料答案与解析：**

1. 定义：以一种碳原子(碳-12)质量的 1/12 为标准, 其他原子的质量与它相比, 得到这种原子的相对原子质量(符号为 $A_{r}$ )。

# 2. 计算公式

某原子的相对原子质量 $(A_{\mathrm{r}})=\frac{\text{一个该原子的质量(kg)}}{\text{一个碳-12原子质量(kg)}\times\frac{1}{12}}$ 不是“g”或“kg”一个碳-12原子质量 $(\mathrm{kg})\times\frac{1}{12}$

3.单位：相对原子质量有单位,国际单位为“1”,一般不写也不读。

4. 近似计算：整个原子的质量主要集中在原子核上, 相对原子质量 $\approx$ 质子数 + 中子数。

特别说明 碳原子有很多种,它们的质子数都是6,但中子数有6、7、8等,碳-12是指含有6个质子和6个中子的碳原子。

**展开解析（依据原详解补足理由与步骤）：**

这是原定义和计算关系，不是独立考试题。设一个碳-12原子实际质量为$m_C$，标准为$m_C/12$；某原子质量$m_X$除以这个标准，故$A_r(X)=m_X/(m_C/12)=12m_X/m_C$。分子分母都用同一种质量单位，单位相消，结果不带g或kg。把分母误写整个碳-12质量会少12倍。质子和中子质量相近且电子很轻，故初中近似为质子数加中子数；这不意味着周期表中的标准相对原子质量必须整数。
