# 优化

**一句话概念** — 学生已经能**可靠成篇**、有余力时才进入。按优先级补：**补漏点和明显错误 → 补一两个具体细节 → 改善连接 → 只升级真正会的表达**。

## 怎么认

- 底稿已经完整、大致切题、基础可靠；
- 学生明确要求「优化 / 写高级一点」。

## 思路

**每次只做一级，做完停。**

1. **补完成度**：还有没有空槽、主题是否跑掉、能补的必写要点是否漏掉、有没有明显的人称/时态/单复数/拼写错误；
2. **补细节**：只选一两个最值得补的位置，加人物、时间、地点、原因、做法或结果，不整篇重写；
3. **改善连接**：在学生已经会用的范围内补连接词；已有 `First of all`、`What's more`、`In the end` 时不为换词而换词；
4. **升级表达**：只替换学生真正学过、能再次写出来的表达。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 完成度 | 补空槽、漏点、明显错误 | 细节、连接、升级 |
| L1 细节 | 补一两个具体细节 | — |
| L2 连接 | 在会用范围内改善连接 | — |
| L3 表达 | 替换真会、能再写出的表达 | — |

**默认停在 L0。** 优化开始增加错误，就退回上一版正确底稿。

## 怎么讲

1. 先核对原题和要保留的真实内容，再做局部、可解释的修改；
2. 可以汇总成完整可誊写版本，但不替换已正确的骨架、不虚构学生经历、不塞入没掌握的难句；
3. **常见卡点**：
   - 学生说「全部重写」→ 仍先核对原题和真实内容；
   - 「高级」被理解成全文换难句 → 让每处升级都有明确作用。

## 易错

**没有原题就宣称优化稿已满足全部要求。** 只能做基础正确性和已确认内容的局部优化，并标明题目要点仍待核对。
**改动破坏了原来正确的句子。** 一旦开始增加错误，就退回正确的简单版本。
