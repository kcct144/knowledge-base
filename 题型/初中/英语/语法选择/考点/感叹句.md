# 感叹句

**一句话概念** — 感叹句用 `what` 或 `how` 引出；选哪个，看感叹部分的中心词是名词还是形容词、副词。

## 怎么认

选项常出现 `what / what a / what an / how`，句末通常有感叹号，或语气明显表示赞叹、惊讶。

常见结构：

```text
What + a/an + 形容词 + 可数名词单数 + 主语 + 谓语！
What + 形容词 + 可数名词复数或不可数名词 + 主语 + 谓语！
How + 形容词或副词 + 主语 + 谓语！
```

**信号不是绝对规则**：判断 `what / how` 的关键是中心词，不是只看中文「多么」；口语里主谓还可能省略，如 `What a pity!`。

## 思路

**先找中心词，再定 `what / how`。**

1. **找中心词**：感叹部分以什么为中心
2. **定感叹词**：中心是名词或名词短语 → `what`；中心是形容词或副词 → `how`
3. **补细节**：`what` 后若是可数名词单数，再判 `a/an`；检查后面的主语和谓语是否完整

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 识别 | 认出这类选项，注意句末感叹语气 | 冠词发音细节 |
| L1 中心词判断 | 找中心词，名词或名词短语用 `what`，形容词或副词用 `how` | 省略主谓的情况 |
| L2 结构细化 | `what` 后接可数名词单数时判 `a/an`；检查主谓是否完整 | 固定感叹方式 |
| L3 边界 | 省略主谓的口语感叹；同题兼考冠词 | — |

**默认停在 L1。**

## 怎么讲

1. 先给上面那句概念，够认就行
2. 用最简例子走一遍「信号 → 判断 → 依据」
3. 先找中心词，再套结构，别一上来就背公式
4. **常见卡点**：
   - 一看到名词就选 `what`，没判断名词是否属于后面的主语
   - 忘记可数名词单数前的 `a/an`
   - 把所有「多么」都翻译成 `how`
   - 只背公式，不先找中心词

## 易错

**看不出名词前的形容词不是中心。**

```text
a beautiful tower            ← 中心仍是名词 tower
How beautiful the tower is!  ← 中心是 beautiful，后面的 tower 是主语
```

名词前有形容词时，中心仍可能是名词；`How beautiful the tower is!` 不能因为后面出现 `tower` 就选 `what`。可数名词单数、复数和不可数名词对应的 `what` 结构不同。

## 例题

**例一**　____ lovely cat it is!
A. What a　B. How　C. What
→ **A**。中心是可数名词单数短语 `lovely cat`，用 `What a`。

**例二**　____ beautiful the old tower is!
A. What　B. How　C. What a
→ **B**。感叹部分以形容词 `beautiful` 为中心，后面是完整的 `the old tower is`，用 `How`。

（两例均为自编例题）
