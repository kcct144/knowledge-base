# 词框观察

**一句话概念** — 快看词框，给每个认识的词标一个"核心意思 + 最常用词性"，再想它可以填到什么样位置。词框不只是选词仓库，是缩小候选的入口。

## 怎么认

题感：每个词框都是一堆待选词。看它时不是背词义，而是问两件事：

- 这个词最常用是什么词性？
- 这种词性通常出现在句子的哪里？

## 思路

**一遍轻标注，不列全。** 第一遍只写最可能的一个入口，一个词可能兼多种词性，不要锁死。

| 词性 | 常见作用或位置 | 还要检查 |
|---|---|---|
| 名词 | 主语、宾语、表语；限定词、形容词或介词后 | 可数性、单复数、所有格、具体词义 |
| 动词 | 谓语；也可能在 `to`、情态动词或其他结构后 | 时态、主谓、语态、非谓语形式 |
| 形容词 | 名词前；`be` 或常见系动词后 | 是否真修饰名词或说明主语状态 |
| 副词 | 修饰动词、形容词、副词或整句 | 位置、程度、逻辑、具体词义 |
| 介词 | 通常引出名词、代词或动名词短语 | 固定搭配和时间、空间、关系意义 |
| 连词 | 连接词、短语、分句或句子 | 前后结构是否对等、逻辑关系 |
| 代词 / 限定词 | 指代人或物，或限定后面的名词 | 指代对象、人称、数、格，后面有没有名词 |
| 情态动词 | 位于主语后、动词原形前 | 语气和上下文意思 |

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L1 基本词性 | 给熟悉词标名词、动词、形容词、副词等常见词性 | 后缀派生体系、冷僻词义 |
| L1 明显搭配 | 认出少量一眼可见的搭配 | 长搭配表和固定结构清单 |
| L1 双向入口 | 从熟悉词说出它通常找什么结构或位置 | 精确语义和复杂边界 |
| L6 一词多性 | 一个词可作多种词性时，保留为多个候选 | 只在真题需要时 |

**默认停在 L1。** 词框能快速分成几个候选组就停，别顺手把后缀和派生都倒出来。

## 怎么讲

1. 先给上面那句概念，用一两个熟词示范标词性
2. 只标最常用那一个，不确定标 `?`
3. **常见卡点**：
   - 看到熟悉词义就定词义，不看常用词性
   - 一个词只记一种词性，遇到别的用法就排除
   - 想把词框所有词义、搭配一次列完，耗时又背不完

## 易错（题面看不出来的坑）

- 一词可能多词性：`well / fast / hard` 等既是形容词也可能是副词。
- 只看到熟悉词尾就锁死词性，如看到 `-ing` 就以为一定是进行时。
- 词框标注只是候选入口，不是最终答案。
