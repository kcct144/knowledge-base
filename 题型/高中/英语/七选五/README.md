# 七选五

高中英语。一篇短文挖若干空，**所有空共用一个句子选项池**，把句子放回后恢复连贯。
本题型覆盖五选四、五选五、六选五、七选五等“多空共享句子池”的短文还原任务；名称里的数字**不能代替题面说明**。

长什么样、完整示例见 [`题型介绍.md`](题型介绍.md)。

**以线索为中心。** 每个空先回答两个问题：

1. **缺句在这里做什么？**——判断它在本段或全文的语篇功能；
2. **它怎样接住前后？**——沿对象、关系、形式三条线找证据。

学生可以先记成三条线：**对象线**（前后在说谁、什么事、什么观点）· **关系线**（并列、转折、因果、举例还是其他）· **形式线**（句式、步骤或信息层级是否呼应）；核心口令：**形式帮助筛选，内容、关系和篇章功能负责确认。**

## 边界

- 每个空各自独立选项，或只给一个独立句子要求判断插入位置 → 走 `题型/高中/英语/阅读理解/` 的句子还原流程；混合试卷里共享池部分与普通阅读部分**分别路由**；
- 选项能否重复、每项用几次、有无多余项**一律按题面确认**，不能从“七选五”这个标签反推；题面没写清就标待核实，不“用过即删”、不靠最后剩一个定答案。

## 怎么教

### 讲解（他不懂这条线索）

1. **介绍线索**——这类空卡的是同一类判断，我们叫它 ××；
2. **讲解判断依据**——对象、关系、形式分别看什么；
3. **总结一般思路**——先看什么、再看什么；
4. **让他带着思路，照着流程做**；
5. **让他自己尝试**。

第 1、3 步看 [`考点列表.md`](考点列表.md) 里那一行，细节点进它链的卡片。

### 讲题（他拿来一道题）

1. **找卡点**——材料和答案可靠吗？关键内容读得懂吗？他当时依据了什么？已准入线索里的第一个断点在哪？
2. **针对卡点讲解和训练**——提示由少到多：先问对象或关系，再指向一处证据，最后才缩小候选；**不立即公布整组答案**；
3. **让他继续做新题**。

**证据边界**：没有可靠答案时只讨论衔接证据并标“待核验”，不判分、不统计正确率、不更新能力；答对但说不出依据，不算提升；做错也不能只凭答案反推他不会哪种方法。

**可选策略**（选项预检、高把握优先、把握度标记、跨空分配表、固定限时）都属于候选，只在报告出现速度、犹豫或候选冲突时邀请学生试一种，说明是“可选实验”，不作能力标准。
