# 写作手法

**一句话概念** — 作者怎样组织或呈现信息，以及这样写在局部起什么作用。

## 怎么认

`How does the author ...?` / `Why does the author mention ...?`

## 常见手法

| 手法 | 常见信号或表现 |
|---|---|
| 举例 | `for example / such as / like`，具体案例 |
| 对比 | `but / while / compared with`，两个对象并置 |
| 因果 | `because / so / as a result`，原因与结果 |
| 问题—解决 | 提出困难，再给办法或结果 |
| 顺序 | `first / then / next / finally` |
| 列数字 | 数量、比例、时间或实验结果 |
| 描述 | 特征、场景、动作和感受 |

## 思路

```text
确认题干问“手法”还是“局部作用”
→ 定位目标段或句
→ 找具体文本信号
→ 说清作者怎样写
→ 再说明它帮助解释、证明、对比或突出什么
```

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 认问法 | 认出问“怎么写”或“局部作用”的题 | 不要求辨手法 |
| L1 区分手法和作用 | 分清“怎么写”和“这样写起什么效果” | 常见手法 |
| L2 识别手法与局部作用 | 用原文信号认手法，说它在局部起什么作用 | — |

**默认停在 L1。**

## 怎么讲

1. 先给上面那句概念；
2. 演示“找信号 → 说怎么写 → 说局部作用”；
3. **常见卡点**：凭文体常识猜手法，不指出原文信号；出现数字或例子却不说它支持什么。

## 易错

- 出现数字不等于数字本身就是答案，还要说明数字证明什么；
- 出现例子时要回到例子支持的观点；
- 全文目的（作者为什么写整篇）属主旨大意，不在这里。
