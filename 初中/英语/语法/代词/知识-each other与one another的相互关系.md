## 讲解

### 是什么

each other、one another 表示两个及以上参与者相互作用；常作动词或介词宾语。反身代词说明动作回到施事自己，相互代词说明不同参与者彼此作用，不能因为都含“自己人”就互换。

### 怎么来的

I think you and I must have misunderstood each other/one another. 是你误解我、我误解你的互相关系，不是分别误解自己。原书同一句列 both forms，即说明不宜硬规定 each other 只能两人、one another 一定三人以上；现代常用中两式差别不大。

We can wear each other's/one another's clothes. 在整个相互表达末尾加 's，表示对方的衣服，clothes 是被穿的对象。这与 each of... 的每个或反身 ourselves 都不是同一结构；把单词拆译不能解释彼此的关系。

原提醒“以相互代词作宾语的句子不能变被动”说明不能将互相对象按普通独立名词硬提升为主语，丢掉谁与谁相互的联系。这一常见改写限制不能扩大为任何出现 each other 或其所有格的句子都绝不可能有被动语态；先认它在当前结构中是什么角色。

### 什么时候能用

描述参与者彼此的动作、交流或所属时，先核对是否真正互相，再选相应表达。两个参与者可用原书两种形式，不以数量口诀代替意思。相互表达通常需要一个可理解的复数主体或多方范围，不能只给一个无关联人物便孤立解释彼此。

本小节没有专门独立题，原误解与换穿衣服句足以说明相互与所属；不自编反身对比题或被动改写题。

## 例题

I think you and I must have misunderstood each other/one another. 原意思：我想你我之间一定有误会。原列两式均体现你我互相，不是每人对自身。

We can wear each other's/one another's clothes. 原意思：我们可以相互换着衣服穿。's 放在相互表达末尾，clothes 为所属对象。

## 易错

- **彼此等于各自自己**：相互和反身的动作方向不同。
- **两人强制排除 one another**：原句已同时给出两式。
- **each others'**：原相互所属为 each other's，不能将它当普通复数名词构造。
