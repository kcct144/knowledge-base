# 时态语态

**一句话概念** — 谓语动词要同时交代三件事：什么时候发生（时态）、主语自己做还是承受（语态）、主语是单数还是复数（主谓一致）。

## 怎么认

选项通常是同一动词的不同谓语形式：

```text
rings / rang / will ring
welcomes / is welcomed / are welcomed
```

当选项主要改变时间、助动词、被动结构或单复数，且没有明显 `to do` 对比时，优先想「时」。

**信号不是绝对规则**：没有明显时间词时，也可能靠上下文判断时态；看到 `be` 不一定是进行时，也可能是被动语态。

## 思路

**先确认空格是不是谓语、主语是谁，再找时间依据。**

1. **找主语再判单复数**：主语和谓语之间可能有较长修饰语，别只看离动词最近的名词
2. **判断动作关系与时间**：主语是自己执行（主动）还是承受（被动）？再找时间标志词和事件发生顺序
3. **代回上下文**：与同句其他谓语核对，必要时利用前后谓语和事件关系判断

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 句子骨架 | 在短句中找到主语和谓语 | 时态混合、语态 |
| L1 一般现在时 | 经常、事实和当前状态；第三人称单数 | 其他时态 |
| L2 一般过去时 | 明确过去时间和过去叙事；规则及少量常用不规则过去式 | 完成时、被动 |
| L3 一般将来时 | `will do` 和明确的将来语境 | 条件、时间从句中的将来表达 |
| L4 三种基本时态混合 | 在一般现在、一般过去、一般将来之间按时间和上下文切换 | 进行时、被动、完成时 |
| L5 现在进行时 | `be doing` 与正在发生的动作 | 被动和复杂状态动词 |
| L6 被动语态 | 在已学时态中判断主动或被动 | 完成时被动等复合结构 |
| L7 完成与复杂结构 | 现在完成时及项目确认需要的复杂结构 | — |

**默认停在 L1。** 一次原则上只学一个台阶，按 L1 → L2 → L3 → L4 铺设三种基本时态；L1—L4 未稳定时，不主动讲或考被动语态、现在完成时。
## 怎么讲

1. 先给上面那句概念，够认就行
2. 强调一个完整分句通常需要一个谓语核心，先找主语再判断单复数
3. 只讲当前台阶，别顺手把被动、完成时一起倒出来
4. **常见卡点**：
   - 只看到时间词，不检查主动或被动
   - 只看离动词最近的名词，找错真正主语
   - 看到 `now` 就机械选择进行时，忽略动词和语境
   - 前文使用过去时，就把所有句子都改成过去时

## 易错

**看不出句中藏着被动，或藏着一个更远的主语。**

- `be doing` 是进行时，`be done` 常是被动语态，不能只看到 `be` 就下判断
- 主语与谓语之间有较长修饰语时，容易找错主语
- 没有明显时间词时，要读前后谓语和事件关系，不能只看本句
- 过去叙事中出现客观事实时，客观事实仍可能用一般现在时

## 例题

**例一**　Last night, the bell ____ at ten o'clock.
A. rings　B. rang　C. will ring
→ **B**。空格是谓语；主语 `the bell` 为单数；`Last night` 表示过去，所以用一般过去时 `rang`。

**例二**　The lost cat ____ by everyone at its new school.
A. welcomes　B. is welcomed　C. are welcomed
→ **B**。猫是被欢迎的对象，要用被动；主语 `cat` 为单数，所以用 `is welcomed`。

（两例均为自编）
