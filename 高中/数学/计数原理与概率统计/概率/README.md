# 概率

先说清“一次试验做什么、记录什么”，再确定样本空间和事件。计算前说明等可能性、互斥性或独立性的依据；这些是不同的条件，决定能用哪条公式。

1. 读[随机试验、样本空间与事件](知识-随机试验样本空间与事件.md)、[事件关系与并交运算](知识-事件的包含相等与并交运算.md)、[互斥与对立](知识-互斥事件与对立事件.md)。练[现象与事件分类](考点-区分随机现象与确定事件.md)、[列举样本空间](考点-列举样本空间与基本事件.md)、[翻译事件条件](考点-用事件运算翻译条件并判断关系.md)。检查[列举的顺序与身份](坑点-列举样本点忽略顺序身份或重复.md)、[互斥误当对立](坑点-把互斥事件一律当作对立事件.md)。
2. 读[基本性质与古典概型](知识-概率的基本性质与古典概型.md)、[加法与对立事件公式](知识-概率加法与对立事件公式.md)。练[等可能事件计算](考点-用古典概型计算等可能事件概率.md)、[由概率求数量与参数](考点-由概率条件求样本数量与参数.md)、[互斥分解与对立转化](考点-用互斥分解或对立事件求概率.md)。检查[结果名称不能保证等可能](坑点-把等可能性当成结果名称一样.md)、[重叠事件不能直接相加](坑点-直接相加重叠事件的概率.md)。
3. 读[独立性及判据](知识-事件相互独立的含义与判据.md)、[独立事件和补事件乘法](知识-独立事件与补事件的乘法公式.md)、[多个独立试验的组合](知识-多个独立试验的事件组合.md)。练[判断独立](考点-根据试验机制与概率判断独立性.md)、[同时或指定事件](考点-求独立试验中同时或指定事件的概率.md)、[恰好发生](考点-用互斥分解计算恰好发生的概率.md)、[至少发生](考点-用补事件计算至少发生的概率.md)。检查[互斥与独立混淆](坑点-把互斥与独立混为一谈.md)、[乘法的机制和条件](坑点-忽略放回机制或独立条件直接相乘.md)、[两两独立与相互独立](坑点-把两两独立直接当作相互独立.md)。
4. 读[频率、概率与稳定性](知识-频率概率与频率的稳定性.md)、[频率估计的条件与局限](知识-用频率估计概率的条件与局限.md)。练[频数频率求未知量](考点-由试验频数频率与总次数求未知量.md)、[解释生活概率](考点-解释天气抽奖与生活中的概率.md)、[比较游戏获胜机会](考点-按规则比较游戏获胜机会与公平性.md)。检查[概率误当固定次数](坑点-把概率当作每次必有的精确次数.md)、[稳定误当逐次逼近或补偿](坑点-把频率稳定理解成逐次逼近或补偿.md)。
5. 读[随机模拟模型](知识-随机模拟的模型与实施方法.md)，练[随机数与试验模拟](考点-用随机数或试验模拟估计概率.md)，检查[编码和规则](坑点-模拟编码未保持等可能性与试验规则.md)。先证明模拟规则对应原试验，再用大量模拟的频率估计；增加次数不能修正一个错误模型。

所选原题与原解保留，补讲和资料疑点另列。有限且等可能的样本点模型可用“有利结果数÷全部结果数”；一般有限模型要按各样本点的概率求和。一个事件的发生概率与某一批试验的实际频率也应分开理解。
