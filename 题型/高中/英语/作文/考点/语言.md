# 语言（句子与基础正确）

**一句话概念** — 在保持文章完整的同时，稳定**人称、主要时态、动词形式、单复数、拼写、标点**。重复使用正确的简单句，好于为了变化而写错较难句型。

## 怎么认

- 内容完整，但基础错误较多、影响理解；
- 人称在 I / we / you 之间跳；
- 时态混用，或动词形式、单复数、拼写出错。

## 思路

**只改当前作文暴露最明显的一类错误。**

1. **统一人称**：全文主要用 I、we 还是 you；
2. **定主要时态**：全文主要写现在、过去还是将来；
3. **查形式**：动词形式、名词单复数、拼写、标点；
4. **改完写一篇新作文验证**，而不是只改旧作文。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 识别 | 认得出哪句对、哪句错 | 讲整章语法 |
| L1 人称＋时态 | 全文人称、主要时态统一 | 其他语法点 |
| L2 形式细节 | 动词形式、单复数、拼写、标点 | — |
| L3 迁移 | 新作文独立避免同类错误 | — |

**默认停在 L1。** 不要借一处错误顺带讲完整语法专题。

## 怎么讲

1. 先保留学生所有正确、可用的句子；
2. 找第一个影响最大的断点，只处理它；
3. **常见卡点**：
   - 一处错误引出一整章语法 → 停，只补这一类；
   - 只在旧作文上改对 → 换新作文再验一次。

## 易错

**把模板里的难句当成学生的能力。** `so ... that`、`be about to`、`it was ... who`、`has taught` 等结构，学生背过可整句调用，但不证明他能独立变换；不要据此展开这些语法教学，也不要判定已掌握。
**为「高级」而全文换成陌生难句。** 「高级词汇、从句和高级句型」只是有余力时的优化，不是保底稿的准入条件。
