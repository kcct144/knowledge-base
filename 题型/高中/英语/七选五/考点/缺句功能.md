# 缺句功能

**一句话概念** — 每个空先回答：**缺句在这里做什么？**它在本段或全文中的语篇功能。

## 怎么认

先看这一段像是在做什么：

| 粗标签 | 可能的作用 |
|---|---|
| 命名或引入 | 提出接下来要谈的人、事、问题、观点或步骤，给后文提供展开对象 |
| 定义或展开 | 解释已经提出的对象是什么、为什么、怎样做或具体包含什么 |
| 例证或支撑 | 用例子、事实、理由或细节支持前文 |
| 承接或转向 | 接住前文并改变角度、层次或方向 |
| 结果或收束 | 说明结果、总结本段或引向下一部分 |

再看它和邻句是什么关系：并列或递进 / 转折或对比 / 原因或结果 / 概括或例证 / 时间或步骤顺序 / 问题与回应。

**最要紧的区分**：命名或引入是**把一个对象带入**当前语篇；定义或展开以**这个对象已经出现**为前提，继续解释它。段首、段中、段尾只能提供线索，不能单独决定功能。

## 思路

1. 先判这里要**命名引入**，还是**定义展开 / 支撑 / 转向 / 收束**；
2. 再看它与邻句的具体关系；
3. 用功能标签**缩小候选**，最后交回代回验证。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 识别 | 区分“命名或引入新对象”和“定义或展开已有对象” | 完整功能标签、邻句关系 |
| L1 基础 | 用“支撑、转向、结果、收束”给当前空贴功能标签 | 邻句关系分类 |
| L2 完整 | 判断该句与邻句的具体关系（并列、转折、因果、例证、顺序、问答） | 全文主线 |
| L3 整体 | 结合空格位置与全文主线，排除“局部通顺却不符合本段功能”的候选 | — |

**默认停在 L1。** 只有 L1 稳了、真题需要、或学生明确追问，才往下走。

## 怎么讲

1. 先给上面那句概念，够认就行；
2. 用最简例子走一遍“看本段 → 判功能 → 给候选”；
3. 只讲当前台阶，别一次列全五类标签和六种关系；
4. **常见卡点**：
   - 只看局部通顺就选，不判这里需要什么功能的句子；
   - 混淆“命名或引入新对象”和“定义或展开已有对象”。

## 易错

**段首、段中、段尾不是功能标签。** 位置只能提供线索：段首不一定“引出下文”，段尾不一定“总结”，不能按位置直接定功能。
**同一句可能同时承担两种作用**，功能标签也不是封闭分类，不能拿标签当答案公式。
