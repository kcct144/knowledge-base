# 配对阅读

多个信息或段落与同组选项配对，选项可为标题、读后感或图片。本册有猫狗五标题、五新闻七评论、三步骤四图片，配对不总左右栏，也不总有余项。

句子放回短文多空走初中还原句子，词框填词走选词填空。独立单句位置留阅读理解。选项使用次数依原指令，不从“配对”反推。

先查卡在哪：信息要点未抓、选项意义误解、只看关键词、漏限定或整组冲突。教学先把一条信息概括为事件/需要/段落功能，再示范一个候选匹配和一个最像余项的不同；学生能继续时停。反馈说明关系哪里相合，不能只说有同词。

旧题型介绍中的植物材料仅供结构观察、原未附答案，本次新书三组有原答案原解析，可从完整条目学方法。没有给旧无答案材料补造标准答案或改变学生实例。新练习按学生意愿与真实来源，不能依据教师加工宣布学生进阶。
