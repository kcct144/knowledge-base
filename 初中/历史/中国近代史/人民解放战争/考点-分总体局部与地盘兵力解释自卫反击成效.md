## 讲解

### 判据

原材料一面说敌强我弱、敌占地盘，一面说集中优势、全面进攻被粉碎，这是比较层次不同，应从局部作战怎样改变总体持续进攻能力入手。

### 流程

1.敌强我弱是总体条件，先确认不是每个战场都永远敌多我少。

2.机动集中我军，对敌军分布中的一部分形成局部优势；原原则因而可以实施各个歼敌。

3.逐次削弱有生力量，使敌可用一线兵力不足。地盘的暂得不能自动补回被削弱的作战力量。

4.把结果写回题目：全面进攻受挫。总体防御中的具体进攻与运动作战不矛盾，机动也不是拒绝战斗。

5.核112万与190多万的主体和统计方式，不用不同口径相减给出没有依据的伤亡数。

## 例题

本项原资料没有另列匹配的独立题。下面完整保留原表或原陈述作辨析，不将它另计为一道试题。

**原自卫反击表及续表（Y20-S04、S08）：**

| 项目 | 原内容 |
| --- | --- |
| 实际情况 | 国民党军队疯狂进攻，敌强我弱 |
| 中共中央号召 | 解放区军民以自卫战争粉碎国民党军队进攻 |
| 作战原则 | 集中优势兵力，各个歼灭敌人 |
| 作战方针 | 积极防御 |
| 主要方式 | 运动战 |
| 主要目标 | 歼灭敌人有生力量 |
| 结果 | 经过半年多作战，国民党军队虽占领一些地盘，但损失大量有生力量，能够用于一线的兵力日渐不足，对解放区的全面进攻被粉碎 |

**完整分析补写：**“敌强我弱”描述总体对比，不能推出我军在每一个具体地点都只能比敌人少。通过机动集中力量，在选定战场对敌军的一部分形成优势，才有条件各个歼敌；不是拿分散的少量兵力在所有地点同时硬守。运动战强调在机动作战中寻找有利战机，机动服务于作战目标，并非只撤退、不作战。积极防御既应对来犯，又主动选择时机与方法，因此总体防御可以包含具体的进攻行动。续表的判断依据是敌人一线作战力量减少、持续进攻能力受损；敌暂占地盘与其全面进攻被粉碎并不矛盾，也不表示土地、人口、生产的损失无关紧要。


**原战果陈述（Y20-S10）：**“从1946年7月到1947年6月，解放区军民在自卫反击作战中，共歼敌112万人，自身总兵力发展到190多万人，粉碎了国民党军队的进攻。”

**完整口径分析补写：**112万人是指定时期内累计的敌军损失指标，190多万人是我方发展后的总兵力状态，主体和统计方式都不同。因而不能用190减112求我方伤亡，也不能把112加190当新增兵员。“歼敌”不能全替换为“击毙”，原句没有给击毙、俘虏等细项，无法据此计算各项比例。原“190多”不是精确190。数字支持在反击中削弱敌人并发展自身力量的判断，却没有单独提供1947年6月全体敌军剩余人数。

**时段边界补写：**原重点进攻表包含青化砭、沙家店等先后战役；这些战役并不因排在该战果句上方便都发生在1947年6月前。党史资料核到沙家店作战在1947年8月，本条仅用来纠正排版可能造成的误读，不将这个补核日期加入原战果统计或伪称原题已给。


## 易错

不能由“粉碎”推出所有敌军已全部不存在；原战果是一段自卫反击统计，没有给每次战役人数，缺数据就不补数字计算。
