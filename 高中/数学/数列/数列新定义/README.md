# 数列新定义

新定义由原题自己的条件决定。先逐字拆出对象、下标、量词、运算和要求：是每一项、相邻项、任意两项还是存在某项；是元素的存在，还是每个位置的计数。重复的数仍可处在不同序号，不能把数列直接当集合删除重复项。

把定义转换成等式、不等式、递推或计数条件后，再用已有数列方法。必要条件得到候选结果，还须按原定义回验充分性、初值、整性和非零分母；不能只因几个算出的项符合就判断整列成立。

新运算按原约定执行，不擅自沿普通加乘的结合律、交换律。新情景先明确编号和次序，说明为何所构造的新数列适用等差、等比或求和方法，再将结论返回原题。
