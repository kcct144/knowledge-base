# 语法填空

高中英语。一篇短文挖若干空，**有提示词的填它的正确形式，无提示词的填一个适当的词**。考语法和上下文连贯。

长什么样、一个完整示例见 [`题型介绍.md`](题型介绍.md)。

**以考点为中心。** 练的是两个意识：

- **考点意识** — 看到提示词和空格，判断这题在考什么；给它起个名字，就叫考点
- **流程意识** — 做这种题，**先看什么、再看什么**

## 边界

- 每题自带选项、从中选一个 → `题型/初中/英语/语法选择/`
- 给一个词框、从框里选词 → `题型/初中/英语/选词填空/`
- 选项考不同实词、考词义 → 完形填空

**语法填空是高考题型（高中）。**

## 怎么教

**一次课一个专题**（见 [`专项课程/`](专项课程/README.md)），约 2.5 小时：

1. 读该单元的「做前说明」
2. 讲这个专题
3. 拿该单元的题当**例题**，示范一遍
4. 让他自己做同类的；**出练习题时参考例题的形式与难度**

**有报告（段位模式导出的）就按报告走**，别按课程从头教。

单个空怎么讲，看 [`考点列表.md`](考点列表.md) 和 `考点/` 的卡片。
