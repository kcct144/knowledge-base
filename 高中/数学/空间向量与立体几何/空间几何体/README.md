# 空间几何体

先用定义识别几何体，再理解直观图与实际尺寸的关系，最后计算面积、体积及切接球。空间图形画在纸上时会失真，长度和垂直关系必须从条件得到。

1. 读[棱柱棱锥棱台的结构](知识-棱柱棱锥棱台的结构.md)、[圆柱圆锥圆台与球的结构](知识-圆柱圆锥圆台与球的结构.md)和[简单组合体与展开图](知识-简单组合体与展开图.md)。用[按定义识别与旋转组合](考点-按定义识别几何体与旋转组合.md)核对底面、侧面、旋转轴与截面。
2. 读[斜二测画法](知识-斜二测画法.md)，再练[由直观图还原长度面积](考点-由直观图还原长度面积.md)。检查[直观图直接保长度角度与面积](坑点-直观图直接保长度角度与面积.md)，不要把纸上量出的角和长度当成原图条件。
3. 读[柱锥台的表面积与体积](知识-柱锥台的表面积与体积.md)、[球的表面积体积与截面](知识-球的表面积体积与截面.md)。练[面积体积及等体积转化](考点-求几何体表面积体积及等体积转化.md)与[展开侧面求最短路径](考点-展开侧面求最短路径.md)，先核对公式要求的高、母线和可行路径。
4. 读[内切球与外接球](知识-几何体的内切球与外接球.md)，再练[截面与球心距离求半径](考点-用截面与球心距离求半径.md)及[切接条件求球半径体积](考点-用切接条件求球半径与体积.md)。[截面圆半径与球半径](坑点-把截面圆半径当成球半径.md)是两种不同的长度。

面积、体积还要检查[侧棱母线与高](坑点-把侧棱母线当作高.md)以及[组合体内部接触面](坑点-组合体表面积重复计算内部接触面.md)。需要证明平行、垂直或作角和距离时，接着读[点、直线、平面之间的位置关系](../点、直线、平面之间的位置关系/README.md)。
