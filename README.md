# 知识库

AI 讲解时用的**内容库**：教材、题、题型、考点知识。
与 `学习数据/`（学生数据）、`.kilo/`（harness）分开维护，**一份知识库服务多个学生**。

## 根目录

| 目录 | 装什么 | 谁维护 |
|---|---|---|
| `教材/<学段>/<学科>/目录/<册别>.md` | 教材**目录**骨架（查章节名；以后可放 `电子书/`） | 老师 |
| `题库/` | **题**：一题一 md，带 id / 考点 / 台阶 / 状态；靠 frontmatter 标学科、题型、学段 | 老师 |
| `题型/<学段>/<学科>/<题型>/` | **题型介绍 + 做题思路**（入口与索引） | 老师 |
| `通用/` | 跨学科方法：时间分配、草稿规范、检查、心态 | 老师 |
| `初中/<学科>/`、`高中/<学科>/` | **学科内容**：知识（是什么）/ 考点（怎么判）/ 坑点（哪儿翻车） | 老师写 + AI 追加坑点 |
| `README.md` | 本文件 | — |

## 边界：谁说什么话

- **题型层**：这类题**怎么练**（题型介绍、做题思路、可用题清单）——是入口，不是内容本体
- **教材层**：考什么**范围**（章节骨架）
- **学段学科层**：这个考点**怎么理解、怎么判断、哪儿会翻车**（知识 / 考点 / 坑点）
- **题库**：可练的**题**（唯一题源，只有 `状态: 已校验` 的能用）

四者用**同一套考点名**互相关联，内容不重复。

## 三条关联规则

1. **题目不复制**：题型工作区只放 `可用题.md`（列出题库里适用本题型且已校验的题 id），不导出副本——副本会分叉、会过期
2. **考点不重复**：题型的"做题思路"每一步**指向**学科内容里的考点文件，自己不重写定义与判据
3. **坑点指向来源**：坑点条目写明来源与频次（如「来自 7 名学生的 12 道错题」），与错题本打通，按命中率排序

## 学生数据不进这里

学习进度、学习记录、错题、背诵卡都**不在**本目录——它们在每个学生自己的 workspace 里。
