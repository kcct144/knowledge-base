# 词汇门槛

**一句话概念** — 完形首先是词汇题：四个选项认不认识，决定这题能不能用来练方法。方法能帮你调用**已经认识**的词，不能替代词汇量。

## 怎么认

做题前，先标出四个选项中**不认识或说不清核心意思**的词，按数量分流：

| 生词数 | 默认判断 | 处理 |
|---|---|---|
| 0 | 可以正常训练方法 | 按流程作答 |
| 1 | 可以尝试，但答案可能靠排除 | 作答后补认该词；排除做对 ≠ 认识它 |
| 2 | 词汇已成为该题主要障碍 | 不把错主要归因于方法；先处理词义或换较易材料 |
| 3～4 | 该题无法可靠作答 | 停止硬猜，标记材料明显偏难 |

整篇很多题都达到两个以上 → 这份材料不适合练完形技巧，先降难度、补词汇。

## 思路

1. 逐题标生词 → 数数量 → 分流；
2. 判断的是**这题能不能用**，不是“做对没做对”；
3. 猜对不算掌握：排除了三个已知项选对，仍要记录生词没掌握。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 标生词 | 认出每题选项里不认识 / 说不清核心意思的词 | 不判答案 |
| L1 分流 | 按 0 / 1 / 2 / 3～4 生词数判断这题是否可用于训练方法 | 高频词积累 |
| L2 补漏 | 处理本次真正遇到的高频 / 必要词，再回原题 | 不背整张选项表 |

**默认停在 L1。** 通过后不要求背完整篇生词，直接进入篇章定位。

## 怎么讲

1. 先给那句概念：**方法不能替代词汇量**；
2. 用一道题的四个选项走一遍“标生词 → 数数量 → 得出这题能不能用”；
3. 只处理本次必要的词，不扩展同义词大全；
4. **常见卡点**：
   - 四个选项大半不认识，仍把错误归为“不会技巧”；
   - 把不认识的选项直接排除，碰巧做对就以为掌握了；
   - 用更多技巧训练掩盖材料不匹配。

## 易错

**“我认识”≠ 说得出核心意思。** 让学生用中文说出每个选项大意，不要替他假定；不确定的要当场标 `?`，不能靠“好像见过”混过去。

> 这一关是**前置闸**：不通就不进入后面的方法诊断。
