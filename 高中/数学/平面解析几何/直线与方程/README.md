# 直线与方程

把直线的几何条件转成坐标式，再用式子核对位置、距离或对称关系。先检查能否用斜率；一般式和非零方向向量可以覆盖竖直线。

## 学习顺序

1. 读[倾斜角与斜率](知识-倾斜角与斜率.md)和[两点斜率与斜率变化范围](知识-两点斜率与斜率变化范围.md)。倾斜角满足0°≤α<180°；90°时斜率不存在，不能跨90°直接比较斜率大小。
2. 读[点斜式与斜截式](知识-直线的点斜式与斜截式.md)、[两点式与截距式](知识-直线的两点式与截距式.md)、[一般式与方向参数表示](知识-直线一般式与方向参数表示.md)。先核分母及非零方向，再按已知点、斜率、截距选择形式。
3. 用[两直线的位置关系判据](知识-平面两直线的位置关系判据.md)区分相交、平行、重合、垂直。方向相同还要比较位置；一般式判据不必除以可能为零的系数。
4. 读[交点与直线系](知识-直线交点与过交点的直线系.md)。联立所得解就是公共点，过交点的参数族要检查漏掉的原直线及相交前提。
5. 读[平面距离与中点公式](知识-平面距离与中点公式.md)。点线距离来自法向投影；平行线距离先统一同一法向系数，中点来自端点位置的平均。
6. 读[中心对称和轴对称](知识-点与直线的中心对称和轴对称.md)、[折线路径最值](知识-对称与折线路径最值.md)。用中点与垂直确定反射，再确认最短路径下界能否在规定范围内达到。

## 条件复核

- [倾斜角与斜率跨直角比较](坑点-把倾斜角与斜率跨直角比较.md)：分别在两个区间讨论，不把正切间断处接起来。
- [设方程漏特殊直线](坑点-设斜率或截距式漏特殊直线.md)：竖直、水平、过原点各查一次。
- [斜率相等却未排除重合](坑点-用斜率相等判平行却未排除重合.md)：方向相同不是位置分离的证据。
- [全零系数或坐标比除零](坑点-直线系数全零或坐标比除零.md)：先保证方程确实代表直线。
- [直线系漏原直线或相交前提](坑点-直线系漏原直线或相交前提.md)：参数族的覆盖范围要说明。
- [距离绝对值与统一系数](坑点-距离去绝对值或平行线未统一系数.md)：距离非负，法向缩放不能只缩一部分。
- [反射最短的范围](坑点-反射最短不核同侧与交点范围.md)：折点须在题目允许的位置。

圆方程和直线与圆的关系接[圆与方程](../圆与方程/README.md)。条目中的原题原解与补讲、资料说明分列；遇到原件符号疑点，先看对应说明再使用结论。
