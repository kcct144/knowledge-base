# 学习路径

**有报告就按报告走，别按本文件从头教。** 下面是**没有报告时**的系统起步顺序。

## 默认路线

    材料与词汇匹配 → 篇章定位 → 代入与排除 → 找线索 → 全文检查 →（按报告）高中扩展

五关逐级走，不合并、不跳关；后一关暴露问题才回头补前一关。

## 第一关：材料与词汇匹配

**查缺**：让学生标出每道错题四个选项里的生词；用一两句中文说出文章人物、事件、结果。

**分流**：

- 大多数题 0～1 个选项生词、且说得出大意 → 材料适合，训练方法；
- 少数题两个以上生词 → 只处理这些高频 / 必要词，再回原题；
- 大量题两个以上生词、或理不出主线 → 暂停技巧训练，换更容易的完形，另行安排词汇。

材料偏难时，不要求一次背完整篇生词，也不继续用正确率评价完形能力。

## 第二关：篇章定位

词汇够用后，先查学生逐空前有没有建立上下文：能说出主要人物 / 事物、当前目标 / 问题 / 变化、整体态度 / 方向吗？有没有把低把握答案当成后续题的事实？

同一段连续错时，先找最早改变人物 / 事件 / 态度理解的那一题，不立即拆成多个词义问题。

**完成证据**：新材料开头能用短语建草图；局部定不了时会主动找前后文，并把待定答案与确认信息分开。

## 第三关：代入与排除

先学负担最小的流程：

    提取最小短语 → 逐项代入 → 说出能排除的理由

**完成证据**：能自己截取合适的小结构，不把整句塞进脑子；能区分“我知道它不合适”和“我只是不认识它”。

## 第四关：找线索

按实际报告逐个补，不一次教完：原词照应 → 同义复现 → 反义复现 → 形容词褒贬。

**完成证据**：不仅能圈出线索，还能说明线索怎样支持或排除某个答案。

## 第五关：全文检查

两个习惯：用作答后的新信息更新人物、事件、方向；一篇完形至少完整读一遍，并回查低把握题。

**完成证据**：局部两选项都通时主动扩大上下文；填完能用后文线索修正或确认答案。

## 高中扩展关：精辨与句篇证据

只有前面相关基础关通过、或真实高中题明确需要时才进入。按报告**只选一个分支**：

- 词都认识但分不清 → [`词义精辨`](考点/词义精辨.md)；
- 局部都成立 → [`句篇逻辑`](考点/句篇逻辑.md)；
- 证据句看不懂 → [`关键长句`](考点/关键长句.md)；
- 单空能做、整篇不稳 → 在难度相近的新整篇里标记低把握题并完成全文回查。

完成一个分支不自动证明其他高中能力。

### 高中扩展的台阶（逐级保留）

| 台阶 | 只解决的目标 | 进入信号 | 完成后去向 |
|---|---|---|---|
| H0 基础流程 | 词汇门槛、篇章定位、代入排除、找线索、全文验证 | 所有学生先从这里开始 | 基础流程能解决就停，不启用扩展 |
| H1 单空精辨 | 最后两个候选只比较一个决定性语义维度 | 词都认识但只能说“都可以” | 同类新空验证后回整篇 |
| H2 句间逻辑 | 识别一个明确的转折、因果、时间或态度变化 | 局部都通，近处上下文能决定 | 新空能独立说出两层意思和锚点后回整篇 |
| H3 篇章追踪 | 跨句或跨段追踪视角、指代、态度与结果 | 同一关系影响相邻多空，或结尾回扣前文 | 新篇中能更新草图并避免同类连错 |
| P 句法补丁 | 拆开阻断当前判断的一处关键结构 | 证据存在但句子结构读错 | 拆清即回 H1 / H2 / H3，不单独扩展语法 |

H1～H3 不固定顺序；P 可在任一台阶临时调用。没被真实题目触发的内容保持未评估。

## 强化与过关标准

- 补完报告中的问题后，优先回到来源相近、词汇难度合适的新完形检验；AI 当场只用同范围新空确认方法能被调用，不连续生成多篇材料。
- **可独立**：无需提示能说明依据并完成刚补的动作；**稳定**：还需近变式、新整篇或间隔复测（1 天、3～4 天、1～2 周）。
- **答案对但说不出依据、或凭语感猜中，不算能力提升**；材料看不懂时先补语言或换材料，**不能用猜中率评价完形能力**。

## 整篇复盘

按“错误诊断顺序”找第一个断点：

    选项认识几个？→ 有没有说出谁、什么事、方向？→ 有没有截取合适短语？
    → 有没有逐项代入和排除？→ 有没有找上下文线索？→ 有没有用话题主线？
    → 有没有完整读过并复查？

第一个断点决定补什么；词汇门槛没过，先归词汇 / 材料问题，不往下诊断。
