# 考点列表

## 怎么用这张表

**先根据题干认出考点，再按该考点的流程作答、说出依据。**

题干特征用来**认考点**；原文证据才是**选答案**的依据。完整顺序：
读题干 → 判考点 → 建 / 用主旨草图 → 扫读定位 → 读足证据 → 核对选项。

## 九类核心考点

| # | 考点 | 题干信号 | 思路（作答时重点检查） | 卡片 |
|---|---|---|---|---|
| 01 | 细节理解 | who / when / where / why / how / according to | 定位词 → 原文证据 → 同义对应 | [01](考点/细节理解.md) |
| 02 | 推理判断 | infer / imply / suggest / probably / learn from | 先排明显错的 → 对剩余选项找决定性证据 → 只补最少一步 | [02](考点/推理判断.md) |
| 03 | 词义猜测 | mean / probably means / can be replaced by | 选项代入所在短语 → 不够再读整句、前后句、段落 | [03](考点/词义猜测.md) |
| 04 | 主旨大意 | mainly about / main idea / purpose / why does the author write | 对象 + 重点 + 覆盖主要段落；目的题加写作动作 | [04](考点/主旨大意.md) |
| 05 | 标题归纳 | best title / which title | 先独立说主旨，再查标题是否覆盖全文 | [05](考点/标题归纳.md) |
| 06 | 代词指代 | what does "it / they / this" refer to | 找候选 → 语法匹配 → 语义代回 → 篇章延续 | [06](考点/代词指代.md) |
| 07 | 文章结构 | how is the passage organized / how does the author develop | 段落功能标签 + 逻辑关系；用选项核对，不只数段落 | [07](考点/文章结构.md) |
| 08 | 句子还原 | which sentence can be put in the blank / where can the sentence go | 主旨与段落功能 → 前后双向衔接 → 代入通读 | [08](考点/句子还原.md) |
| 09 | 写作手法 | how does the author... / why does the author mention | 找文本信号 → 说清怎么写 → 说清局部作用 | [09](考点/写作手法.md) |

**题干信号只是常见情况，不是绝对规则**：同一问法可能考不同判断；认错考点就先纠正题干信号，不继续执行错误流程。

## 边界

- 多空共用一个句子选项池 → 七选五，不在这里。
- 局部作用归写作手法；全文目的归主旨大意。
