## 讲解

### 判据与流程

组合数和带符号、权或平方时，寻找能生成这些结构的有限多项式恒等式。先核 n 的整数范围；全体命题不能用有限试值代替证明。

1. 无权或奇偶和：从 (1+x)ⁿ 出发，代 x=1 与 −1 后相加/相减，精确产生所求的下标集合。n=0 时不能把 (1−1)ⁿ=0 当作现成等式，须单独核命题。
2. 有 r 权：求导或用 rCₙʳ=nCₙ₋₁ʳ⁻¹，重标下标并核边界；线性权也可对称配对。
3. 有两个组合数相乘：构造两有限多项式的乘积，取同一幂的系数。只有两边是同一多项式，才可比较对应系数；每条搭配下标相加须等于目标幂。
4. 奇数阶交替平方和可直接按 r 与 N−r 配对，因为 $C_N^r=C_N^{N-r}$，而 (−1)ʳ 的符号相反；N 奇数确保没有一个 r=N−r 的未配对中央项。N 偶数时这理由失效，不能把结论外推。

所选变式10-3用 N=2n+1。乘积 (1+x)ᴺ(1−x)ᴺ=(1−x²)ᴺ 的 xᴺ 系数在右边为 0；左边为 $-\sum_{r=0}^{N}(-1)^r(C_N^r)^2$，原式的整体负号应一致保留，最后再由 −A=0 得 A=0。

## 易错

- 看见“平方”就把 (ΣCₙʳ)² 写成 Σ(Cₙʳ)²，漏了交叉项；应比较乘积指定幂。
- 系数比较时只改开头负号却未改末尾，得到另一个不成立的和式。
- 原题只写 n 偶数但节内默认正整数；纳入 0 后须核边界，不能说全体偶数都对。

## 例题

### 【例10】：偶数恒等式

来源：HSMA-B5-C6-D8ee685bf3cd9-P0346-P0352。原件：专题6.3 二项式定理【十一大题型】（举一反三）（人教A版2019选择性必修第三册）（解析版）.docx。

#### 原题与原解（完整保留）

【例10】（24-25高二下·全国·课后作业）证明：${C}_{n}^{0}+{C}_{n}^{2}+{C}_{n}^{4}+\ldots +{C}_{n}^{n}={2}^{n-1}$（n是偶数）.

【解题思路】由${(a+b)}^{n}={C}_{n}^{0}{a}^{n}+{C}_{n}^{1}{a}^{n-1}b+{C}_{n}^{2}{a}^{n-2}{b}^{2}+\cdots +{C}_{n}^{n}{b}^{n}$分别令$a=1,b=1$和$a=1,b=-1$可得.

【解答过程】$\because {(a+b)}^{n}={C}_{n}^{0}{a}^{n}+{C}_{n}^{1}{a}^{n-1}b+{C}_{n}^{2}{a}^{n-2}{b}^{2}+\cdots +{C}_{n}^{n}{b}^{n}$，

令$a=1,b=1$，得${C}_{n}^{0}+{C}_{n}^{1}+{C}_{n}^{2}+\cdots +{C}_{n}^{n}={2}^{n}$，

令$a=1,b=-1$，得${C}_{n}^{0}-{C}_{n}^{1}+{C}_{n}^{2}-\cdots +{C}_{n}^{n}=0$，

两式相加得$2\left( {C}_{n}^{0}+{C}_{n}^{2}+{C}_{n}^{4}+\cdots +{C}_{n}^{n}\right)={2}^{n}$，

$\therefore {C}_{n}^{0}+{C}_{n}^{2}+{C}_{n}^{4}+\cdots +{C}_{n}^{n}={2}^{n-1}$.

#### 补讲与必要修正

本题按本节上下文应取正偶数 n；若允许 n=0，左边=1、右边=1/2，命题不成立，应单列这一边界。n≥1 时 (1−1)ⁿ=0 合法。全体系数和 S=2ⁿ，交替和 D=0，相加得到偶数下标和 E=(S+D)/2=2ⁿ⁻¹。由于 n 为偶数，最后偶数下标恰是 n；若 n 为奇数，最后偶数下标改为 n−1，偶数和数值仍是 2ⁿ⁻¹。不能为了保持题尾 Cₙⁿ 而把奇数 n 也代进去。

### 【变式10-3】：交替平方恒等式

来源：HSMA-B5-C6-D8ee685bf3cd9-P0366-P0375。原件：专题6.3 二项式定理【十一大题型】（举一反三）（人教A版2019选择性必修第三册）（解析版）.docx。

#### 原题与原解（完整保留）

【变式10-3】（2024高三·全国·专题练习）求证：${\left( {C}_{2n+1}^{0}\right)}^{2}-{\left( {C}_{2n+1}^{1}\right)}^{2}+{\left( {C}_{2n+1}^{2}\right)}^{2}-{\left( {C}_{2n+1}^{3}\right)}^{2}+\cdots +{\left( -1\right)}^{2n+1}\cdot {\left( {C}_{2n+1}^{2n+1}\right)}^{2}=0$ $\text{．}$

【解题思路】利用恒等式${\left( 1+x\right)}^{2n+1}\cdot {\left( 1-x\right)}^{2n+1}={\left( 1-{x}^{2}\right)}^{2n+1}$及二项式定理，左右展开后对应项系数相同，利用组合数性质计算即可.

【解答过程】考虑恒等式：${\left( 1+x\right)}^{2n+1}\cdot {\left( 1-x\right)}^{2n+1}={\left( 1-{x}^{2}\right)}^{2n+1}$，

有$\left( 1+{C}_{2n+1}^{1}x+{C}_{2n+1}^{2}{x}^{2}+\cdots +{C}_{2n+1}^{2n+1}{x}^{2n+1}\right)\left( 1-{C}_{2n+1}^{1}x+{C}_{2n+1}^{2}{x}^{2}+\cdots +{\left( -1\right)}^{2n+1}\cdot {C}_{2n+1}^{2n+1}{x}^{2n+1}\right)$

$=\left( {C}_{2n+1}^{0}-{C}_{2n+1}^{1}{x}^{2}+{C}_{2n+1}^{2}{x}^{4}+\cdots +{\left( -1\right)}^{2n+1}{C}_{2n+1}^{2n+1}{x}^{2\left( 2n+1\right)}\right)$．

左边展开式中${x}^{2n+1}$的系数为：

${C}_{2n+1}^{0}\cdot {\left( -1\right)}^{2n+1}\cdot {C}_{2n+1}^{2n+1}+{C}_{2n+1}^{1}\cdot {\left( -1\right)}^{2n}\cdot {C}_{2n+1}^{2n}+\cdots +{C}_{2n+1}^{2n}\cdot {\left( -1\right)}^{1}\cdot {C}_{2n+1}^{1}+{C}_{2n+1}^{2n+1}\cdot {\left( -1\right)}^{0}\cdot {C}_{2n+1}^{0}$ $=-{\left( {C}_{2n+1}^{0}\right)}^{2}+{\left( {C}_{2n+1}^{1}\right)}^{2}-{\left( {C}_{2n+1}^{2}\right)}^{2}+\cdots +{\left( -1\right)}^{2n+1}\cdot {\left( {C}_{2n+1}^{2n+1}\right)}^{2}$，

而右边展开式中${x}^{2n+1}$项的系数为零．

所以$-{\left( {C}_{2n+1}^{0}\right)}^{2}+{\left( {C}_{2n+1}^{1}\right)}^{2}-{\left( {C}_{2n+1}^{2}\right)}^{2}+\cdots +{\left( -1\right)}^{2n+1}\cdot {\left( {C}_{2n+1}^{2n+1}\right)}^{2}=0$.

即得所证等式．

#### 补讲与必要修正

取 N=2n+1，其中 n 为非负整数，所以 N 为正奇数。设 $A=\sum_{r=0}^{N}(-1)^r(C_N^r)^2$。r 与 N−r 不同，组合数相等而符号相反，因为 (−1)ᴺ⁻ʳ=−(−1)ʳ；把所有项两两配对，A=0，覆盖全部下标且无中间剩项。

原解的系数比较也能规范写成：乘积左边 xᴺ 的系数为

$$\sum_{r=0}^{N}C_N^r(-1)^{N-r}C_N^{N-r}=-\sum_{r=0}^{N}(-1)^r(C_N^r)^2=-A.$$

右边 (1−x²)ᴺ 只有偶次幂，xᴺ 系数为 0，所以 −A=0，推出 A=0。原 P0372/P0374 在展开 −A 时最末项仍写 $(-1)^N(C_N^N)^2$，和前面的整体负号不一致；末项规范应为 $+(C_N^N)^2$。原载体确有此符号，原块保留，目标恒等式正确。
