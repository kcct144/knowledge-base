# 函数的应用

本专题把实际条件转成函数关系，并将数学结果放回原情境检验。先从[实际函数模型的变量与可行域](知识-实际函数模型的变量与可行域.md)入手：明确每个变量表示什么、使用什么单位、哪些取值在实际情境中允许。

## 第三章建模入口

- 变化描述给出比例或倍数关系时，读[比例幂模型与倍数关系](知识-比例幂模型与倍数关系.md)，再核查原题的变化假设。
- 根据表格选择模型时，读[函数拟合的数据口径与预测限度](知识-函数拟合的数据口径与预测限度.md)。模型应与其余已知数据相容，预测使用范围也需要说明。
- 收入、路程、耗电和分段收费等题目，先区分单位量与总量，再建立关系；参数、分支起点、整数数量及严格阈值都在对应考点中解释。

同一种判断可以服务不同情境。例题的作用是展示如何识别条件、建立关系和回代检验，不以重复的场景数量衡量知识覆盖。

## 零点与近似求解

1. [函数的零点与实根及交点横坐标](知识-函数的零点与实根及交点横坐标.md)：把问题写成同一个等式，分清点、横坐标与方程的解。
2. [连续异号的零点存在定理](知识-连续异号的零点存在定理.md)：理解连续和端点异号各有什么作用；存在一个零点不自动意味着只有一个。
3. [二分法的括根不变量与误差保证](知识-二分法的括根不变量与误差保证.md)：每次保留仍含目标零点的半区间，最后依据区间宽度说明近似精度。

指数增长、衰减及拟合模型也归本专题。先交代每个时间间隔的变化规律，再处理阈值、取整和预测范围；连续计算结果是否符合实际限制，须另行检验。
