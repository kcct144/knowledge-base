# 计数原理

从确定一个完整结果开始：先分清分类与分步，再判断顺序是否改变结果，最后处理约束。二项展开式把乘法中的选择计数转成系数计算。各条目保留完整原例，定义、推导、适用条件、使用流程与边界可单独阅读。

## 学习顺序

1. 计数对象的一一对应 → 分类加法与分步乘法 → 补集、整数与涂色。
2. 排列与组合 → 特殊位置、捆绑、插空、定序 → 有标签与无标签分组、相同元素分配。
3. 二项式通项 → 项序与系数 → 赋值、系数搭配与最大项 → 整除、近似和杨辉三角。

计数时“独立”容易混义：分类要互不重叠，分步要逐个合法前步历史核可选数；分组先问组是否有名称；系数先问是组合数还是带符号的实际数值系数。
