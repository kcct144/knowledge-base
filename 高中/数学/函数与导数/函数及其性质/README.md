# 函数及其性质

先理解函数怎样规定输入与输出，再学习怎样描述和判断它的性质。下列顺序可作自学入口；各条目都有自身的讲解、条件与原资料例题。

## 概念与表示

1. [函数的概念](知识-函数的概念.md)：分清对应规则、定义域、值域与题设的输出集合。
2. [函数的定义域](知识-函数的定义域.md)与[函数的值域](知识-函数的值域.md)：分别处理哪些输入合法、哪些输出能够实际出现。
3. [函数的三种表示法](知识-函数的三种表示法.md)与[分段函数](知识-分段函数.md)：把式子、表格和图象中的条件读完整。
4. [复合函数](知识-复合函数.md)：跟踪实际输入进入哪一层，避免将内外自变量混用。

## 比较与最值

从[函数的单调性](知识-函数的单调性.md)开始，再读[按定义作差证明单调性](考点-按定义作差证明函数单调性.md)。需要组合已有函数时，接着学习[运算性质](知识-单调函数的运算性质.md)和[复合函数的单调性](知识-复合函数的单调性.md)，每次都核查实际范围。

[函数的最大值与最小值](知识-函数的最大值与最小值.md)解释“界”与“能够取到”的区别；限定区间或含参数的题目再沿相应考点处理端点、分支和取到条件。[非减函数](知识-非减函数与严格递增的区别.md)用于区分允许平台的条件与严格递增的条件。

## 对称与周期

依次读[函数的奇偶性](知识-函数的奇偶性.md)、[奇偶函数的运算性质](知识-奇偶函数的运算性质.md)、[对称区间上的单调与最值](知识-奇偶性与对称区间的单调及最值.md)，再联系[图象的轴对称与中心对称](知识-函数图象的轴对称与中心对称.md)。

[周期性与反周期关系](知识-函数的周期性与反周期关系.md)讲怎样由合法的函数关系推导平移规律，不能把一个已找到的周期直接称为最小正周期。

## 特殊函数与题设新定义

[取整函数与小数部分](知识-取整函数与小数部分.md)、[对勾函数](知识-对勾函数及其正负分支范围.md)等按资料需要查阅。原题使用“含峰”“凹凸”“商函数”等专用名称时，以该题给出的条件为准；相关条目将这些条件还原为单调、最值或输入输出关系，不能仅凭名称套用其他章节的结论。

坑点条目用来检查具体错步，不能代替前面的概念与方法学习。
