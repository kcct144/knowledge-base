# 考点列表

## 怎么用这张表

**先看提示词和空格需求认考点，再按该考点的步骤作答、说出依据。**

提示词只给入口，**"空格需要什么"才决定方向**；两样结合后才定考点。完整顺序（五步）：

看提示 → 看空格作用 → 两边结合判断考点 → 按考点流程求解 → 写出并代回检查。

不能只看提示词就作答；无提示词也不能直接认定只填某几类词。

## 识别入口（先看这里）

| 观察入口 | 结合空格重点确认 | 可能进入的求解方向 |
|---|---|---|
| 给出动词 | 本分句还需不需要谓语、有没有别的结构要求 | 谓语动词 / 非谓语动词 / 词性转换 |
| 给出名词 | 是否仍需名词，数量、所属、修饰关系如何 | 单复数 / 所有格 / 词性转换 |
| 给出形容词、副词 | 修饰什么，是否表达比较 | 词性转换 / 比较等级 |
| 给出代词 | 指代谁，在句中承担什么作用 | 代词形式 |
| 无提示词 | 缺限定、连接、指代还是搭配成分 | 冠词 / 介词 / 代词 / 并列连词 / 从句引导词 |

这是检索入口，不是互斥且穷尽的答案表；一个词可能经历多个变化。

## 十一个求解考点

| # | 考点 | 判断入口 | 思路（作答时重点检查） | 卡片 |
|---|---|---|---|---|
| 1 | 谓语动词 | 给动词，本分句缺谓语 | 时态、语态、主谓一致，组成完整形式 | [谓语](考点/谓语动词.md) |
| 2 | 非谓语动词 | 给动词，已有谓语或搭配要求 | 当前结构、搭配、逻辑关系确定形式 | [非谓](考点/非谓语动词.md) |
| 3 | 名词 | 给名词，空位仍需名词 | 数量、可数性、所属关系 | [名词](考点/名词.md) |
| 4 | 形容词、副词与词性转换 | 空位需要另一词性，或修饰关系 | 句中作用 → 派生 → 再核对数或形式 | [词性](考点/形容词、副词与词性转换.md) |
| 5 | 比较等级 | than、比较范围或两个变化 | 比较意义、范围、结构，不凭单个标志词 | [比较](考点/比较等级.md) |
| 6 | 代词 | 给代词，或空格需指代 | 指代对象、句中作用、形式 | [代词](考点/代词.md) |
| 7 | 冠词 | 无提示，名词短语缺限定 | 泛指 / 特指、a / an 发音 | [冠词](考点/冠词.md) |
| 8 | 介词 | 无提示，搭配或关系缺失 | 当前搭配和语境关系，只补当前必要 | [介词](考点/介词.md) |
| 9 | 定语从句 | 从句补充说明前面的名词 | 先行词、从句缺口、关系词 | [定从](考点/定语从句.md) |
| 10 | 名词性从句 | 从句整体作主语 / 宾语 / 表语 / 同位语 | 从句类型、内部缺口、引导词 | [名从](考点/名词性从句.md) |
| 11 | 并列句与状语从句 | 连接两个单位 | 连接单位、并列 / 从属关系、语义 | [并列](考点/并列句与状语从句.md) |

**提示词信号不是绝对规则**：给动词不一定是谓语（可能是非谓语或派生）；无提示词也不限定只填冠、介、连、代。

## 前置与综合

- **前置**：词性与句子成分、基本句子结构、分句边界（Unit 01）。不熟时先补，不在本题型里展开成套语法。
- **综合**：整篇、自行判断考点并回填检查（Unit 14）。详见 [`学习路径.md`](学习路径.md)。
