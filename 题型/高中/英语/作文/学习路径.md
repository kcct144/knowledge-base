# 学习路径

**有报告就按报告走，别按本文件从头教。** 下面是**没有报告时**的系统起步顺序。

## 默认顺序

    成篇 → 结构 → 要点 → 语言 → 优化

核心一句话：**先成篇，再达标，后优化。** 作文的第一个检查不是「高级句型够不够」，而是「学生能不能写出来」。台阶不能跳。

## 一、成篇（最低成本草稿）

**练什么**：抓主题 + 两三个内容点 → 选骨架 → 一个内容点写成一个简单句 → 达到可誊写。

**过关**：给出主题和两三个短语后，能借模板得到有开头、正文、结尾的底稿；没有 `(topic)`、`do sth.` 等空槽。

## 二、结构（提纲并选模板）

**练什么**：只看题目做短语提纲；判断「列点还是记叙」；把一个短语放进一个已会句型。

**过关**：新题目无需提示完成提纲，并选出可用骨架。

## 三、要点（逐步满足题目要求）

**练什么**：识别形式、主题、主要要点、人称、时态和给定内容；一个题目要点对应提纲一项；保留给定称呼、开头、结尾。

**过关**：新题目能完成主要要点，且不因审题增加而重新写不出。

## 四、语言（提高基础正确性）

**练什么**：保持文章完整的同时，稳定人称、主要时态、动词形式、单复数、拼写、标点。一次只改当前作文暴露最明显的一类错误，改完写新作文验证。

**过关**：在新作文中独立避免同类错误，而不是只会改旧作文。

## 五、优化（限时成篇与安全优化）

**练什么**：先限时完成底稿，再用剩余时间按顺序补：

    补漏点和明显错误 → 补一两个具体细节 → 改善连接 → 只升级真会的表达

**过关**：限时新题能先完成、后优化，优化没有破坏原来正确的句子。

## 六、话题迁移与准备

**练什么**：用尽量少的骨架覆盖不同常见话题，只积累常见主题、每个主题两三个低成本内容点、可跨话题复用的句型积木。**不把准备内容称为「必考预测」。**

**过关**：新话题能被原模板承载时，不增加新模板。

## 过关标准

- **需提示**：给出模板、句首或内容点后可以完成；
- **可独立**：新同类题中无需提示完成当前台阶；
- **稳定**：跨话题、限时或间隔后仍能完成；
- **背出模板不等于会写作文**，能力证据必须含至少一次实际替换或迁移；
- 没有新证据时，不自动增加新模板、难句或陌生文体。

已掌握的仍要间隔复习：1 天、3～4 天、1～2 周。
