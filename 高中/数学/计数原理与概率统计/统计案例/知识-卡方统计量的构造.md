## 讲解

### 是什么

2×2表四观察频数a、b、c、d，总n；行合计r₁=a+b、r₂=c+d，列合计s₁=a+c、s₂=b+d。四个行列合计都正，观察格允许0。H₀独立时，用样本边际频率拟合交叉概率，得到四格的拟合期望频数（这里不是已知真实总体概率算出的精确期望）：

$$e_a=\frac{r_1s_1}{n},\quad e_b=\frac{r_1s_2}{n},\quad e_c=\frac{r_2s_1}{n},\quad e_d=\frac{r_2s_2}{n}.$$

卡方统计量把每格偏差“观察−期望”平方，再除以该格期望，相加衡量偏离独立模型的程度。记作χ²或K²；上标2是统计量名称的一部分，此处不先把χ当另一个观测变量。

### 怎么来的

独立的乘积规则给P(X=x₁,Y=y₁)≈(r₁/n)(s₁/n)。乘总数n得eₐ=r₁s₁/n，其余同理。直接比较a−eₐ会受格大小影响；平方避免正负抵消，除以期望格使相对尺度差异进入统计量。这个构造是Pearson偏差平方和，临界分布的理论是拓展，考试可用，不要求以高等数学证明其近似分布。

设D=ad−bc，先逐项算偏差。第一格

$$a-e_a=\frac{an-(a+b)(a+c)}n=\frac{a(a+b+c+d)-(a^2+ab+ac+bc)}n=\frac{ad-bc}n=\frac Dn.$$

第二格因为同一行的偏差和0，b−e_b=−D/n；同一列偏差和0，c−e_c=−D/n；第四格d−e_d=D/n。这也可由各自乘积展开验证。于是

$$\chi^2=\sum\frac{(\text{观察}-\text{期望})^2}{\text{期望}}=\frac{D^2}{n^2}\left(\frac1{e_a}+\frac1{e_b}+\frac1{e_c}+\frac1{e_d}\right).$$

将每个e的倒数代入，括号提取n，再按行列分别合并：

$$\begin{aligned}
\frac1{e_a}+\frac1{e_b}+\frac1{e_c}+\frac1{e_d}
&=n\left(\frac1{r_1}+\frac1{r_2}\right)\left(\frac1{s_1}+\frac1{s_2}\right)\\
&=n\frac{r_1+r_2}{r_1r_2}\frac{s_1+s_2}{s_1s_2}
=\frac{n^3}{r_1r_2s_1s_2}.
\end{aligned}$$

最后相乘D²/n²×n³/(r₁r₂s₁s₂)，消去n²，得

$$\chi^2=\frac{n(ad-bc)^2}{(a+b)(c+d)(a+c)(b+d)}.$$

因此χ²≥0；χ²=0等价于本样本ad=bc。交换两行或两列使D变号，平方不变；转置交换边际位置，乘积不变。它衡量关联偏差，不给方向，方向可回看组内频率差。

### 什么时候能用

四格观察数允许0，只要四个行列合计都正，四个拟合期望数就正、闭式可算。若整个一行或一列为空，分母0，不能硬套公式。可计算也不等于临界χ²近似可靠；随机成对样本、观察单位独立或合理近似，以及足够大的期望频数等另需检查，见[抽样前提](知识-独立性检验的抽样前提与应用范围.md)。

真实载体来源：HSMA-B5-C8-D9e1bd0cb65d9-P0336-P0343，原件《专题8.3 列联表与独立性检验【八大题型】（举一反三）（人教A版2019选择性必修第三册）（解析版）.docx》。原WMF image18、20公式已实际查看，因子次序不同而乘积等价；以上补足期望格到闭式的理由。

## 易错

- 要求“四格观察都正”会错误排除允许的0格；应检查边际及期望格。
- 只看ad−bc大小，遗漏分母与n，不能跨任意不同样本直接比。
- 统计量大代表偏离H₀证据强，不是“有关系的概率”大，也不直接表示效应强。

## 例题

### 原例：例5：篮球迷与性别的检验

来源：HSMA-B5-C8-D9e1bd0cb65d9-P0412-P0462。原件：专题8.3 列联表与独立性检验【八大题型】（举一反三）（人教A版2019选择性必修第三册）（解析版）.docx。

#### 原题与原解（完整保留）

【例5】（24-25高二下·山东德州·阶段练习）某学校在一次调查“篮球迷”的活动中，获得了如下数据，以下结论最准确的是（   ）

|  |  | 男生 | 女生 |  |
| --- | --- | --- | --- | --- |
| 篮球迷 |  | 90 | 20 |  |
| 非篮球迷 |  | 60 | 30 |  |

附：${χ}^{2}=\frac{n{(ad-bc)}^{2}}{(a+b)(c+d)(a+c)(b+d)}$

| $P\left( {X}^{2}\ge k\right)$ | 0.10 | 0.05 | 0.01 | 0.005 |
| --- | --- | --- | --- | --- |
| k | 2.706 | 3.841 | 6.635 | 7.789 |

A．有99．5%的把握认为是否是篮球迷与性别有关

B．有$99\%$的把握认为是否是篮球迷与性别有关

C．在犯错误的概率不超过0.1的前提下，可以认为是否是篮球迷与性别有关

D．在犯错误的概率不超过0.05的前提下，可以认为是否是篮球迷与性别有关

【解题思路】列出$2\times 2$列联表，计算${χ}^{2}$即可得解.

【解答过程】列出$2\times 2$列联表：

|  |  | 男生 | 女生 |  |
| --- | --- | --- | --- | --- |
| 篮球迷 |  | 90 | 20 | 110 |
| 非篮球迷 |  | 60 | 30 | 90 |
|  |  | 150 | 50 | 200 |

${χ}^{2}=\frac{n{(ad-bc)}^{2}}{(a+b)(c+d)(a+c)(b+d)}=\frac{200\times {\left( 90\times 30-20\times 60\right)}^{2}}{150\times 50\times 110\times 90}\approx 6.061>3.841$，

故在犯错误的概率不超过0.05的前提下，可以认为是否是篮球迷与性别有关.

故选：D.

#### 补讲与资料勘误

总样本200，男150、女50，篮球迷110、非篮球迷90。按原表取a=90、b=20、c=60、d=30，则ad−bc=2700−1200=1500，四边际为110、90、150、50。χ²=200×1500²/(110×90×150×50)=200/33≈6.060606。

在H₀下，四格期望频数为110×150/200=82.5、110×50/200=27.5、90×150/200=67.5、90×50/200=22.5。四格“观察−期望”的平方除以期望再相加也得到200/33，解释了闭式的来源。

3.841<χ²<6.635，所以α=0.05拒绝H₀，但α=0.01不拒绝。A的99.5%、B的99%档均未达到；C较宽的0.1档也可拒绝，但题问“最准确”，D使用样本所能支持的更严格0.05档，故原答案D。表内0.005档实际XML写7.789；同源其他表写7.879，原表照留并单列此误植，终答未使用该列。“犯错误概率”仍应按H₀成立时程序的误拒风险理解，不能变成本次结论正确率。
