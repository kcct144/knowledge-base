## 错法

解出通项指数为 0 的某个实数 r 就报有常数项；未知 n 算出一个数就接受，不核项序是否存在；或者看常数项不含 x，就把原式定义域扩大到 x=0。

r 是从 n 个因子中选择第二部分的次数，不是任意实数。根式、分母限制属于原表达式，某个展开项不再含 x 不能取消这些限制。

## 正解

先写原式定义域，再写 n 为非负整数、r∈{0,…,n}。问第 j 项固定 r=j−1，还要 n≥j−1。指数方程的实数解必须回这些离散条件；不合法就是无该项，不向最近整数取整。

原变式2-1的 (1/x−√x)⁶ 要求 x>0，指数 −6+3r/2=0 给 r=4，合法，所以第 5 项为 15；这只是函数在 x>0 的展开中有常数贡献，不说原函数在 0 有定义。原例3中解得 n=18，既是正整数又不小于 3，才确认第 4 项存在。

分数指数涉及实数负 x 时，保留真实奇次根可避免未经约定的任意实幂；偶次根必须先核非负。整式项另要求最终 x 指数为非负整数，不能把所有合法根式项都称整式项。

## 例题

### 【变式2-1】：分式常数

来源：HSMA-B5-C6-D8ee685bf3cd9-P0057-P0064。原件：专题6.3 二项式定理【十一大题型】（举一反三）（人教A版2019选择性必修第三册）（解析版）.docx。

#### 原题与原解（完整保留）

【变式2-1】（23-24高二下·陕西渭南·阶段练习）二项式${\left( \frac{1}{x}-\sqrt{x}\right)}^{6}$的展开式中常数项为（　　）

A．第$3$项  B．第$4$项  C．第$5$项  D．第$6$项

【解题思路】利用二项展开式的通项公式求特定的项.

【解答过程】二项式${\left( \frac{1}{x}-\sqrt{x}\right)}^{6}$展开式的通项为：

${T}_{k+1}={C}_{6}^{k}{\left( \frac{1}{x}\right)}^{6-k}{\left( -\sqrt{x}\right)}^{k}={(-1)}^{k}{C}_{6}^{k}{x}^{k-6}{x}^{\frac{k}{2}}={(-1)}^{k}{C}_{6}^{k}{x}^{\frac{3k}{2}-6}$，

令$\frac{3k}{2}-6=0$，解得，$k=4$，

所以二项式${\left( \frac{1}{x}-\sqrt{x}\right)}^{6}$的展开式中常数项为第5项${T}_{5}={(-1)}^{4}{C}_{6}^{4}=15$.

故选：C.

#### 补讲与必要修正

实数范围须 x>0：根号要求 x≥0，分母又排除 0。通项中第一部分给 x⁻⁽⁶⁻ᵏ⁾，第二部分给 (−1)ᵏxᵏ⁄²，所以指数相加为 −6+3k/2。常数项需这个指数为 0，而不是令整项的数值为 0；解得 k=4，在整数范围 0≤k≤6 内。其项序是 k+1=5，系数是 (−1)⁴C₆⁴=15。A、B、D 的项序各使指数不为 0。

### 【例3】：指定项求指数

来源：HSMA-B5-C6-D8ee685bf3cd9-P0080-P0085。原件：专题6.3 二项式定理【十一大题型】（举一反三）（人教A版2019选择性必修第三册）（解析版）.docx。

#### 原题与原解（完整保留）

【例3】（23-24高二下·江苏连云港·期末）若${\left( \sqrt[5]{x}-\frac{1}{x}\right)}^{n}$的展开式中第4项是常数项，则n的值为（    ）

A．14  B．16  C．18  D．20

【解题思路】写出二项式展开式的通项，令$k=3$时$x$的指数位置等于$0$即可求解.

【解答过程】${\left( \sqrt[5]{x}-\frac{1}{x}\right)}^{n}$展开式的通项为${T}_{k+1}={C}_{n}^{k}{\left( {x}^{\frac{1}{5}}\right)}^{n-k}{\left( -1\right)}^{k}{x}^{-k}={C}_{n}^{k}{\left( -1\right)}^{k}{x}^{\frac{n}{5}-\frac{6k}{5}}$，

令$k=3$可得${T}_{4}={C}_{n}^{3}{\left( -1\right)}^{3}{x}^{\frac{n}{5}-\frac{18}{5}}$为常数项，可得$\frac{n}{5}-\frac{18}{5}=0$，可得$n=18$，

故选：C.

#### 补讲与必要修正

第 4 项先固定 k=3，第一部分贡献 x⁽ⁿ⁻³⁾⁄⁵，第二部分贡献 x⁻³，指数相加为 (n−18)/5。常数项要求 n=18；它确实是非负整数且 n≥3，故第 4 项存在。实数五次根允许负 x，但 1/x 要求 x≠0；在负 x 上最好保留真实奇次根乘法，不能把它未经约定解释为任意实指数幂。四个选项中仅 C 使指数等于 0。
