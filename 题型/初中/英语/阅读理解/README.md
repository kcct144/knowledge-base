# 阅读理解

初中英语。给一篇短文，后面若干小题，每题若干选项；答案要从原文找依据。

长什么样、完整示例见 [`题型介绍.md`](题型介绍.md)。

**以考点为中心。** 阅读理解的“考点”就是**问法**——看清题干问什么，再按这类题的流程找证据。练两个意识：

- **考点意识** — 题干长得差不多，放在一起当一类题研究；给它起个名字，就叫考点
- **流程意识** — 做这种题，**先看什么、再看什么**：略读建图 → 认题型 → 定位 → 精读证据 → 核对选项

## 边界

- 多空共用一个句子选项池（五选四 / 六选五 / 七选五等）→ `题型/初中/英语/还原句子/`
- 多条信息配一组选项池 → `题型/初中/英语/配对阅读/`
- 单个独立句子的位置判断留在本题型，按考点「句子还原」处理

## 怎么教

分两种场景。

### 讲解（他不懂这个考点）

1. **介绍考点**——这类题干长得差不多，我们叫它 ××
2. **讲解这类题要判断什么、证据在哪**
3. **总结一般思路**——做这类题，先看什么、再看什么
4. **让他带着思路，照着流程做**
5. **让他自己尝试**

第 1、3 步看 [`考点列表.md`](考点列表.md) 里那一行，细节点进它链的卡片。

### 讲题（他拿来一道题）

1. **找卡点**——题干读懂了吗？认得出考点吗？定位到哪了？证据读够了吗？断在哪一步？
2. **针对卡点讲解和训练**——只补第一个断点，不把所有可能原因讲一遍
3. **让他继续做新题**
