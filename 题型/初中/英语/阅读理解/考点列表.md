# 考点列表

本题型的“考点”就是**问法**：看清题干要判断什么，再按对应流程找证据。

## 怎么用这张表

**先根据题干认考点，再按该考点的流程定位证据、核对选项。**

任何答案都要回到原文证据，不能只凭常识或原词重现。完整顺序：认题型 → 划定位词 → 定位 → 读足必要上下文 → 用自己的话说出证据 → 核对选项。

## 通用前置（不单独成考点）

- **材料与阅读方式**——先判断材料是否适合、学生是否习惯逐句翻译（见 [`学习路径.md`](学习路径.md) 第零关）；
- **主旨意识**——正式做题前用一句话建立“对象 + 重点”，它是所有题型的定位地图（见 [`学习路径.md`](学习路径.md) 第一关）。

## 九类考点

| 考点 | 题干信号 | 思路（作答时重点检查） | 卡片 |
|---|---|---|---|
| 细节理解 | who / when / where / why / how / according to | 定位词 → 原文证据 → 同义对应 | [细节](考点/细节理解.md) |
| 推理判断 | infer / imply / suggest / probably | 先排明显错项，再回原文找决定性证据，只补最短一步 | [推理](考点/推理判断.md) |
| 词义猜测 | underlined word ... mean / probably means | 逐项代回所在短语，比较搭配和语义 | [词义](考点/词义猜测.md) |
| 主旨大意 | mainly about / main idea / purpose | 对象 + 作者重点 + 段落覆盖 | [主旨](考点/主旨大意.md) |
| 标题归纳 | best title | 先出主旨，再查覆盖全文和文体 | [标题](考点/标题归纳.md) |
| 代词指代 | refer to | 候选先行词 → 语法匹配 → 语义代回 | [指代](考点/代词指代.md) |
| 文章结构 | how is the passage organized | 段落功能标签 + 逻辑推进 | [结构](考点/文章结构.md) |
| 句子还原 | which sentence can be put in ... | 前句承接 + 后句开启，双向衔接 | [还原](考点/句子还原.md) |
| 写作手法 | how does the author ... / why mention | 找文本信号 → 说局部作用 | [手法](考点/写作手法.md) |

**题干信号只是入口，不是答案**：认出题型后还要走该题型的证据流程，先回到原文再选。

## 按卷型启用

句子还原、写作手法按学生所在地区和卷型出现时才练，不主动安排；多空共享句子选项池转 `题型/初中/英语/还原句子/`，不走「句子还原」。

## 本册细分判据

九类是问法入口，不能把同一类所有题压成一条口令。[完整条目](条目索引.md)另展开共同点的双方条件、重复事件排序、品质与态度对象、续写预测、栏目范围、目的动作、五种猜词证据、段落与全文主旨、标题主线等。

图文转换需同时核目标状态和各部位；跨学科读图需分清量、单位、测点与未给区间。原图只提供题内证据，不自动成为现实动物或健康指导。题型由任务形式决定，多空句池归初中还原句子，独立单句位置题留本目录。
