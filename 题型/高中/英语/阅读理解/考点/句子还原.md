# 句子还原

**一句话概念** — 判断一个独立句子应放在文章哪个位置，填入后前后都连贯。

## 怎么认

`Which sentence can be put in the blank?` / `Where can the sentence best go?`；每空的选项各自独立，或一句配几个位置。

## 边界

只处理**单个独立句子**的位置判断，或各小题不共享句子池的独立判断。
同一短文多空共用一个句子选项池（五选四、六选五、七选五…）→ 转七选五工作区，不用这里评价。

## 思路

**全文主线 + 前后双向衔接。**

1. 先掌握全文主旨和段落功能；
2. 读候选句，圈出代词、连接词和关键词；
3. 看空格前一句需要怎样承接；
4. 看空格后一句需要怎样开启；
5. 检查指代、复现、逻辑、时态和人物一致；
6. 代入后同时通读前后。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L1 单侧明显 | 前侧或后侧线索明显，先对接住的那一侧 | 复杂指代、多种线索纠缠 |
| L2 分线索 | 代词、起承转合、连词、复现、总分各练一类 | 综合 |
| L3 综合通读 | 前后都要接上，时态与人物变化有语境依据 | — |

## 怎么讲

1. 先给概念和边界；
2. 分别说明候选句怎样承接前文、怎样引出后文；
3. 只讲当前台阶；
4. **常见卡点**：
   - 只与前一句通顺就选，不管后一句；
   - 看到相同词就直接选，不检查整个关系。

## 易错

**前后双向核对不能省**；前侧或后侧是本台阶重点，不意味着另一侧可以矛盾。
