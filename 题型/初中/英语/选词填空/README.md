# 选词填空

初中英语。一篇短文挖若干空，给一个词框，从框里选词填进去；题目常要求用正确形式，并规定每词用几次、有几个多余词。

**讲究的是：迅速用词性意识观察题目。**

练的是两个意识：

- **词性意识** — 看空：这里缺的是什么词性的词？看词框：这个词一般怎么用、用在哪？
- **观察意识** — 主动扫两边、先比词性再谈意思，**不凭语感猜**

## 边界

- 每题自带选项、考语法和上下文 → `题型/初中/英语/语法选择/`
- 选项是不同实词、考词义 → `题型/初中/英语/完形填空/`
- 初中不给词框、按提示词或语境写形式 → `题型/初中/英语/语篇填空/`；高中材料按高中路由。

## 怎么教

**先看断点**：分不清词性时，用当前原句示范一个角色，再按需回查[`词性.md`](词性.md)。不要求先背完九类词性才能开始做题。

分两种场景。

### 讲解（他不懂这类空怎么看）

**别逐空讲。** 先扫一遍，挑出**容易填对的空**——能一眼套上 [`观察清单.md`](观察清单.md) 那两张表的（比如 `限定词 + ___` → 名词）。只讲这些：

1. **示范一个**——看到什么 → 想到什么 → 怎么验证
2. **让他自己做**同一类的下一个
3. **再挑一个另一类的容易空**，重复
4. 剩下的难空**这一轮先不碰**——不硬讲；等容易的空都拿下了，再用「代入、排除」处理

轻松的空先拿下，速度和正确率都会涨。**不追求把整篇讲完。**

### 讲题（他拿来一道题）

1. **先挑容易的做**——能迅速套上观察清单的空，当场做掉，边做边排除
2. **卡点**在哪：读不出这个空需要什么词性？词框里的词性认不认？清单里的哪一条没套上？
3. **针对卡点示范、训练**
4. **让他继续做新题**
