# 知识库

AI 讲解时用的**内容库**：题、题型、学科知识。
与 `学习数据/`（学生数据）、`.kilo/`（harness）分开维护，**一份知识库服务多个学生**。

## 架构

```
knowledge-base/
│
├─ 教材/<学段>/<学科>/目录/<册别>.md   章节名对照表（查章节名 / 给 topic 取名）
│
├─ 题库/                              ① 题
│  ├─ 规范.md · 索引.md · 管理.py
│  └─ <分类>/<id>.md                    一题一 md（id / 考点 / 台阶 / 状态）
│
├─ 题型/<学段>/<学科>/<题型>/           ② 练法
│  ├─ AGENTS.md                        题型介绍 + 做题思路
│  ├─ 考点地图.md                       该题型考的考点
│  └─ 可用题.md                         题库里适用且已校验的题 id
│
├─ 通用/*.md                           ③ 跨学科方法：时间分配、草稿、检查
│
├─ 格式/                               ④ 文档格式
│  └─ 知识模板.md · 考点模板.md · 坑点模板.md
│
└─ 初中/ 高中/                         ⑤ 学科知识库
   └─ <学科>/
      ├─ index.md                     板块 → 专题 清单
      └─ <板块>/<专题>/
         ├─ 知识-<概念>.md            是什么
         ├─ 考点-<考点>.md            怎么判
         └─ 坑点-<坑>.md              哪儿翻车
```

## 三级定位

```
高中/物理/力学/牛顿运动定律/
├─ 知识-惯性.md
├─ 知识-牛顿第一定律.md
├─ 考点-整体法与隔离法.md
├─ 考点-瞬时加速度问题.md
└─ 坑点-误把「速度为零」当平衡.md
```

| 级 | 粒度 | 稳定性 | 例 |
|---|---|---|---|
| 板块 | 课标大领域 | 改课标才动 | 力学 · 电磁学 |
| 专题 | 一级主题（约一章的体量） | 几年一变 | 牛顿运动定律 |
| 条目 | 一个概念 / 考点 / 坑 | 随时增补 | 惯性 · 整体法与隔离法 |

## 各学科的板块

各科的板块 → 专题清单见 `初中|高中/<学科>/index.md`。

## 关联规则

1. **题库是唯一题源**，只有 `状态: 已校验` 的能用
2. **题型工作区**的"做题思路"每一步**指向**学科知识库的 `考点-…` 文件
3. **关联单向**：每条只声明自己的向上依赖——考点写 `知识`/`前置`，知识写 `前置`，坑点写 `考点`。反向关系靠 grep，不写第二遍，免得两边漂
4. 四层用**同一套考点名**互相关联

学习进度、学习记录、错题、背诵卡在各自的 workspace 里，本目录不放。
