# 学习路径

三个阶段，按学生的卡点走。**有报告就按报告走，不从头教。**

> 前置：词框里关键候选都不认识 → 先补词，那不是技巧问题。

## 一、培养意识（没有做题思路）

**目标**：会**看两边**——看空问"缺什么词性"，看框问"这个词能当什么用"。

- 拿一道题，只挑**容易的空**示范
- 让他自己说：这个空缺什么？这个词能当什么？
- **过关**：不靠猜，能说出"我是从哪看出来的"

## 二、积累情况（选不对词）

**目标**：把 [`观察清单.md`](观察清单.md) 的条目一条条变熟。

- 每遇到新的「看到什么 → 想到什么」，**和他一起总结、加进清单**
- 逐条练：能主动认出触发 → 迅速验证
- **过关**：新题里能**主动调用**（熟练度到"可快速调用"），不是被动想起

## 三、完善检查流程（用不对形式）

**目标**：词选对了，**形式也对**。

| 查什么 | 看什么 |
|---|---|
| 动词 | 时态、主谓一致、语态 |
| 名词 | 单复数、可数性、所有格 |
| 形容词 / 副词 | 比较级 |
| 代词 | 人称、格、后面有没有名词 |
| 全部 | 拼写、大小写、每空一词 |

- **过关**：新题里能自己查出形式错误，不用提醒

## 做题三步

1. **先套容易的**——能迅速套上观察清单的空，当场做掉，边做边排除
2. **剩下仔细看**——先查固定搭配，几个候选都合适时看语境（人物、事件、逻辑）；代入也行，此时候选少了
3. **检查**——全文读一遍 + 按上表查形式 + 核对用的次数和剩余词（**只用来排错，不当解题依据**）
