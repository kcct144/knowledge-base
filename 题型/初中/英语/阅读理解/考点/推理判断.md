# 推理判断

**一句话概念** — 由原文事实能够支持、但没有完全照抄的结论；推得出，但不推太远。

## 怎么认

题干用 `infer / imply / suggest / conclude / probably / learn from` 等。

## 思路

```text
看清题干在问什么
→ 带着它扫四个选项，排掉一眼就错的
→ 对剩下的选项回原文找决定性证据
→ 用自己的话重述证据，只补最少一步，不新增原文没有的信息
```

先理解全文主旨，再走上面的流程会顺利很多：主旨决定方向，能帮着判断哪些选项一看就偏。“一步推理”表示距离尽量短，不是只能做一个逻辑动作。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 认问法 | 从题干认出推理题 | 不要求推理 |
| L1 基础推断 | 主旨清楚、附近事实足够时作最短推断 | 证据边界 |
| L2 证据边界 | 区分“原文写了什么”和“我多推出什么” | — |

**默认停在 L1。**

## 怎么讲

1. 先给上面那句概念；
2. 演示“扫选项排错 → 回原文定案 → 说最少一步”；
3. **常见卡点**：排错凭感觉；用“哪个顺眼”定案，不找决定性原文依据。

## 易错

- 符合常识但原文没有依据；
- 从“可能”推成“一定”；
- 把局部人物的情况扩大到所有人；
- 加入新的原因、动机或结果；
- 与全文态度或发展方向冲突。

**边界**：不能仅因某选项接近原文表述就排除它；主旨草图限制推理方向，但不能代替具体证据。
