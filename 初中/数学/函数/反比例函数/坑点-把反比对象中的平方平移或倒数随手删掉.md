## 错法

看到1/x或1/x²就直接说“y与x反比”，忽略外面的−1和分母的平方。原四句③把y与x错误配对；原拓展例y3/x²也改变了所谈第二个量，不能据它证明同一y、x反比却不是反函数。容易错是将“出现倒数”当定义，而不是检查两量的非零恒定乘积。

## 正解

逐句圈整量并相乘。y=1/x−1两边加1成为(y+1)x1，所以反比对象是y+1与x。y=1/(2x²)给yx²1/2，xy却1/(2x)变；xy=−2变为y=−2(1/x)则关于倒数输入是正比。当所说的同一y、x本身满足xy=k≠0，就能除x得到y=k/x，确是反函数关系，不能照抄原拓展的错误一般断言。改变变量时明说新量是什么并保其域。

## 例题

### 四句辨析先识别真正成比例的两个量

> 来源ID Q15-01；第15章反比例函数；151-200/full.md 第1752–1755行。原答案与解析定位：151-200/full.md 第1752–1755行。

1. 在 $y=\frac{1}{x}-1$ 中， $y+1$ 与 x 成反比例关系. (√)  
2. 在 $xy = -2$ 中， $y$ 与 $\frac{1}{x}$ 成正比例关系. （√）  
3. 在 $y = \frac{1}{2x^{2}}$ 中，y 与 x 成反比例关系. (×)  
4. 在 $xy = -3$ 中， $y$ 与 $x$ 成反比例关系. （√）

**原资料答案与解析：**

1. 在 $y=\frac{1}{x}-1$ 中， $y+1$ 与 x 成反比例关系. (√)  
2. 在 $xy = -2$ 中， $y$ 与 $\frac{1}{x}$ 成正比例关系. （√）  
3. 在 $y = \frac{1}{2x^{2}}$ 中，y 与 x 成反比例关系. (×)  
4. 在 $xy = -3$ 中， $y$ 与 $x$ 成反比例关系. （√）

**展开解析（依据原详解补足理由与步骤）：**

①把原式两边加1，得到y+1=1/x，故(y+1)x=1；成反比的是整量y+1与x，原√成立。y与x的乘积却是1−x，不是同一断言。②xy=−2且x≠0，除x得y=−2(1/x)，把1/x当输入，非零比例系数−2，所以这两个量成正比，原√成立。③y=1/(2x²)，与x相乘得xy=1/(2x)，会随x变化，故y与x不成反比，原×成立；恒定的是yx²=1/2。④xy=−3本身就是非零恒定乘积，除x得y=−3/x，原√成立。不能只看分母里有x就确定哪两个量成反比。
