# 作文

高中英语。**主观题**：按题目要求写一篇短文（应用文写作等）。没有选项，答案不唯一，考的是把想法写成切题、正确、完整的一篇。

长什么样、完整示例见 [`题型介绍.md`](题型介绍.md)。

**以「先成篇，再切题，后优化」为主线。** 作文没有固定选项考点，先判断两件事：

- **这次要写什么** —— 形式、主题、要点、人称、时态、给定内容；
- **最少怎样写成一篇** —— 用骨架和句型积木，先得到可誊写底稿。

## 边界

- 有选项、对错唯一的题 → 走对应客观题型；
- 材料同时有「回答问题」和「书面表达」→ 只处理书面表达；
- 读后续写是另一题型，本工作区不做。

## 怎么教

### 讲解（他不懂这一类写作）

1. 介绍能力项——这类写作卡的是同一类判断，我们叫它 ××；
2. 讲这项要做什么、看什么依据；
3. 总结一般思路——先做什么、再做什么；
4. 带他照做一遍；
5. 让他自己写一篇。

第 1、3 步看 [`考点列表.md`](考点列表.md) 里那一行，细节点进它链的卡片。

### 讲题（他拿来一篇作文或题目）

1. **找卡点** —— 能成篇吗？切题吗？第一个断点在哪？
2. **只补当前断点** —— 保留他写对的部分，一次只处理最早一个；
3. **提示** —— 先让他自己写；卡住才给最低成本骨架或句首，提示后完成与独立完成分开记；
4. **怎么判** —— 没有唯一答案，按「能成篇 ＞ 大致切题 ＞ 覆盖要求 ＞ 基础正确 ＞ 表达自然」的顺序看，不判客观对错；
5. **范文怎么用** —— 模板可整句套用，但不要求讲透其中语法；他没背过时改用更短的简单句。
