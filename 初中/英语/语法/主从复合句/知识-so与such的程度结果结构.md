## 讲解

### 是什么

so...that...与such...that...可说明程度导致的结果。so通常直接限定形容词、副词或many/much/few/little数量程度；such通常限定名词短语。先找被强调的核心，再决定结构和词序。

### 怎么来的

原so tired that I went to sleep early以tired形容词的程度作为结果起点；such delicious cookies that we all ate them up以cookies名词短语作为对象。单数名词可见such a clever boy，也可用so kind a man，so后先形容词再a和名词，不能把两式拼成so a kind man。

原so many friends that she is never lonely强调many的数量多，虽后面有friends名词仍用so many。many/few接可数复数，much/little数量义接不可数；little若表示个头小则是普通形容词修饰名词，不能因相同拼写套数量少的so little规则。

读that后结果还要确认完整小句，原I went...、everyone liked...、we ate...各有主体和谓语。so本身不是每次都引出结果，so that目的也另有框架；识别被隔开的程度词才可区分。原cookies delicious只给语言情境，不能量化食物质量或卡路里。

### 什么时候能用

先圈程度对象是形副、数量还是名词短语，再核对冠词位置、数和结果小句。原little小/少口诀是词义区别提示，须读实际名词与语境；无对应little独立题，不自编一题充当证据。

### 复合句节补充：冠词位置与转换信息

Dad looks so weak that we are all worried about him.强调weak程度；Kathy is so lovely a girl that...与Kathy is such a lovely girl that...分别用so+形容词+a+名词、such+a+形容词+名词，不混成so a lovely girl。These were such difficult questions...是复数名词，不添a；such terrible weather...为不可数weather，也不添a。原many/few复数数量、much/little不可数量仍用so，little为少的义项才适用。

The room is so dark that I can’t see anything.=The room is such a dark place that I can’t see anything.第二式为给such建立名词中心place，不能只把so改such仍接dark。原They were so tired that they couldn’t go any farther.=...too tired to go any farther.与He is so strong that he can lift the heavy box.=...strong enough to lift...有同一活动主体与能力/障碍意义。

原“否定结果都可too、肯定结果都可enough”过宽；转换还需结果是该主体可否达到动作门槛，不能任意把别人受影响的结果删成同主语不定式。原room与看不见的主体I不同就说明不能仅凭从句有can’t套too。

### EN-LEX-S原词汇补充

原The problem is so difficult that I can’t work it out.中so修饰difficult、that后结果为我不能解；原She is such a lovely girl (=so lovely a girl) that everyone likes her.说明such+a lovely girl与so+lovely+a girl两种名词组词序。原It’s such good weather that we want to swim.的weather不可数不加a，want未报已游；I hope to get such a pen.原get/such空格按读法恢复。

## 例题

**原资料词形、词组或例句，非独立试题。** 本小节未配一题单独检验本概念，保留原材料并解释这一缺口。

从属连词；意义及用法；例句

so...that...；意为“如此......以至于......”,so修饰形容词或副词。常见结构有:1so+adj./adv.+that从句2so+adj.+a/an+可数名词单数+that从句；I was so tired that I went to sleep early.我太累了,以至于早早地就睡觉了。He was so kind a man that everyone liked him.他是一个非常善良的人,以至于每个人都喜欢他。

such...that...；意为“如此......以至于......”,such修饰名词。常见结构有:1such+adj.+可数名词复数/不可数名词+that从句2such+a/an+adj.+可数名词单数+that从句；He made such delicious cookies that we all ate them up.他做了如此美味的饼干,以至于我们都吃光了。He is such a clever boy that we all like him.他是如此聪明的一个男孩,以至于我们都喜欢他。

原数量例：She has so many friends that she is never lonely. many量可数friends，故so many。

原程度例：Dad looks so weak that we are all worried about him.；Kathy is so lovely a girl that we all like to play with her.=Kathy is such a lovely girl that we all like to play with her.；These were such difficult questions that none of us could answer them.；We had such terrible weather that we couldn’t get there on time.。

原转换：The room is so dark that I can’t see anything.=The room is such a dark place that I can’t see anything.；They were so tired that they couldn’t go any farther.=They were too tired to go any farther.；He is so strong that he can lift the heavy box.=He is strong enough to lift the heavy box.。

易混辨析
such...that...与 so...that...

## 易错

- **名词出现就一律such**：原many friends强调数量，so many。
- **so a kind man**：原so kind a man保留正确词序。
- **little一律少**：形容个头小与数量少要分清。
- **so that总是程度结果**：还可能为目的。

补充：such a good weather；so a lovely girl；want swim当已游；结果that删掉并不当原等价。
