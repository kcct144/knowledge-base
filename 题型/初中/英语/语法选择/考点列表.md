# 考点列表

## 怎么用这张表

**先根据选项差异认考点，再按该考点的步骤作答、说出依据。**

不能只看选项外形就作答——选项特征用来**认考点**；句子结构、搭配和语境才是**选答案**的依据。

完整顺序：观察选项差异 → 判断考点 → 确定空格在句中的作用 → 用该考点的判断步骤 → 代回句子验证。

## 十类核心考点

口诀「人、时、名、非、介、连、比、冠、情、词」——**导航用的**，第一次讲必须给完整名称。

| 口诀 | 考点 | 选项信号 | 思路（作答时重点检查） | 卡片 |
|---|---|---|---|---|
| 人 | 人称代词及相关形式 | 同一代词的主格、宾格、物主、反身 | 指代对象、空格位置、后面有没有名词 | [02-人](考点/人称代词.md) |
| 时 | 谓语动词的时态和语态 | 同一动词的时态、语态、单复数，通常没有 to do | 缺不缺谓语、主谓一致、时间、主动还是被动 | [04-时](考点/时态语态.md) |
| 名 | 名词的单复数和所有格 | 单数、复数、's、s' | 是否所属、可数不可数、数量信号 | [01-名](考点/名词.md) |
| 非 | 非谓语动词 | 出现 to do，或比 to do / doing / done | 是否已有谓语、固定搭配、主动被动 | [08-非](考点/非谓语.md) |
| 介 | 介词 | in / on / of / with / for 等 | 固定搭配、时间空间关系、句意 | [07-介](考点/介词.md) |
| 连 | 连词 | and / but / if / because / when 等 | 前后结构、逻辑关系、句意 | [09-连](考点/连词.md) |
| 比 | 形容词、副词的比较 | -er / -est / more / most | than、比较范围、固定结构、句意 | [06-比](考点/比较.md) |
| 冠 | 冠词 | a / an / the | 可数单数、泛指特指、读音、固定用法 | [03-冠](考点/冠词.md) |
| 情 | 情态动词 | can / could / may / must / should 等 | 说话人的意思、语气、时态、语境 | [10-情](考点/情态动词.md) |
| 词 | 词性 | 同词根、后缀不同 | 空格在句中的成分、修饰关系 | [05-词](考点/词性.md) |

**选项信号只是常见情况，不是绝对规则**：`to` 可能是不定式标志也可能是介词；`-s` 可能是名词复数也可能是动词三单。
