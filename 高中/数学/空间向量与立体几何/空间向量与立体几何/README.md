# 空间向量与立体几何

学习顺序是“向量与基底 → 数量积与坐标 → 位置关系 → 角度和距离”。先把几何条件译成向量关系，再选择基底或直角坐标系，计算后回到原图验证范围和非退化条件。

1. 读[概念与线性运算](知识-空间向量的概念与线性运算.md)，练[概念辨析](考点-辨别空间向量概念与运算关系.md)、[图形中的线性运算](考点-在空间图形中作线性运算.md)、[线性关系求系数参数](考点-由向量线性关系求系数与参数.md)。有向线段先看起终点，首尾相接才可直接相加。
2. 读[共线共面条件](知识-空间向量共线与共面的条件.md)、[位置向量与点的共线共面](知识-位置向量与点的共线共面表示.md)，练[条件求参数](考点-用共线共面条件求参数.md)、[证明点共线共面](考点-用位置向量证明点共线或共面.md)。检查[承载直线与自由向量](坑点-把向量共面误作承载直线必须共面.md)、[非零和不共线条件](坑点-缺非零或不共线条件套向量表示.md)、[共同起点及系数和](坑点-点共面表示漏共同起点或系数和.md)。
3. 读[基本定理与基底](知识-空间向量基本定理与基底.md)、[唯一性与变换](知识-空间基底表示的唯一性与变换.md)，练[判断基底与转换表示](考点-判断基底并转换向量表示.md)。空间基底要三个不共面向量；一般基底不要求单位长度或两两垂直。
4. 读[夹角、数量积与运算律](知识-空间向量夹角数量积与运算律.md)、[投影与正交分解](知识-空间向量的投影与正交分解.md)，练[几何数量积与模](考点-从空间几何计算数量积与模.md)、[垂直及参数](考点-用数量积判断垂直与求参数.md)、[向量夹角与投影](考点-求空间向量夹角与投影向量.md)。检查[零向量夹角](坑点-给零向量定义夹角或在夹角式除以零.md)、[数量积随意消去因子](坑点-把数量积当向量乘法随意消去因子.md)。
5. 读[直角坐标系与点坐标](知识-空间直角坐标系与点的坐标.md)、[坐标运算与度量](知识-空间向量坐标运算与度量公式.md)，练[建系求点与对称点](考点-建直角坐标系求点坐标与对称点.md)、[坐标求模数量积夹角](考点-按空间坐标求模数量积与夹角.md)、[坐标判共线垂直求参数](考点-用空间坐标判断共线垂直与求参数.md)。检查[斜基底误套直角公式](坑点-在斜基底下直接套直角坐标度量公式.md)。向量坐标由终点坐标减起点坐标，不能把终点坐标直接当作一般向量坐标。
6. 读[方向、法向量与位置表示](知识-方向向量法向量与空间位置表示.md)、[平行与垂直判据](知识-平行与垂直关系的向量判据.md)，练[方向与法向量求法](考点-求直线方向向量与平面法向量.md)、[平行证明](考点-用空间向量证明线线线面或面面平行.md)、[垂直证明](考点-用空间向量证明线线线面或面面垂直.md)。检查[零法向量和一个方向不足](坑点-法向量取零或只垂直一条平面内直线.md)、[包含与重合未排除](坑点-平行方向条件忘排除包含与重合.md)。
7. 读[线线角与线面角](知识-线线角与线面角的向量求法.md)、[二面角与范围](知识-二面角的向量求法与角的范围.md)，练[方向和法向量求线角](考点-用方向与法向量求线线角或线面角.md)、[指定半平面的二面角](考点-按指定半平面求二面角.md)。检查[向量夹角误代指定二面角](坑点-向量夹角代替二面角并一律取绝对值.md)。先定角的对象和范围，再决定公式中的绝对值与符号。
8. 读[点到直线距离](知识-点到直线的正交投影距离.md)、[点到平面及平行面距离](知识-点到平面与平行平面的距离.md)、[异面直线距离](知识-异面直线距离与公垂线法向量.md)，练[点线与点面距离](考点-用空间向量求点到直线或平面距离.md)、[公垂方向求异面距离](考点-用公垂方向求异面直线距离.md)。检查[斜距、投影与实际距离](坑点-把斜距投影长度与实际距离混淆.md)。距离须对应最短的垂线段，不能仅把任意连线取模。
9. 练[空间存在性方程](考点-用空间向量方程处理存在性问题.md)。方程算出的参数先回代检验，再核对点在线段还是延长线上、图形是否仍成立；代数解不自动成为原题的几何解。

原题及原解保留，补讲和资料疑点另列。方向向量和法向量须非零；直线、平面与指定半平面是不同几何对象，不能用相近的公式名称替代适用条件。
