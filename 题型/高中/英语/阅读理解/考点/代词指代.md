# 代词指代

**一句话概念** — 问 `it / they / this / that / these / those / one / ones` 等具体指什么。

## 怎么认

`What does "it / they" refer to?` 这类问法，文中代词有划线或编号。

## 思路

**候选先行词 → 语法匹配 → 语义代回 → 篇章延续。**

1. 找到代词及所在句；
2. 向前寻找可能的名词、名词短语或整件事；
3. 检查单复数、人或物等语法匹配；
4. 代回原句检查语义是否合理；
5. 检查当前段正在延续哪个人物或概念。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L1 指人 / 指物 | he / she / it / they / them 的单复数与身份匹配 | 指代整句或观点 |
| L2 指句子或观点 | this / that / it 承接前面的动作、事实或观点 | — |

## 怎么讲

1. 先给概念；
2. 重点：`this / that` 可能指整个动作、事实或观点；`one / ones` 指前文同类事物，不必完全相同；
3. 只讲当前台阶；
4. **常见卡点**：
   - 直接选最近的名词，不检查单复数和语义；
   - 只核对语法，不代回原句读通。

## 易错

**最近名词只是候选，不是答案规则**。它若在单复数、语义或篇章重点上不匹配，要继续向前寻找。
