# 等差数列

等差数列从第2项起，相邻后项减前项都等于同一个常数d。首项a₁与公差d决定aₙ=a₁+(n−1)d；d=0的常数列也属于等差数列。定义是全体相邻差恒定，不能只验某几个差。

先读定义、通项及下标性质，再读前n项和。倒序相加得到Sₙ=n(a₁+aₙ)/2，代通项得到Sₙ=na₁+n(n−1)d/2；只有d≠0才是关于n的二次式。若Sₙ=An²+Bn（无常数项），求差并核首项后，公差为2A，A可以为0；有常数项的原式可能使首项脱离后续等差规律。

等距离下标的项和、连续等长分段和均须从通项推导。项和的最值用Sₙ−Sₙ₋₁=aₙ查增减、变号与零项，再核正整数及有限末端；二次顶点只是定位，不直接成为最优项数。含绝对值时先找合法变号位置再分段求和。
