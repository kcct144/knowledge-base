## 错法

$NaCl$含$CuSO_{4}$加$NaOH$只见蓝沉淀便说得到纯$NaCl$液。

## 正解

沉淀只处理$Cu^{2+}$，$SO_4^{2-}$仍留液为$Na_{2}SO_{4}$。列全离子而非一视觉对象，合理试剂需同时除两杂离子且不带新杂。

## 例题

### 四方案除杂判断

> 来源ID Q13-05；专题二共存鉴别分离除杂；151-200/full.md 第1300–1302行。原答案与解析定位：151-200/full.md 第1304–1306行。

例5 (2024 重庆 B 卷中考)下列除杂(括号中的物质为杂质)所用试剂及方法正确的是 ( )

| 序号 | 实验对象 | 试剂及方法 |
| --- | --- | --- |
| A | $CuO$ 粉末(炭粉) | 加入足量的稀硫酸,过滤 |
| B | $CO_{2}(CO)$ | 气体通过足量的木炭,加热 |
| C | $NaOH$ 溶液( $Na_{2}CO_{3}$ ) | 加入适量  $Ba(OH)_{2}$  溶液,过滤 |
| D | $NaCl$ 溶液( $CuSO_{4}$ ) | 加入适量 $NaOH$ 溶液,过滤 |

**原资料答案与解析：**

解析 A(×)$CuO$ 能与足量的稀硫酸反应生成硫酸铜和水,炭粉不与稀硫酸反应,过滤后杂质没有除去,反而把原物质除去,不符合除杂原则。B(×)在加热的条件下,一氧化碳和木炭不反应,不符合除杂原则。C(√)$Na_{2}CO_{3}$能与适量的 $Ba(OH)_{2}$ 溶液反应生成碳酸钡沉淀和氢氧化钠,能除去杂质且没有引入新的杂质,符合除杂原则。D(×)$CuSO_{4}$能与适量的 $NaOH$ 溶液反应生成氢氧化铜沉淀和硫酸钠,能除去杂质但引入了新的杂质硫酸钠,不符合除杂原则。

答案 C

**展开解析（依据原详解补足理由与步骤）：**

选C。A $CuO$为主，却与稀硫酸溶为$CuSO_{4}$，留下炭杂，主物丢失；B炭不除$CO$且高温反把主$CO_{2}$变$CO$，$C+CO_2\xlongequal{\text{高温}}2CO$，原解只说$CO$不反应还不足，补主物损失；C适量$Ba(OH)_{2}$把$Na_{2}CO_{3}$转$BaCO_{3}$沉淀和所需$NaOH$，过滤除沉淀，符合；D $NaOH$只沉$Cu^{2+}$，$SO_4^{2-}$仍在液为$Na_{2}SO_{4}$新杂，不能仅有沉淀就说全杂除。$NaCl$去$CuSO_{4}$可适量$Ba(OH)_{2}$同时去两种杂离子，须控制量。
