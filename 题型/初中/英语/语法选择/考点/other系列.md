# other 系列

**一句话概念** — other / another / the other / others / the others 的区别，取决于后面有没有名词、数量范围和是否特指。

## 怎么认

选项常集中出现：

```text
other / another / the other
others / the others
```

看到这些形式对比时，先判断它们后面是否需要接名词，再判断范围和特指。

**信号不是绝对规则**：后面是否有名词只是第一步，还要判断数量和特指。

## 思路

**先看空格后有没有名词，再看数量和特指。**

1. **有没有名词**：有名词 → 考虑 other、another、the other；没有名词 → 考虑 others、the others
2. **范围和特指**：是「另一个」、两者中的另一个，还是一组中的其余部分

依据行：other + 可数名词复数或不可数名词，表示“其他的”；another + 可数名词单数，常表示“另一个、再一个”；the other 常表示两者中的另一个，也可修饰特定范围中的其他名词；others 相当于 other + 复数名词，后面不再接名词；the others 表示特定范围内剩余的全部人或物。the other + 复数名词还可表示特定范围内其他的若干项，不能只记“两者中的另一个”。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 识别 | 从选项认出这五个形式 | 不要求判答案 |
| L1 基础流程 | 后面有无名词 → 排除不合适形式 | 特指范围 |
| L2 范围 | 区分一个、两个和一组中的其余部分 | 固定搭配 |
| L3 特指 | others 与 the others 的范围差异 | — |

**默认停在 L1。**

## 怎么讲

1. 先给上面那句概念，够认就行
2. 用最简例子走一遍「有无名词 → 数清范围 → 选词 → 依据」
3. 只讲当前台阶，别顺手把 another two days 等特殊形式一起倒出来
4. **常见卡点**：
   - 后面没有名词却选择 other
   - 看到“另一个”就选 another，忽略两者限定
   - 混淆 others 和 the others 的特指范围
   - 只背固定搭配，不在上下文中数清范围

## 易错

**看不出上下文的数量范围。**

```text
One was small, and ____ was large.                               ← 明确只有两把钥匙，指两者中的另一把，用 the other
Some students stayed downstairs, while ____ climbed the tower.   ← 空格后没有名词，用 others
```

another 不等于所有语境中的“其他”，它通常强调再一个或不同的一个；解题要回到上下文数清是一个、两个还是一组里的其余部分。

## 例题

**例一**　Emma had two keys. One was small, and ____ was large.
A. another　B. the other　C. others
→ **B**。明确只有两把钥匙，指两者中的另一把，使用 the other。

**例二**　Some students stayed downstairs, while ____ climbed the tower.
A. other　B. another　C. others
→ **C**。空格后没有名词，表示另一些学生，使用代词 others。

（两例均为自编）
