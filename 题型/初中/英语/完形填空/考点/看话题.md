# 看话题

**一句话概念** — 局部多个选项都说得通时，回到全文话题和情节方向，看哪个更符合人物、事件和情感主线。

## 怎么认

四个选项词性相同、放在局部都能搭配，答案取决于人物、事件或情感主线时用。

## 思路

1. 作答前用一句中文概括文章讲什么；
2. 逐空过程中根据新信息更新这个概括；
3. 判断当前选项是否符合人物、事件和情感主线；
4. 三个轻量问题：谁或什么？发生了什么变化或问题？整体态度、结果或发展方向是什么？

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 一句话概括 | 用一句中文说出文章讲什么 | 更新主线 |
| L1 更新主线 | 逐空根据新信息更新，判断选项是否合主线 | 首尾照应 |
| L2 首尾照应 | 涉及主题、结果或首尾照应时回到全文 | — |

**默认停在 L1。**

## 怎么讲

1. 先给上面那句话；
2. 用一道题走一遍“概括 → 更新 → 判断”；
3. 只讲当前台阶；
4. **常见卡点**：
   - 只凭局部搭配就定，不回主线；
   - 看完开头就把话题定死，不更新。

## 易错

**看话题不能替代精确词义。** 局部能直接决定的空，不要硬扯全文；反过来，只有主线能决定时，也不要停在局部。
