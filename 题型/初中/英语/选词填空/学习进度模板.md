## 观察熟练度

熟练度：**见过 / 需提示 / 可快速调用 / 稳定迁移**。空白 = 未评估。

### 看缺空处

| 情况 | 熟练度 |
|---|---|
| 限定词后 → 名词 | |
| 形容词后 → 名词 | |
| 介词后 → 名词 / 代词 / 动名词 | |
| 主语后 → 谓语动词 | |
| 主语前 → 形容词 | |
| 情态动词后 → 动词原形 | |
| `to +` → 动词原形 | |
| `be +` → 形容词 / 名词 / 分词 | |
| 系动词后（feel / look…） → 形容词 | |
| `very / so / too +` → 形容词或副词 | |
| `___ + 名词` → 形容词 / 限定词 | |
| 分句之间 → 连词 | |

### 看选词框

| 情况 | 熟练度 |
|---|---|
| 名词 → 主语 / 宾语 / 表语；限定词 · 形容词 · 介词后 | |
| 动词 → 谓语；`to` · 情态后 | |
| 形容词 → 名词前；`be` · 系动词后 | |
| 副词 → 修饰动词 / 形容词 / 副词 / 整句 | |
| 介词 → 后接名词 / 代词 / 动名词 | |
| 连词 → 连接，常在主语前 | |
| 代词 · 限定词 → 指代或限定 | |
| 情态动词 → 主语后、动词原形前 | |
| 复合不定代词 → 形容词后置 | |
| 框里两个介词 → 大概率有误导项 | |
