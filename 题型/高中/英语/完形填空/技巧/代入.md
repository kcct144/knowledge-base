# 代入

**一句话概念** — 先提取包含空格的**最小有意义结构**，再逐个代入选项。不要把整个长句同时塞进脑子。

## 怎么认

空格附近能截出一个能决定搭配或意义的小结构，就该先代入：

    ____ information        feel very ____
    ____ from the app       a ____ decision

常见最小结构：动词 + 宾语、系动词 + 形容词、动词短语 + 宾语、形容词 + 名词 / 介词短语。

局部都成立（尤其高中四个选项词性相同、都能搭配）时，别硬在短语里找证据——扩大到句 / 前后句 / 段 / 全文。

## 思路

1. 只保留能决定搭配或意义的词，截出最小结构；
2. 逐个把选项放进去，检查：词义是否合、放入是否自然、与人物 / 动作 / 褒贬是否冲突；
3. 局部能唯一决定就作答；否则带着明确问题扩大范围。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 截取 | 从空格附近截出最小有意义结构 | 不处理整句 |
| L1 代入 | 逐项代入，看词义和自然度 | 局部都成立时扩大上下文 |
| L2 扩大范围 | 局部不定时按“句 → 前后句 → 段 → 全文”找证据 | 高中词义精辨 |

**默认停在 L1。** 四个选项词性相同、局部都通时直接升到 L2。

## 怎么讲

1. 先给概念：**短语只是降低处理压力的起点，不是每空必须停留的范围**；
2. 用 `feel very ____` 走一遍“截取 → 代入”；
3. 只讲当前台阶；
4. **常见卡点**：
   - 代入时同时处理整个长句，工作记忆负担过大；
   - 只看空格前后两三个词，局部都成立仍不扩大。

## 易错

**“读起来顺”不是依据。** 代入后必须说出是哪条词义、搭配或上下文证据让你留下或排除它。
