# 句篇逻辑

**一句话概念** — 局部都对、句子本身决定不了时，证据在**句间或跨段的关系、视角和时间**里：谁在什么时间、对什么、持什么态度。

> 高中扩展。基础流程走完仍有断点才用；一次只处理一个关系。

## 怎么认

- 空格所在短语 / 单句里两个选项都能成立，决定性证据在前后句、前一段或结尾；
- 出现 `though / sure / however / actually / as`、分号、直接引语等转折或视角信号；
- 叙述者从过去到现在改变看法，学生却把早期抱怨当成最终态度；
- 他人引语、叙述者旧观点和当前观点混在一起；
- 相邻多空连续受同一次态度转变、因果链或跨段照应影响；
- 学生只用“正面 / 负面”，说不清“谁对什么、在什么时候怎样看”。

## 思路

1. **定视角**——这句话是谁说、谁想、谁在评价；
2. **定时间**——过去经历、后来反思，还是现在结论；
3. **写两层意思**——用短语概括连接词 / 分号 / 段落前后的内容；
4. **命名关系**——并列、递进、因果、条件、让步后转折、解释、指代照应中选当前需要的一种；
5. **找锚点**——圈出证明该关系的原文事实、重复概念、态度词或结果；
6. **比较候选**——能完成这条关系的留下；只在局部通顺却破坏时间线或态度线的排除；
7. **更新篇章草图**。

用态度记录代替笼统褒贬：`人物 / 声音 · 时间阶段 · 态度对象 · 具体态度 · 变化信号`。

三类常见增量：

- **让步—转折**：先承认一个事实，再转向作者真正要推进的判断（`Though ...`、`Sure, ...; ...`）；
- **态度随时间变化**：画 `过去怎么看 → 什么经历触发变化 → 现在怎么看`；
- **跨句 / 跨段照应**：`this`、概括名词或结尾价值判断可能回指前一句，也可能概括整段，先明确回指范围。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| H2 句间逻辑 | 识别一个明确的转折、因果、时间或态度变化 | 跨段 |
| H3 篇章追踪 | 跨句 / 跨段追踪视角、指代、态度与结果 | — |

**按报告进入**：近处上下文能决定 → H2；同一关系影响相邻多空或结尾回扣前文 → H3。H2、H3 不固定顺序。

## 怎么讲

- “这是谁的看法，过去还是现在？”
- “前后两层是顺着走，还是承认以后转向？”
- “哪个原文事实是锚点？”
- “换成另一个候选，哪条时间线或态度线会断？”

## 易错

- 只圈连接词，不说两层意思之间的关系；
- 把他人话语当作者结论；
- 把“过去抱怨”当成最终态度；
- 把待定答案当篇章事实用于跨空推理。
