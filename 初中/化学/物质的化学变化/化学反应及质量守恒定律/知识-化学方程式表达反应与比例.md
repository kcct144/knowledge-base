## 讲解

### 是什么

正式化学方程式需符合真实反应、正确化学式、配平原子数，并标必要条件及生成状态。计量数比表示反应粒子数比，质量比须乘各自相对质量。

### 怎么来的

如$2H_2+O_2\xlongequal{\text{点燃}}2H_2O$，粒子比2∶1∶2；每份相对质量2、32、18，质量比$2\times2:1\times32:2\times18=4:32:36$。大量同样反应组只放大同一倍数，比例不变。

### 什么时候能用

只配平的虚假产物仍错。反应条件写点燃、通电、高温等，不能以燃烧、电解过程代替；催化剂写条件不计入参加原料。气体标↑按反应物状态和题设常见规范，不机械把所有气体都标。

## 例题

### 方程式正误逐项检查

> 来源ID Q05-09；第五单元化学反应的定量关系；51-100/full.md 第1261–1268行。原答案与解析定位：51-100/full.md 第1270–1272行。

例1 下列化学方程式书写正确的是

( )

A. 氧化铝溶于稀硫酸: $Al_{2}O_{3} + 2H_{2}SO_{4} = 2AlSO_{4} + 2H_{2}O$   
B. 镁在空气中燃烧: $Mg + O_{2} \xlongequal{\text{点燃}} MgO_{2}$   
C. 铜在氧气中加热: $Cu + O_{2} = CuO$   
D. 向硫酸铜溶液中滴加少量氢氧化钠溶液: $\mathrm{CuSO}_{4} + 2\mathrm{NaOH} = \mathrm{Cu(OH)}_{2} \downarrow + \mathrm{Na}_{2}\mathrm{SO}_{4}$

**原资料答案与解析：**

解析 A(×)写错物质的化学式,硫酸铝的化学式为 $\mathrm{Al}_{2}(\mathrm{SO}_{4})_{3}$ , 正确的化学方程式为 $\mathrm{Al}_{2}\mathrm{O}_{3} + 3\mathrm{H}_{2}\mathrm{SO}_{4} = \mathrm{Al}_{2}(\mathrm{SO}_{4})_{3} + 3\mathrm{H}_{2}\mathrm{O}$ ; B(×)写错物质的化学式,氧化镁的化学式为 $MgO$, 正确的化学方程式为 $2Mg + O_{2} \xlongequal{\text{点燃}} 2MgO$ ; C(×)未注明反应条件,且未配平,正确的化学方程式为 $2Cu + O_{2} \xlongequal{\triangle} 2CuO$ 。

答案 D

**展开解析（依据原详解补足理由与步骤）：**

选D。A硫酸铝式应为$Al_2(SO_4)_3$，正确式为$Al_2O_3+3H_2SO_4=Al_2(SO_4)_3+3H_2O$；原选项式和数都错。B氧化镁为$MgO$，不能用MgO₂凑氧；应$2Mg+O_2\xlongequal{\text{点燃}}2MgO$。C缺加热且Cu、O不平衡，应$2Cu+O_2\xlongequal{\triangle}2CuO$。D物质式正确，Cu1、S1、Na2、O6、H2两边相同，溶液中生成氢氧化铜沉淀标↓，书写正确。

### 考试方程式四项

> 来源ID Q05-16；第五单元化学反应的定量关系；51-100/full.md 第1459–1467行。原答案与解析定位：51-100/full.md 第1407–1409行。

例1 下列化学方程式正确的是

( )

A. 细铁丝在氧气中燃烧: $4Fe + 3O_{2} \xlongequal{\text{点燃}} 2Fe_{2}O_{3}$   
B. 水通电分解: $2H_{2}O \xlongequal{\text{通电}} 2H_{2}\uparrow + O_{2}\uparrow$   
C. 红磷在空气中燃烧: $2P + O_{2} \xlongequal{\text{点燃}} P_{2}O_{5}$

D. 实验室用高锰酸钾制取氧气: $2 \mathrm{KMnO}_{4} = \mathrm{K}_{2} \mathrm{MnO}_{2} + \mathrm{MnO}_{2} + \mathrm{O}_{2} \uparrow$

**原资料答案与解析：**

例1 解析 A(×) 细铁丝在氧气中燃烧生成四氧化三铁, 正确的化学方程式为 $3Fe + 2O_{2} \xlongequal{\text{点燃}} Fe_{3}O_{4}$ ; C(×) 未配平, 正确的化学方程式为 $4P + 5O_{2} \xlongequal{\text{点燃}} 2P_{2}O_{5}$ ; D(×) 未注明反应条件, 正确的化学方程式为 $2KMnO_{4} \xlongequal{\triangle} K_{2}MnO_{4} + MnO_{2} + O_{2} \uparrow$ 。

答案 B

**展开解析（依据原详解补足理由与步骤）：**

选B。A虽然按所写$Fe_{2}O_{3}$能配平，但实际细铁丝在氧气燃烧教材产物为$Fe_{3}O_{4}$，应$3Fe+2O_2\xlongequal{\text{点燃}}Fe_3O_4$。B两侧H4、$O_{2}$，通电条件与两气体↑标记齐全。C左P2、$O_{2}$，右P2、O5，不平衡，应$4P+5O_2\xlongequal{\text{点燃}}2P_2O_5$。D原书实际第31页也写K₂MnO₂，保留为错项；不仅缺加热，产物式也错，正确为$K_{2}MnO_{4}$。原详解仅提缺条件，本文补齐漏评。

### 二十克氢氧混合气双选

> 来源ID Q05-12；第五单元化学反应的定量关系；51-100/full.md 第1331–1339行。原答案与解析定位：51-100/full.md 第1341–1343行。

例4 (双选)现有氢气与氧气的混合气共 $20 \mathrm{~g}$ , 在密闭的容器中点燃, 生成 $18 \mathrm{~g}$ 水, 则下列对混合气成分的分析正确的是 ( )

A. 氢气 $10 \mathrm{~g}$ , 氧气 $10 \mathrm{~g}$

B. 氢气 $2 \mathrm{~g}$ , 氧气 $18 \mathrm{~g}$

C. 氢气 $4 \mathrm{~g}$ , 氧气 $16 \mathrm{~g}$

D. 氢气 $1 \mathrm{~g}$ , 氧气 $19 \mathrm{~g}$

**原资料答案与解析：**

解析 由 $2 \mathrm{H}_{2} + \mathrm{O}_{2} \xlongequal{\text {点燃}} 2 \mathrm{H}_{2} \mathrm{O}$ 知, 氢气在氧气中燃烧时, 参加反应的氢气与氧气的质量比为 $1:8$ , 本题中生成 $18 \mathrm{~g}$ 水, 则反应物的质量必然是氢气 $2 \mathrm{~g}$ , 氧气 $16 \mathrm{~g}$ 。若混合气按 B 选项组成会剩余 $2 \mathrm{~g}$ 氧气; 若按 C 选项组成会剩余 $2 \mathrm{~g}$ 氢气。故 B、C 选项都有可能。

答案 BC

**展开解析（依据原详解补足理由与步骤）：**

选BC。$2H_2+O_2\xlongequal{\text{点燃}}2H_2O$的质量比$4:32:36=1:8:9$；18 g水对应参加H₂2 g和O₂16 g，共18 g，剩余气体20−18=2 g。A10 g氧只能与$10/8=1.25$ g氢反应，不能成18 g水。B氢2、氧18，可反应2与16，剩氧2，成立。C氢4、氧16，反应氢2，剩氢2，成立。D氢1，只能配氧8，成水9 g，不成立。两个可能方案来自未给剩余气体身份。
