## 讲解

### 是什么

语段衔接要求话题连贯、指代明确、逻辑与表达风格相配。一个空或一句通常同时受前文与后文限制，恰当句不仅自己语法通顺，还要完成它在段落中的连接任务。

### 怎么来的

原语言规范段前讲不能马虎，后列古人认真用字故事，过渡句需回指所谈方面并引出向古人学习。原C兼有这方面与向古人学习两端；A只强调重视，B只引古人，D另作古今优劣判断。比较的是整段连接完整性，不等于A、B作为孤立句全都错误。

原中学时光段则先让之所以接就是因为，再按知识基础到精神气质的原表达层次连小句群。关联词、代词、时间词帮助建立局部连接，局部顺序确定后，还要核整个语段是否连续；不能因为一个配对吻合就不看剩下两句。

内容顺序可能按时间、空间或逻辑组织，应由材料识别，不以背过的万能序列替代。原表说排列一般有逻辑约束，含一般，不表示所有散文任何两句都只许一个顺序。解题要列前空任务、内部关系、后空承接三层证据，再完成全文回读，才能解释最恰当而非仅解释可读。

### 什么时候能用

用于原衔接排序题。比较段内作用，不额外作材料没有的事实评价；确定顺序在所给句子和原段约束内，不推广为所有人生或写作唯一顺序。

## 例题

### 原例题 CN-SEN-E03

例1 (2024 江西中考)阅读下面的文字,完成问题。

语言是一个民族的灵魂。语言文字的错误看起来无伤大雅，实际上既关系到民族语文的纯正性、规范性和严肃性，又关系到一个国家的精神面貌，不能马虎。\_\_\_\_。唐代苦吟派诗人贾岛和韩愈“推敲”用字的故事、吕不韦“悬书城头改一字赏千金”的典故，等等，无不启示我们，对语言文字应该保持应有的敬畏和认真。

下列填入文中横线处的语句,衔接最恰当的一项是 ( )

A.在这方面我们要高度重视

B. 我们应该向古人学习

C. 在这方面我们应该向古人学习

D. 今人在这方面不如古人

**原答案**：C。

**原解析（原文）**

横线处的前文强调语言文字与民族语文、国家关系极大,横线处的后文罗列的事例体现了古人对语言文字的敬畏与认真。横线处的语句应承上启下,发挥过渡作用,所以 C 项最恰当。

答案 C

**完整解析（依据原解析展开）**

先找空两侧任务：前文说语言规范关系民族国家，后文举贾岛韩愈推敲与吕不韦故事。过渡句要用这方面回指规范敬畏的主题，还要引出向古人学习。C两层都具备。A仅回承重视，缺古人学习引例线索；B仅向后引古人，不如C显明回扣这一方面；D无依据断言今人不如古人，语气与段落劝诫目的不合，原文没有作整体古今优劣评判。故C最恰当，A、B不是单句语法错误，而是衔接完整程度不及C；选择最恰当须比较上下两侧而非只看一侧。

### 原例题 CN-SEN-E04

例2（2024 吉林中考改编）阅读语段,按要求回答问题。

在人的一生中,中学阶段正是求知欲最旺盛、记忆力最好、想象力最丰富,对一切都充满幻想的时期。许多在各自领域出类拔萃的人回忆起自己的中学时光,之所以会常常心存感念,\_\_\_\_,\_\_\_\_,\_\_\_\_。学校除了给学生提供知识,更重要的是还提供一种求知的方法、路径,是打开

认知世界、观察社会的窗户，或者说是一个眺望世界的平台。

将下列语句依次填入文中横线处,最恰当的一项是

( )

①他们的精神气质是在那时形成的  
②就是因为他们的人生理想是从那时起步的  
③他们的知识基础是在那时奠定的

A.②①③

B.③①②

C.②③①

D.①②③

**原答案**：C：②③①。

**原解析（原文）**

结合横线前“许多在各自领域出类拔萃的人回忆起自己的中学时光,之所以会常常心存感念”可知,横线处句子应该解释为什么他们会“常常心存感念”,即中学时光对他们的影响。②句中的“是因为……”与前文“之所以……”构成固定搭配,故②句应填在第一空。知识是基础,而精神气质则是更高层次的东西,二者应是递进关系,按逻辑关系,①句应在③句之后。故排序为②③①。

答案 C

**完整解析（依据原解析展开）**

第一空先由前文之所以常常心存感念寻找解释原因的接句，②含就是因为，可直接完成之所以—就是因为结构，①③直接接前文均未完成这个连接，所以先排B、D。再比较A②①③与C②③①：原三项中人生理想起步为起点，知识基础奠定为学习基础，精神气质形成在原解析中作为更高层次的成长，③在①前构成由基础到精神的递进。故C。完整代入确认主语他们、那时均回指前文出类拔萃者和中学时光。不能把人生所有阶段都规定为同一唯一顺序；这里按原给三句与原段表达层次排序。

## 易错

仅看前侧；仅看后侧；单句通顺等于最恰当；找到一对关联后忽略余句；添加原文没有的比较结论。
