# 等差数列与等比数列综合应用

同时出现等差和等比条件时，先分清哪些项属于同一个数列，哪些数按指定顺序组成另一数列。等差用a₁、d，等比用b₁、q，把文字条件转成同一组基本量方程，再筛选符合原条件的根。

等比中项的平方式不自动保留非零条件；正项、递增、有限项数等条件会进一步限制根。正项无穷等差数列可限制d，有限正项等差数列的限制须按实际末项检验，不能互换。

混合求和时先写清所求通项，分别识别相加、相乘或奇偶拼接。相加可分组，相乘可能需错位相减；最终公式核首项、公比特殊值和完整n范围，再回到原交汇条件。
