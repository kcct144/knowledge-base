# 统计

按“怎样得到数据 → 怎样描述数据 → 怎样估计总体”学习。先核对调查对象、抽样方式与单位，再计算；统计估计要同时说清依据和局限。

1. 读[总体个体样本与获取数据](知识-总体个体样本与获取数据.md)、[简单随机抽样与实现方法](知识-简单随机抽样与实现方法.md)。练[调查方式与样本对象](考点-辨别调查方式与样本对象.md)、[抽签与随机数表](考点-用抽签与随机数表实施抽样.md)，检查[对象与变量混淆](坑点-把抽样对象与所调查变量混淆.md)。
2. 读[分层随机抽样与比例分配](知识-分层随机抽样与比例分配.md)、[样本与分层总体均值估计](知识-样本均值与分层总体均值估计.md)。练[抽样机会与配额](考点-计算抽样机会与分层配额.md)、[分层设计](考点-按差异分层设计抽样方案.md)、[层权重估计均值](考点-按层权重估计总体均值.md)。检查[每次抽中与最终入样概率](坑点-把每次抽中概率与最终入样概率混淆.md)和[分层并非一律比例分配](坑点-把分层抽样一律当作比例分配.md)。
3. 读[频率分布表与直方图](知识-频率分布表与直方图.md)、[统计图选用与比较](知识-统计图的选用与比较.md)。练[面积求频率频数人数](考点-用直方图面积求频率频数与人数.md)、[多图读取比较](考点-从多种统计图读取并比较信息.md)，检查[高度直接当频率](坑点-把直方图高度直接当频率.md)。
4. 读[百分位数及计算约定](知识-百分位数的定义与计算约定.md)、[平均数中位数众数](知识-平均数中位数与众数.md)。练[有序数据求百分位](考点-按有序数据求百分位数.md)、[原始数据集中趋势求参](考点-由原始数据求集中趋势与参数.md)、[分组估计集中趋势](考点-由分组数据估计集中趋势.md)。检查[排序与位置错误](坑点-百分位数未排序或取错位置.md)和[中点估计误当精确统计量](坑点-把分组中点估计当作精确统计量.md)。
5. 读[方差标准差](知识-方差与标准差的含义及计算.md)、[线性变换影响](知识-数据线性变换对均值与离散程度的影响.md)。练[离散程度与稳定性](考点-计算方差标准差并比较数据稳定性.md)、[频率表估计离散程度](考点-由频率表估计方差与标准差.md)。检查[平方单位与分母](坑点-方差计算漏平方或混淆单位与分母.md)、[标准差漏绝对值](坑点-标准差随线性变换漏绝对值.md)。
6. 读[统计调查与分析报告](知识-统计调查与分析报告.md)，练[综合描述与群体比较](考点-综合统计描述估计总体并比较群体.md)、[按证据和局限组织报告](考点-按问题证据与局限组织调查报告.md)。检查[样本描述误当总体定论或因果](坑点-把样本描述直接当作总体定论或因果.md)。

原题与原解完整保留，补讲和资料疑点分开。分组表通常丢失组内原始取值；合理抽样仍有随机误差，不能保证每一次估计都接近总体真值。计算结论应保留这些使用条件。
