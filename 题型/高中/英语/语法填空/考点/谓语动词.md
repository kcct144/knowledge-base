# 谓语动词

**一句话概念** — 一个分句的谓语要同时管住**时间（时态）、主动还是被动（语态）、跟主语一致（单复数）**，缺一个都写不全。

## 怎么认

给动词，且**本分句还没有别的谓语**，这个空多半填谓语。

对照：本分句已有谓语 → 更可能是非谓语（见 [`非谓语动词`](非谓语动词.md)）。

**信号不是绝对规则**：给动词不一定是谓语；一个词可有多种词性；并列结构和从句**各有自己的谓语**，不能因为整句已有一个动词就把后面都算非谓语。

## 思路

**先定分句，再定时间和语态，最后写全形式。**

1. **定分句与主语**：这个空属于哪个分句？主语的**中心词**是谁？
2. **判时间**：语篇时间、参照点、事件先后；时间词只是证据之一。
3. **判语态**：主语和动作是主动还是被动？
4. **核对一致并组成完整形式**：助动词、情态动词、实义动词一起写全。
5. **代回语境验证**。

## 台阶（讲到哪停）

材料里的 Unit 03，逐关如下，**每一关一级，不合并**。

| 关 | 本级只解决 |
|---|---|
| 01 | 过去叙述中确定一般过去时，独立写出规则和不规则形式 |
| 02 | 区分截至现在与截至过去参照点的完成意义，写全形式 |
| 03 | 结合已有情态动词或过去语境，补全被动形式 |
| 04 | 已规定一般现在时的条件下，按主语中心完成一致变化 |
| 05 | 区分一般事实、一贯表现与此刻正在发生的动作 |
| 06 | 对照 is / was 经历表达，并迁移到其他现在和过去参照 |
| 07 | 混合运用时间关系、主语和完整形式 |

不要求逐级学完；按当前断点挑关，不稳就退一关。

## 怎么讲

1. 先给上面那句概念，够认就行。
2. 用上面的顺序，配一个最简例子走一遍"判断 → 依据"。
3. 只讲当前范围，不从一个时态扩展成高中全部时态课。
4. **常见卡点**：
   - 只看时间词就定答案
   - 把"一般过去时会了"当成"过去完成时也会"
   - 说得出该用什么时态，却写不出形式（这是补词形，不重讲识别）
   - 整句已有一个动词，就把后面的都当非谓语

## 易错

**时间词是证据之一，不是答案。**

```text
had done      ← 需要另一个过去的参照点，不是"发生在过去"就够
was/were done ← 被动要有 be + 过去分词
has/have done ← 与现在有关，和"只是一件过去的事"不同
```

主语的**中心**可能被长修饰语或插入成分隔开，判一致要看中心词。
