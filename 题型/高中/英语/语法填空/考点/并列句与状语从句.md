# 并列句与状语从句

**一句话概念** — 连接词连接两个单位：**并列**是地位相同，**状语从句**是从属并表达时间 / 条件 / 原因 / 结果 / 转折等关系。

## 怎么认

无提示词，空位用来连接两个单位（词、短语、分句），就是并列或从属连接词。

**信号不是绝对规则**：不只看"有没有两句话"，要看**连接的是什么单位**。

## 思路

**先找出空格两边对应的单位，再判并列还是从属，最后看语义。**

1. **找单位**：空格两边连接的是词、短语、谓语，还是分句？
2. **判关系**：地位相同（并列）还是从属（状语从句）？
3. **看语义**：转折、对照、让步、结果、条件、时间？
4. **选连接词并代入核对**。

## 怎么讲

1. 先给概念：连接词先看**连接谁、是什么关系**，再谈选哪个词。
2. 用一句走"找单位 → 判关系 → 看语义"。
3. **常见卡点**：
   - 只看"两句话"，不看连接单位
   - `and / but` 连接的单位判错
   - 结果与条件混淆

## 易错

**先看连接单位和语义关系，再判结构、意义。**

```text
and 连接并列不定式 / 名词短语 / 谓语  ← 单位不同，判断方式不同
but / while / although              ← 转折、对照、让步
so ... that / such ... that         ← 程度导致结果
if / unless / when / while          ← 条件、时间
```

三类从句（定语、名词性、状语）的混合判断放在 Unit 13 末尾，跨单元综合。
