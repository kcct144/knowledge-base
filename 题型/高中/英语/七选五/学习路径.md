# 学习路径

**有报告就按报告走，别按本文件从头教。** 下面是**没有报告时**的系统起步顺序。

## 默认路线

    材料适配 → 执行核心动作 → 只补真实断点 → 回到新材料

材料适配随文章变化，不作为稳定能力等级。

## 一、材料适配

先确认学生能否：

- 理解所有空共用一个句子池；
- 按题面说清空数、选项数、能否重复、有无多余项；
- 说出文章或相关段落的大意；
- 说出关键选项和空格附近句子的核心意思。

处理方式：

- 不懂共享池规则 → 用一个微型共享池说明规则概念；
- 题面不完整 → 先索取完整说明或截图；完整原题仍漏写使用规则 → 标待核实、向教师或原出处确认，确认前不“用过即删”、不靠最后剩余项定答案；
- 少量生词或长句 → 只补完成当前空判断所需的语言；
- 多个关键选项和上下文都读不懂 → 换较易材料，暂不评价方法。

## 二、核心动作

第一次系统学习时，用一篇难度合适、答案可靠的完整材料走一遍：

1. 看出当前空前后在谈的对象、角色、视角和关系；
2. 粗判这里在命名或引入对象，还是定义、展开、支撑、转向或收束；
3. 用对象线、关系线或形式线建立并比较候选；
4. 把候选代回必要上下文验证；
5. 完成后检查共享池和全文连贯。

只要某一步出现明确断点，就**停在该步补漏**，不一次讲完所有线索。

## 三、按报告进入的补漏分支

顺序由证据决定；下面是出现断点时可走的六条分支。

| 分支 | 最小目标 |
|---|---|
| 对象搭桥 | 说清前文的旧对象和角色、候选怎样接住它、后文继续展开什么 |
| 关系判断 | 先用中文说出前后关系、过程先后和必要前提，再用候选验证 |
| 缺句功能 | 区分“命名或引入新对象”和“定义或展开已有对象”，再用支撑、转向、结果、收束说明这里缺什么 |
| 结构呼应 | 先排除人称、单复数、时态、句法接口等硬冲突，再用并列步骤、同层句式建立候选，句壳相似降为弱线索 |
| 代回验证 | 指出候选接住什么、推进什么；证据不足时主动扩大到段落或全文 |
| 共享池冲突 | 比较候选在哪个空有更独特的证据，并把整组代回验证 |

完成本轮最小目标后**立即停止**，不顺带进入其他分支。

## 四、过关标准

- **可独立**：无需提示，能说明证据并完成刚补的动作；
- **稳定**：还需变式、完整新篇或间隔复测支持；
- **答案对但说不出依据，不算能力提升**；
- 材料看不懂时先补语言或换材料，**不能靠技巧猜中率评价七选五能力**；
- 迁移与间隔复测稳定后，才记“已巩固”；没有新证据时，不补“以后可能会考”的相邻技巧。

## 五、整篇复盘

做完一篇，按报告诊断顺序找错因：

    材料和答案是否可靠
    → 关键内容是否读得懂
    → 学生当时依据了什么
    → 已准入线索中第一个有证据的断点
    → 多个错空是否同源
    → 本轮一个最小目标

学生按题号作答、没有先看选项或没有先做高把握项，**本身都不构成缺口**。
