# 学习路径

**有报告就按报告走，别按本文件从头教。** 下面是**没有报告时**的系统起步顺序。

**报告优先**——只处理报告实际暴露的问题：

    先查选项和正文是否读得懂
    → 区分词汇障碍、篇章意识与其他方法障碍
    → 只补第一个真实断点 → 少量验证 → 回到新完形

报告没有出现的技巧、词义或线索类型保持未评估，不沿本路径自动补完所有方法。

## 默认顺序

**材料与词汇匹配 → 篇章意识 → 代入与排除 → 找线索 → 全文检查**

## 一、材料与词汇匹配

**查缺**：让学生标出每道错题四个选项中的生词；检查是否大量题目达到两个以上选项不认识；用一两句中文说出文章主要人物、事件和结果。

**分流**：

- **材料适合**：大多数题只有 0～1 个选项生词，且能说出大意 → 训练方法；
- **局部词汇缺口**：少数题有两个以上选项不认识 → 只处理这些必要词汇，再回原题；
- **材料整体偏难**：大量题都有两个以上选项不认识，或读不出主线 → 换更容易的完形，另行积累词汇。

材料整体偏难是**诊断结论**：不要求一次背完整篇生词，不继续用正确率评价完形能力，也不给学生贴“不会完形”的标签。

## 二、篇章意识

词汇基本够用后，先检查学生逐空作答前是否建立了上下文：

- 能否说出主要人物或事物；
- 能否说出当前目标、问题或变化；
- 能否判断整体态度和发展方向；
- 是否把低把握答案当成后续题的事实。

同一段连续错时，优先找最早改变人物、事件或态度理解的那一题，不立即拆成多个词义问题。

**过关**：能在新文章开始时用短语建立篇章草图；局部无法决定时主动找前后文；能把待定答案与确认信息分开。

## 三、代入与排除

先学最基础、负担最小的流程：

    提取短语 → 逐项代入 → 说出能排除的理由

**过关**：能自己截取合适的小结构，不把整句全塞进脑中；能区分“我知道它不合适”和“我只是不认识它”。

## 四、找线索

按实际报告逐个补，不一次教完：原词照应 → 原词复现；换一种说法 → 同义复现；转折或对比 → 反义复现；形容词情感方向问题 → 褒贬法。

**过关**：不仅能圈出线索，还能说明线索怎样支持或排除某个答案。

## 五、全文检查

养成两个习惯：根据作答后的新信息更新人物、事件和整体方向；一篇完形至少从头到尾完整读一遍，并回查低把握题。

**过关**：局部两个选项都说得通时能主动扩大上下文；填完后能利用后文线索修正或确认答案。

## 强化与整篇复盘

补完问题后，让学生回到来源相近、难度合适的新完形检验。同类新空中能独立执行刚补的步骤就结束本轮；迁移与间隔复测稳定后才记“已巩固”。

做完一篇，按证据诊断顺序找错因：

    选项认识几个？
    → 逐空前是否说出了谁、什么事、发展方向？
    → 是否提取了合适的短语？
    → 是否寻找了上下文线索？
    → 是否利用了话题主线？
    → 是否完整读过并复查？

**答案对但考点判断错、或凭语感猜中，不算能力提升。**
