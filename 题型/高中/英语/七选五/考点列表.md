# 考点列表

本题型的“考点”就是**线索类型**：这个空卡住时，该沿哪条线找证据。

## 怎么用这张表

**先看当前空卡在哪一步，再沿对应线索找正面证据、说出依据。**

每个空先问两个问题：**缺句在这里做什么**（语篇功能）→ **它怎样接住前后**（对象、关系、形式）。
任何线索都只能**建立候选**；候选最终都要**代回**必要上下文和全文主线验证。

| 线索 | 信号（怎么认） | 思路（作答时重点检查） | 卡片 |
|---|---|---|---|
| 缺句功能 | 这一段像是要命名引入 / 定义展开 / 例证支撑 / 承接转向 / 结果收束，或与邻句并列、转折、因果、顺序、问答 | 先判缺句在本段做什么，再判它与邻句的关系；段首段中段尾只给线索 | [缺句功能](考点/缺句功能.md) |
| 对象搭桥 | 指代词、原词或词族、同义近义反义、上下位、叙述者 / 发言者 / 参与者 | 接住了前文什么旧信息，给后文带来什么新信息；所指是否清楚、是否同一对象 | [对象搭桥](考点/对象搭桥.md) |
| 关系判断 | also / but / however / because / for example / first / if / unless 等，或没有连接词也有隐性关系 | 先用中文说出前后关系，再验证连接词；检查过程链和后文依赖的语义前提 | [关系判断](考点/关系判断.md) |
| 结构呼应 | 人称、单复数、时态、连接结构、句法接口；并列步骤、相似句式、同层信息 | 硬语法冲突可排除候选；软结构只建立候选；常见句壳相似算弱线索 | [结构呼应](考点/结构呼应.md) |
| 代回验证 | 已有候选但不确定，或证据只来自一侧 | 相邻句 → 当前段 → 前后段 → 全文主线，逐条检查后再定 | [代回验证](考点/代回验证.md) |
| 共享池 | 两个空争用同一候选；有多余项；题面没写清选项使用规则 | 按题面确认规则；比哪个空证据更独特；整组代回复查 | [共享池](考点/共享池.md) |

**信号只是线索，不是答案口诀**：有连接词不代表关系真成立，找到同词不代表是同一对象，语法没错不代表答案对。
