# 观察清单

**看两边，想到什么。** 这张表越厚，做题越快。以后跟着学生遇到的新情况继续加。

## 看缺空处

| 看到 | 想到 |
|---|---|
| `限定词 + ___`（a / an / the / my / this…） | 先找中心名词；空可能为名词，也可能修饰后面已给名词 |
| `形容词 + ___` | 名词 |
| `介词 + ___` | 名词、代词或动名词 |
| `主语 + ___` | 谓语动词 |
| `名词前` | 可能修饰该名词；还须核整句角色，主语前不自动是形容词 |
| `情态动词 + ___` | 动词原形 |
| `to + ___` | 不定式标记后原形；介词to后名词、代词或动名词，先识别完整结构 |
| `be + ___` | 形容词、名词、现在分词、过去分词 |
| `常见系动词 + ___`（feel / look / sound…） | 形容词 |
| `very / so / too + ___` | 形容词或副词 |
| `___ + 名词` | 形容词、限定词 |
| `完整分句 + ___ + 完整分句` | 连词 |

## 看选词框

| 看到 | 想到 |
|---|---|
| 名词 | 主语、宾语、表语；限定词 / 形容词 / 介词后 |
| 动词 | 谓语；`to`、情态动词后 |
| 形容词 | 名词前；`be` 或系动词后 |
| 副词 | 修饰动词、形容词、副词或整句 |
| 介词 | 后接名词、代词、动名词 |
| 连词 | 连接词、短语、分句；常在主语前 |
| 代词 / 限定词 | 指代或限定后面的名词 |
| 情态动词 | 主语后、动词原形前 |
| 复合不定代词 | 作主语或宾语；形容词后置 |
| 框里出现两个介词 | 分别核它们对应的关系和题面使用规则，不凭词类重复认定余项 |

**看到的情况不是答案**，只是缩小范围——最后仍要代回句子验证。
