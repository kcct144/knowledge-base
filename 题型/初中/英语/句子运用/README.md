# 句子运用

本册三类任务是汉语补全、全句翻译与句型转换，15道原题均有完整原答和详解；另合任务型阅读原章的两句英译汉，来源分开保留。目录内容与原章覆盖分开记录，不把同一题多处引用当新增题。

## 路由和证据

明确句子补全、翻译、转换走本目录；阅读事实问答归回答问题；选字母判语法归语法选择；篇章填词归语篇填空或选词填空。综合任务逐小题识别输出，不能同篇一条万能流程。

原题原答原详解为例证，系统补写主干、已给与未给信息、时态和等义前提。原范句不自动是唯一译法，原评分细则未给则不自定分值。若转换增加持续或能力信息，明确题内假设而不改原题使其强制唯一。

## 教学与反馈

先诊断原意读不懂、缺入口、结构角色错、时间人称错或拼写错。没有入口先示范“中文什么已译→哪里缺→句架允许何形式”；只有某一步卡就修这一判断。已有助动与do支持、目的与时间、点动作与状态按实际断点取，不一次讲全清单。

反馈先核目标意义是否保持，再核形式；同义词选对但时态或否定反了不能算对，语法通顺但新增事实也需返修。选对后能解释一个关键依据才算这一判断成立；不凭加工条目更新学生能力。

学生要求练才取真实题，不为检验主动加作业。缺可靠原答只讨论证据，不评分。能够独立完成一个同类判断并解释原因便结束本轮，后续新原题再查迁移。
