# 平面向量的基本定理及坐标表示

非共线的两个向量可以构成平面的一组基底。坐标表示是在选定基底后，把向量关系转成数的关系；坐标公式所用的基底条件必须清楚。

1. 先读[平面向量基本定理与基底](知识-平面向量基本定理与基底.md)，理解表示为什么存在、为什么唯一，以及非共线条件的作用。
2. 再读[坐标表示与运算](知识-平面向量的坐标表示与运算.md)，区分点的坐标和向量的坐标，理解终点减始点及正交单位基底下的数量积计算。
3. 练[比较基底系数](考点-利用非共线基底比较系数.md)、[坐标判断共线垂直与求夹角](考点-用坐标判断共线垂直与求夹角.md)及[坐标条件求参数与范围](考点-由向量坐标条件求参数与范围.md)。

边界集中看[用共线向量作基底](坑点-用共线向量作平面基底.md)与[除以可能为零的分量](坑点-共线坐标判据除以可能为零的分量.md)。坐标法的目的在于把已知和目标放进同一套表达式，不需要给每道题另造坐标系。
