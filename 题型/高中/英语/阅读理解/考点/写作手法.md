# 写作手法

**一句话概念** — 作者**怎样**组织或呈现信息，以及这样写在**局部**起什么作用。

## 怎么认

`How does the author ...?` / `Why does the author mention ...?` / `What is the role of ...?`

## 思路

**识别文本信号 → 说清怎么写 → 说清局部作用。**

1. 确认题干问“手法”还是“局部作用”；
2. 定位目标段或句；
3. 找具体文本信号；
4. 说清作者怎样写；
5. 再说明它帮助解释、证明、对比或突出什么。

## 常见手法

| 手法 | 常见信号或表现 |
|---|---|
| 举例 | for example / such as / like，具体案例 |
| 对比 | but / while / compared with，两个对象并置 |
| 因果 | because / so / as a result |
| 问题—解决 | 提出困难，再给办法或结果 |
| 顺序 | first / then / next / finally |
| 列数字 | 数量、比例、时间或实验结果 |
| 描述 | 特征、场景、动作和感受 |

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L1 认手法 | 用原文信号辨认主要写法 | 作用 |
| L2 局部作用 | 说明这一写法让哪一点更具体、清楚或有说服力 | — |
| L3 目的作用 | 高中问测量、设计、引语或段落的作用 | 按高中扩展处理 |

## 怎么讲

1. 先给概念，分清“怎么写”和“起什么作用”；
2. 用最简例子走一遍“信号 → 手法 → 局部作用”；
3. 只讲当前台阶；
4. **常见卡点**：
   - 只答手法名称（举例、列数字），不说明作用；
   - 凭文体常识猜手法，不指出原文信号。

## 易错

**出现数字或例子不等于它本身就是答案**——还要说明数字、例子证明或支持了哪个观点。**全文目的**（作者为什么写整篇）属主旨大意，不在本卡。
