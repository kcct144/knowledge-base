# 学习路径

**有报告就按报告走，别按本文件从头教。** 下面是**没有报告时**的系统起步顺序。

**报告优先**——只处理报告实际暴露的问题：

    先排除词汇、题干理解等基础障碍
    → 检查是否把逐句翻译当成默认阅读方式
    → 检查是否建立主旨和段落地图
    → 判断错在哪一种题型流程
    → 只补第一个断点 → 少量验证 → 回到新阅读

报告没有出现的题型保持未评估，不把九种题型一次讲完。

## 默认顺序

**材料与阅读方式适配 → 主旨先行 → 题型分流 → 证据作答 → 混合迁移**

## 第零关：材料适配与分层阅读

先确认材料基本适合，并观察学生怎样读：

- 关键词大量不认识 → 先处理词汇或更换材料；
- 词大多认识，但看不清句子主干和关系 → 补当前关键句的结构；
- 基本能懂，却坚持每句变成完整中文才继续 → 按「分层阅读」训练（略读不逐句翻，证据受阻时才局部拆句或翻译）；
- 能略读建图、扫读定位，只精读必要证据 → 直接进入主旨和题型流程。

**过关**：在难度匹配的新材料里，不逐句翻译也能说出“对象 + 重点”和段落标签；知道证据受阻时才局部拆句或翻译。

## 第一关：主旨意识

这是默认优先级最高的阅读方法。学生先练：

- 根据版式、标题、开头结尾和重复实词判断话题；
- 用“对象 + 重点”说出全文主旨；
- 给主要段落贴功能标签；
- 识别过宽、过窄和局部冒充主旨。

**过关**：在新文章中无需提醒先建立主旨草图，并能大致说出一道题该去哪个段落找。

## 第二关：Scanning 与细节证据

先从最常见的明确细节开始：

    题干定位词 → 预计同义替换 → 原文位置 → 必要上下文 → 选项核对

**过关**：不因原词重现就选答案，能指出定位句并解释选项与原文的对应关系。

## 第三关：按报告补题型流程

只在真实题目出现时逐个补，一次只补一个断点，不自动讲相邻题型：

- 推理：先扫选项排明显错的，再回原文找决定性证据；
- 词义：逐项代回所在短语，不够再读整句、前后句、当前段；
- 主旨 / 标题：用段落覆盖检查；
- 指代：语法匹配、语义合理、代回；
- 结构：识别段落功能和逻辑推进；
- 句子还原：前后双向衔接；
- 写作手法：分清“怎么写”和“在局部起什么作用”。

**过关**：不看提示能复述主要判断顺序；新题里先认考点、再给证据；同类关键错连续两轮不重复。

## 第四关：混合与整篇迁移

在词汇难度合适的新文章里混合不同题型，检查学生能否：

1. 先建立主旨；2. 自己识别题型；3. 用相应定位和证据范围；4. 识别干扰项；5. 低把握时回原文。

**过关**：在新文章里独立走完上面五步，主旨和证据质量稳定。

## 主旨意识不足的常见信号

- 一开始就看题、搜关键词，从未概括全文；
- 每道题都能找到相似单词，但连续选错；
- 主旨只能说成一个宽泛名词；
- 不知道各段作用，把例子或某一段当全文中心。

出现以上信号时先补主旨意识，不急着逐题讲九种技巧。

## 翻译依赖的常见信号

- 从第一句起按相同速度逐句处理，不区分主旨与例子细节；
- 每句话都要形成完整中文才继续；
- 遇到不影响主旨的生词也立刻停下；
- 全文译了很多，却说不出段落功能和证据位置。

只出现“用时较长”不能确诊，先排除材料、词汇和句子结构问题。
