# 数列求和

先看通项能否直接对应等差或等比求和，再按结构选择方法：差的形式用裂项；等差项与等比项乘积可考虑错位相减；首尾成对有固定关系用倒序相加；几种可求和结构相加或交替排列可分组、并项。

每一种方法都把原有限和逐项展开，说明相消或配对的理由。错位相减保留首尾项及q=1分支；裂项先验等式、分母和步长，再数未相消端点；倒序相加计算的是两份原和；并项须查总项数奇偶及最后余项。

前n项和通常从第1项起。求其他起点或带跳步的和，须跟踪真正上下界，不能仅看到熟悉形式就照搬公式。求严格不等式时，放缩与恒等裂项分开，具体证明见数列不等式。
