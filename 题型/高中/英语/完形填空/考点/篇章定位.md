# 篇章定位

**一句话概念** — 逐空前先知道文章大致在讲什么，再理解每个空在这件事里起什么作用。它不是逐句翻译，也不是先猜出所有答案。

## 怎么认

该做这件事的信号：

- 准备从第一空直接开始；
- 说得出生词，却答不出“主要写谁 / 发生了什么 / 往哪发展”；
- 每空都当孤立单句处理，不看前后。

只给一个孤立错句、又可能依赖上下文时，先请学生补前后句或原文——**没有语篇就无法诊断上下文意识**。

## 思路

作答前用已有正文回答三个问题（短语或一两句中文即可）：

    谁或什么？→ 发生了什么目标、问题或变化？→ 整体态度和发展方向？

- 允许写“暂不确定”，读到新信息再更新；
- 确认信息（未挖空正文、已确认答案）与自己的待定答案分开，用 `✓` / `?` 标记；
- 文章较长或转折时，每读完一段用几个字更新草图。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 三问 | 用短语说出谁 / 什么事 / 什么方向 | 不要求逐句翻译 |
| L1 更新主线 | 读到新信息时更新草图，读到新段时接回主线 | 段落推进结构 |
| L2 连续错回溯 | 从该串最早的错误 / `?` 题回退，用原文重建主线 | — |

**默认停在 L1。** 连续错时才用 L2。

## 怎么讲

1. 先给概念：**先知道讲什么，再看每空起什么作用**；
2. 用一篇未挖空短文示范“三问 → 草图”；
3. 只讲当前台阶，不把它扩展成全文逐句翻译课；
4. **常见卡点**：
   - 把篇章意识理解成全文翻译，负担过大；
   - 看完第一句就把话题定死，后面转折也不更新；
   - 把自己低把握的答案当成确定线索。

## 易错

**把自己填的 `?` 当成后文事实。** 低把握答案只能当假设。连续错时先用没挖空的正文重建主线；若多题因此一起改正，说明断点是篇章意识，不是多个词义问题。
