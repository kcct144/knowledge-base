# 主旨大意

**一句话概念** — 全文或某一段主要讲什么；问写作目的时，还要说作者为什么写整篇。

## 怎么认

`What is the passage mainly about?` / `main idea of the passage / paragraph` / `mainly tells us` / `What is the purpose ...?` / `Why does the author write ...?`

## 思路

```text
确认问全文还是某一段
→ 找核心对象
→ 结合标题、首尾、段落功能和重复内容确定作者重点
→ 用一句话概括
→ 检查是否覆盖主要段落
→ 排除过宽、过窄、局部细节和无中生有
```

问全文目的（作者为什么写整篇）时，概括主旨后再加上写作动作：介绍、解释、报告、比较、讨论、质疑、提醒、倡议，核对选项是不是动作开头。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 认问法 | 认出主旨题，看清问全文还是某段 | 不要求概括 |
| L1 概括主旨 | 用“对象 + 作者重点”概括，并覆盖主要段落 | 全文目的 |
| L2 全文目的 | 概括主旨后加写作动作，判断作者为什么写 | — |

**默认停在 L1。**

## 怎么讲

1. 先给上面那句概念；
2. 演示“找对象 → 定重点 → 概括 → 覆盖检查”；
3. **常见卡点**：只给一个宽泛名词（如“树”），没有作者重点；把例子或某一段当全文中心。

## 易错

- 文章确实提到，但只覆盖一个例子或一段；
- 只有宽泛话题，没有作者具体重点；
- 加入文章没有讨论的大概念；
- 把结果、原因或背景中的一项冒充全文中心。

**边界**：首段、末段、段首句是高价值线索，不是固定答案位置；目的题问的是“为什么写”，答案多为动作开头（`To encourage ...`），与主旨题的概括式选项不同。
