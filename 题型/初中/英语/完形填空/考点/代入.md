# 代入

**一句话概念** — 先提取包含空格的最小有意义短语，再逐个代入选项，减少整句同时处理的压力。

## 怎么认

局部短语或搭配就能决定答案时用。常见最小结构：

- 动词 + 宾语，如 `collect information`；
- 系动词 + 形容词，如 `feel proud`；
- 动词短语 + 宾语，如 `benefit from the app`；
- 形容词 + 名词、介词短语或主谓小结构。

## 思路

1. 只保留能决定搭配或意义的部分，如 `____ information`；
2. 在短结构里逐个代入选项；
3. 能明确排除就说理由；
4. 两个选项在局部都成立 → 扩大到完整句、前后句或段落，不把“只看短语”当绝对规则。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 提取短语 | 从长句里截出包含空格的最小结构 | 代入判断 |
| L1 基础代入 | 在短结构里逐个代入，排除明显不自然的 | 扩大范围 |
| L2 扩大范围 | 局部都成立时，按需扩大到完整句、前后句、段落 | — |

**默认停在 L1。** 局部能决定就用局部，决定不了再往下。

## 怎么讲

1. 先给上面那句话；
2. 用一道题走一遍“截短语 → 代入 → 说理由”；
3. 只讲当前台阶；
4. **常见卡点**：
   - 把整个长句同时塞进脑中，工作记忆负担过大；
   - 只看空格前后两三个词，局部都成立仍不扩大上下文。

## 易错

**最小短语只是默认起点，不是每空必须停留的范围。** 四个选项词性相同、局部都能搭配时，直接扩大到完整句、前后句、段落，不要硬找不存在的唯一证据。
