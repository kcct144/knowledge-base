## 错法

算出两线方向共线，就写两线平行；算出直线方向与面法向量点积0，就写线面平行；算出两面法向量共线，就写面面平行。它们把不含位置的“走向条件”当成完整位置关系，遗漏重合或包含，也可能把0方向导致的假共线当真实对象。

## 正解

先检查方向及法向量都非零。两线u=λv之后取各线上点A、B：B−A若也共线于u，两线重合；若不共线，两线不同而平行。线面u·n=0之后取线上点A、面内点Q：n·(A−Q)=0给整条线在面内，非0才给严格平行。

两面法向量共线时，取α内A、β内B，公共法向量n。若n·(B−A)=0，它们方向和位置都相同而重合；非0才为不同平行面。这个点积是有向法向差，任何同一面内移动都不改，所以检一点足够，但一点必须是真在相应对象上。

原知识P0062/P0064的线线/面面等价式须补不同对象这一前提；P0063已经写l不包含于α，不能误称原件没写。参数题解出的零向量、共线三点或恰使包含/重合的参数要剔除；不能从示意图看起来分开当作排除证明。

### 原例：只有方向时只能说相容或可能包含

来源：`HSMA-B3-C1-Df3c5c6c7abec-P0111-P0119`；原件《专题1.5 空间向量的应用（一）：用空间向量研究直线、平面的位置关系（举一反三讲义）数学人教A版2019选择性必修第一册（解析版）.docx》。题号、学年及地区按讲义原标注，未另作来源核验。

以下完整保留原题、原答案与原详解（仅统一等价公式排版及配图路径）：

【例3】（24-25高二上·上海·阶段练习）若直线$l$的方向向量为$\vec{r}$，平面$\alpha $的法向量为$\vec{n}$，能使$l//\alpha $的是（   ）

A．$\vec{r}=\left( 1, 0, 0\right), \vec{n}=\left( -1, 0, 0\right)$  B．$\vec{r}=\left( 1, -2, 3\right), \vec{n}=\left( 0, 3, 2\right)$

C．$\vec{r}=\left( 0, 1, 1\right), \vec{n}=\left( -1, 0, -1\right)$  D．$\vec{r}=\left( 1, 3, 5\right), \vec{n}=\left( 1, 0, -1\right)$

【解题思路】根据给定条件，逐项计算$\vec{r}\cdot \vec{n}$即可.

【解答过程】对于A，$\vec{r}\cdot \vec{n}=-1\ne 0$，A不是；

对于B，$\vec{r}\cdot \vec{n}=1\times 0-2\times 3+3\times 2=0$，$\vec{r}\perp \vec{n}$，B是；

对于C，$\vec{r}\cdot \vec{n}=-1\times 0+0\times 1-1\times 1=-1\ne 0$，C不是；

对于D，$\vec{r}\cdot \vec{n}=1\times 1+0\times 3-1\times 5=-4\ne 0$，D不是.

故选：B.

#### 补充讲解

四组方向向量和法向量都非零。点积逐项为−1、0、−1、−4，只有B的方向与法向量垂直。B在方向上与线面平行相容；原答案B完整保留。

**位置条件说明：**单给方向r与法向量n，不能知道l上的某点是否在α内。r·n=0只使l平行于α的方向，实际位置可能是l∥α，也可能是l包含于α。若“能使”指存在位置使它平行，B可以选；若理解为已经必然严格平行，还须补查l不包含于α。原知识P0063本来就有l不包含于α，不能说原知识遗漏了此条件。本例原题没有点或平面位置数据，不能暗中当成已检验排除包含。

### 原例：用面方程实际排除包含与重合

来源：`HSMA-B3-C1-Df3c5c6c7abec-P0171-P0194`；原件《专题1.5 空间向量的应用（一）：用空间向量研究直线、平面的位置关系（举一反三讲义）数学人教A版2019选择性必修第一册（解析版）.docx》。题号、学年及地区按讲义原标注，未另作来源核验。

以下完整保留原题、原答案与原详解（仅统一等价公式排版及配图路径）：

【例4】（24-25高二上·全国·课后作业）如图所示，$ABCD$为矩形，$PA\perp $平面$ABCD$，$PA=AD$，$M$，$N$，$Q$分别是$PC$，$AB$，$CD$的中点．求证：

![原资料配图](配图/B3-C1-C-Df3c5c6c7abec-image23.webp)

(1)$MN//$平面$PAD$；

(2)平面$QMN//$平面$PAD$．

【解题思路】（1）由已知可证得$AB,AD,AP$两两垂直，所以以$A$为原点，分别以$AB$，$AD$，$AP$所在直线为$x$轴、$y$轴、$z$轴建立空间直角坐标系，利用空间向量证明；

（2）证明$QN$平行于平面，结合面面平行判定定理证明结论.

【解答过程】（1）证明：因为$PA\perp $平面$ABCD$，$AB,AD\subset $平面$ABCD$，

所以$PA\perp AB,PA\perp AD$，

因为四边形$ABCD$为矩形，所以$AB\perp AD$，

所以$AB,AD,AP$两两垂直，

所以以$A$为原点，分别以$AB$，$AD$，$AP$所在直线为$x$轴、$y$轴、$z$轴建立空间直角坐标系，如图所示，

![原资料配图](配图/B3-C1-C-Df3c5c6c7abec-image24.webp)

设$B(b,0,0)$，$D(0,d,0)$，$P(0,0,d)$.

则$C(b,d,0)$，因为$M$，$N$，$Q$分别是$PC$，$AB$，$CD$的中点，

所以$M\left( \frac{b}{2},\frac{d}{2},\frac{d}{2}\right)$，$N\left( \frac{b}{2},0,0\right)$，$Q\left( \frac{b}{2},d,0\right)$，

所以$\vec{MN}=\left( 0,-\frac{d}{2},-\frac{d}{2}\right)$.

因为平面$PAD$的一个法向量为$\vec{m}=(1,0,0)$，

所以$\vec{MN}\cdot \vec{m}=0$，即$\vec{MN}\perp \vec{m}$.

又因为$MN\not\subset $平面$PAD$，所以$MN//$平面$PAD$.

（2）因为$\vec{QN}=(0,-d,0)$，

所以$\vec{QN}\cdot \vec{m}=0$，所以$\vec{QN}\perp \vec{m}$，

又$QN\not\subset $平面$PAD$，所以$QN//$平面$PAD$.

又因为$MN\cap QN=N$，$MN,QN\subset $平面$MNQ$，

所以平面$MNQ//$平面$PAD$.

#### 补充讲解

ABCD是非退化矩形，所以b=AB>0、d=AD=AP>0。PA⊥底面使PA分别垂直AB、AD，矩形给AB⊥AD，三轴两两垂直后才能把点的坐标用于普通点积。

（1）M与N由中点公式得原坐标，MN=(0,−d/2,−d/2)非零，法向量m=(1,0,0)非零，点积0说明方向在PAD方向内。PAD是x=0，M、N的x都为b/2>0，因此整条MN在x=b/2上，确不在PAD内，才可断定MN∥PAD。

（2）Q、M、N均在x=b/2；QN=(0,−d,0)与MN不共线，因为前者z=0、后者z=−d/2≠0。这保证QMN是一个真正平面，且其法向量也可取(1,0,0)。两个平面x=b/2与x=0常数不同，故平行而不重合。原两条相交直线分别平行于PAD的证明也成立；排除条件不能只从图看起来分开得出。
