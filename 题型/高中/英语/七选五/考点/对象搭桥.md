# 对象搭桥

**一句话概念** — 前后在说谁、什么事、什么观点；候选要**接住前文的旧信息，并把后文要继续的对象带出来**。对象不只指语法主语，也包括叙述者、发言者和事件参与者。

可靠的桥长这样：

    前文给出旧信息 X
    → 候选接住 X，并引入或突出 Y
    → 后文继续解释 Y

## 怎么认

四类线索：

- **指代链**：children → they；a method → this method；several problems → these problems；前文一整件事 → this / that / such a change；
- **角色与视角链**：谁是叙述者、谁在说话或提建议、谁是动作的执行者或承受者、引语中的 I/we 与引语外是否切换；
- **词汇链**：原词复现、词族或词形变化、同义近义反义、上下位或类属关系、同场景词；
- **新旧信息承接**：候选从前面接住了什么、给后面带来了什么。

要问：代词或概括语具体指谁、什么、哪件事？单复数、人物和事物是否匹配？候选放入后所指是否清楚？

**同场景词只算弱线索**（如 teacher、classroom、homework）；只因为同属“科技”“教育”等大话题，也只是弱相关，多余项也常与全文话题相关。

## 思路

1. 前文出现的旧对象是谁 / 什么？
2. 候选怎样接住它，并给后文带出什么新信息？
3. 所指是否清楚、前后是不是**同一个**对象或**有效**对立（不是偶然同词）？
4. 交回代回验证。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 同形 | 认出原词复现、词族或词形变化 | 指代、同义、上下位 |
| L1 指代 | 代词或概括语找到明确所指，核对单复数、人物和事物是否匹配 | 角色与视角切换 |
| L2 同义反义 | 认出同义、近义、反义关系（反义要有对比或转折才成立） | 上下位、类属 |
| L3 上下位 | 认出上下位或类属关系（animals → birds、technology → messaging apps） | — |
| L4 角色视角 | 分清叙述者、发言者、参与者，引语内外是否切换 | — |

**同场景词始终只是弱线索，不单独决定答案。** 默认停在 L1。

## 怎么讲

1. 先给那句概念，够认就行；
2. 用最简例子走一遍“找旧对象 → 候选接住它 → 后文继续展开”；
3. 只讲当前台阶，别一次把指代、词族、上下位、角色全倒出来；
4. **常见卡点**：
   - 只找一样的词，没有确认是不是同一对象；
   - 没有确认指代对象；
   - 混淆叙述者、发言者和事件参与者。

## 易错

**`it` 不一定回指前文。** 天气、时间、距离表达，形式主语或形式宾语，以及 `It is/was ... that/who ...` 强调结构中的 `it`，都不能强行寻找前文名词；先判断它在句中的语法和语义作用。
**`so` 有多种词性和用法**，必须按句中作用判断，不能一律当指示代词。
