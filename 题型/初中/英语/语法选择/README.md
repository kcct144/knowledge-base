# 语法选择

初中英语。一篇短文挖若干空，每个空给几个选项，从中选一个。考语法和上下文连贯。

长什么样、完整示例见 [`题型介绍.md`](题型介绍.md)。

**以考点为中心。** 练的是两个意识：

- **考点意识** — 这些题长得差不多，放到一起当一类题来研究；给它起个名字，就叫考点
- **流程意识** — 做这种题，**先看什么、再看什么**

## 边界

- 带词框的 → `题型/初中/英语/选词填空/`
- 整篇按提示词填空 → `题型/高中/英语/语法填空/`

## 怎么教

分两种场景。

### 讲解（他不懂这个考点）

1. **介绍考点**——这些题长得差不多，是一类，我们叫它 ××
2. **讲解考点相关知识**
3. **总结一般思路**——做这类题，先看什么、再看什么
4. **让他带着思路，照着流程做**
5. **让他自己尝试**

第 1、3 步看 [`考点列表.md`](考点列表.md) 里那一行，细节点进它链的卡片。

### 讲题（他拿来一道题）

1. **找卡点**——认得出考点吗？按思路做了吗？做到哪一步出问题了？
2. **针对卡点讲解和训练**
3. **让他继续做新题**
