# 搭配

**一句话概念** — 有些空靠固定搭配或常见组合一眼锁定：哪个词能和空格前后组成常见的表达。

## 怎么认

题感：空格两边有词和它"老在一起出现"，像：

```text
remind sb. of ...      be known for ...       as long as ...
a lot of ...           be interested in ...   make a difference ...
```

看到这种结构，优先想「搭配」这一考点。

## 思路

**先查搭配，再回上下文验证。**

1. 看空格前后两三个词，能不能组成一个常见固定表达
2. 能组成 → 从词框找符合该搭配的词
3. **放回原句和上下文**确认真成立——不能因为"这两个词经常一起出现"就忽略意思

推荐检查顺序：

```text
明显搭配 → 词性和句子结构 → 当前句意思 → 必要的前后文和全文方向
```

顺序不是"搭配永远优先于语义"，而是先用最强、负担最低的证据，任何候选都要代回验证。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L1 明显搭配 | 一眼能看出的固定搭配，做短标记 | 长搭配表 |
| L3 搭配验证 | 搭配 + 一句话意思确认 | 一词多义搭配 |
| L6 搭配边界 | 搭配不成立或一词多义时，改看结构或语境 | 只在真题需要时 |

**默认停在 L1 / L3 之间。** 明显搭配先做，减少候选。

## 怎么讲

1. 先给上面那句概念，举一两个常见固定搭配
2. 示范"搭配 → 找词 → 代回验证"
3. **常见卡点**：
   - 只按中文意思选词，看不出搭配
   - 拼出一个像样子的搭配就直接用，不代回句子
   - 把"经常一起出现"当成绝对规则

## 易错（题面看不出来的坑）

- 固定搭配必须放回上下文验证，不能因为两个词常一起出现就忽略意思。
- 看起来像搭配的结构也可能被句意否掉；搭配只缩小范围，不代替语义。
- 靠"最后只剩这个词"得到的答案不能反推成通用搭配，只能算待验证。
