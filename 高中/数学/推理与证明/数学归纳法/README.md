# 数学归纳法

数学归纳法证明从某个正整数起连续成立的命题：先证起点n₀，再对任意k≥n₀，在假设第k个命题成立的条件下证明第k+1个命题。起点和连续递推共同覆盖其后每个整数，有限例子或只验一个下一项不能代替这一逻辑。

写递推前先比较目标两边从k到k+1改变了什么，列新增项、变动系数或条件；明确在哪一步使用归纳假设。假设的是整个第k个命题，不能把待证的k+1命题当作已有结论。

恒等式、不等式、整除、几何计数和数列性质各有不同的增量。递推步骤须保持符号、整数性、可用范围及几何构造条件；若只从偶数推下一个偶数，不能据此覆盖所有整数。归纳法属于证明，不把观察猜想与证明混称。
