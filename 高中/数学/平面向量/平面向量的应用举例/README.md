# 平面向量的应用举例

把几何或物理条件转成向量关系之前，先说清每个向量表示什么，再选择基底、坐标或数量积。计算之后还要回到原问题解释结果。

1. 读[平面几何中的向量方法](知识-平面几何中的向量方法.md)，理解从几何关系到向量表达、再回到长度和角度的过程。
2. 练[选择基底或坐标](考点-选择基底或坐标解决平面几何.md)和[向量关系处理几何最值](考点-用向量关系处理几何最值.md)，把活动点的实际范围与等号是否可取一起检查。
3. 读[力、位移、速度与功的模型](知识-力位移速度与功的向量模型.md)，再练[物理方向与单位转成向量关系](考点-把物理方向与单位转成向量关系.md)。方向约定、参考系和单位是建模条件的一部分。

[合力合速度直接相加各自的模](坑点-合力合速度直接相加各自的模.md)解释为什么只有特定方向关系下才能直接相加大小。三角形边角计算接着读[解三角形](../../三角函数与解三角形/解三角形/README.md)。
