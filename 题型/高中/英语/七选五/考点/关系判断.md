# 关系判断

**一句话概念** — 前后是并列、转折、因果、例证、顺序、条件还是问答；**先用中文说清关系，再看连接词**。

## 怎么认

| 关系 | 常见显性信号 |
|---|---|
| 并列或递进 | also、moreover、in addition |
| 转折或让步 | but、however、yet、although |
| 原因或结果 | because、therefore、as a result |
| 概括或例证 | for example、for instance、such as |
| 顺序 | first、then、later、finally |
| 条件、假设或例外 | if、unless、only when、except、otherwise |
| 问题与回应 | 问句后回答，或提出问题后给出办法 |

连接词是**关系约束，不是答案口诀**：有连接词时，要检查它连接的两部分是否真的满足该关系；没有连接词时，也可能存在隐性的转折、因果或对比。

## 思路

1. 先用中文说出前后关系；
2. 再看连接词是否真的满足该关系；
3. 检查候选是否给后文补上必要的**语义前提**：后文的 then、结果句或进一步说明究竟承接的是什么；
4. 交回代回验证。

**过程链**（不靠显性连接词）：提出对象或条件 → 完成必要动作或说明 → 出现下一步、结果或例外。时间相邻不等于过程成立。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 显性信号 | 认出连接词，判断它连接的两部分是否真满足该关系 | 隐性关系、过程链 |
| L1 中文说关系 | 没有连接词时，也能用中文说出隐性转折、因果或对比 | 过程链、语义前提 |
| L2 过程链 | 检查事件或推理的先后条件，补上缺的一环 | 语义前提 |
| L3 语义前提 | 检查候选是否为后文的 then、结果句、进一步说明建立了必要前提 | — |

**默认停在 L1。**

## 怎么讲

1. 先给那句概念；
2. 用最简例子走一遍“说关系 → 验连接词 → 查前提”；
3. 只讲当前台阶，别一次列全七类关系；
4. **常见卡点**：
   - 背“看到 but 就选后者”“虽然但是看但是，因为所以看所以”；
   - 只看连接词，不检查关系是否真成立；
   - 把时间相邻当成过程成立；
   - 漏掉后文依赖的语义前提（如已有 0、后文又出现 again 的 2，中间要检查是否缺第一次发生的 1）。

## 易错

**`but` 比较的是完整命题**，不要求凑一对反义词；看到 `but` 也不能直接选“后者”。
**没有连接词时也可能有隐性关系**，别只盯连接词。
**“问题—对策”不是七选五的默认结构**，只是可能的篇章组织，不能见到问句就套对策。
