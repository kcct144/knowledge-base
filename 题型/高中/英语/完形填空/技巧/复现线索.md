# 复现线索

**一句话概念** — 答案常常在**别处**被“说过一遍”：同词、近义表达或相反信息。找到它，就找到了证据，而不是凭语感。

## 怎么认

文章其他位置出现下面几类对应信息：

- **原词复现**：同一个词或同一词形家族再次出现；
- **同义复现**：出现近义词、短语或对该词的解释；
- **反义复现**：转折 / 对比处出现相反信息。

另外还可关注人物态度、因果、转折和事件结果——基础层也归“找线索”，系统性比较放在高中 [`句篇逻辑`](句篇逻辑.md)。

## 思路

按**由近到远**找：空格所在句 → 前后句 → 当前段 → 全文。

1. 找到疑似线索词；
2. 说明它和答案是什么关系（同词 / 相近 / 相反）；
3. 用这条关系留或排选项，不能只圈一个“看起来像”的词。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 原词复现 | 找到同词或同词形家族 | 同义、反义 |
| L1 同义复现 | 找到近义表达 / 解释 | 反义 |
| L2 反义复现 | 在转折或对比处找相反信息 | 句篇逻辑 |

**按报告进入**：出现原词照应才讲 L0，出现换说法才讲 L1，出现转折 / 对比才讲 L2。**不一次讲完三种。**

## 怎么讲

1. 先给概念：**答案在文中被“说过一遍”**；
2. 用一个原词复现的例子走一遍“找 → 说明关系 → 定答案”；
3. 只讲报告触发的那一级；
4. **常见卡点**：
   - 看到相同词就机械选择，没说明复现关系；
   - 只圈词，不说它怎样支持答案。

## 易错

**复现要成立，得是同一个对象 / 同一件事。** 出现同一个词也可能是偶然；先确认它和空格讲的是不是同一回事，再当线索用。
