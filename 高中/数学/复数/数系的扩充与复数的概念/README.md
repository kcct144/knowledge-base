# 数系的扩充与复数的概念

复数把实数扩充到能表示虚数单位的数系。先分清数的类型和实虚部，再把复数与平面上的点联系起来，最后学习非零复数的三角表示。

1. 从[复数与虚数单位](知识-复数与虚数单位.md)和[复数相等与实部虚部](知识-复数相等与实部虚部.md)开始，明确标准形式、实数与纯虚数的条件，以及相等时为什么要分别比较两个实数系数。
2. 练[按类型求参数](考点-按实部虚部条件判断复数类型与参数.md)及[利用复数相等建方程](考点-利用复数相等建立参数方程.md)。检查[虚部误写成含i的项](坑点-把虚部写成含i的项.md)和[纯虚数非零条件](坑点-忽略纯虚数非零条件.md)。
3. 读[复平面与复数的模](知识-复平面与复数的模.md)、[共轭复数](知识-共轭复数.md)，再用[位置与模处理条件](考点-用复平面位置与模处理条件.md)。[复数的大小比较](坑点-把复数当作可直接比较大小的实数.md)说明为什么模的大小和数系中的大小关系不能混用。
4. 读[三角形式与辐角](知识-复数的三角形式与辐角.md)，理解模表示长度、辐角表示方向。练[两种形式互化](考点-复数代数形式与三角形式互化.md)，同时看[象限与周期](坑点-辐角忽略象限与周期.md)；零复数没有确定的辐角。

运算接着看[复数代数形式的四则运算](../复数代数形式的四则运算/README.md)。原例与原解保留，补讲和资料勘误分别列出；三角表示及进一步运算按条目说明的资料范围学习。
