# 题型规则

**一句话概念** — 先读词框上方的说明，它决定这道题能不能变形、每个词用几次、有没有多余词、每空填几词。规则没读清，后面全白做。

## 怎么认

题感：说明里出现这些字样：

```text
使用正确形式 / change the form      → 可以、且要求变形
每词仅用一次 / use each word once   → 一词一次，不能复用
有两词多余 / extra words            → 词框用不完，最后剩词是正常的
每空一词 / one word for each blank  → 只能写一个词
```

不同试卷规则不同，**每次都重新读**，不能把一处的规则套到另一处。

## 思路

**先圈规则，再动手。**

1. **变形**：能不能变？变了要不要写完整单词？
2. **次数**：一词只能用一次，还是可重复？
3. **多余词**：几个？最后必须剩几个？
4. **词数**：每空限填几个词？
5. **词汇门槛**：词框里有没有不认识、说不清词性的词？多个关键候选都不认识时，先记为词汇障碍或材料偏难，别用"看词性"掩盖无法比较词义的问题。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 读规则 | 找出变形、次数、多余词、每空词数四条 | 不进入选词 |
| L1 词汇门槛 | 标出词框中不认识、词性不确定的词，判断能否继续 | 不补整章词汇 |

**默认停在 L0。** 规则读清、词框关键词能比较，就进下一考点。

## 怎么讲

1. 先给上面那句概念，够认就行
2. 让他自己圈出说明里的四条规则，你只核对
3. **常见卡点**：
   - 不读说明，凭平时练习习惯直接变形
   - 把"使用正确形式"理解成可以随便派生到别的词性
   - 没注意有剩余词，做不满就慌

## 易错（题面看不出来的坑）

- "使用正确形式"不等于允许任意词性派生。名词复数、动词时态、比较级等屈折变化通常明确；跨词性派生要依当前说明和可靠实例，不能自造远亲词形。
- 只给一个孤立句子时，不能可靠使用"一词一次、剩余词、全文话题"这些规则证据。
