# 点、直线、平面之间的位置关系

先明确对象的位置，再用判定建立关系、用性质推出结论。每条定理的前提都要在题设或已证结论中找到，不能依据透视图直接判断。

## 平面与平行

1. 读[平面基本性质与确定条件](知识-平面的基本性质与确定条件.md)、[空间点线面位置关系](知识-空间点线面的位置关系.md)。练[共线共面共点](考点-用平面性质判共线共面共点.md)、[作截面](考点-按交线与共面条件作截面.md)和[新增平面统计空间区域](考点-用新增平面统计空间区域.md)。
2. 读[空间平行与等角定理](知识-空间平行与等角定理.md)、[线面平行判定与性质](知识-直线与平面平行的判定与性质.md)、[面面平行判定与性质](知识-平面与平面平行的判定与性质.md)。练[平行关系相互转化](考点-将线线线面面面平行相互转化.md)与[比例和定点](考点-用平行性质求线段比例与定点.md)。
3. 检查[空间不相交与平行](坑点-把空间不相交直接当作平行.md)、[线面平行的面外条件](坑点-线面平行判定漏直线在平面外.md)和[面面平行的相交双线](坑点-面面平行只验证一条直线.md)。

## 垂直、角与距离

1. 从[异面直线角与垂直](知识-异面直线所成角与垂直.md)和[平移作角](考点-通过平移作异面直线所成角.md)开始，再读[线面垂直判定与性质](知识-直线与平面垂直的判定与性质.md)，练[相交双线判定](考点-用相交双线判定线面垂直.md)。
2. 读[线面角](知识-直线与平面所成角.md)与[距离和垂足](知识-空间距离与垂足.md)，练[作射影求角](考点-作射影求线面角.md)、[垂足与等体积求距离](考点-用垂足与等体积求空间距离.md)。
3. 读[二面角与平面角](知识-二面角与平面角.md)、[面面垂直判定与性质](知识-平面与平面垂直的判定与性质.md)，练[作二面角并解三角形](考点-作二面角平面角与解三角形.md)及[垂直性质与探究条件](考点-用面面垂直性质处理探究条件.md)。
