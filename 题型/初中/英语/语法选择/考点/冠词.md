# 冠词

**一句话概念** — 名词前的小词，管"是不是特指"：非特指的可数名词单数用 `a / an`，再次提到或明确特指用 `the`。

## 怎么认

选项常直接出现：

```text
a / an / the
```

也可能加入不填冠词的选项。看到这些形式时，优先想「冠」。

**信号不是绝对规则**：`a / an` 按后一个词开头的发音判断，不只看首字母；单数名词前也不一定填 `a / an`，还可能用 `the` 或零冠词。

## 思路

**先找冠词后面的核心名词，再看是泛指还是特指。**

1. **判可数性**：是不是可数名词单数？`a / an` 只用于可数名词单数
2. **判泛指特指**：首次、非特指 → `a / an`；再次提到、双方都知道、被后置内容限定或独一无二 → `the`
3. **选 a 还是 an**：看后一个词开头的发音（如 `an hour` 中 h 不发音，`a useful book` 中 u 发 /juː/）

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 识别 | 从选项认出 `a / an / the` | 零冠词和固定搭配 |
| L1 高频核心 | 首次、非特指用 `a/an`；再次提到或明确特指用 `the`；按发音选 `a/an` | 零冠词、专有名词、成批固定搭配 |
| L2 常见特指 | 后置限定、双方都知道、独一无二等常见 `the` 用法 | 机构功能和专名边界 |
| L3 零冠词与积累 | 零冠词、机构功能、常见固定搭配；每次只积累一个真实遇到的用法 | 生僻专名规则 |

**默认停在 L1。** 不得在基础冠词课中一次罗列大量固定搭配；真实题目遇到一个固定用法时，只补这一个、配一个例句并安排复现，不顺带扩充整张表。

## 怎么讲

1. 先给上面那句概念，够认就行
2. 用最简例子走一遍「信号 → 判断 → 依据」
3. 只讲当前台阶，别顺手把零冠词、专有名词和成批固定搭配一起倒出来
4. **常见卡点**：
   - 只看首字母选择 `a / an`，不听发音
   - 看到单数名词就默认 `a / an`，不判断是否特指
   - 忽略前文已经提到的对象
   - 把固定搭配当成所有名词都适用的规则

## 易错

**看不出首字母和发音不是一回事。**

```text
an hour        ← h 不发音，开头是元音
a useful book  ← u 发 /juː/，开头是辅音
```

还有跨句的坑：首次提到和再次提到往往跨句出现，只读本句看不出特指，需要读上下文。

## 例题

**例一**　There is ____ useful book on the desk.
A. a　B. an　C. the
→ **A**。首次引入一本非特指的可数名词单数；`useful` 开头发 /juː/，所以用 `a`。

**例二**　Emma saw a cat in the tower. ____ cat was sleeping on the button.
A. A　B. An　C. The
→ **C**。第二句再次提到前一句的猫，已经明确特指，所以用 `the`。

（两例均为自编）
