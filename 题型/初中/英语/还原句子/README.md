# 还原句子

短文多个空共享完整句子池，按前后衔接和全篇分配还原文章。本册含演讲五选五、城市探索七选五两组，共10空。几选几不决定学段，当前全部归初中。

单个独立句位置题归阅读理解；词池填词归选词填空。选项是否一次、多余数按原指令，不能默认全部七选五。

断点依次查：读不懂前后意思、缺句子功能判断、代词对象断、逻辑关系断、局部正确但全组冲突。先示范一个有原证据的入口，再让学生继续；每轮只补实际卡住的判断，不把四种方法挨个讲一遍。反馈必须指出哪一侧、哪一关系支持，选对但说不出依据不算掌握。

学生想练时从本题型真实练习取；当前两组是书内教学例，没有另建学生练习或自编题。能够独立说明一个空的前后关系并核全篇即可结束本轮；不会为了完成方法清单加作业。
