# 形容词、副词与词性转换

**一句话概念** — **先看空位需要什么词性，再把提示词派生过去**；定完词性，可能还要继续变形（数、时态、一致）。

## 怎么认

给形容词 / 副词 / 名词 / 动词，但空位需要的却是**另一类词**，或需要说明性质、修饰动作，就走词性转换。

**信号不是绝对规则**：词尾只是辅助，不能代替结构判断（不是一律加 `-ly`）。

## 思路

**先判句中作用，再定目标词性，最后派生并核对形式。**

1. **判作用**：修饰名词、作表语、修饰动作、作主语 / 宾语？
2. **定词性**：这里需要名词、形容词还是副词？
3. **派生**：把提示词变成目标词性。
4. **再核对形式**：名词要不要变复数？形容词 / 副词是否还要比较等变化？

## 台阶（讲到哪停）

材料里的 Unit 06，逐关如下，**每一关一级，不合并**。

| 关 | 本级只解决 |
|---|---|
| 01 | 在定语和表语位置填写形容词 |
| 02 | 根据修饰对象将形容词变副词 |
| 03 | 从句中作用判断需要名词，并写出派生形式 |
| 04 | 混合判断名词、形容词与副词需求 |
| 05 | 派生为名词后，继续核对单复数与可数性 |

不要求逐级学完；按当前断点挑关。

## 怎么讲

1. 先给概念：看的是**空位需要什么**，不是提示词长什么样。
2. 用一个词走"判作用 → 定词性 → 派生 → 再核对"。
3. **常见卡点**：
   - 只看词尾，一律加 `-ly`
   - 判出词性就收工，忘了继续核对数 / 形式
   - 分词形容词混用（`-ing` 表事物特征 / `-ed` 表人的感受）

## 易错

**"词尾只是辅助"，别用词尾代替结构判断。**

```text
peace → peaceful      ← 系动词后作表语
function → functional ← 名词前作定语
interest → interested ← 人的感受
frighten → frightening ← 事物特征
```

派生后可能还有多步变化，数、谓语等判断要调用相应考点。
