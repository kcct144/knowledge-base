## 讲解

### 是什么

used to＋动词原形表示过去常有的动作或曾存在的状态，常带有现在情况已有变化的对照。它不是某一次过去事件的普通过去式，也不是现在“习惯于”的另一套结构。

### 怎么来的

原句 I used to live in London. 说明过去居住这一状态；She used to work for a large company. 说明过去的工作情况。两个句子不需要为 I、She 改变 used to 的形状，后面 live、work 都保留原形。

改成 did 支持的否定或疑问时，过去信息由 did 承担，所以原书给 He didn't use to/usedn't to smoke. 与 Did you use to play the piano?：前一否定常用 didn't use to，后一问句用 did＋use to。不能保留 did 又机械把 use 加回 d。原书 usedn't to 是较少用的另种否定，阅读时能识别即可。

used to 可说过去状态及反复动作，would 表过去习惯时通常需有背景并偏重重复行为；两者不是所有句子里可无条件互换。是否包含现在已改变，要读上下文，不凭此强加原文未明说的具体当前地点、职业或频率。

### 什么时候能用

有“过去常常”或过去持续状态的语境才用；某一次明确事件应按相应过去谓语处理。used to 的 to 后是动词原形。不要把它与 be/get used to 的“习惯于”结构混同：后者的 to 是介词，结构来源不同；该区别需在资料有对应材料时进一步对照，不在这里自编题。

这组原例只给知识说明，没有一题独立辨析 used to 与 be used to，缺口如实保留。

## 例题

**原资料词形、词组或例句，非独立试题。** 本小节未配一题单独检验本概念，以下保留原材料并解释。

原句：Did you use to play the piano? 你过去常弹钢琴吗？

**分析**：did 已表示过去，use to 保留此结构所需的 use 原形；play 同样是 used to 后的动作原形。问的是过去是否常做，不是某天有没有弹过。

### 时态章补充：过去反复与过去状态

原The river used to be clean.说河流过去曾处于干净状态，used to后be原形；它不要求过去每一天都发生一个“变干净”的重复动作。一般过去也能陈述过去习惯，而used to常突出从以前到如今的对照。原句没有给出污染数值、变化日期或明确今天河流的全部状况，不额外编造结论。

# ·知识拓展·

“used to+动词原形”也可表示过去经常或反复发生的动作。

例 The river used to be clean. 这条河以前是干净的。

## 易错

- **did 后仍写 used to**：原书常用疑问否定写 use to。
- **把“曾经”理解成任意一次过去事件**：本结构说过去习惯或状态。
- **把两种 to 混同**：used to do 与 be used to 的后接要求来自不同结构。
