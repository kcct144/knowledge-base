# 切题

**一句话概念** — 写的是**题目要的东西**。已经能成篇之后，第一件要补的就是它。

## 怎么认（审题六项）

看到题目，能正常审题时快速圈出：

1. **形式**：普通短文、邮件、信件、演讲稿等；
2. **主题**：全文主要写什么；
3. **要点**：题目明确要求写哪些内容；
4. **人称**：主要用 `I`、`you` 还是 `we`；
5. **时态**：主要写现在、过去还是将来；
6. **给定内容**：题目给出的开头、结尾、称呼或署名。

学生一审题就卡住时，先只问两句——「这篇主要写什么？」「你现在能想到哪两三件事？」
先动起来，剩余要求等成篇后再补。

## 怎么做

**先成篇，再逐条对要点。**

1. 一个题目要点对应提纲中的一项（要点在题目里通常用（1）（2）（3）标出）；
2. 开头或结尾点一下主题；
3. 题目给了称呼、开头、结尾的，**保留**，不要因为只学了模板就删掉；
4. 一次只补**最明显的漏点**，不同时重写全文。

## 怎么判

- **不看文采，先看要点**：能补的必写要点有没有漏；主题有没有完全跑掉。
- 题目没给、由助手代选的内容，判的时候**不算已覆盖要点**，要标「代选内容」。
- 没有原题时明确写「切题性和必写点仍待核对」，不声称已经满足全部要求。

## 怎么讲

- 用「要点 → 提纲项 → 句子」三列让他自己连线，缺哪条补哪条。
- 漏点是**最影响分数**的断点之一，发现就先补它，不再往表达上走。

## 卡点

- **不会选骨架**：不知道列点还是记叙 → 给二选一（见 [`成篇`](成篇.md)）。
- **能成篇但偏题/漏点**：任务识别和要点对应不稳 → 回到审题六项逐条对。
- **审题反而更不敢写**：先只抓主题和两三个内容点，把六项留到成篇后。

## 易错

- 只写自己会写、跟题目无关的内容，把「好写」当成了「切题」。
- 题目给的开头/结尾不抄或用错人称，导致整篇跑偏。
- 把助手建议的内容当成题目规定，最后要点没对上。
