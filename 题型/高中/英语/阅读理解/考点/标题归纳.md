# 标题归纳

**一句话概念** — 为整篇文章选择最合适的标题。

## 怎么认

`What / Which is the best title for the passage?`

## 思路

**主旨准确优先，再检查覆盖和简洁。**

1. 先独立说出全文主旨（对象 + 重点）；
2. 提取核心对象和作者重点；
3. 检查标题是否覆盖主要段落；
4. 检查是否符合文章文体和态度；
5. 排除细节标题、过宽标题和无中生有。

## 好标题的顺序

1. 准确；
2. 能覆盖全文；
3. 简洁清楚；
4. 在准确的前提下可以有吸引力。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L1 基本流程 | 先说主旨，再选覆盖全文的标题 | 排除动作分开练 |
| L2 三类排除 | 以偏概全、过于宽泛、无中生有各判一类 | — |
| L3 反推检查 | 用标题反推文章应写什么，再对照原文 | — |

## 怎么讲

1. 先给概念；
2. 先说主旨再选，避免被生动选项带偏；
3. 只讲当前台阶；
4. **常见卡点**：
   - 跳过主旨，直接凭标题的字面吸引力选；
   - 用一个警句或例子代替全文。

## 易错

**最生动的选项不一定最好**；不硬性规定标题必须是 3～5 个词，选项题以准确概括原文为准。
