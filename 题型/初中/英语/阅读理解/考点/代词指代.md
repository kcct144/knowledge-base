# 代词指代

**一句话概念** — `it / they / this / that / these / those / one / ones` 等具体指什么；不机械选最近名词。

## 怎么认

`What does "it / they / this" refer to?`

## 思路

```text
找到代词及所在句
→ 向前寻找可能的名词、名词短语或整件事
→ 检查单复数、人或物等语法匹配
→ 代回原句检查语义是否合理
→ 检查当前段正在延续哪个人物或概念
```

## 重点

- `he / she` 通常指人，并要符合人物信息；
- `it` 常指单数事物，也可能承担形式结构；
- `they / them` 通常要求复数或群体；
- `this / that` 可能指前面的整个动作、事实或观点；
- `one / ones` 指前文同类事物，不一定是完全相同的对象。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 认问法 | 认出指代题 | 不要求代回 |
| L1 指人 / 指物 | 用单复数、人和物先匹配候选 | 指句子或观点 |
| L2 指句子或观点 | 处理 `this / that / it` 指整个动作、事实或观点 | — |

**默认停在 L1。**

## 怎么讲

1. 先给上面那句概念；
2. 演示“列候选 → 语法和语义排除 → 代回读通”；
3. **常见卡点**：直接选最近的名词，不检查单复数、语义和篇章重点是否匹配。

## 易错

最近名词只是候选，不是答案规则。若最近名词在单复数、语义或篇章重点上不匹配，应继续向前寻找。
