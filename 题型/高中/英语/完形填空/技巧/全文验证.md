# 全文验证

**一句话概念** — 一篇完形**至少完整通读一次**，带着答案检查故事 / 说明是否连贯、人物态度是否一致、低把握题能否被后文证实。

## 怎么认

- 填完最后一空就结束了；
- 有几个标了 `?` 的低把握题还没回查；
- 想改某个答案，却说不出新证据。

## 思路

带所选答案从头读一遍，检查四件事：

1. 故事或说明是否连贯；
2. 人物态度 / 褒贬方向是否前后一致；
3. 代词、动作和事件发展是否合理；
4. 低把握题能否从后文得到新线索。

**“读起来顺”不是唯一证据**：改答案要指出新发现的词义、搭配或上下文线索。

完整通读的时机可自选：**先读后做**（能顺畅读懂、需先掌握情节）或**先做后读**（空格多容易卡住）。两种都可以，但都不能省略。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 完整通读 | 带答案从头到尾读一遍 | 逐项检查 |
| L1 四项检查 | 查连贯 / 态度 / 代词动作 / 低把握题 | 改答案有据 |
| L2 有据修改 | 改答案时指出新证据 | — |

**默认停在 L1。**

## 怎么讲

1. 先给概念：**不完整读一遍，不算做完**；
2. 让他先填完，再带答案完整读，回查 `?`；
3. **常见卡点**：
   - 逐空孤立处理，从未读完整篇；
   - 填完就停，不回查低把握题；
   - 只用“顺不顺”改答案。

## 易错

**低把握题不能互相证明。** 后续题只能把未挖空正文和已有明确证据的答案当确认信息，不能用 `?` 去证明另一个 `?`。
