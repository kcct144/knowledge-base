# 细节理解

**一句话概念** — 原文明确写了人物、时间、地点、原因、方式、结果或事实，答案能在原文找到对应。

## 怎么认

题干用 `who / when / where / why / how / which / according to` 等直接询问信息。

## 思路

```text
明确题干到底问什么
→ 划出少见且稳定的定位词
→ 预测可能的同义替换
→ 扫读找到证据区
→ 读定位句及必要前后句
→ 用自己的话说出答案
→ 核对四个选项
```

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 认问法 | 从题干认出细节题 | 不要求定位 |
| L1 基础定位 | 定位词明显时找到证据句并读出答案 | 同义替换 |
| L2 同义替换 | 定位词被改写时，用少见实词和段落判断位置 | 跨段证据 |

**默认停在 L1。** 定位词明显就先走通基础定位。

## 怎么讲

1. 先给上面那句概念，够认就行；
2. 用一道题走一遍“定位词 → 原文证据 → 同义对应”；
3. 只讲当前台阶；
4. **常见卡点**：找到关键词就立刻选，不读周围文本；把“题目顺序≈文章顺序”当成规则。

## 易错

- **张冠李戴**：原文信息属于 A，选项安到 B 身上；
- 原文未提；信息正确但答非所问；只说对一半；
- 偷换时间、范围、程度或肯否；
- 复现原词但改变原文关系。

**边界**：答案在原文不等于原词重现，同义替换很常见；找到关键词后必须读周围文本，题序与文序接近只是弱提示。
