# 定语从句

**一句话概念** — 定语从句**补充说明前面的名词或名词短语**（先行词）；关系词既连接，又在从句里**充当一个成分**。

## 怎么认

从句补充说明一个名词，或空位是关系词，就是定语从句。

**信号不是绝对规则**：先行词是时间 / 地点，也**不一定**用 `when / where`——要看从句里缺什么。

## 思路

**先找先行词，再划从句边界，最后看缺什么。**

1. **找先行词**：从句在说明哪个名词？指人还是指物？
2. **划边界**：从句从哪里到哪？**逗号**是限制 / 非限制的边界。
3. **判缺口**：从句里缺主语、宾语、定语还是状语？
4. **选关系词**：关系代词（who / which / whose / that），或介词 + 关系词。

## 台阶（讲到哪停）

材料里的 Unit 11，逐关如下，**每一关一级，不合并**。

| 关 | 本级只解决 |
|---|---|
| 01 | 根据先行词和从句缺口填写 who / which（作主语） |
| 02 | 区分时间状语与宾语位置，并核对逗号边界 |
| 03 | 区分 whose 和介词后的 which |
| 04 | 在地点语境中区分状语、主语与宾语缺口 |

不要求逐级学完；按当前断点挑关。

## 怎么讲

1. 先给概念：关系词是**连接 + 在从句里当成分**，两件事。
2. 用一句走"找先行词 → 划从句 → 看缺口 → 选词"。
3. **常见卡点**：
   - 只看先行词，不看从句缺什么（who / which / where / when 混）
   - 漏看逗号，限制与非限制混
   - 不判从句内部，凭中文意思填

## 易错

**先行词是时间 / 地点，不代表一定用 when / where。**

```text
..., which originated in China   ← 指物，从句缺主语
..., who doesn't smoke           ← 指人，从句缺主语
the place where ...              ← 从句缺状语
the place which/that ...         ← 从句缺主语或宾语
```

判断依据是**从句里缺什么成分**，不是先行词是什么类型。
