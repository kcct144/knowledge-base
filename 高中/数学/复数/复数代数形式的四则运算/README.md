# 复数代数形式的四则运算

复数运算先按代数法则展开，再用虚数单位的性质化为标准形式。涉及除法、开方或几何方向时，先核对对象及条件。

1. 读[加减法与向量意义](知识-复数的加减法与向量意义.md)、[乘除法与共轭化](知识-复数的乘除法与共轭化.md)，理解实虚部分别计算和分母为何能化为实数。练[化简与参数判断](考点-复数运算的化简与参数判断.md)、[共轭与模关系](考点-利用共轭与模关系求复数.md)。
2. 读[虚数单位的幂与复数乘方](知识-虚数单位的幂与复数乘方.md)，再练[四周期处理幂](考点-用i的四周期处理幂.md)。分清[复数平方与模平方](坑点-复数平方与模平方混淆.md)，检查[除法分母非零](坑点-复数除法忽略分母非零.md)。
3. 读[复数域内的因式分解与方程](知识-复数域内的因式分解与方程.md)，再看[解方程与因式分解](考点-复数范围内解方程与因式分解.md)。说明在哪个数系求解，是判断根是否完整的前提。
4. 三角表示下的运算读[乘除的旋转与伸缩](知识-复数乘除的旋转与伸缩.md)及[几何意义求模与角](考点-用复数乘除几何意义求模与角.md)。进一步读[乘方与n次方根](知识-复数的乘方与n次方根.md)、[列出全部方根](考点-按模与辐角列出复数的幂与全部方根.md)，检查[只取一个根或重复计数](坑点-复数开方只取一个根或重复计数.md)。

本专题把常规代数运算与资料中的三角表示拓展接在同一学习路径上；是否需要学习拓展，按具体教学与考试范围判断。
