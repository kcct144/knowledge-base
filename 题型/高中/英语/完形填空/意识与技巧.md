# 意识与技巧

**练两个意识，其余都算技巧。**

## 线索意识（重点）

**答案在原文里。** 每个空都要能在文中找到**支持它或排除它**的依据——不是凭语感。

| | 信号 | 怎么找 | 卡片 |
|---|---|---|---|
| 复现线索 | 文章别处出现同词、近义表达或相反信息 | 原词 → 同义 → 反义，由近到远；说明线索怎么支持答案 | [复现线索](技巧/复现线索.md) |

## 主旨意识（重点）

**先看清谁、什么事、什么方向，再谈这个空。**

| | 信号 | 怎么做 | 卡片 |
|---|---|---|---|
| 篇章定位 | 想从第一空开始，却答不出「谁 / 什么事 / 方向」 | 作答前用短语建草图，读到新信息再更新；低把握答案不当事实 | [篇章定位](技巧/篇章定位.md) |
| 话题主线 | 局部两三个选项都说得通 | 用一句中文概括话题，选更符合人物、事件、情感主线的 | [话题主线](技巧/话题主线.md) |
| 褒贬方向 | 选项是形容词，涉及人物态度或情感走向 | 先分正面 / 负面 / 中性，再用走向缩范围（**只缩范围**） | [褒贬方向](技巧/褒贬方向.md) |

## 技巧

| | 信号 | 怎么做 | 卡片 |
|---|---|---|---|
| 词汇门槛 | 四个选项里有不认识或说不清核心意思的词 | 数生词：0～1 练方法；2 归词汇主导；3～4 停做换材料；**猜对不等于认识** | [词汇门槛](技巧/词汇门槛.md) |
| 代入 | 空格附近能截出一个最小有意义结构 | 截短语 → 逐个代入 → 看词义和自然度 | [代入](技巧/代入.md) |
| 排除 | 有选项与词义 / 搭配 / 人物 / 褒贬 / 上下文明确冲突 | 先排明确冲突，再比剩余；**不认识 ≠ 排除** | [排除](技巧/排除.md) |
| 全文验证 | 填完了，需要检查连贯和低把握题 | 带答案通读一遍；改答案要指出新证据，不凭「顺」 | [全文验证](技巧/全文验证.md) |

## 高中扩展

基础都用过仍有断点时才用，**一次只走一个**。

| | 信号 | 怎么做 | 卡片 |
|---|---|---|---|
| 词义精辨 | 四个词大致认识，最后两个意思接近，局部都通 | 共同点 → 一个决定性差异 → 文本约束 → 排除理由 | [词义精辨](技巧/词义精辨.md) |
| 句篇逻辑 | 局部都通，证据在前后句 / 段；出现 though、however、引语、分号 | 定视角 → 定时间 → 写两层意思 → 命名关系 → 找锚点 | [句篇逻辑](技巧/句篇逻辑.md) |
| 关键长句 | 线索就在句中，但找不到主干、指代或从句关系 | 保句 → 框主谓宾 → 隔开从句 / 非谓语 → 还原指向 → 回选项 | [关键长句](技巧/关键长句.md) |

**信号只是常见情况**：词义对不代表搭配对，看到相同词不代表是复现，局部通顺不代表答案对。
