# 句子还原

**一句话概念** — 判断一个独立句子应放在文章哪个位置，前后双向都要接上。

## 怎么认

`Which sentence can be put in the blank?` / `Where can the sentence best go?`

## 题型边界

只处理**单个独立句子**的位置判断，或各小题不共享句子池的独立判断。多空共用一个句子选项池 → `题型/高中/英语/七选五/`。

## 思路

```text
先掌握全文主旨和段落功能
→ 读候选句，圈出代词、连接词和关键词
→ 看空格前一句需要怎样承接
→ 看空格后一句需要怎样开启
→ 检查指代、复现、逻辑、时态和人物一致
→ 代入后同时通读前后
```

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 认问法 | 认出单句还原题 | 不要求衔接 |
| L1 前侧或后侧明显 | 一侧线索明显时先接上，再确认另一侧通顺 | 复杂指代 |
| L2 指代 | 先练对象明确的向前指代，代入核对 | 起承转合 |
| L3 起承转合 | 用 `however / therefore / also` 等判断整句方向 | 连词内容 |
| L4 连词连接的内容 | 看清 `and / but / because / so / if` 连接哪两部分 | 复现 |
| L5 复现 | 用原词、同义词、上下位概念接上前后 | 总分 |
| L6 总分衔接 | 总述句与后面的例子、分述相连 | — |
| L7 综合通读 | 前后一起通读，时态与人物变化有语境依据 | — |

这些是训练侧重点，可以重叠；入门时只让一种线索成为主要难点。

## 怎么讲

1. 先给上面那句概念；
2. 演示“读候选句 → 看前句 → 看后句 → 代入通读”；
3. **常见卡点**：只和前一句通顺就选，不看后一句；看到相同词就选。

## 易错

- 只与前一句通顺不够，还要与后一句相连；
- 看到相同词不能直接选择，要检查整个关系；
- 本题型未出现在学生当前考试范围时不主动训练。
