# few / little 系列

**一句话概念** — few / a few 管可数名词复数，little / a little 管不可数名词；带 a 偏肯定，不带 a 偏否定。

## 怎么认

选项常出现：

```text
few / a few / little / a little
```

判断需要同时处理两个维度：后面的名词是否可数，以及句子表达“有一些”还是“几乎没有”。

**信号不是绝对规则**：看到字母 a 不能机械选择，还要确认名词类型。

## 思路

**先看后面的名词，再看句意肯否。**

1. **可数性**：可数名词复数 → 在 few / a few 中选择；不可数名词 → 在 little / a little 中选择
2. **肯定还是否定**：有 a 通常偏肯定（有一些）；没有 a 通常偏否定（几乎没有）

依据行：time / money / water / information 等通常为不可数名词；句中出现 but / so / enough 等上下文信息时，会影响肯定或否定判断。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 识别 | 从选项认出这四种形式 | 不要求判答案 |
| L1 基础流程 | 先判可数性，再判肯否 | quite a few 等变式 |
| L2 上下文 | 用 but / so / enough 等判肯否 | 独立使用 few |
| L3 变式 | only a few、quite a few 的含义 | — |

**默认停在 L1。**

## 怎么讲

1. 先给上面那句概念，够认就行
2. 用最简例子走一遍「可数性 → 肯否 → 选词 → 依据」
3. 只讲当前台阶，别顺手把 quite a few 等变式一起倒出来
4. **常见卡点**：
   - 不判断名词可数性，只凭中文选
   - 混淆“有一些”和“几乎没有”
   - 认为带 a 的形式后一定接单数名词
   - 忽略 so / but 等上下文信号

## 易错

**看不出中文都是“少”，语气却相反。**

```text
Only ____ students knew how to open the old door, but they were willing to help.   ← 可数复数 + 确实有一些，用 a few
There was ____ time left, so they had to hurry.                                    ← 不可数 + 几乎没时间，用 little
```

quite a few 表示“相当多”，不是“相当少”；only a few / only a little 虽然形式带 a，语境仍强调数量有限。

## 例题

**例一**　Only ____ students knew how to open the old door, but they were willing to help.
A. a few　B. a little　C. little
→ **A**。students 是可数名词复数，只能考虑 few / a few；句子表示确实有一些学生，选 a few。

**例二**　There was ____ time left, so they had to hurry.
A. few　B. little　C. a few
→ **B**。time 是不可数名词；后文“必须赶快”说明几乎没时间，选择 little。

（两例均为自编）
