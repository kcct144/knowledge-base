# 成篇

**一句话概念** — 先写出一篇完整作文：有开头、正文、结尾，没有空槽，能誊写。作文的第一道关不是「高级句型够不够」，是「能不能写出来」。

## 怎么认

- 面对题目写不出、只有几个零散词；
- 不知道从哪下手，或一审题就卡住；
- 明确说「不会写 / 写不出来 / 快没时间了」。

## 思路

**先成篇，再达标。**

1. **最低限度审题**：抓主题 + 现在能想到的两三个内容点。其余的（形式、人称、时态、给定内容）等成篇后再补；
2. **写提纲**：每个内容点只写一个中文或英文短语，不先写完整句；
3. **选骨架**：用一个最熟悉的骨架（见 [结构](结构.md)）；
4. **填成句子**：一个内容点写成一个完整句，优先用会写的主谓结构和模板原句；
5. **达到可誊写**：有头身尾、没有未替换的槽位、大致围绕一个主题、能看懂能抄。

**急救模式**：学生明确说不会写或快没时间时，不先长篇讲解，直接放进最熟悉的模板，先交付完整保底稿，再问要不要补题目要求或字数。已知且能用简单句覆盖的要点直接放进去，**不故意漏点**。

## 台阶（讲到哪停）

| 台阶 | 本级只解决 | 暂不展开 |
|---|---|---|
| L0 零散词 | 助手代选主题和内容点，先拼出完整底稿 | 不要求自己提炼要点 |
| L1 有主题短语 | 借一个骨架得到可誊写底稿 | 覆盖全部要点、字数 |
| L2 有提纲 | 自己选骨架、填句、检查空槽 | 表达自然、高级 |
| L3 能成篇 | 限时独立完成保底稿 | — |

**默认停在 L1。** 已经能写出可誊写底稿，就停止讲更难表达。

## 怎么讲

1. 先给那句概念，够认就行；
2. 用最简单例子走一遍「主题 + 两个内容点 → 骨架 → 完整句」；
3. 只讲当前台阶，别顺手倒高级词汇和复杂从句；
4. **常见卡点**：
   - 学生一审题就卡住 → 立即降级成「主题 + 两三个内容点」，别让审题本身挡住动笔；
   - 学生其实会写，只是怕错 → 先让他用简单句写出来。

## 易错

**把「先成篇」理解成故意漏点。** 题目明确、又能用简单句覆盖的要点，首版就要放进去。
**用语体、自然度、模板痕迹压住成篇。** 初学阶段保留 `In the end`、允许反复用 `should`、允许 `Let's take action!` 作通用结尾。
