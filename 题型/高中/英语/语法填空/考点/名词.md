# 名词

**一句话概念** — 表示人或事物的名称。它有两种变化：**数**（单复数）和**所属**（所有格）。

## 怎么认

给名词，且空位**仍需要名词**（不作谓语、不需要换词性），就来看名词的形式。

**信号不是绝对规则**：`-s` 也可能是动词三单；`'s` 也可能是 `is / has` 的缩写。

## 思路

**先看所有格，再看单复数。**

1. **所有格**：空格后面**有没有名词**？有 → 多半用所有格（还要确认语义上确实所属）。
2. **单复数**：`a / an / one / each / every` → 可数单数；`many / several / a few / few` → 可数复数；
   `some / a lot of` → 复数或不可数，**先判名词性质**。
3. **写形式并核对拼写**。

派生为名词（如 solve → solution）归 [`形容词、副词与词性转换`](形容词、副词与词性转换.md)，不在本考点。

## 怎么讲

1. 先给上面那句概念，够认就行。
2. 用最简例子走一遍"信号 → 判断 → 依据"。
3. **常见卡点**：
   - 看到 `-s` 就选复数，不先查所有格
   - 看到空格后有名词就机械加 `'s`，不判所属关系
   - 把 `some` 当成只能接复数（它后面也可能是不可数）

## 易错

**不规则复数和复数所有格最容易漏。**

```text
phenomenon → phenomena      ← 不规则复数
variety   → varieties       ← 辅音字母 + y，变 y 为 i 加 es
factor    → factors         ← one of 后用复数
students  → students'       ← 复数已以 s 结尾，所有格只加 '
```

`one of ...` 后接复数名词；写完要**核对拼写**。
