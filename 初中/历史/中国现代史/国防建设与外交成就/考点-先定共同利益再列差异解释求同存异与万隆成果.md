## 讲解

### 判据

题问全面理解求同存异，必须同时回答共同合作目标、客观差异和为何差异不必妨碍合作；不能将同写所有制度相同。

### 流程

1. 先核1955亚非会议与周恩来方针，区别1953五原则首次。

2. 保原同的两个层次，但对全称殖民身份单独注明，教学用反殖民独立发展共同利益概括。

3. 列制度、思想、宗教、习惯四差异，存异不要求各国先改制度。

4. 共同目标使协商有基础，允许差异减少排斥，因此能缓和紧张并合作，说明不是两词并列背诵。

5. 联系公报十原则与场外交往，保原三成果；方针可促进合作，不等一切分歧已彻底消失。

## 例题

### 原例题：全面理解求同存异

**原问。** 如何全面理解“求同存异”方针？

**原答案，完整两点。**

1. “同”一是与会国家遭遇相同，都曾沦为殖民地或半殖民地；二是都面临发展民族经济、维护民族独立的任务。
2. “异”是社会制度、意识形态、宗教信仰、生活习惯等差异。

**解析。** 先辨共同合作基础，不是把所有社会制度说相同；再辨客观存在的差异，存异不是要求各国改变制度和信仰。因为共同利益可以成为合作目标，差异便不必变成互相排斥和阻断协商的条件，这解释原万隆紧张气氛为何能缓和。原两点应同时写，单说求团结没有说明同在哪，单说有差异也没说明如何合作。

**原答案与核查内容分开。** 原答“都曾沦为殖民地或半殖民地”是过强的全称概括，保留用于追溯。外交部所载周恩来1955年4月19日补充发言说的是亚非绝大多数国家和人民遭受殖民主义灾难，并未说每个参会国家都有完全相同的殖民身份。教学应改用“反对殖民主义、维护独立、发展经济等共同利益”说明同，不断言每国经历完全相同；这一区分不改变原存异所列四类差别。

### 原资料：万隆会议过程与三项成果

原时间地点：1955年，印度尼西亚万隆。原特点：“第一次没有西方殖民主义国家参加的国际会议”。

原三成果：①周恩来提出求同存异，撇分歧、为反殖民共同利益加强合作，缓和紧张；②《亚非会议最后公报》形成和平共处、友好合作十项原则，体现引申五项原则；③场外活动加强亚非团结合作，打开广泛交往大门。

**因果解释。** 与会国家有不同制度和信仰，若把这些差别作为互相排斥的条件，便难在共同事务达成合作。先抓反殖民、独立与发展的共同利益，同时保留差异，分歧才不必阻断协商；共同原则又把合作方向形成公开规范，场外接触扩展往来。

**原句范围补核。** 外交部史料将“首次”限定为亚非国家在无西方殖民国家参与下自行召开会议。原书泛称“第一次……国际会议”应加这一亚非自主会议范围，不扩大为世界历史上一切国际会议都从未出现过这种情况。十项是万隆公报原则，五项是和平共处原则，体现引申不等名称和数量完全相同。

### 第一单元原题第6题完整原答与逐项依据

**单元原第6题，原标“2024山东济宁中考改编”。** 1949—1954年与中国建交的亚非国家很少；1955—1964年数量极速增加，其中多数主动签友好条约。主要因为中国（ ）。

A.坚定站社会主义阵营一边；B.提出并践行和平共处五项原则；C.派代表参加万隆亚非会议；D.恢复在联合国一切合法权利。

**原答案C。完整原解。** 1955万隆是无西方殖民国家参加的亚非会议，周恩来提出求同存异，加强亚非团结合作、促进建交，因而到1964前许多亚非国家建交。

**完整推理与歧义。** 原解抓数量变化起点1955与交往对象亚非，将万隆及求同存异打开交往大门作具体节点解释，所以保C。B的原则同样是跨制度合作的重要基础，并非对这些外交成果毫无作用；仅按本题概括的时段和对象，未给对各原因的进一步比较材料，不能严断B在历史上完全不成立。这里保原答案与其节点解释，登记B/C因果层次存在解释空间，不擅改原答为B。A只抓阵营，不能解释与不同制度亚非国家广泛合作；D属后来联合国地位事件，不能倒作1955前后已发生的原因。


**四项逐项解析补写。**

- A（不选）：特定阵营取向不是与不同制度亚非国家广泛交往的充分解释，原变化具体节点为万隆。

- B（原答不选，有歧义）：五原则确提供合作基础，不讲成无作用；原解突出1955万隆节点，题面缺进一步原因比较，保原C并登记解释空间。

- C（原答选）：1955及亚非范围与万隆求同存异打开交往相符，是原详解所用具体事件节点；不称参加会而无需外交工作便必然建交。

- D（不选）：恢复联合国一切合法权利在后来的1971年，不能作为1955—1964已发生增长的原因；此点只作时间排除补讲。

### 九下万隆精神与发展中国家登台

# 知识点① 万隆会议★★★

| 背景 | 第二次世界大战后,民族解放运动空前高涨,越来越多的亚非国家取得独立;新独立的国家都面临巩固政权、发展经济的共同问题 |
|---|---|
| 时间 | 1955年4月 |
| 地点 | 印度尼西亚的万隆 |
| 内容 | 通过了和平相处、友好合作的十项原则 |
| 地位 | 第一次没有西方殖民主义国家参加的国际会议 |
| 重要方针 | 周恩来提出“求同存异”方针 |
| 万隆精神 | 亚非国家和地区团结合作、友好相处,共同反对帝国主义和殖民主义,争取和巩固民族独立,保卫世界和平的精神 |
| 影响 | 1提高了亚非国家和地区的民族自信,鼓舞了亚非拉人民争取民族独立的斗争2发展中国家作为一支新兴独立的政治力量登上了国际舞台3中国提出的和平共处五项原则受到国际社会的认可,逐渐推行开来 |

**八维原知识解释。**新独立国家共同面对巩固政权发展经济，制度信仰不同仍可抓反殖民和平发展合作，求同存异使差异不必阻断协商；十原则把合作方向形成规范，万隆精神强调团结独立和平。原“第一次没有西方殖民国家国际会议”沿已有核查口径限定亚非自主会议，不推广为世界从未任何别的国际会议；十原则与五原则为不同名称数量，体现推广不等首次提出就在万隆。发展中国家作为政治力量登台讲自主联合提高影响，不等1955之前没有任何独立国家外交。
