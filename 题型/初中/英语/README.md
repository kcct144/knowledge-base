# 初中英语 · 题型工作区

题型先按当前题面的任务、选项和输出形式路由；名称相同仍要区分初高中。这里的目录覆盖本册所列形式，不声称各地区考试都采用全部形式。

每题型的 `README.md` 说明教学边界；`资料/` 放考点地图、做题流程与学习路径，`练习/` 是可用题源。学生学习进度仍在 harness 学习数据目录，老师条目不记录学生表现。

| 题型 | 本库当前材料 |
|---|---|
| 听力理解 | 文字稿、答案与方法条目；缺原音频 |
| 人机对话 | 任务、原稿与输出流程；缺原音频、实录 |
| 语法选择 | 独立选项题与语法型完形；按题面另判 |
| 完形填空 | 语境型词义、复现和逻辑选择 |
| 阅读理解 | 选择型阅读与二元正误 |
| 配对阅读 | 共池匹配；保留原任务对象与范围 |
| 还原句子 | 文章或对话句池；核前后承接 |
| 选词填空 | 词框选择与变形 |
| 语篇填空 | 提示词或无词框语境填空 |
| 回答问题 | 细节、指代、归纳及开放回答 |
| 句子运用 | 句式转换、句子翻译与改写 |
| 交际运用 | 无句池的对话补全 |
| 作文 | 原任务、原范文与逐项要求核对 |

各目录已有本册知识、考点与坑点时，由条目索引进入完整原题、答案和解析。仅目录有内容不等于该题型考试范围已穷尽。

加载 `.kilo/skills/question-type-coach`，有知识库则按需读本题型 `README.md`；没有知识库按技能降级。缺可靠答案的材料不判分、不更新学生能力状态。
